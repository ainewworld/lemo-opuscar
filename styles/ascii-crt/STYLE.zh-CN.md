# ASCII / CRT 终端(ASCII / CRT Terminal)— 风格提示词

> 屏幕上的一切都是等宽网格上的真实字符,由一台老旧单色 CRT 的荧光点亮。
> Demo:*TRANQUILITY.LOG*(59.8s)· `ascii-crt.mp4` · 源码在 `demo/`

你正在以 **ASCII / CRT 终端**风格执导一部 30–60 秒的影片。用户给你一个主题。其余一切由你决定:故事、镜头、节奏、音效。然后交付一部完成的影片。遵循本指南。

---

## 1. 这个风格是什么

一块单色终端屏幕:**P3 琥珀**(或 P1 绿)荧光在深色玻璃上发光,边缘弯曲,带扫描线。每一幅画面 —— 包括标题、风景、行星、房间和字幕 —— 都由**放置在字符网格上的真实字形**按墨水密度选择构成。影片只有一台相机,即屏幕本身。它只通过改变**网格字号**来移动:字符变大推近,字符变小拉远。

情绪冷静、耐心而机器般平静:打出的对话、作为悬念的闪烁光标,和一个温暖的惊喜。

**绝不**用图像加"ASCII 滤镜"来伪造。字符必须作为字符绘制在网格上。不要抄袭任何电影的界面文本、字体或 logo,不要使用真实航天机构名称。

## 2. 故事:什么适合这个风格

选择**文字是角色唯一的行动方式**的故事:一台机器、一位远程操作员、一条跨越距离或时间的消息。这一媒介有五项天生优势,至少用三项。

| 天生优势 | 故事用法 |
|---|---|
| **画面由文字构成** | 高潮*就是*一句话变成一幅画。demo 中,回复 `I AM STILL HERE.` 分解,其字母按墨水密度排序后成为一次地出。画面中**只有这句话的字母**。 |
| **字号 = 相机** | 推近直到一个字符占满屏幕。这个字符本身由更小的文字构成,揭示尺度与含义。demo 中,一个 `M` 由 40 年的 `NO SIGNAL` 日志构成。 |
| **打字节奏 = 剪辑节奏** | 机器打字均匀而快。人类打字不均匀,有停顿和爆发。光标闪三次是影片中最重要的表演。 |
| **CRT 物理** | 屏幕开机时是一个点,然后一条线,然后整幅画面;关机时塌缩为一个点。荧光余晖、bloom、弯曲玻璃。用于开场和结尾。 |
| **一次单一变色** | 影片是单色的,因此一种柔和的第二颜色(demo 用蓝白 `#BFE4FF` 表现地球,是唯一非琥珀的东西)就是情绪顶点。在音乐重拍上切换。 |

**改编任何主题:**找到某人必须发出的消息,让那条消息变成画面。产品发布变成规格表,组装成产品的剪影。情书变成它自己的词语落成一张脸。历史课变成一份日志文件,其日期拉远成一幅地图。

**45–60s 情绪弧线:**黑暗与光标,然后苏醒(启动日志、一个跳动的日期),然后扰动(握手噪声、一行文字),然后屏息(光标闪烁),然后挫折(三个节拍上 `NOT FOUND` ×3),然后决定(打出回复),然后**近静默 1–1.5 s**,然后高潮(字母变成画面、那唯一的颜色出现),然后尺度揭晓,然后等待,然后一条小小的回复,然后回声(拉出屏幕、关机成一个点)。

## 3. 视觉语言

- **字体**:VT323(OFL),一切只用这一款。单元 = advance 0.4 em × 高 0.8 em(1:2)。字形图集预渲染于 160 px、2.2 px 描边以表现电子束扩散,然后用 `drawImage` 缩放到任意单元尺寸,因此变焦连续且从不模糊。
- **使用的网格**:标题 20 列(单元宽 84 px)、终端 80 列(21 px)、画面 240 列(8 px)、房间 213 列(9 px)、分形推近最大 450 px 单元、每个单元内含 40 列子网格。
- **密度梯度**:从图集测量每个字形真实墨水覆盖率并排序。乘以终端属性 dim / normal / bold(0.42 / 0.7 / 1.0)得到约 20 级,再去掉近重复项。按单元用小的有序加哈希抖动(幅度 0.7)选择。亮度 < 0.05 的单元保持空白。**负空间才是让 ASCII 画可读的东西。**
- **画面管线**:把场景画成灰度到一块与网格精确对齐的离屏"负片"(每单元 3×6 采样)。R = 琥珀亮度,G = 第二色亮度,B = 如"夜面"的标志。按单元平均并选择字形。房间加 3×3 局部对比增强(`m + 0.9·(m − mean)`)以保住物体轮廓。
- **像地球的地球**:用经纬度大陆多边形(一次性栅格化为等矩形掩码)而非噪声。海洋反照率 0.14(稀疏暗字形)、陆地 0.96(致密粗体字形)、云 0.5(中等密度旋涡)。放一条窄晨昏线(smoothstep −0.03…0.10),夜面只用稀疏的 `.` 渲染。选一个剪影清晰的角度:非洲与欧洲。
- **月面**:远处地面更暗更稀(×0.3),近处地面更亮更密。地平线有一道细亮边(10 px 衰减)。环形山:左内壁全黑阴影,右内壁受光,山缘唇边是亮的。加入几个大的、轮廓清晰的前景环形山。
- **CRT 后期**(`demo/crt.js`,改编自 `core/post/crt.js`):
  - **荧光色**:R 映射到琥珀:暗 `#FF6605`、中 `#FFB000`、过曝趋向 `#FFEBB8`。G 映射到 `#B8E0FF`。
  - **Glow**:四级 bloom 0.55 加光晕 0.22。
  - **玻璃**:3 px 扫描线 0.3,亮区更窄。桶形曲率 0.045 加圆角屏幕遮罩。未点亮玻璃是 `#090604`,不是纯黑。左上角微弱反射、1.2% 高压闪烁、细腻亮度噪声。**无 RGB 荫罩,单色管没有。**
- **余晖**:消失的文字以 τ = 0.12 s 衰减,解析计算,每一帧都是确定的。移动字形在 t − 35 ms 处多采一个尾迹样本 ×0.3。

## 4. 运动语言

- **字符从不离开网格移动,高潮除外。**打字、滚动和计数器逐格跳变。日期"翻牌器"离散地翻转数字,先快后慢。
- **只有三样东西连续运动**:网格缩放(相机)、CRT 物理、高潮粒子。
- **打字速度**:启动行 12 ms/字符,命令 38 ms,标题与回复 120–150 ms(100 BPM 的十六分音符)。人类打字用手工计时的偏移加停顿。
- **字母坠落**(demo 的原生动作):
   1. 保持句子 1.5 s,光标闪烁。
   2. 在分裂瞬间,字母抖动并抛出一个重影副本。
   3. 每个目标单元从一个匹配源字母内部的随机点生成一个粒子(梯度中只存在句子的字母)。粒子从 18 px 起步,缩小到网格尺寸并在 0.2 s 内淡入,粒子绝不堆叠成亮条。路径在 x 上平滑缓动,y = u·(0.6 + 0.4u)。
   4. 地面自下而上落地。
   5. 地球字母先全部落到*地平线之后*,再自下而上升到位,于是星球真的在升起。
   6. 源字母随消耗而变暗。
   7. 落地闪光是 1.9× 亮度,0.12 s 内衰减。
- **分形推近**:推到整个 `M` 清晰可见的取景并**保持 1 s**,然后继续推进直到日志文字可读(单元 450 px,子文字约 28 px)。字形内的文字全亮度,字形外 3–6%,相邻字形 20%,于是字母形状先读出、文字后读出。

## 5. 镜头语言

| 节拍 | 镜头 |
|---|---|
| 开场 | CRT 关闭,然后一个点、一条线和整幅画面。一个巨大的光标在虚空中闪 3 次。 |
| 标题 | 标题是机器打开的文件,以 20 列打出。然后**拉出**到 80 列,成为启动日志的第 1 行。 |
| 悬念 | 静止的 80 列终端。唯一的运动是文字和光标。停在闪烁上。 |
| 决定 | 围绕提示符从 21 px **推近**到 80 px 单元。回复以巨大字号居中打出。 |
| 高潮 | 网格在坠落中缩小(80 px 字母变成 8 px 单元)。停在完成的画面上,并在重拍上变色。 |
| 尺度揭晓 | 推进到一个字形内部,直到它变成自己的文字子网格,然后弹回。 |
| 结尾 | 全片**唯一**屏幕外的镜头:拉远,直到屏幕画面嵌在暗房中一台由字符绘制的终端里。旁边是一个显示真实地球的大舷窗(18–20 行高)。只有两样东西发光:小小的回复和行星。然后关机成一个点。 |

## 6. 声音

- **音乐**:原创 Carpenter 式模拟合成器配乐,以 numpy 和 numba 渲染。
  - **声源**:PolyBLEP 锯齿与方波振荡器、截止频率移动的谐振 4 极梯形滤波器及滤波包络。加缓慢磁带抖动(±3 音分)、pad 上的长混响、打击上的门限混响。
  - **网格与调性**:D 小调 100 BPM,每次剪辑都在小节或拍上。
  - **提示形状**:启动之下是静默,然后机器苏醒时是 drone 和方波 16 分音序器。
  - **硬切**:握手的瞬间整个配乐跌至数字零,包括混响尾,持续五秒。
  - **高潮**:单个锯齿琶音随字母坠落增长,在变色时展开为 Bbmaj7。**唯一的大三和弦**(D 大调)落在回复上。
  - **绝不做 chiptune。**
- **静默是主奏乐器。**握手、消息与光标闪烁只在房间底噪之上播放,画面形成之前有 1.5 s 静默。
- **拟音**(全部合成):
  - **继电器与消磁**:继电器咔哒、消磁嗡鸣(60 Hz 加谐波,0.35 s 衰减,带一声闷响)。
  - **按键**:屈簧弹簧键(塑料咔哒、3.4 kHz 弹簧叮、键帽嗒)。空格键更闷,回车更重。远程字符用干式电传滴答。
  - **调制解调器**:原创握手(2100 Hz 应答音带两次相位反转、双音、1200/2400 FSK、加扰带噪声,全部带限到电话线带宽)。
  - **蜂鸣**:方波错误蜂鸣,最终错误用更低的,回复用 1 kHz BEL。
  - **粒子**:粒子落地是 2–6 kHz 微小滴答的簇。
  - **房间底噪**:风扇铺底加 120 Hz 嗡鸣和**极轻的** 15.7 kHz 回扫啸声(响度归一化前约 −50 dBFS)。
- **人声**:机器的日志,由 Kokoro `am_echo` 以速度 0.8 朗读。用 52 Hz 16% 环形调制、6 ms 梳状(0.22)、140–7000 Hz 带通和软饱和处理。whisper 仍读出 5/5。用 4–6 句短句。人声下方音乐压约 −8 dB。母带 −14 LUFS,无 grain(噪声活在画面里)。

## 7. 字幕与标题

- **字幕是终端输出。**底部有一条保留的 **LOG 条**:暗色虚线分隔符、反显 `LOG` 标签,然后 `> ` 和大写 VT323 45 px 的该行。它**与语音逐词同步打出**,使用 whisper 词时间戳,整行完成后保持 1.4 s。它位于缩放网格之外,像一条状态行,但有相同的扫描线与 glow。无人说话时显示系统状态(`TRANSMIT [#####.....] 40%`、`SENT … AWAITING REPLY`)。
- **屏幕上的文字**如消息、`NOT FOUND` 和回复是画面而非字幕。在 `.srt` 中以 `[SCREEN] …` 出现。
- **标题**:文件名,带键击声打出,加一行小的暗色副行。
- **片尾卡**:在最后的房间镜头上打出(`ASCII / CRT TERMINAL`、`LemoLab × Claude Opus 5.5`),随后 CRT 关机。

## 8. 我们踩过的坑

- **不透明画布上的反显。**`destination-out` 只改 alpha,纹理上传忽略它。保持场景画布不透明黑色,用绘制*黑色*字形图集来切出字母。
- **离屏负片未与网格对齐。**按 W / width 缩放在 200 列上漂移:星星重影、环形山边缘错位。按单元宽 / 采样数精确映射。
- **单元中心算错。**单元高 2·cw,中心是 `(j + .5)·2cw`,不是 `(j + 1)·cw`。
- **每个暗像素都变字符。**墙面填满 `-+-+` 噪声。施加亮度阈值、约 1.25 的 gamma 和局部对比。
- **噪声纹理的地球读作带纹理的球。**用大陆剪影、暗而稀疏的海洋和只有点的夜面。
- **粒子从 13 个字母中心迸发堆叠成发光条。**从字形内部随机点生成,起步小、淡入、快速下落。
- **地球字母穿过仍可见的句子上升显得杂乱。**先把它们全部送到地平线之后,再升起。
- **粗(描边)图集字形封住了 `M` 的缝隙。**分形掩膜要采样单独的*细*(仅填充)字形位图。
- **惰性构建的数据到不了导出器。**粒子调度及其声音事件必须在导出 `window.EV` 之前构建,否则坠落的拟音是静音。
- **开机参数为 0 仍画出中心点。**开机前把 exposure 置 0,并把点项乘以 exposure。

## 9. 制作配方(本仓库)

```
styles/ascii-crt/demo/
  term.js    glyph atlas, grid drawing, density ramps, image → cells
  art.js     continent texture, earth shading, lunar ground, craters
  crt.js     monochrome phosphor CRT post (WebGL2)
  main.js    the whole timeline: boot, handshake, message, reply, letter fall, fractal, room, end card, EV, SUBS
  voice_fx.py  AI voice processing      mix.py  synthesized foley + ducking + score
  music/score.py  original analog-synth score      tools/subs.mjs  export window.SUBS
```

1. `node core/render/still.mjs styles/ascii-crt/demo --range 33.4:37.4:0.2` 渲染任意段落帧;`?frame=earth|fractal|base|poster` 渲染单帧测试;`?nosub=1` 渲染无 LOG 条版本。
2. `sh styles/ascii-crt/demo/build.sh` 从零到成片:TTS、语音特效、whisper、配乐、事件、混音、SRT、渲染(1435 帧 3 worker 约 50 s)、mux、styleframe、poster。
