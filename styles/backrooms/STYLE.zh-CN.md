# 后室影像(Liminal Found Footage)— 风格提示词

> 从空旷、无尽、荧光灯照明空间中被找回的家用摄像机磁带。规则代替怪物。
> 类型参考:"Backrooms" 网络民俗与新怪谈 / 规则怪谈。Demo:*Night Shift Orientation*(59.7 s)· `backrooms.mp4` · 源码在 `demo/`

你正在以**后室影像**风格执导一部 45–60 秒的影片。用户给你一个主题。其余一切由你决定 —— 故事、规则、路线、音效、字幕 —— 并交付一部完成的影片。遵循本指南。

---

## 1. 这个风格是什么

一段单一第一人称**家用摄像机录像**(1990 年代 VHS,4:3),走过一个**空旷、熟悉却不对劲的室内**:芥末色墙纸、潮湿地毯、布满嗡鸣荧光面板的吊顶,无限重复。没有东西追逐任何人。恐惧来自**空旷、重复、官僚规则,以及相机本身在错误时刻的机械故障**。观众应当感到后颈发凉,而不是从座位上跳起来。

**绝不**在影片中使用"Backrooms"一词、wiki 的"Level"编号、社区实体名称,或任何现成机构/logo。类型名只存在于本文件中。屏幕上的一切 —— 规则、表格、公司口吻、"那个东西" —— 都是原创的。

## 2. 故事:什么适合这个风格

录像媒介本身就是叙事者。五项天生优势 —— 至少用三项,把最强的放在情绪顶点:

| 天生优势 | 故事用法 |
|---|---|
| **自动对焦 / 自动曝光狩猎** | 相机只在合焦时"看见"它。第一次锁定时它在,第二次不在了。停电后 AE 滞后,画面随增益噪声泵动。 |
| **磁带跟踪损伤** | 一次跟踪撕裂是*宇宙做的剪辑*。之后取景相同,但 OSD 时钟跳了几小时 / 电池掉电 / 一盏灯灭了。 |
| **OSD 即剧情** | REC 红点、电池、日期与时间码是叙事内的证据。摄像机字幕发生器可以把片名写在第一个镜头上。 |
| **画面中的规则文本** | 打印的告示、以平静公司口吻播出的 PA 广播。规则从平凡开始渐渐不对劲;其中两条互相矛盾;最后一条对着观众说。 |
| **空旷与重复** | 同一张告示在另一处再次出现;同一个房间换了一个细节;一条走廊通向雾中。空旷本身就是威胁。 |

改编任何主题:把主题变成**一次入职指引、一套流程或一张检查清单**,由某人录在磁带上 —— 新工作的第一个班次、一次建筑检查、搬家日看房、学校安全演练、酒店夜审。写 5–6 条规则。让媒介背叛规则。

**45–60 s 情绪弧线:**无聊的正常(约 20 s 几乎什么都没有)→ 一点小不对劲(矛盾、重复的告示)→ 一条规则被检验(灯闪)→ 看见 / 看不见(对焦狩猎)→ 时间被抽走(跟踪撕裂)→ 一条规则被打破(出口)→ 最后一条规则转向观众 → REC 关闭。一个主体(相机操作员 —— 只闻其声,画面上从不超过鞋)、一个目标(按流程走)、一个转折(时间码证明他已不在"正常"之中)。

## 3. 视觉语言

- **画幅**:4:3 画面以 1920×1080 上下留黑边(左右黑条)。3D 以 **720×540** 渲染,由 VHS 通道负责放大 —— 低分辨率是外观的一部分,也掩盖 CG 的干净感。
- **空间**:2.4 m 网格上 0.16 m 厚的轴对齐隔墙、随机缺口与残端、偶尔的方柱;吊顶高 2.70 m;吊顶板 0.6×1.2 m;每 2.4 m 一个嵌入式灯具(0.6×1.2 m 棱镜面板)。在程序化填充的办公室中手工设计一条路线(起始房间 → 长走廊 → 侧廊 → 一间小房),让每个门口都露出更多空房间。
- **灯光 = 千盏灯,无阴影**:把每个灯具的颜色/强度存入一张 128×128 浮点 **DataTexture**;每个片元累加最近 5×5 面板(发射体余弦 × Lambert / (d²+0.3))加同邻域的反弹项。无遮挡 —— 后室的光是平的。逐灯差异:±8% 暖/冷、+0–7% 绿、3.5% 死灯、2.5% 闪烁。GTAO(半径约 0.55 m)压暗墙/地接缝。
- **雾跟随局部光**:雾颜色 ×(局部反弹光 / 平均)。灯死的地方雾也暗,那里的剪影读作*光中的洞*。场景背景 = 雾 × 0.15,走廊溶解进黑暗而不是撞上亮墙。
- **调色板**(反照率,sRGB):墙纸 `#d5bd66` 带更暗条纹 `rgba(140,112,40,.7)` 和菱形立柱,每卷褪色程度不同;踢脚线 `#4d3d26`;地毯 `#8c763c` 斑驳,潮湿斑块 ×0.6 带微弱高光;吊顶板 `#d9d3b8`,格栅 `#e6e1cf`;灯具扩散罩 `#fbfaf0` 自发光 ×5;**唯一的高饱和色是红色 EXIT 出口牌**(`#ff2a1a`,自发光 ×9 以便 bloom)。
- **克制的破败**(干净是风格的一部分 —— 绝不做废墟):*部分*墙根有水渍线,吊顶下有尼古丁黄带,偶尔翘边的接缝(约 7% 的卷,浅色纸背三角 + 阴影),零星小污渍,约 4% 泛黄吊顶板,约 2% 回风格栅,<1% 缺失板材(黑洞),扩散罩内的死昆虫。
- **告示**:黄化纸上的办公室激光打印:IBM Plex Sans Condensed 标题("FLOOR STAFF — PLEASE READ"、"FORM NS-01 (REV. 9)")、Plex Sans 600 的编号规则、"Thank you for your cooperation. — Management"。钉在软木板上或贴在墙纸上。拍特写时**降低相机让镜头与纸面平行** —— 对着竖直的纸俯拍会把文字剪切成都市传说的假斜体。
- **VHS 摄像机通道**(自定义 shader,*不是* CRT):逐行时基抖动(小;低频摆动 ≤0.25 px 否则文字倾斜)、底部 8 行磁头切换带、按需的跟踪撕裂;桶形畸变 0.07 + 晕影 0.42 只作用于画面而**不**作用于 OSD;亮度带宽限制(高斯 σ≈1.25 px @720)+ 边缘增强振铃(sharp 0.9);色度按 ±10 px 平均并右移 1.6 px;亮光源向右拖尾;AWB 色调漂移;AGC 噪声(条状,暗部更强);每帧 0–2 条信号失落;黑抬升 0.045、软高光削波。噪声以 30 fps(磁带速率)运行,即使输出是 24 fps。无扫描线,无 RGB 荫罩。
- **OSD**:手工 5×7 点阵字体带黑描边:左上 `● REC`,右上电池,右下 `PM 11:58` / `SEP.27.1996`。片名用同一字体 ×2,像摄像机字幕发生器。

## 4. 运动语言

- **一个连续的手持长镜头。**剪辑只发生在磁带断裂处:开机卷入、跟踪撕裂、REC 关闭。
- 手持 = 步行步态(0.72 m 步幅、头部上下 3 cm、左右摆 1.8 cm、侧倾 ±0.8°)+ 呼吸(0.27 Hz)+ 1、3.5、9 Hz 的颤抖噪声,幅度随**恐惧**曲线上升。在"屏息"瞬间**全部冻结**。
- 低头:俯仰约 −1.2 rad,相机前推 0.2 m —— 画面里只有鞋尖和地毯,绝不出现裤腿。
- 自动对焦是带过冲动画的 DOF 焦距:模糊 → 锁定 → 滑失 → 锁定。模糊来自把焦点拉*近*(远目标在焦点过冲到无穷远时几乎不模糊)。变焦把 FOV 从 52° 收窄到 27° 并把光圈提高 ×5。
- 灯光以三次 0.1 s 停电的方式闪烁;之后 AE 以约 0.45 s 滞后变亮。
- 门自己缓慢打开(1.3 s,缓动)。

## 5. 镜头语言

| 节拍 | 镜头 |
|---|---|
| 开场 | 磁带卷入,AWB 由蓝摆到黄,AF 在墙上找到一张告示;摄像机字幕叠在上面 |
| 空间揭示 | 从告示缓慢摇向一条由隔墙与灯组成、消失进雾中的走廊 |
| 例行 | 行走 POV,瞥向潮湿地毯上的鞋;约 20 s 无事件 |
| 矛盾 | 蹲向一张重复的告示;保持 ≥4 s,无物遮挡文字 |
| 遵守规则 | 猛地甩向鞋;让地毯上的光变化,而非拍天花板 |
| 顶点 | 沿走廊变焦 + 对焦狩猎;那个人影只存在于合焦的约 0.5 s 里 |
| 时间剪辑 | 跟踪撕裂,然后*完全相同*的取景 —— 只有 OSD 变了 |
| 打破规则 | 拐角转向红色 EXIT;在彻底静默中静止;推近;门自行打开 |
| 结尾 | 最后一张告示合焦 ≥3 s → REC 关闭:冻结、撕裂、黑 |

**"那个东西"** 绝不给特写:2.4 m 剪影(一个错了 15–40% 的同事:小头、歪斜长颈、窄高肩、手臂长及膝),以有机 Canvas2D 剪影绘制在朝向相机的 billboard 上,约 33 m 外、一段死灯区中、只有身后远处微光。缓慢小幅挥手(3.6 s 周期)。目标:*你看得出它在挥手,你数不出手指。*把 billboard 排除出 GTAO 预通道(`mesh.isPoints = true`),否则会盖出一个暗矩形。

## 6. 声音

- **无配乐。**只有磁带本来会录下的声音。
- **荧光灯铺底**:120 Hz + 谐波(1、.55、.42、.22、.16、.06 于 ×1…×7)、一个发嗡的带通方波分量、微弱的约 9 kHz 镇流器啸声、随机坏管"zzz"爆发;由与画面相同的光曲线门控;小房间内更近时 +3 dB。
- **PA 广播**:平静的公司口吻(Kokoro `af_bella`,速度 0.82–0.84)过"吸顶喇叭":带通约 310–3500 Hz、约 1.3 kHz 纸盆谐振、tanh 饱和、房间混响 —— 保持足够干以便 whisper 转写(混响过多曾把"night shift"转成"my church")。每条规则前有原创双音提示音(颤音琴 E5→C5);时间跳跃后提示音与人声都随磁带抖动变平。
- **操作员**:3–4 句短句(`am_michael`),低电平、近讲低频、跟随语音包络的一层气息、压缩。Kokoro 无法真正耳语 —— 目标是"小声说话"。近讲呼吸,频率跟随恐惧曲线;屏息后一次长呼气。
- **叙事内等待音乐**:原创轻音乐循环(demo 中为 88 BPM F 大调、颤音琴旋律、2、4 拍的清音吉他切音、指弹贝斯),带通并淹没在混响中如隔墙传来,以减速磁带曲线(1.00 → 0.97 → 0.89)和渐增抖动回放。停电期间切断,在那次静默中死去,不再回来。
- **拟音**:湿地毯脚步(60–85 Hz 闷响 + 细小湿哒声 0.9–2.6 kHz)、转身衣物摩擦、REC 开/关的摄像机咔哒 + 马达、变焦伺服啸声、AF 马达滴答、每次闪烁的镇流器"叮"+ 电弧嗡、头顶一段几乎听不见的拖拽声、门闩 + 粘滑铰链吱呀 + 推气声。
- **静默即高潮**:出口出现时整整一秒数字零(包括尾音);字幕 `[SILENCE]`。唯一允许的惊吓是柔和的:声音回来时所有镇流器同时重燃并带一声低闷响。
- 低音 drone(35–55 Hz 布朗噪声 + 41/43.5 Hz 拍频)从时间跳跃升到静默。人声下压铺底与音乐 ≈ −8 dB。响度 −14 LUFS,grain 0(噪声在画面里)。

## 7. 字幕与标题

- **CEA-608 式隐藏字幕**:IBM Plex Mono 600、42 px、白字置于每行实心黑框上、每行 ≤32 字符,居中于 4:3 画面内、OSD 时钟上方。它们不受磁带噪声影响(是电视解码出来的)。
- 说话人标记:广播加 `[PA]` 前缀;操作员用斜体(首句标注 `(whispering)`);SDH 音效描述加方括号:`[FLUORESCENT LIGHTS HUMMING]`、`[LIGHTS FLICKER]`、`[TAPE NOISE]`、`[SILENCE]`。
- 告示上的规则*不加*字幕 —— 它们是画面。保持文字在 1080p 下可读,每张告示无遮挡 ≥3–4 s。
- 标题:摄像机字幕发生器点阵文字打在第一个镜头上。片尾卡:黑底、点阵字体标题、风格名、`LemoLab × Claude Opus 5.5`。

## 8. 我们踩过的坑

- 全亮的场景读作医院走廊。把墙打断成带缺口的隔断;让远处区域沉入黑暗。
- 灯穿过墙壁泄漏(无遮挡)—— 一块"死区"需要 ±5 m 内所有灯全死、其后走廊也暗,否则人影衬在一扇亮窗前。
- 场景背景在走廊尽头显示为亮矩形 —— 设 background = 雾 × 0.15。
- 均匀的雾色把剪影抬成灰色;让雾跟随局部光。
- VHS 通道的低频行摆动让文字倾斜;保持 ≤0.25 px。相机俯拍告示让文字像斜体 —— 改为降低相机。
- 胶囊体拼的人像读作玩具 / 火柴人。把剪影以有机曲线画在 billboard 上。
- 基本几何拼的腿像管子;只拍鞋尖(挤出鞋印轮廓带倒角、更亮的鞋底、鞋带)。
- ×3 的红色自发光达不到 bloom 阈值(纯红亮度低);用 ×9。
- 用*滤波前*峰值归一化滤波后的提示音,把 PA 总线炸了 16 dB —— 按处理后的信号归一化。
- 重 PA 混响毁掉可懂度;每句处理后的台词用 whisper 检查,也要检查完整混音。
- 时间压缩已完成的 timeline:关键帧写在"原始"时间里,再经一个分段线性变形 `W()` 映射;记得别处硬编码的时间也要变形。
- VHS 噪声让文件变大:CRF 24 → 60 s 约 47 MB。

## 9. 制作配方(本仓库)

```
styles/backrooms/demo/
  story.js    timeline (single source of truth), camera keyframes, focus/aperture/fear curves, OSD clock, time warp W()
  world.js    layout (walls/pillars/route), light DataTexture, custom lighting/fog shaders, props (notices, EXIT, door, outlets)
  tex.js      procedural textures (wallpaper, carpet, ceiling, troffer, notices, EXIT, cork, outlet)
  figures.js  operator's shoes, the silhouette billboard      thing2d.js  organic silhouette drawing
  vhs.js      VHS camcorder ShaderPass (pillarbox, jitter, tear, luma/chroma, AGC, dropouts)
  osd.js      5×7 bitmap font, REC/battery/clock, title generator      subs.js  608 captions
  main.js     renderer, post chain (core/three/post.js GTAO+DOF+bloom → VHS), handheld rig, events
  sheet.js    silhouette design sheet (?sheet=1)      music/muzak.py  original hold music (sampler)
  mix.py      all sound → mix.wav        tools/mux.sh  core mux with CRF parameter        build.sh
```

1. `node core/render/still.mjs styles/backrooms/demo <t…> [--q nosub=1|raw=1|sheet=1]` —— 审查静帧。
2. `sh styles/backrooms/demo/build.sh` —— TTS → whisper → 音乐 → 事件 → 混音 → 对处理后语音再 whisper → 渲染(1433 帧 3 worker 约 80 s)→ mux(−14 LUFS)→ SRT → poster/styleframe。
