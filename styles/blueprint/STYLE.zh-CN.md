# 蓝图(Blueprint)— 风格提示词

> 在一张氰版蓝晒纸上活起来的工程图:普鲁士蓝上的白色技术线条,按制图顺序绘制,注释会移动。
> Demo:*Patent Pending: The Cloud Catcher*(46.7 s)· `blueprint.mp4` · 源码在 `demo/`

你正在以**蓝图**风格执导一部 30–60 秒的影片。用户给你一个主题。你决定故事、镜头、节奏、音乐、音效与字幕,并交付一部完成的影片。遵循本指南。

---

## 1. 这个风格是什么

整部影片发生在**一张蓝图纸上**,铺在暗色绘图桌上。一切是不均匀普鲁士蓝上的白色线条:中心线、轮廓线、剖面线、尺寸线、带编号气泡的引出线、标题栏与注释栏。相机像阅读图纸的眼睛在纸面上移动。这是一种**2D 线稿语言**。可以用正投影与斜测/等测投影,但**绝不用 3D 渲染**。

魅力在于**严谨的工程惯例**与**奇思妙想**之间的张力。图纸枯燥而精确。注释负责抖包袱("10 · COUNTERWEIGHT (GRANDMOTHER'S IRON)")。而每部影片一次,一个绘图符号打破规则变成真实。

从以下来源学习语法但绝不抄袭:Prologue Films 的*《钢铁侠》*(2008)片尾字幕中的动态技术图纸、达芬奇的*《大西洋古抄本》*页面、19 世纪美国专利图纸(Fig. 1 / Fig. 2、零件气泡、细线阴影)与*《雨果》*(2011)中的自动机图纸。不用漫威元素、不用真实专利、不用真实发明家的机器或签名。

## 2. 故事:什么适合这个风格

机器(或物体、或方案)**就是角色**。零件在表演:吊杆充满希望地抬起或垂落,风向标振作或耷拉,风箱呼吸,仪表指针在零位抽动。发明人只以**带笔尖的手影**或一个签名出现。

| 天生优势 | 故事用法 |
|---|---|
| **制图顺序** | 物体像工程师那样画出自己:中心线 → 轮廓 → 齿轮/细节 → 剖面线 → 尺寸 → 气泡 → 标注。每层落在一个节拍上。 |
| **活的注释** | 尺寸线测量运动部件,数字在变。引出线与气泡随爆炸零件飞舞。剖面线 A–A 扫过一个壳体并揭示内部。 |
| **图号作转场** | "FIG. 1" 被划掉改写为 "FIG. 2 · EXPLODED VIEW",再到 "FIG. 3 · IN OPERATION"。 |
| **投影即相机** | 把斜测深度因子从 0(平面立面)动画到 0.5。线稿在"转身"并获得厚度,无需任何 3D 渲染器。爆炸零件沿深度轴飞出。 |
| **绘图符号成真**(放在情绪顶点) | 一个修订云变成真正的雨云。其他候选:尺寸箭头变成真箭,剖面线纹变成雨,中心线变成道路,焊接符号迸出火花。规则:**这一个符号是全片唯一离开绘图语言的东西。**它获得柔和体积、渐变、光晕,以及投在图纸线条上的影子。 |
| **氰版与水** | 纸上的雨:每滴绽开更深的蓝色带一圈浅色潮痕,污渍内的白线变柔。签名上的一滴水让它洇开。 |
| **标题栏** | 标题卡 = 图纸页眉。状态栏 = 故事的判决(一枚红色橡皮图章是全片唯一的非蓝颜色)。片尾卡 = 标题栏最后一行被写入(STYLE / DRAWN BY)。 |

**改编任何主题:**把主题变成**一件被设计出来的东西**,让图纸发现一个只有图纸能修复的缺陷。产品发布变成 Fig. 1、爆炸图、运转、再加一次补上缺失功能的修订。爱情故事:一张纸上的两台机器,一朵修订云画出桥。历史课:一份一再修订的城市规划(REV. 1、2、3)。

**情绪弧线(40–50 s):**好奇(空白纸、物体被画出)→ 自豪(爆炸图)→ 兴奋(它转起来了,踩着节拍)→ 缺陷(它完美运转但世界缺了什么;音乐停)→ 手修订图纸 → **符号成真**(悬挂和弦、无人声)→ 收获 → 回声(图章、签名、标题栏)。

## 3. 视觉语言(demo 的精确数值)

- **纸**:3200 × 2200 单位,对折成四分之一。蓝色由 WebGL 片元 shader 以*图纸坐标*程序生成,任何缩放下保持锐利。`#18336B` 与 `#2A58A6` 之间的低频 fbm、水平涂布条痕、轻微的左到右淡出、纤维噪声、稀疏纤维、折痕(亮边、暗边、沿折线的磨损泛白)、不规则漂白边缘与圆角、小斑点。纸外:暗色绘图纸 `#0D1116` 带投影。
- **线条**:淡蓝白 `#E7F0F9`,略柔(mipmap 渗色),带纸纹驱动的微弱断墨。
  - 图纸单位线宽:轮廓 3.2、细节 2.0、细 1.25、发丝 0.9。
  - **屏幕线宽 = 图纸线宽 × zoom^0.65。**特写不变香肠、全景不消失。
  - 虚线:中心线 `[34,7,6,7]`、隐藏线 `[11,7]`、假想线(剖切面)`[30,6,5,6,5,6]`,全部随 zoom 缩放使图案留在纸上。
- **遮挡**:每个实体先以"纸"填充(墨水缓冲中为黑色)再描轮廓,按画家顺序。斜测的挤出用扫描法:以 2× 宽度在 N 个深度步描轮廓,再以纸色填同样的 N 步。留下的是半宽的干净剪影。正面与可见顶点连线画在上面。
- **合成**:墨水画布为灰度(白 = 曝光线条)。fx 画布 R = 阴影加深、G = 湿度、B = 图章墨,以 `lighter` 相加。覆盖层画布放字幕。阴影也压暗线条 —— 这就是一个被抬起的物体证明自己离开了纸面的方式。要让物体不被自己的影子压暗,在 fx 画布上把它的区域乘 `rgb(0,255,255)`。
- **剖面线**(细线阴影)用于剖切、泥土与配重,45°,间距 8–14 单位。
- **魔法物体**(仅高潮):圆的并集(15 个扇边 + 4 个内裂片)。
  - 平面态:向外扇边的修订云。
  - 鼓起态:整个并集上一个径向渐变(左上受光)加顶部裂片上的小高光、模糊的白色光晕、右下的镌刻月牙阴影(掩膜 = 并集减去左上移位的并集)、阴影侧更粗的轮廓。
  - 它在被画过的地方留下浅色"未曝光印痕"。它的影子偏移随抬起增大(最多向下约 240 单位)。
- **调色纪律**:只有蓝与白。一种图章红 `#C23B2E`,只用一次。
- **字体**(全部 OFL):
  - Architects Daughter 用于手写体(页眉、标注、注释、字幕)。
  - B612 / B612 Bold 用于标题栏字段与 "PATENT PENDING"。
  - Allura 用于签名。
  - 文字由一支发光的笔尖从左到右写出。

## 4. 运动语言

- 线条**绘出**按弧长截断,笔头带一个小发光笔尖。同层内的项目错峰。每层从一个节拍开始。
- **爆炸图**:零件依次飞出,每件间隔约 0.055 进度,踩八分音符,缓动运动。相机拉远腾出空间。零件回归时**每组一个八分音符带一声铜管咔哒**。
- **机构踩网格**:齿轮每个八分音符前进一齿(7.5°),0.35 拍缓出,像擒纵机构。啮合相位经过计算,齿真正咬合。链节随小齿轮移动。风箱每拍呼吸。
- **机器表演**:吊杆角度、风向标垂度、风箱体积与仪表指针是它的脸。失败 = 齿轮变慢、风箱瘪下、吊杆下垂、风向标耷拉,约 1.5 s。喜悦 = 风向标弹直、指针过冲(回缓)到 1。
- **相机按一帧一拍(24 fps)运动**,段内连续,段间在大拍上硬切。两次轻微的相机颠簸:拍纸与盖章。

## 5. 镜头语言

| 节拍 | 镜头 |
|---|---|
| 开场 | 暗桌上的整张纸。图纸卷啪地展开,然后是丁字尺。仅建置镜头。 |
| 标题 | 推向页眉文字。 |
| 绘图 | Fig. 1 中景,机器约占画高 80%,右侧留空天空(字幕住那里)。 |
| 爆炸图 | 拉远使机器居左,零件清单从右侧探入。 |
| 运转(记忆点镜头) | 切到曲柄与齿轮的 2× 特写,然后**沿传动链上移**经桅杆到吊杆,跟随网的弧线。相机跟随力的路径。 |
| 缺陷 | 大量空天空的中远景。空旷就是笑点。 |
| 修订 | 手影绘制时锁定机位。完成的符号上停一拍。 |
| 符号成真 | 缓慢推近,无人声。 |
| 收获 | 跟随物体落到目标,推近结果(那朵花)。 |
| 结尾 | 拉回整张纸(尺度揭晓)。图章落在全景里。推向标题栏出片尾卡。 |

叙事镜头保持近景。只有开场与结尾的建置镜头是全纸的。

## 6. 声音

- **音乐**:G 大调 108 BPM 的二声部**巴洛克创意曲**。羽管键琴主题(一小节十六分音符"齿轮"动机),大管断奏在低两个八度上模仿。
  - 运转段加入小提琴与大提琴的 spiccato 八分音符("齿轮咬合")。
  - 缺陷:乐器以写出的渐慢退出,然后是真正的数字静默。
  - 修订段静默,只有三音疑问句。
  - 奇迹悬挂在 Dsus4 弦乐和弦上,两次呼吸起伏,不解决。
  - 收获在大拍上解决到 G。
  - 雨用竖琴与羽管键琴琶音。
  - 一段短全终止落在图章上,主题以增值形式回归片尾卡。
  - 用 `core/audio/sampler.py` 渲染:VCSL 羽管键琴与竖琴、VSCO 2 CE 大管、弦乐与 spiccato。
- **拟音跟随材质**:
  - 纸:卷筒展开爆裂与拍击、丁字尺木滑、技术笔刮擦(2–6 kHz 颗粒、时长 = 笔画长度)、写字(短笔画爆发)、圆规吱呀、剖面线(13 笔/秒)。
  - 黄铜与木:零件咔哒(3.1 / 5.2 kHz 谐振)、擒纵滴答、链条哗啦、风箱呼吸、按 ×1.35 减慢的落体滴答。
  - 魔法时刻:两次呼吸上柔软的纸"噗"、一个噪声涌起,别无其他。
  - 水:每滴柔软的阻尼拍打加一层轻雨铺底。
  - 橡皮图章闷响、最后笔帽咔哒。
- **人声**:冷幽默的英国工程师读自己的设计笔记,Kokoro `bm_daniel`、`lang en-gb`、速度 0.9。五六句短句。高潮保持无人声。
- **混音**:人声下音乐压至约 0.36,拟音减半。呼啸声低通 2.5 kHz(它们在 whisper 里盖住了"bellows")。−14 LUFS。`mux.sh` grain 4(纸纹已在画面里)。

## 7. 字幕与标题

- **字幕即图纸注释**:一个浅色框(rgba(12,28,62,.58)、1.2 px 外白线与 0.8 px 内白线、高约 110–150 px)、B612 Bold 的 "NOTE / n" 单元格、Architects Daughter 38 px 的文字在 0.35 s 内写出,左下角一个小引出刻线。
  - **逐镜头定位,放在空天空里**,绝不固定在底部。画面底部是地面线、基准与标题栏的地盘。
  - 约每 880 px 折行。
- 每条字幕同时也写入图纸的 **GENERAL NOTES** 注释栏(位于固定注释 "ALL DIMENSIONS IN MILLIMETRES." 与 "DO NOT SCALE DRAWING." 之下),最终全景把整段旁白展示为图纸注释。
- **标题**:图纸页眉(Architects Daughter 132 单位、加字距、双下划线),带 PATENT PENDING 与 B612 副标行。
- **片尾卡**:标题栏。最后一行被写入:STYLE: BLUEPRINT / DRAWN BY: LemoLab × Claude Opus 5.5。

## 8. 我们踩过的坑

- **机器靠近纸边**:全景露出了桌子。把主体放在距任何会在全景取景的纸边至少 `960/zoom` 处,或把纸做大(我们从 3200×2000 → 3200×2200 并把机器右移)。
- **向上爆炸撞到页眉。**主要向上和向两侧炸,爆炸期间放平吊杆让网向侧面展开。
- **墨水画布上的字幕**在纸外消失且不能遮挡线条。用单独的覆盖纹理最后合成(premultiplied alpha)。
- **魔法物体被自己的影子压暗。**在 fx 画布上把它的区域乘 `rgb(0,255,255)`,只把阴影通道清零。
- **逐裂片着色变成"葡萄"或气泡膜。**并集上用一个渐变、用"并集减移位并集"掩膜的月牙、弧线只放在上部内裂片上。
- **叠加的加法圆填充产生泡泡。**把并集当作一条路径以 `fill('nonzero')` 填充。
- **扇边弧画反方向像旭日。**选择包含裂片向外角度的弧方向。
- **半鼓的云像甜甜圈。**让内裂片早长(`r × min(1, pf × 2.2)`)。
- **收获必须够大。**第一版让花作为下三分之一里的一小簇,削弱了情绪回报。给收获物体约 1/3 画高、居中、逐笔画出(茎 → 叶 → 每拍一瓣),周围有明显污渍。字幕避开它。
- **被接住的物体透过网显示。**不要整片把网画在它上面:先用物体身体填充前沿以下的袋体,再在其上画网与前沿,跳过后沿。
- `sfx.thump()` 长 0.35 s:加入更长缓冲前先补零。
- Whisper 把 "Figure one" 读成 "Figure 1":在 `lines.json` 用 `asr` 字段。
- **仓库根目录出现杂散文件**:始终用样式目录内的绝对路径写入。

## 9. 制作配方(本仓库)

```
styles/blueprint/demo/
  paper.js    WebGL2 compositor: procedural cyanotype sheet, ink bleed, wet stains, shadows, stamp, roll
  draw.js     drafting engine: camera, oblique projection, draw-on polylines, solids, hatching, dims, balloons, text
  machine.js  the Cloud Catcher: parts, gear meshing, explode offsets and paths, garden and flower
  sheet.js    border, header, title block, parts list, notes, revision cloud ↔ cloud, rain, hand shadow, stamp
  film.js     the whole timeline (108 BPM grid): cameras, acting, subtitles, sound events
  main.js     page entry (?frame=1|2|3 gate frames, ?nosub, ?poster)
  mix.py      foley + voice + music ducking       music/score.py  original score (sampler)
  tools/      subs.mjs (SUBS → subs.json), check_mix.py (whisper on the final mix)
```

1. `node core/render/still.mjs styles/blueprint/demo --range 0:46:1.5` 然后 `sheet.py` 审查。逐段迭代。
2. `.venv/bin/python core/tts/tts.py lines.json voices`,然后 `asr_check.py`(6/6 OK)。
3. `node core/render/events.mjs`,然后 `music/score.py`,然后 `mix.py`,然后 `tools/check_mix.py`。
4. `node core/render/video.mjs styles/blueprint/demo --fps 24 --workers 3`(1120 帧,Canvas2D + WebGL,约 30 s)。
5. `sh core/render/mux.sh out/video24.mp4 mix.wav blueprint.mp4 24 4`。或用 `sh styles/blueprint/demo/build.sh` 一键完成。
