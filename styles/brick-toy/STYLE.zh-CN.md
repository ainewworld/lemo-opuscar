# 积木玩具(Brick Toy)— 风格提示词

> 像在真实书桌上拍微距摄影一样的定格动画玩具积木影片。
> Demo:*Rocket from Spare Parts*(54s)· `brick-toy.mp4` · 源码在 `demo/`

你正在以**积木玩具(Brick Toy)**风格执导一部 30–60 秒的影片。用户给你一个主题(也许还有故事)。其余一切由你决定 —— 故事、镜头、节奏、音效 —— 并交付一部完成的影片。遵循本指南。

---

## 1. 这个风格是什么

一个完全由带圆凸点的互锁塑料积木构成的世界,摆在**真实的木书桌**上,用**微距镜头**拍摄、以**定格动画**方式制作。魅力来自玩具世界与周围真实房间之间的张力。

**绝不**使用 LEGO 名称、logo 或小人偶剪影(商标问题)。角色*由积木搭建*(1×1 柱做腿、2×2 砖做躯干、圆砖做手臂、2×2 圆盔)。凸点上不带任何文字。

## 2. 故事:什么适合这个风格

选**媒介本身在讲故事**的故事。积木有四项天生优势 —— 至少用三项:

| 天生优势 | 故事用法 |
|---|---|
| **拼搭** | 剧情就是一次搭建。以一块积木开场,以一块积木收尾。 |
| **无损的散架** | 东西散开,变成更好的东西的零件。失败 → 备用零件。 |
| **真实桌上的玩具** | 真实物件成为风景:茶壶是山,一摞书是月亮,台灯是太阳。 |
| **手工定格动画** | 12 fps 的运动、微小的不完美,连火与烟都是积木做的。 |

改编任何主题:把主题变成**正在被搭建的东西**。产品发布 → 产品被一块块积木组装起来。爱情故事 → 两个角色在两本书之间搭一座桥。历史课 → 一个时代被搭建、倒塌、重建。

**45–60s 情绪弧线:**好奇 → 兴奋 → 挫折(倒塌)→ 一个安静的节拍 → 重建 → 高潮 → 温暖的尺度揭晓。保持一个角色、一个目标。

## 3. 视觉语言

- **塑料**:ABS 带强清漆层(0.85,清漆粗糙度 0.07);粗糙度贴图带微弱指纹与划痕(基色约 0.17,划痕至约 0.65);倒角半径 0.06 使边缘能接住高光。颜色取经典积木调色板:红 `#c91a09`、蓝 `#0055bf`、黄 `#f2cd37`、绿 `#237841`、白 `#f2f2ee`、黑 `#1b2a34`、橙、浅/深灰、棕褐、天蓝。
- **几何**:圆角盒身(倒角约 0.045 凸点)、带薄唇的凸点。单位 = 1 个凸点间距(8 mm);砖高 1.2、板 0.4。底板是哑光绿(清漆低于砖,否则在影棚反射中发青)。
- **场景**:一张真实书桌(胡桃木纹理)、真实比例的真实道具(1 m = 125 凸点):茶壶、杯子、铅笔、书、台灯。中性日光影棚 HDRI —— **不是**钨丝灯室内(白砖会发橙)。
- **灯光**:玩具摄影布光。左上方向性主光(`#fff4e8`,投影;为每个镜头适配其阴影平截头体以获得锐利影子)、两三盏 **RectAreaLight 柔光箱**(主光左前、冷轮廓光在后、一盏照终场布景),让光泽塑料呈现干净的矩形高光,环境保持低(约 0.45)以获得对比。当主光影子落到主角物体后面时,补一块柔和的接触阴影斑块。
- **环境光遮蔽必不可少**:GTAO(半径约 3.5 凸点、scale 2.5)压暗堆叠砖之间的接缝、凸点根部与接触点 —— 没有它积木像贴上去的。
- **调色**:轻微偏冷的白平衡让白砖读作纯白(房间反弹光把它们推向奶油色)、柔对比(+0.26)、饱和度 ×1.1。
- **2× 超采样**(渲染 3840×2160,交付 1080p):否则细的凸点边缘与倒角高光会闪烁。
- **镜头**:物理景深(CoC ∝ |1/focus − 1/z|)。特写光圈约 500–700、中景约 800、最终全景约 400。焦点总在角色头部或正被放置的积木上。
- **特效即积木**:火焰 = 半透明橙/黄圆板,逐帧抖动;烟 = 白色圆砖,长大并向外滚动;月亮 = 带陨石坑贴片的灰色圆板。

## 4. 运动语言

- **角色与积木以 12 fps 迈步**("二帧一拍");**相机、焦点、火焰与载具飞行按一帧一拍** 24 fps(《乐高大电影》的做法)。相机也二帧一拍读作颠簸而非魅力 —— 我们试过,看起来不流畅。
- 积木**沿弧线飞入**并** snaps 拼合**,带微小过冲(0.35 凸点 → 0 用时约 0.17 s)。每次拼合在声轨上是一声咔哒。
- 角色以大而可读的姿势表演:自豪的双手举 V、惊慌的双臂甩起、悲伤的低头坐地、喜悦的一跳。行走循环腿部摆动 ±0.55 rad 带小幅起伏。
- 倒塌用真实物理:绕底缘的刚体倾覆,然后独立刚体带重力(约 420 凸点/s² 比真实 1225 观感更好)、反弹(恢复系数约 0.3)、摩擦、平躺安顿。预模拟以保证每次渲染一致。

## 5. 镜头语言

| 节拍 | 镜头 |
|---|---|
| 开场 | 单块积木的极微距,缓慢推近,背景虚化为真实道具 |
| 搭建 | 低角度让渺小的角色显得英勇;每小节一切 |
| 挫折 | 倒塌时的手持晃动,然后一个**低、广、孤独**的画面,角色很小 |
| 情绪节拍 | 正面特写,角色的手与积木合焦 |
| 高潮 | 低角度向上跟随;然后一个与运动物体并行、目的地在前方可见的**跟踪镜头** |
| 结尾 | 缓慢拉回到整个书桌的高全景:尺度揭晓 |

别让前景杂物进画面边缘(零件堆最爱挡镜头)。逐镜头检查头顶空间。

## 6. 声音

- **音乐**:搭建用俏皮的木吉他/尤克里里(按小节切),重建时同一主题安静回归,高潮用管弦涌起。剪辑使高潮重击落在关键动作上、最终和弦落在片尾卡上(按小节对齐跳切、色度相似)。
- **静默是工具**:倒塌时音乐骤停;只剩房间底噪与滴答的钟。高潮前再次抽走音乐(倒计时下低沉的心跳鼓)。
- **拟音**(全部合成):积木咔哒(短瞬态 + 2.9 kHz / 4.6 kHz 谐振)、木面啪嗒、撞击(大量啪嗒)、投掷呼啸、倒塌前的塑料吱呀、细小塑料脚步、发现时的铃"叮"、点火轰鸣与火箭咆哮。
- **人声**:温暖的英国讲故事人(Kokoro `bm_george`,速度约 0.9)。次要人声过收音机滤波(带通 380–2800 Hz + 软饱和)带 Quindar 蜂鸣。4–6 句短句,每句留呼吸空间。用 whisper 验证每一句。
- 混音:人声压缩,人声下音乐压约 40%,响度 −14 LUFS。

## 7. 字幕与标题

- 字幕:深色圆角药丸(rgba(18,20,26,.62))居中于底部上方 150 px,Fredoka 600 46 px 白字,左侧一个小的黄色 2×1 积木图标。无线电台词用红色积木图标加 "MISSION CONTROL" 标签。
- 标题:Fredoka 700,以 12 fps 步进弹入,带一行小的黄色副标("A BRICK TOY FILM")。
- 片尾卡:压暗的最终全景、标题、积木图标、风格名、致谢。

## 8. 我们踩过的坑

- 钨丝 HDRI → 白砖发橙。用中性影棚 HDRI。
- 球面片段做的头盔面罩会消失在圆柱盔内;改用弯曲的开圆柱面板。
- 大底板上的清漆把柔光箱反射成青色水洗 —— 改哑光。
- 光圈过大使中距主角发虚;按景别缩放光圈。
- 只是向上加速的火箭变成空白墙上的一个点 —— 用瞄准目的地的跟踪镜头跟随它。
- 一个道具(台灯)放在后续镜头的光轴上,不停溜进背景;逐相机核对道具。
- 随机抖动上的材质索引运算可能为负 → 未定义材质崩溃。做 clamp。
- 第一版观感平而微锯齿:均匀光、无 AO、单采样渲染、二帧一拍的相机。以柔光箱 + 低环境光、GTAO、2× 超采样、冷调色、一帧一拍相机修复。

## 9. 制作配方(本仓库)

```
styles/brick-toy/demo/
  bricks.js   geometry + plastic materials        rockets.js  props, physics, fx
  actors.js   brick-built character rig            set.js      desk, HDRI, real props, moon
  story.js    timeline aligned to music bars        main.js     acting, cameras, subtitles, events
  lines.json  voice script    mix.py  foley+voice+music    music/edit.py  score edit
```

1. `node core/render/still.mjs styles/brick-toy/demo <t…>` —— 审查静帧,迭代。
2. `.venv/bin/python core/tts/tts.py lines.json voices` → `core/tts/asr_check.py` 验证。
3. `node core/render/events.mjs styles/brick-toy/demo` → `python music/edit.py` → `python mix.py`。
4. `node core/render/video.mjs styles/brick-toy/demo --fps 24`(1296 帧,2× SSAA + GTAO,M4 Pro 上约 65 s)。
5. `core/render/mux.sh out/video24.mp4 mix.wav brick-toy.mp4 24`。
