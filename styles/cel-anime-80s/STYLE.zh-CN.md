# 80 年代赛璐璐动画(80s Cel Anime)— 风格提示词

> 日本 OVA 黄金时代的手绘赛璐璐动画,用代码重现:喷笔背景上的平涂双色赛璐璐、逆光霓虹、有限动画节奏 —— 并以 1987 年录像带在 CRT 电视上播放的形式回放。
> Demo:*City Lights, 1987*(59 s)· `cel-anime-80s.mp4` · 源码在 `demo/`

你正在以**80 年代赛璐璐动画**风格执导一部 30–60 秒的影片。用户给你一个主题(也许还有故事)。其余一切由你决定(故事、镜头、节奏、音效)并交付一部完成的影片。遵循本指南。本风格*受 1980 年代日本赛璐璐动画启发*:借用那个时代的工艺,绝不借用具体作品的角色、机甲、logo、地名或标志性镜头。

---

## 1. 这个风格是什么

两层材料上下叠加,它们之间的反差就是本外观:

| 层 | 外观 | 我们如何制作 |
|---|---|---|
| **背景画** | 柔和、 painterly、喷笔渐变、发光的窗、湿润反射 | 加载时一次性画进大型离屏画布(颜色 + 自发光成对),之后每帧只*平移* |
| **赛璐璐**(角色、载具、道具) | 平涂填充、**硬边**阴影与高光形状、**彩色**轮廓线(皮肤用深棕、头发用深紫、蓝色夹克用深藏青,绝不用纯黑) | 每帧绘制的矢量路径,以 12 fps 或 8 fps 步进 |
| **光** | 逆光赛璐璐(透過光):霓虹、灯、标题字母*穿透*画面发光;镜头光斑、光晕 | 单独的自发光画布,喂给 bloom + 红色光晕 pass |
| **回放** | CRT 上的录像带:水平色度溢出、细扫描线、RGB 孔径荫罩、荧光辉光、压暗四角、微弱信号噪点;开头开机线、故事节拍处的跟踪噪声 | WebGL 后期 pass(逐帧确定);ffmpeg 里只留一丝噪点 |

如果一帧看起来像现代数字动画,你就丢了上表四行中的一行。

## 2. 故事:什么适合这个风格

选这个媒介最擅长讲的故事。80 年代赛璐璐有五项天生优势;至少用四项:

| 天生优势 | 故事用法 |
|---|---|
| **绘制城市 vs 平涂赛璐璐** | 夜城、雨、霓虹、日落、太空、黎明的海。把一个小小的平涂主角放进巨大的绘制世界。 |
| **有限动画** | *停住*的瞬间:定格的特写、高潮上的定格、跨一张大静画的摇移。静止是戏剧,不是省钱。 |
| **逆光** | 任何发光的东西:招牌、车灯、驾驶舱仪表、屏幕、激光、星星、标题卡。 |
| **速度语法** | 载具、追逐、飞行、竞速、变身:速度线、循环背景、冲击帧。 |
| **主题曲** | 一个属于 city pop、合成 funk 与动画 OP 的时代。一首歌可以成为剧情道具(一盘磁带、一次电台广播、一场演唱会)。 |

**45–60 s 情绪弧线:**带期限的冷开场 → 主角出发(标题重击)→ 欢快推进的蒙太奇 → 障碍 → 决定性的一动(高潮*定格*)→ 释放进新的光(夜变黎明、雨变晴空)→ 片尾卡。一个主角、一个目标、一个期限。

改编任何主题:把它变成**一次递送、一场与期限的赛跑或一次发射**。产品发布 → 信使载着产品穿越霓虹城市冲向舞台。爱情故事 → 两盏光穿越沉睡的城市。历史课 → 飞行员穿越被画成背景的各个时代。早早就植入目标(地平线上的火箭、钟楼),第二幕阻挡它,结尾在光中揭示它。

## 3. 视觉语言

**赛璐璐渲染(让它读作赛璐璐的规则):**
- 填充,然后**硬**阴影月牙,然后**硬**高光月牙,然后彩色轮廓线。赛璐璐形状内绝不用渐变(例外:高潮处一张单独的手绘"harmony"静画)。
- 自动阴影技巧:裁剪到形状内,用阴影色填充 `形状 − 形状向光侧平移` 的区域(even-odd 路径)。高光用远离光的小平移同理,霓虹**轮廓光**用高饱和色同理。这让你一行代码获得一致的双色着色。投射阴影(刘海投影额头、下巴投影脖子)另加手工阴影形状。
- 中景轮廓线在 1080p 下约 2–3 px;大特写全局线宽按比例下调(0.45–0.8×),否则线变成马克笔笔画。
- **按时段配色模型**(色指定):以日光色定义角色一次,然后分别乘亮部 / 阴影 / 线条颜色得到夜与黎明套装(夜:亮部 ×[.78,.74,1.0]、阴影 ×[.58,.52,.92];黎明:亮部 ×[1.04,.9,.84])。逆光剪影套装(带橙色轮廓光的深紫)用于对着天空的英勇时刻。
- **角色设计 —— 如何画一位 80 年代女主角(与现代萌系动画区分的规则):**
  - *构造*:颅骨球 + 下颌。长**蛋形**脸(比你以为的更窄,下面部略长),下巴是*软尖* —— 既不是 V 也不是 U。3/4 视角远侧眼睛透视缩短(约 0.6 宽),远侧脸颊轮廓呈现**颧骨转折**(眼下鼓起、再向嘴内收),鼻尖靠近远侧轮廓。脖子正常粗细、起于下巴之后;喉咙线起于下颌角之下。侧面:后颅小、干净的眉–鼻–唇–下巴线、小巧微翘的鼻、脖子前倾。
  - *比例*:眼睛位于头部(头顶到下巴)垂直中线附近,间距约一眼宽;嘴在鼻底到下巴的上三分之一处。
  - *眼睛*:杏仁形(内角低、外角上挑)、**厚上睫毛线**向外加厚并甩出 2–3 根分离睫毛、双眼皮线、**高椭圆形虹膜**分层为顶部暗带 → 上半暗 → 主色 → 下亮月牙、瞳孔、一大一小两个高光;下睫毛只在外角一笔微弱短线;细长眉。绝不用大虹膜的圆萌眼。
  - *鼻与嘴*:鼻子是一个小阴影面加底部一笔;嘴有唇形、带舌/齿的暗红口腔,以及一组口型(闭、抿、说、"哦"、喘、微笑、张嘴笑)加下唇一笔微弱线。腮红只有一层淡色 —— 不画排线腮红(那是 2000 年后的习气)。
  - *头发*:有厚度互相重叠的发束、束间有暗缝隙(一层比发束更宽的暗底);发尖长短不齐而锐利;2–3 根乱发;标志性**"天使环"高光** —— 一条跟随头颅曲线的连续带、下缘锯齿;逆光时轮廓光边缘。发束轮廓线要细、接近头发阴影色,否则头发变成一团乱线。
  - *彩色线稿*:皮肤用**细暖深棕**(≈ #5a2e2e)勾线,头发用深紫、睫毛/眉用近黑紫;只有硬道具(耳机、护目镜)保留近黑、略重的线。统一粗黑线读作现代矢量图。
  - *着色*:一个一致的光向:双色赛璐璐,刘海在额头投下浅阴影(跟随发束边缘、保持淡)、下巴投影脖子、远侧颧骨下与鼻侧有阴影面。当主光来自另一侧时,切换为近侧自动月牙加受光轮廓上的暖轮廓光。
  - *表演*:眨眼要快 —— 闭合画稿保持 2–3 帧(8 fps 一拍)。情绪住在眉(内侧向下 = 决意;外侧向下 = 疲惫/担忧)、上眼睑高度、虹膜大小(惊讶时小)与嘴角;辅以身体(喘气时耸肩)。
  - *夜色模型*:皮肤单独覆盖(中性亮 + 冷紫阴影);把日光皮肤乘蓝紫夜色会让整张脸在霓虹下发粉。
  - 先做**模型图**(3/4、侧面、正面 × 4 表情 + 头部特写)并批准后再把脸放进镜头;每个镜头都从同一个头部函数绘制。
- **调色板:**夜 = 靛 / 深紫 / 霓虹品红 / 青 / 暖窗金;黎明 = 长春花 / 玫瑰 / 桃 / 淡金。给主角一个在两者中都跳出的点缀色(demo 中:珊瑚围巾)。

**背景(绘制层):**
- 加载时构建每块背景板:天空渐变、喷笔云(模糊椭圆带受光下缘)、带窗格网的天际线塔楼、带亮橱窗的沿街立面、霓虹招牌(管状笔画 = 白芯 + 彩边)与墙上彩色泼洒。
- 永远配套画一块**自发光板**(只有光源),与颜色板一起平移;它喂给辉光 pass。
- **湿沥青**:沿街立面板(颜色与自发光)垂直翻转、模糊、拖影的副本,以水平波纹带压暗。这一个技巧就卖出"被雨浸透的霓虹城市"。
- 招牌文字:只用通用词(BAR、CAFE、喫茶、ホテル、カラオケ…),绝不用真实品牌。
- 移动背景加轻微水平涂抹(约 16 px)—— 足以柔化频闪,又不像照片。

**光与镜头:**
- 逆光赛璐璐:招牌、灯、仪表、标题字母也画在自发光画布上。自发光画布的 bloom 要强;颜色画布的 bloom 只在高阈值(0.9)之上且弱,否则白色赛璐璐被洗掉。
- 光晕:最宽的 bloom 层染成红橙色,叠加在上。
- 镜头光斑:星芒、一条长的水平变形宽银幕条纹、沿过画面中心直线排布的六边形鬼影。用在车灯、太阳、眼中的闪光上。
- **遮挡辉光**:当赛璐璐走到亮背景之前,把它的剪影以黑色盖到自发光画布上,否则霓虹 bloom 会透过角色溢出。

**录像带 + CRT 回放(克制):**设定是"一盘 1987 年的 OVA 录像带,在 CRT 上观看"。在后期 shader 中逐帧且确定地:
- *色度溢出*:转 Y/Cb/Cr,保持亮度锐利,水平方框模糊色度(1080p 下约 7 px),红差通道右移约 2 px。
- *扫描线*:3 px 周期、强度约 0.18、余弦轮廓;亮像素上暗缝收窄(`1 − a·ph·(1 − 0.6·L)`)。锚定到输出像素而非图像,画面跳动时它们不动。
- *RGB 孔径荫罩*:竖直 R/G/B 条纹,±0.06。
- *荧光辉光*:亮区加宽模糊(约 0.35)。
- *四角*:压暗(`1 − 0.28·(2u²v² + 0.25(u²+v²))`);不做曲屏黑边。
- *噪点*:shader 内每像素微弱信号噪;ffmpeg 只用 `noise=c0s=2:allf=t`(CRT 纹理已经费码率 —— 保持 CRF ≈ 23 以贴近每分钟 30 MB)。
- *字幕在磁带上*:在 shader 内、调色之后扫描线/荫罩之前合成,让它们获得同样的电视质感而不被调色。
- *两处点睛*:第一帧**开机**(一个点拉成亮横线、再纵向展开,约 0.6 s,带一声小"咚"+ 行啸声),以及涉及磁带的故事节拍处 6–10 帧**跟踪噪声**(逐行水平撕裂、一条滚动的噪声带、一次垂直跳变、底部磁头切换条,混音里配短促嘶声/颤声)。
- 移除胶片专属瑕疵(走片抖动、灰尘、划痕、套色偏移);它们与录像带设定矛盾。
- *摩尔纹检查*:导出一帧,降到 1280×720 检查。3 px 正弦扫描线在 720p 成为干净的 2 行交替(无拍频);900p 显 5 行淡纹;480p 以下消失。

**画幅:**完整 16:9,当作剧场正片对待。(4:3 竖桶装对 OVA 质感成立但浪费展示。)

## 4. 运动语言

- **角色以 12 fps 迈步(二帧一拍)**;表演节拍(眨眼、睁眼、拧油门、口型)按 **8 fps(三帧一拍)**步进。相机摇移、光扫、光斑与雨按一帧一拍(24 fps)。相机步进读作颠簸。
- **循环**用于次级运动:头发与围巾是由行进正弦驱动的缎带,4 张循环(风平浪静时 6 张)。载具颠簸 = 少量 px 的 12 fps 随机抖动。
- **移动光,而非画稿**:一张定格赛璐璐上有彩色光带扫过(在赛璐璐层 `source-atop` 合成)是让特写显得最快的最便宜方法。
- **冲击帧**:命中瞬间 2 帧(1/12 s)的反转或单色剪影叠在放射线上,然后切到结果。
- **定格高潮**:最大的瞬间是一张手绘静画("harmony"赛璐璐),缓慢摇移,只有循环在动。
- **口型**:台词播放时 3–4 个口型以 8 fps 循环;以定格表情收尾。
- 眼睛:眨眼/睁开三张画稿(0.3 → 0.72 → 1.0 睁),然后为决心收窄上眼睑。音乐重音上高光里一颗星芒。

## 5. 镜头语言

| 节拍 | 镜头 |
|---|---|
| 冷开场 | 在一块高绘板上的**多层起重机下降**(天空 → 屋顶 → 霓虹 → 街道),前景层更快 |
| 重要的物 | 手持物的紧凑特写,身后柔景深,一道高光滑过它的塑料 |
| 决意 | 眼睛大特写,说台词时睁眼 |
| 标题 | 逆光标题卡,字母以 12 fps 闪烁点亮,一道光条扫过,星芒 |
| 推进 | 带视差的 3–4 层侧向跟踪 + 尾灯拖尾;后视冲进霓虹峡谷(伪 3D);带光带的定格半身;机械特写(车轮、仪表);**植入目标**的广角建置镜头 |
| 障碍 | 第一人称逼近障碍;手与仪表大特写,切换加速 |
| 高潮 | 放射速度线上的低前视 → 一拍定格 + 白闪 → 冲击帧 → 缓慢摇移的手绘静画 → 冲击帧 → 带相机抖动的着陆 |
| 释放 | 与夜驰相同的侧向跟踪构图,重绘为天空敞亮的黎明 |
| 结尾 | 回应开场台词的温暖特写,然后片尾卡 |

按小节切。让字幕避开重要动作的底部 120 px。

## 6. 声音

- **音乐**:原创 city pop / 合成 funk"动画 OP"最合适(我们用 numpy 合成了一首 —— 见 `demo/music/score.py`):110–120 BPM、带 maj7/9 和弦的大调、J-pop"王道进行"(IVM7–V7–iii7–vi7)、FM 电钢(DX7 式 1:1 载波 + 14:1 铃音瞬态)、 slap 贝司(拇指 + 八度弹击)、门限混响军鼓、合成铜管切分、合唱感十六分吉他 chank、弦乐 pad、可跟唱的主旋律钩子、FM 铃光,以及最后一段副歌**升半音转调**。
- **为剪辑写谱**:冷开场下是 intro、留出引擎轰鸣空间的一小节 fill、铜管重击上的标题、蒙太奇下的主歌、预副歌推进、高潮前**一拍真静默**、高潮上的副歌、着陆上的重音、片尾卡上的最终和弦。
- **叙事内反转**:若故事有歌曲道具(磁带、收音机),它"播放"的那一小节把配乐带通成磁带/AM 声,随后随转调打开到全频。
- **拟音**(全部合成):引擎来自 RPM 曲线(谐波锯齿堆 + 点火抖动 + 带通排气脉冲,腾空时低通)、雨铺底 + 随机雨滴、湿路胎嘶、风、铃声、无线电静噪咔哒、撞击闷响、金属刮擦与火花、磁带咔哒、按钮 + 马达、火箭点火与咆哮。
- **人声**:英语配音感 —— 年轻女主角(Kokoro `af_bella`)与无线电调度(Kokoro `am_michael` 过带通 380–2800 Hz + 饱和 + 静噪)。6–8 句短句。用 whisper 验证每一句,改写它听错的(我们把 "Launch is at dawn" 改成 "The launch is at dawn")。
- **混音**:先限幅再压缩 TTS,按 RMS 让人声比压低的音乐高约 10 dB,台词下音乐压约 9 dB,引擎与环境压 3 dB,副歌比 intro 响 4–6 dB,两遍 loudnorm 到 −14 LUFS。

## 7. 字幕与标题

- 字幕是磁带的一部分:画在离屏画布上、在 CRT pass 内合成(获得扫描线但不调色)。半窄无衬线(Barlow Semi Condensed 600、54 px),奶油黄 `#fff0a0` 带 9 px 深色描边与软阴影,底部上方 96 px。无线电台词用青色 `#8ff4ff` 带小框 "● BASE" 标签。一行停留 max(时长 + 0.6 s, 1.9 s),下一行开始时让位。
- 标题卡:粗斜体拉丁标题带**铬渐变**(天蓝 → 白色地平线 → 紫 → 粉 → 金)、厚深描边 + 霓虹描边、上方片假名行(Dela Gothic One)、红色年份、宽字距标语;透过自发光层发光;闪烁点亮与光扫。
- 片尾卡:压暗的最终背景、标题、风格名 "80s Cel Anime"、"LemoLab × Claude Opus 5.5"、一行原创性说明与致谢。

## 8. 我们踩过的坑

- **白色赛璐璐的 bloom**:颜色画布上的阈值 bloom 把白色摩托与夹克变粉。修复:bloom 主要来自自发光画布;颜色画布阈值 0.9 且弱。
- **霓虹透过角色**:自发光板在赛璐璐之后但没有深度。把每张赛璐璐的剪影以黑盖到自发光画布上。
- **车灯里的黑洞**:S 曲线 `c*c*(3-2c)` 在 1.0 以上归零 —— 色调曲线前先 clamp。
- **轮廓光过厚**:偏移月牙须 2–4 px,不是 6–8,否则细发带完全变粉。
- **像触手的头发**:均匀变细、圆头的缎带读作触手。用宽而重叠、尖头的发束,中间夹更暗的一束,后面垫实心发体。
- **刘海盖眼**:发尖保持在上睫毛线之上,双眼之间只留一束。
- **正脸是最难的画**:把骑手藏进着色风挡后,只露护目镜与头发,让车灯光斑扛起镜头。
- **相机身后的伪 3D**:z < 近平面的点向上翻进天空。clamp z。
- **火箭飞出画面**:用延迟的俯仰与更慢(二次)爬升跟随它。
- **字体**:画板前先用 `document.fonts.load` 加载要用的每个字重,否则画布悄悄回退到衬线体。
- **ffmpeg 里的颗粒让文件巨大**:CRF 22 下 luma 4 + chroma 1 约 32 MB/分钟;CRF 18 下 luma 5 + chroma 2 是 270 MB。
- **单遍 loudnorm** 落在 −13.5 LUFS;两遍且 `linear=true` 落在 −14.0。
- **动态**:过热的限幅器把副歌压到与 intro 一样响。按 99.99 百分位归一化,只让罕见峰值撞限幅器。

- **像纸面具的脸**(第一版):3/4 身体配一张拍扁的正脸 —— 双眼等大、无颧骨转折、V 下巴、细长脖。以构造头部(球 + 颌)、透视缩短远眼、画出正确的远侧轮廓修复。
- **80 年代影片里的萌眼**:大虹膜圆眼加排线腮红立刻把画稿日期标到 2000 年代。用杏仁眼、带甩尾的厚睫毛线、淡腮红。
- **统一黑线**让赛璐璐像矢量剪贴画;彩色、更细的皮肤线修复它。
- **夜里的粉脸**:皮肤乘夜色再加品红轮廓光与粉光扫,把脸洗成粉。给皮肤自己的夜色套装,脸上粉光扫更弱。
- **额头补丁**:刘海束间的缝隙露出硬阴影形状;加宽暗底、调浅额头阴影。
- **CRT 下的文件体积**:扫描线 + 荫罩添加细节;CRF 22 超过 35 MB/分钟,CRF 23 加 luma-only noise 2 落在约 31 MB。

## 9. 制作配方(本仓库)

```
styles/cel-anime-80s/demo/
  cel.js     path / cel / ribbon / flutter helpers      pal.js   color models (day → night / dawn / backlit)
  rider.js   side-view bike + rider, limbs, wheels      head80.js  80s heroine head: 3 views × expressions, body/collar/scarf
  hands.js   pinch-grip gloves                          bg.js    painted plates (street, skyline, tall crane plates, reflections)
  fx.js      rain, splashes, speed lines, flares, lamps, light trails
  post.js    WebGL videotape + CRT pass (bloom, grade, chroma bleed, subtitles, scanlines, grille, glow, power-on, tracking noise)
  shots.js + scenes1–4.js   one function per shot     story.js  bar-aligned timeline, lines, credits
  hud.js     VHS-style subtitles     main.js  plates, shot dispatch, sound events
  lines.json voices   mix.py   music/score.py (original score)   tools/ (still, sheet, srt, mux)
```

1. 剧本大纲 → `story.js`(116 BPM 小节网格、镜头、台词)。
2. `node styles/cel-anime-80s/demo/tools/still.mjs styles/cel-anime-80s/demo --range 0.5:58.5:1 --out /tmp/cs` → `tools/sheet.py` 联络表 → 查看 → 修复。`?test=model|close|side` 渲染模型图 / 头部特写 / 骑手;`?raw=1` 绕过 CRT pass;`?nosub=1` 隐藏字幕。
3. `.venv/bin/python core/tts/tts.py demo/lines.json demo/voices` → `core/tts/asr_check.py`。
4. `.venv/bin/python demo/music/score.py`(配乐 + 分轨 + 提示时间)。
5. `node core/render/events.mjs demo` → `.venv/bin/python demo/mix.py`。
6. `node core/render/video.mjs demo --fps 24 --workers 4 --out demo/out/video24.mp4`(1416 帧,M 系 Mac 上约 36 s)。
7. `sh demo/tools/mux.sh demo/out/video24.mp4 demo/mix.wav cel-anime-80s.mp4 24`,`python demo/tools/srt.py`。
