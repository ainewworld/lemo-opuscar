# 蜡笔儿童绘本(Crayon Picture Book)— 风格提示词

> 一本在纹理纸上现场画出的睡前绘本:蜡笔作画,加一层水彩晕染,揭开出蜡笔一直藏着的东西。
> Demo:*The Moon Can't Sleep*(52 秒)· `crayon-book.mp4` · 源码在 `demo/`

你正在以**蜡笔儿童绘本(Crayon Picture Book)**风格执导一部 30–60 秒的短片。用户给你一个主题。其余一切都由你决定——故事、镜头、节奏、声音——并交付一部完成的影片。遵循本指南。

---

## 1. 这个风格是什么

一页**在你眼前被现场画出来**的儿童绘本:蜡笔画在温暖的米白色绘图纸上,一盒有限的蜡笔,儿童逻辑的透视,颜色溢出轮廓线,而且每条线都在轻轻**boiling(沸腾抖动)**,因为每一帧都是一幅全新的画。基调是睡前故事:温柔、缓慢、由音乐主导,配几行旁白——它们就是印在书页上的文字。

它不是"加了蜡笔滤镜的可爱矢量图"。这个外观来自**材料物理**:蜡只附着在纸张纹理的凸峰上,压力决定它触及多少纹理,水彩会被蜡排斥。仅供参考语法的参考:Raymond Briggs 的《雪人》(1982)——会呼吸的手绘纹理帧、无言的温柔、一段由一首歌贯穿全片的抒情段落、夜晚坐在亮灯窗边的孩子。绝不复制其中的角色、歌曲或图像。

## 2. 故事:什么适合这个风格

选择**画画和上色这个行为本身就是剧情**的故事。蜡笔 + 水彩有六种原生能力——至少用三种,并把最强的一种放在情感高潮:

| 原生能力 | 故事用法 |
|---|---|
| **蜡阻隔(wax resist)**——白蜡笔在白纸上看不见,直到刷上一层水彩 | 揭示。从第一帧起就把回报藏在明处(星星、一句话、一条路、一个藏起来的朋友),让一次水彩扫过在高潮处揭开它。 |
| **现场画**——线条一笔一笔出现,颜色涂鸦式填入 | 从空白页开场。世界在主角前方"自己画出来"帮助她(一个在她手下长出横档的梯子、一座桥、一条路)。 |
| **上色即动作** | 角色"做出"某件事的方式是被涂上色:拉起毯子 = 在月亮上涂鸦一床被子;脸红 = 粉色涂鸦;夜幕降临 = 一层水彩。 |
| **沸腾抖动(boil)** | 即使是静止帧也是活的。故事进入睡眠时把抖动减弱(一半振幅)。 |
| **儿童逻辑** | 错误的透视、月亮上有脸、数羊时把数字写在天上。孩子会画出来的东西都允许发生。 |
| **它是一本书** | 结尾拉回到桌上那本实体书,蜡笔放在旁边;翻页到"完"。一页一镜到底的影片由此揭示得到解释。 |

适配任何主题:把它变成**一页被画完的绘本**。产品发布 → 产品先画轮廓、上色,水彩揭开隐藏功能。历史课 → 一页事件逐一上色。感谢影片 → 用白蜡笔写下名字,由水彩揭开。

**45–55 秒的弧线:** 空白页 → 一个角色被画出并醒来(3 秒内出钩子)→ 一个小小的喜剧问题 → 第二个角色 → 一个小小的勇敢举动 → 歌声中水彩揭示(高潮,无旁白)→ 所有人入睡 / 收束 → 拉回到书,翻页。

## 3. 视觉语言

- **纸张**:温暖米白 `#f4efe3`。纸张纹理**锚定在页面上**(随镜头平移;缩放时两个八度交叉淡变,让颗粒在屏幕上保持约 1 px)——绝不固定在屏幕上。程序化纹理高度场:三个八度的值噪声,频率 1.35 / 2.9 / 6.3 px,加一个水平纤维项(x/10, y/1.9),对比度 `smoothstep(.16,.86)`。最后一遍给纸张做浮雕(左上打光,强度约 0.55),蜡已填满纹理处减弱。低频斑驳 ±2%。暖色暗角。
- **蜡附着(核心规则)**:每一层蜡笔都是一个 Canvas2D,RGB = 蜡笔颜色,**A = 压力**。着色器在 `tooth > 1 − 1.22·pressure` 处沉积蜡(软边缘 ±0.07)。轻压力 = 只有凸峰(斑点状);重压力 = 接近实心。更重的蜡也让颜色略微变深(×(1−0.1·p²))。
- **笔触**:轮廓是带手抖的条带(低频法向偏移约 1.7 px),宽度变化 ±15%,两端渐细,笔触内有更密的内芯和 1–2 条细条纹。轮廓宽度:角色约 7 px,建筑 8 px,精细的"大人"物件 4–5 px。
- **上色**:来回之字形排线,间距约 10.5 px,宽约 11 px,每一遍压力略有不同(0.72–1.14×)让单笔可辨;**越出轮廓 0–7 px**(孩子会涂出线);大面积第二遍交叉排线,压力 40–50%。
- **调色板**(12 支蜡笔,绝不多用):墨靛 `#2d3263`(所有轮廓——绝不用黑)、黄 `#f5c63c`、橙 `#ec8a3c`、红 `#d4483c`、粉 `#ee8ea4`、桃 `#f4c7a4`、棕 `#7a4b31`、赭 `#e7b867`、绿 `#62a24c`、天蓝 `#79acd9`、紫 `#6a5aa6`、白 `#fbfaf4`(蜡阻隔)。一种水彩:群青,透射 `(0.15, 0.19, 0.44)`。
- **水彩晕染**:单独的密度画布,正片叠底在页面上。颜料在边缘汇聚(密度 − mip 模糊后的密度 → 更深的边缘),在最深的纹理凹坑中颗粒化,随低频噪声扩散,并且**被蜡排斥**:`density × (1 − 0.93·smoothstep(.12,.55, waxCoverage))`。笔触是带鬃毛条纹的宽条带(沿笔触更暗/更亮的线),运动中的湿润前沿更暗。
- **遮挡**:前面的部件在其轮廓内擦除后面部件的线和颜色,角色身后"保持纸白"(一个恢复纸张并把蜡重置为 0 的挖空通道),就像孩子先画人物、再在周围涂背景。
- **角色**:一个模仿孩子画法的熟练大人:圆头(约 2.6 头高),点状眼睛带白蜡高光,粉色圆脸蛋,简单的管状四肢加连指手,大胆的发型带扇贝形刘海。一个呼应故事的颜色点缀(她的黄色星星发夹 = 星星)。有脸的物件(月亮)有大而可读的眼睛、眼睑、眼袋。
- **儿童透视**:山墙正面 + 倾斜侧墙 + 一个大屋顶面;人比门大;一棵带红点的圆树。

## 4. 动效语言

- **所有绘制内容以 12 fps 步进**(on twos,一拍二):角色、线条、上色、沸腾种子。镜头运动、水彩前沿和星星闪烁以 24 fps 运行。
- **沸腾抖动**:每 2 帧重新抖动每个笔触的整体偏移(±0.8 px)、抖动(±0.9 px)和排线行。角色 ×1;背景*线条* ×0.6;背景*上色*不抖动(一幅静止的背景配上活着的角色,如同《雪人》——而且它把码率减半)。角色入睡后,×0.5。
- **画上**:线条沿长度揭示(`draw` 0→1)用 0.4–0.9 秒;上色逐行揭示。文字逐字母写出,0.35 秒。
- **表演**:替换动画——每个姿势一张新画(翻身的节拍上一个拧紧的脸旋转 35°)。攀爬时每根横档交替两张关键画。保持姿势大而简单;孩子的画不做中间帧。
- **睡眠语法**:眼睑以黄色涂鸦落下,画上一顶睡帽,被子从下往上涂色、折边先出现,一只小手把它掖好。

## 5. 镜头语言

影片是**一页上的一镜到底**(世界 3200×1800;整页 = 缩放 0.6)。每次移动都需要理由:

| 节拍 | 镜头 |
|---|---|
| 开场 | 锁定整页,平拍:在任何东西被画出之前,观众必须先看到纸 |
| 标题退场 | 向角色推进而不是让标题淡出(蜡笔没法淡出) |
| 喜剧节拍 | 锁定中近景;让替换姿势制造笑点 |
| 发现 | 沿角色视线倾斜(镜头*就是*俯视的月亮) |
| 双人镜头 | 一个角色从画面边缘探头,另一个小小地在亮灯的窗里 |
| 勇敢举动 | 紧跟倾斜;世界在主角前方自己画出来 |
| 水彩揭示 | **保持远景。**让画笔和音乐制造动感。小小的人,巨大的天空 |
| 收束 | 缓慢推近入睡的脸,再摇向第二个睡着的人 |
| 结尾 | 拉远直到页面变成桌上一本书;翻页;滑向"完" |

## 6. 声音

- **音乐优先,3/4 拍,72 BPM**(小节 = 2.5 秒)。八音盒(主奏,机械簧片),玩具钢琴(喜剧圆舞曲,每只羊 / 每根横档一个音),长笛作歌声(乐器替代人声),单簧管负责低音和幽默,钟琴为水彩揭开的每颗星星。不用弦乐,不用大钢琴。摇篮曲主题完整出现恰好一次,在水彩处;开场的八音盒动机是它的第一句。结尾八音盒**渐渐停下**(渐慢 + 轻微音高下垂)。
- **静默**:数羊失败后整整一拍静默;歌声前 0.3 秒呼吸。
- **拟音跟随材料**:蜡笔 = 颗粒率跟随笔速的粘滑带通噪声(上色 = 有节奏的来回沙沙声);湿笔刷 = 柔和低通宽带加细鬃毛颗粒,随笔触声像移动;羊落地 = 毛毡噗声;翻身 = 毯子窸窣;翻页 = 抬起 / 嗖 / 啪。夜晚 = 极轻的蟋蟀;书桌 = 温暖的房间底噪和远处的钟。
- **混音**:音乐在旁白下 −7 dB,无词歌声处 +4 dB;八音盒和钟琴分轨 +3 dB,并在 3–7 kHz 轻微提升,让金属在长笛和单簧管上闪光。
- **人声**:温柔温暖的睡前讲述者(Kokoro `af_heart`,语速 0.86–0.90;v3 重配音——`bf_emma` 读得太亮太硬),6–8 句短句,句间有呼吸。链路:高通 75 Hz → **先压缩**(阈值 0.2,2.5:1,8 ms / 140 ms)→ 低搁架 +1.5 dB @220 Hz,−2 dB 下陷 @3.2 kHz,**高搁架 −4 dB @6 kHz** → 分频齿音消除器(4.8–10 kHz,4:1)→ 逐句 RMS 匹配 → 温暖近场混响(12 ms 预延迟,早反射,0.7 秒低通尾,湿声约 −17 dB)。人声下音乐闪避约 7 dB、拟音约 4 dB;人声位于底垫之上约 7–10 dB,绝不超过。用 whisper 逐句核验——干声*和*从成品混音中切出。避免名著短语("Goodnight, Moon"——用"Night, night.")。

## 7. 字幕与标题

- 字幕就是**书页上印的文字**:Patrick Hand(OFL)54 px,靛蓝蜡笔色,底部居中,每个字形带自己的小倾斜和基线偏移,以一拍二沸腾,从左到右 0.35 秒写出。字幕后面是一块粗糙的空白纸面(挖空,不是暗色框),像孩子为文字留了位置。停留 ≥1.8 秒且 ≥ 人声 + 0.6 秒;歌声期间不出现。
- 标题:手写体写在页面上(Gaegu Bold)两行,放在角落,在颜色涂鸦填入时逐字母写出。
- 片尾卡:书的下一页——"The End"(Gaegu Bold),一个小的月牙涂鸦,风格名和署名用 Patrick Hand。

## 8. 我们踩过的坑

- **晕染条带之间的白缝**和停在地面以上的天空:晕染条带必须重叠,最后一条必须一直下到草线;有纸的地方就有天空。
- **低频波浪状条带边缘在天空中看起来像山**。保持条带边缘的波浪小而高频。
- **宽而亮的鬃毛条纹**也像山丘;保持较亮的条纹细而淡(α ≤ 0.12)。
- **轻压力上色的墙在水彩下变脏蓝**(水彩渗进每个缝隙)。任何会被水彩扫过的地方需要更重的压力(≥0.8)或交叉排线。
- **写在天空里的标题和数字能挺过水彩**(蜡排斥水彩!)。把标题放在大远景不会显示的角落,或接受它成为页面的一部分。
- **画在头发上的轮廓线读起来像发带**:只勾勒脸部可见部分;头发块只在外缘勾勒。
- **画成扁平紫色一半的毯子看起来像月亮的暗面。**给它被子特征:拼布方块、缝线、星星贴布、一条向内翻折的亮边、垂出圆盘的裙边,和一只把它拉起来的手。
- **挖空层画入普通层时必须用哑元画布**,否则黑色蒙版会被画成灰色蜡笔。
- **用矩形条带翻页**会显示阶梯状的页边;用仿射变换映射每条条带,让上下边缘保持连续。
- **书桌转场处的双重暗角/浮雕**:以暗角 0 渲染页面纹理,书桌的暗角、浮雕和灯光从 0 渐入。
- **屏幕固定的纸张纹理让影片膨胀到 190 MB**(镜头一动每个像素都变)。把纹理锚定到页面,背景填色不沸腾,不加额外 ffmpeg 颗粒,CRF 26 → 74 MB 无可见损失。
- **女主角消失在夜里**,因为水彩渗进了她上色的缝隙。把故事需要看清的角色在水彩*之后*合成。
- **用单位方差噪声构建的混响 IR** 响得吓人(能量 = 衰减·采样率)。缩放 IR,让湿声位于干声人声之下约 18 dB。

## 9. 制作配方(本仓库)

```
styles/crayon-book/demo/
  gl.js      WebGL2 compositor: paper, wax adhesion, knock-out, watercolour + resist, image pass, final emboss/vignette/lamp
  crayon.js  stroke engine: line (ribbons, taper, streaks, boil), fill (zig-zag hatching, overshoot), text, shapes
  rig.js     parts with occlusion + knock-out, limb tubes, curves
  chars.js   the girl (views × expressions × poses), the sheep, the moon (expressions, nightcap, quilt, crescent face)
  world.js   the page: house, tree, grass, ladder, 250 white-wax stars, 3 wash bands
  film.js    timeline, one-take camera, events, subtitles     end.js  book on a crayon desk, page turn, The End
  sheet.js   model sheets (?test=model&page=girl|moon)        lines.json, mix.py, music/score.py, build.sh
```

1. `node core/render/still.mjs styles/crayon-book/demo 0.5 --q 'test=model&page=girl'`——先出模型表;在任何镜头前迭代角色。
2. `core/tts/tts.py lines.json voices` → `asr_check.py` 直到全部 OK。
3. 在 `film.js` 中构建时间线;用 `still.mjs --range 0.5:51.5:1` + `sheet.py` 审查(至少两轮)。
4. `node core/render/events.mjs` → `music/score.py`(提示点落在 72 BPM 网格上,钟琴来自 `glint` 事件)→ `mix.py`。
5. `node core/render/video.mjs styles/crayon-book/demo --fps 24 --workers 3`(1248 帧,在 M 系列 Mac 上约 80 秒)。
6. `CRF=26 sh demo/tools/mux.sh out/video24.mp4 mix.wav crayon-book.mp4 24 0`——不加颗粒(纸就是颗粒);本地 mux 拷贝暴露 CRF。`demo/build.sh` 运行从 TTS 到成片的整条链。
