# 暗色科技发布(Dark Tech Keynote)— 风格提示词

> 一部以界面本身为主角的软件发布影片:近黑渐变、发丝级网格、柔和光线、单一品牌强调色,以及按吸附网格精度移动的 UI。产品由一次扫光揭示,它的承诺是一个巨大的数字,声音设计字面意义上会把自己"收拾整齐"。
> Demo:*Room to Think*(42 秒)· `dark-keynote.mp4` · 源码在 `demo/` · 为 **Tidy**(一个一键整理桌面、照片和收件箱的虚构应用)拍摄的发布影片。
> **参考(仅语法):** Apple 产品揭示影片(第一代 Apple Watch 和 AirPods 发布)——黑色舞台、扫光揭示、一屏一句、孤立的大数字;Linear / Stripe / Vercel 的发布视频——精确的吸附网格 UI 动效、1 px 线条、柔光和单一强调色;Steve Reich 的《Piano Phase》与《Music for 18 Musicians》——配乐的相位与减法进程;Edgar Wright 的插入剪辑——半秒过载蒙太奇。绝不使用它们的名字、界面、字体、系统控件、旋律或标志。

你正在以**暗色科技发布(Dark Tech Keynote)**风格执导一部 30–45 秒的发布影片。用户给你一个主题(一个产品、一个功能、一次发布)。其余一切(故事、镜头、声音、音乐、字幕)由你决定,并交付一部完成的影片。遵循本指南。

---

## 1. 这个风格是什么

一部**软件**的发布会级产品影片。没有实体产品、没有玻璃渲染:主角是界面——一个光标、窗口、通知、磁贴、一个数字。它活在暗色舞台上(`#0A0B0F → #151822`),由柔和的冷光照明,保留一个品牌强调色只给最重要的那一个元素。

这个风格由**精确**定义。每个元素吸附到网格,每个动效落在节拍上,每个声音属于同一个设计好的声音家族。戏剧性来自对比:问题被表现为失控的 UI 噪声,然后一个动作把每个像素放回原位,然后是一次留白的呼吸。

## 2. 故事:什么适合这个风格

| 原生能力 | 故事用法 |
|---|---|
| **UI 可以无限生成** | 把问题表现为堆积:通知、文件、标签页和照片越冒越快,数以百计。你不是画乱,你是*生成*乱。 |
| **吸附网格** | 整个产品承诺可以是一个动作:所有东西在一拍内飞进网格。那一刻之前网格保持隐形。 |
| **光标是屏幕上唯一活物** | 让光标当主角。它按节拍闪烁,被打断时被撞,犹豫,蓄力,按下。也让它成为品牌标记,这样揭示有两次回报。 |
| **屏幕可以暂停** | 把一切冻结在半空,声音切成数字静默。只有屏幕能让时间这样停止。 |
| **暗色舞台 + 柔光** | 用一条光带扫过产品来揭示:只有光经过的像素点亮。 |
| **数字从字形噪声中滚出** | 那个唯一的统计数字有自己的整屏,一个数字一个十六分音符地乱序锁入。 |

**故事形状(已在 demo 中验证):** 平静的钩子(光标在静默中打出标题)→ 打断(3 秒时第一条通知)→ 一镜到底的持续拉远中堆积(每小节加一层)→ 过载插入 → **冻结 + 静默** → **那一个动作**(所有层重新对齐成一个和弦)→ 产品的扫光揭示 → 大数字 → 一次呼吸中 UI 自己收好、音乐自我减去 → 回声(光标写完它开头那句话)。

**核心导演思路——声音和画面共享一条时间线。** 在 demo 中,每个 UI 元素都*踩在*配乐的一个音符上出现。两台马林巴演奏同一个 12 音模式;第二台慢慢加速并漂出相位。文件和照片出现在对齐网格的那条线上,通知出现在漂移的那条线上,于是视觉混乱*就是*可听的相位差。按下的一刻两条线重新对齐成一个和弦。适配任何主题:先写音符表(`timeline.js`),再让画面去读它。

适配任何主题:挑出你的产品做的那个动词(sort、sync、ship、search、protect)。把它的缺席表现为与相位化或堆积式配乐绑定的生成 UI 噪声。把动作交给光标(或产品最小的活元素)。用光揭示。一个数字。把一切收好。在空屏幕上以最小的东西结束。

## 3. 视觉语言

**舞台**:底色 `#0A0B0F`,上部中心径向提亮到 `#151822`,右上一个大的冷光晕 `#3B4CCA` 8 %,角落暗角 50–55 %。发丝网格 `rgba(255,255,255,.032)` 每 48 px,每第 4 条线为 `.06`。颗粒:无(`mux.sh` grain 0)。

**调色板**
| 角色 | 数值 |
|---|---|
| 窗口表面 / 凸起 / 凸起-2 | `#12151C` / `#1A1E28` / `#222734` |
| 边框 / 内部顶部高光 | `rgba(255,255,255,.08)` / `rgba(255,255,255,.07)`(1 px) |
| 文字 / 次级 / 标签 | `#E8EAF0` / `#8A90A0` / `#5C6272` |
| **品牌强调色(唯一的颜色)** | 莱姆绿 `#B7F34A`,光晕 `rgba(183,243,74,.35)`——光标、"Tidy up" 药丸、对勾、"0.8" |
| 噪声红(仅问题段) | `#FF5A5F` 角标。按下之后红色永不再现:红是噪声,强调色是产品 |
| 三种流动色(坍缩拖尾) | 文件 `#C9D3E6`、照片 `#F2A65A`、通知 `#7E95FF` |

**UI 套件(全部原创,代码绘制)**:窗口(圆角 14,40 px 标题栏,只有小应用图标和标题,绝无红绿灯按钮、菜单栏或 Dock)、通知卡片(圆角约为高度的 24 %,图标方圆形,两行,"now")、折角文件图标带彩色扩展名条带和等宽文件名(`final_FINAL_2.pdf`、`Untitled 38.txt`)、程序化风景照缩略图、带未读点的收件箱行、不断分裂的标签条、红色计数角标、存储条、统一吸附磁贴(60–64 px,圆角 20 %)。

**字体(OFL)**:Inter(UI、字幕、大标题;可变字重),Inter Tight 600 用于巨号数字(字距 −4.5 %),JetBrains Mono 用于标签、文件名和状态文字(小型大写标签字距最高 5 px)。

**深度**:2.5D 相机(`s = 1/(1/zoom − z)`)给出真实视差。靠近镜头的卡片按放大倍率成正比模糊。产品镜头用条带渲染透视(rotY 最高 24°)。

## 4. 动效语言

- **一切落在网格上、落在节拍上。**移动提前一拍开始、正落在拍上。缓动是快出加一个小回弹(`back`,s ≈ 1.3)随即落定。不要漂浮的正弦漂移。
- **出现动效**(混乱段):文件掉落 34 px 加 6 px 弹跳(0.22 s),照片从屏外甩入带旋转(0.3 s),通知从右侧滑入 90 px(0.24 s),窗口弹出 0.94 → 1.0(0.22 s)。冻结前最后一秒一切抖动 ±2.4 px。
- **大坍缩(标志性动作)**:一个环从光标处以 2600 px/s 扩散。环锋经过时,每个元素**朝自己类型的行**发射(文件 → Desktop 行,照片 → Photos 行,通知 → Inbox 行),沿曲线路径;每种类型弯曲方向一致,于是屏幕上呈现**三条彩色流**。同一组内,行按元素的 y 序和 x 序填充,路径不交叉。飞行持续 0.26–0.40 s(视距离而定),在前三分之一变形为统一磁贴,沿最终切线过冲后落定。流动色光尾,9 段,加法混合。网格槽位轮廓在环锋身后以强调色点亮。
- **光标表演**:眨眼 = 0.5 s 亮 / 0.5 s 灭(它是节拍器)。被打断:8 px 推撞 + 10 % 压扁,0.25 s 衰减摇晃,然后保持实心("冻结")。蓄力:高 ×1.35,宽 ×0.8,12 帧缓入(≥ 8)。按下:2 帧高 ×0.3,宽 ×2.4。跟随:0.6 s 内带回弹的弹回。
- **扫光揭示**:亮区滞后锋面 700 px,一个 360 px 柔和闪光以 20 % 骑在锋上,未亮区保持 7 %。耗时 1.3 秒。不要让产品的主要内容在黑暗中超过这个时长。
- **数字乱序**:字形以 24 fps 循环并带 3 份拷贝的垂直拖影;数字按十六分音符从右到左锁定,每个带着小阻尼弹跳落入。
- **收纳**:每拍收回一个元素(侧栏、状态栏、标题栏、表头),然后窗口边缘亮起强调色,然后窗口像 CRT 关机一样垂直坍缩(缓入,0.22 s)缩进光标。

## 5. 镜头语言

| 节拍 | 镜头 |
|---|---|
| 钩子 | 锁定光标和一行文字的极特写(文字约 150 px)。几乎不可察觉的推进(×1.04)。 |
| 堆积 | **一次连续拉远**,4 小节内从 ×5 到 ×1,按小节在对数空间设键、单调插值(每小节一"格",速度连续)。前景卡片模糊掠过镜头。10.5 秒起 1–2° 荷兰角和手持晃动逐渐建立。 |
| 过载 | 三个半秒**插入**,各自从源位置展开(UI 展开转场):999+ 角标 / 148 个细标签页 / 红色存储条。 |
| 冻结 | 静默推近穿过冻结的混乱抵达光标(×0.8 → ×2.6,缓入缓出)。 |
| 按下 | 一拍内**急甩拉出**(×2.6 → ×0.78,三次缓出),让 Press 点和整个网格落位同时可见。 |
| 揭示 | 窗口在 4.5 秒内从 3/4 角度转入(−24° → 0°),同时光扫过。镜头几乎不动:只有光和产品在动。 |
| 数字 | 俯冲进状态栏计数器(对数变焦到 ×16),再匹配剪辑切到全屏数字。原路退出。 |
| 呼吸 | UI 自己收纳时缓慢推进(×1.08)。 |
| 回声 | 与第一个镜头完全相同的取景。光标坐在同一个像素上。 |

**统一转场语法 = UI 展开 / 坍缩**:每次镜头切换都是一个界面元素展开成画面、或画面坍缩进一个元素。没有淡入淡出,没有空帧。

## 6. 声音

- **音乐优先**:`timeline.js` 存放速度网格(120 BPM)、12 音模式和所有声部的音符表(相位在那里计算为时间扭曲)。画面从同一批表生成元素。`tools/cuecheck.py` 检查关键提示点以及每个生成的元素是否落在配乐音符上。
- **配乐(原创,极简主义)**:马林巴(声部 1,对齐网格)+ 硬槌颤音琴(声部 2,同度,随后相位超前;峰值处轻微失谐且更亮)+ 钟琴(声部 3,向另一方向漂移)+ 一个 numpy 铺底(A 音持续音,逐渐加入 G#/D# 不协和并上行)+ 低音正弦脉冲(八分 → 十六分)+ 安静的噪声沙锤。按下的一刻所有声部落在**同一个 A 大调 9 和弦**上,弓奏颤音琴把它带进揭示(L 切),随后一段干净的pattern演奏,呼吸中该模式逐小节减去音符,只剩一个四分音符。采样:VCSL(CC0)。
- **声音调色板 = 故事**:混乱的声音是*散的*(每条通知音高偏差 ±45 音分,随机声像,每个来源不同音色)。Tidy 的声音是*一个家族*:毛毡滴答和玻璃轻敲,全在 A 大调五声音阶上,居中。264 个落位轻敲形成一个调内闪光。
- **分层**:环境(安静房间 + 电脑风扇和一条随混乱增长的 6.8 kHz 线圈啸叫,**压住直到最后一句旁白结束**)、拟音(光标滴答、低调按键、回车、通知玻璃、文件噗通、照片轻弹、窗口嗖、毛刺点缀、存储嗡鸣、堆叠闷响、按下的"doom" = 毛毡槌 + 55→40 Hz 正弦下坠、网格滴答、毛毡滴答、扫光闪烁、数字颗粒、CRT 关机)、音乐。
- **真实静默**:15.0–16.0 s 是**每条轨道的数字零**(屏幕暂停)。之后第一个声音是最重要的那个:按下。33.0–34.0 s 接近静默(−60 dB 房间声)。之后第一个声音是光标滴答,与第 1 帧相同的声音。
- **J / L 切**:拉远之前,一撮闷的通知声在特写下淡入(J);按下和弦延续进揭示(L);光闪烁在光之前 0.4 s 开始(J);数字和弦延续进呼吸(L)。
- **人声**:Kokoro `af_kore`,语速 0.95,自信而克制:短陈述句。人声下音乐闪避 −8 dB、拟音 −4 dB。

## 7. 字幕与标题

- **字幕是一个 UI 组件**:底部居中 toast,`rgba(12,14,19,.72)` 药丸(混乱期间 `.88`),1 px `rgba(255,255,255,.09)` 边框,柔影,Inter 500 40 px `#E8EAF0`,左侧一个 8 px 强调色"正在说话"圆点。以 12 px 上浮 + 淡入 0.16 s 进入。停留 ≥ max(1.8 s, 语音 + 0.6 s)。
- **打出的文字就是它自己的字幕**:标题和最后一句由光标在画面中打出,所以不烧录两次(它们在 .srt 里)。
- **大数字上不放字幕**(数字就是信息)。
- **标题卡** = 特写中光标打出影片标题,配一行小的等宽字上标 `TIDY · A LAUNCH FILM`。**片尾卡** = 打出的标语,加其下左对齐:影片标题、"a launch film for Tidy, a fictional app"、风格名、`Lemo-Opuscar`、`LemoLab × Claude Opus 5.5`、署名。然后一切淡出,只剩光标,眨两下熄灭。

## 8. 我们踩过的坑

- **半透明画布的条带透视出现竖向接缝**(重叠切片让 alpha 翻倍)。先投射*不透明*窗口,再在屏幕空间施加扫光。
- **硬白色闪光读起来像贴纸反光。**保持扫光锋面柔和(700 px),闪光 ≤ 20 %。
- **吸附到最近槽位看起来像闪烁而非坍缩**:行程太短。让每种类型沿曲线路径和拖尾飞向自己的行。长、有序、可读胜过短或随机交叉的路径。
- **元素太少在网格里留下洞**,读起来像失误。按规则生成,再逐组修剪或补齐到精确的槽位数。
- **"窗口关闭"用一块平涂色块看起来像占位符。**压扁真实窗口;只在最后 45 % 上色。
- **在拍上开始展开的插入在拍帧上是看不见的。**提前 1 帧开始展开,让拍帧已经打开 80 %。
- **风扇和线圈噪声掩盖人声**(两者都在 300 Hz–7 kHz)。在该段最后一句结束前压低它们。
- 字幕 toast 可能裁到产品窗口的底边。字幕出现期间把产品抬高 25 px。

## 9. 制作配方(本仓库)

```
styles/dark-keynote/demo/
  engine.js     the style engine (see §10)            timeline.js  tempo grid + pattern + phasing note tables + key times
  world.js      the mess: 264 elements generated from the note tables, spawn poses, freeze, type-row snap targets
  film.js       scenes: mess / inserts / collapse / product reveal / number / breath / echo, captions, event list
  frames.js     engine demo scene          main.js / index.html   page (window.render(t), window.EV)
  music/score.py   original score (sub-agent), stems, score.json      mix.py   foley + voices + ducking + silences
  tools/        dump_timeline.mjs export.mjs cuecheck.py
```
1. 写 `timeline.js`(网格、模式、声部、关键时间)→ `node tools/dump_timeline.mjs` → 把 `timeline.json` + 提示点图交给一个音乐子代理。并行作画。
2. 先构建引擎和产品窗口(它们是风格基准帧),再从音符表构建混乱生成器,再做大坍缩。
3. `sh demo/build.sh` 重建一切:TTS → whisper → 配乐 → 事件 → 提示点检查 → 混音 → srt → 渲染 → mux(−14 LUFS,grain 0)。
4. 用 `node core/render/still.mjs demo --range 0.5:42:1` + `sheet.py` 至少审查两遍,外加坍缩和按下的帧条。

## 10. 引擎用法

`demo/engine.js` 是一个纯 ES 模块(Canvas 2D,除 `core/lib.js` 外无依赖)。所有绘制函数第一个参数是上下文。坐标是当前激活变换的像素。

| 函数 | 作用 |
|---|---|
| `setAccent(hex)` | 设置唯一的品牌色(默认 `#B7F34A`)。所有强调色驱动的内容随之变化:光标、toast 圆点、`litShape({accent:true})`、`trail`。 |
| `bg(g, {lift, cool, dark})` | 带径向提亮和冷光晕的近黑舞台。 |
| `grid(g, {ox, oy, scale, module, alpha, rect})` | 可跟随相机的发丝网格。 |
| `glow(g, x, y, r, color, a)` · `vignette(g, a)` | 柔光池,角落衰减。 |
| `panel(g, x, y, w, h, {r, fill, shadow, cheap})` | 圆角 UI 表面:柔影、顶光填充、1 px 边框、内部高光。`cheap` = 为数百个元素使用偏移阴影。 |
| `litShape(g, path2d, {accent, color, glowR, sweep, bbox})` | **以本风格绘制任意形状**:带轮廓光的暗色受光表面,或(带 `accent`)发光的强调色填充;`sweep` 0..1 添加移动光带。 |
| `sparklePath(cx, cy, r, k, rot)` | 四角星路径(用于闪光、"new" 标记)。 |
| `trail(g, pts, {color, width, caretH})` | 沿点列的衰减光尾,可选以光标收尾。 |
| `caret(g, x, y, h, {sx, sy, on, glow, color})` | 带压扁/拉伸和眨眼的光标。 |
| `tidyMark(g, x, y, s)` · `wordmark(g, x, y, px)` | 品牌标记(方圆 + 光标)和词标 + 光标。为你的产品重命名。 |
| `windowBox` / `windowContent(kind)` / `notif` / `fileIcon` / `photo` / `badge` / `appIcon` / `storageBar` | UI 套件。`windowContent` 种类:note, inbox, browser, sheet, chat, viewer, code。 |
| `flyPose(from, to, p)` · `motionBlur(p, span, n, draw)` | 带过冲、弹簧旋转和变形的吸附飞行;多重采样运动模糊。 |
| `lightReveal(g, src, x, y, w, h, p, {base, soft, band, glint, angle})` | 任意画布的扫光揭示。 |
| `perspective(g, src, cx, cy, w, h, rotY, {slices})` | 平面画布的条带渲染 Y 轴旋转;返回 `map(u,v)` 到屏幕。 |
| `scramble(g, text, x, y, t, locks, {px, fam, color, tracking})` | 字形噪声到数字的滚动,带逐字符锁定时间。 |
| `toast(g, text, a, {dense})` | 字幕组件。 |
| `camera({x, y, zoom, rot, sx, sy})` | 2.5D 相机:`.apply(g, z)` 变换到深度 z;`.proj(x, y, z)` 返回屏幕位置和缩放。 |
| `buf(name, w, h)` · `rr(g, …)` · `font(px, wt, fam)` · `rgba` · `mix` | 辅助函数。 |

**最小示例:一颗带光标尾巴的暖橙色四角火花,以本风格绘制。**
```js
import * as E from './engine.js';
const g = document.querySelector('canvas').getContext('2d');
E.setAccent('#D97757');                       // the one colour
E.bg(g); E.grid(g, { ox: 960, oy: 540 });
const pts = []; for (let i = 0; i <= 40; i++) { const u = i / 40; pts.push([360 + u * 1100, 640 - Math.sin(u * Math.PI) * 260]); }
E.trail(g, pts, { width: 8 });                // the cursor's path as a fading light trail
E.litShape(g, E.sparklePath(1480, 380, 90, 0.2), { accent: true, glowR: 40, bbox: [1390, 290, 180, 180] });
E.caret(g, 1560, 380, 120);                   // a cursor riding the spark
const card = new Path2D(); card.roundRect(300, 200, 420, 160, 28);
E.litShape(g, card, { sweep: 0.5, bbox: [300, 200, 420, 160] });   // any shape as a lit dark UI surface
E.vignette(g);
```
用 `?scene=engineDemo` 渲染(见 `frames.js`)。要在中性画面中让单个元素保持彩色,全部用默认 `litShape` 绘制,只有那个元素用 `{accent: true}`。
