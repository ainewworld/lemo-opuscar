# 数据叙事(Data Storytelling)— 风格提示词

> 一张会讲故事的图表:真实数据,由一支红蓝铅笔在奶油色纸上一笔一笔画出,手写笔记钉在数字上。每个数据点都是一条笔记,而图表本身既是镜头、又是节奏、又是剧情。
> Demo:*A Hundred Summers*(50.0 秒)· `dataviz.mp4` · 源码在 `demo/`。一百零一个夏天的全球真实气温(NASA GISTEMP v4,6–8 月),作为一个女人 1926 到 2026 年的一生来讲述。
> 参考(仅语法):Hans Rosling 的《200 Countries, 200 Years, 4 Minutes》(一个移动的数据点加一位平静的讲述者;一个点就是一个角色)。Ed Hawkins 的变暖条纹(2018):以色带呈现的一个世纪、以参考均值为中心的分歧色带、无坐标轴。The Pudding / 纽约时报的 scrollytelling 图形:一次一个观点、随故事生长的坐标轴、以细引线钉在数据上的笔记、正文即图注。绝不复制它们的具体图表、数据集框架、版式或字体,也绝不在影片中提到它们的名字。

你正在以**数据叙事(Data Storytelling)**风格执导一部 35–55 秒的短片。用户给你一个主题。你为它找一个真实的、开放授权的数据集,其余一切由你决定:故事、镜头、声音、字幕和节奏。然后交付一部完成的影片。遵循本指南。

---

## 1. 这个风格是什么

**图表就是影片。**屏幕上没有一样东西是装饰:每个标记都是一个真实的数字,每次移动都是一个有含义的图表操作。一个点落位,一根轴生长,比例尺重标定,一个系列变形为另一种编码,一条笔记被钉在某个值上。数据必须真实、可溯源。你可以改变框架,绝不改变数字。

**选数据所要求的图表。**我们的 demo 是时间序列,所以画成点和线,再变形为条纹。那是一个数据集的一种选择,不是这个风格。选择适合用户数据和故事的编码:

| 数据关于 | 图表 |
|---|---|
| 比较类别、排名 | 条形图、排名条形竞赛 |
| 两个度量之间的关系 | 散点或气泡图(一个点可以是一个角色) |
| 地点 | 地图、分级统计地图、地图上的点 |
| 整体的部分、人数 | 单元 / 华夫图、比例方块 |
| 之前 → 之后 | 斜率图或哑铃图 |
| 分布 | 直方图、蜂群图 |
| 流向 | 流向 / Sankey |
| 随时间变化 | 折线或点系列、条纹、面积 |

无论什么图表,不变的是:奶油色纸、画出每个标记的铅笔、钉在真实值上的笔记、随故事生长的坐标轴、以图表操作代替剪辑,以及声化(音高 = 数值)。`demo/engine.js` 中的 `inkShape`、`pencilStroke` 和 `stripesFill` 画条形、面积和地图形状与画点一样容易。

三层让它是故事而非信息图:
1. **钉在数据上的人的尺度。**在具体点上的私人手写笔记("1926 — 她出生。")把抽象的系列变成一生。
2. **一位表演者。**一支实体铅笔画出系列。它给这个风格一个能预期、犹豫、退缩、把故事交出去的身体。
3. **声化。**每个点是一个音高,于是系列也是旋律。观众在读懂趋势之前先听到它。

## 2. 故事:什么适合这个风格

| 原生能力 | 故事用法 |
|---|---|
| **一个点 = 一个事实** | 从单个点和单句话开始。第一个点是角色的第一个时刻。 |
| **坐标轴随故事生长** | 不要预先展示图表。一条垂线变成 x 轴;y 轴在旁白第一次提到单位时到来。 |
| **钉住的注释** | 早期笔记是回忆(蓝铅笔)。后期笔记是记录或警告(红铅笔)。笔记内容变化时,情感弧线随之变化。 |
| **重标定 / 破框** | 数据刺穿绘图区顶部,图表必须腾出空间:刻度压缩、新网格线出现。这是只有图表能做的升级。把撕裂的边缘留作伤疤。 |
| **编码变形** | 一串点在一拍内落成条纹(或条形、或热条纹)。这是标志性镜头,是整体的揭示。 |
| **尺度切换** | 一个值的特写 → 整个系列 → 更长的记录。永远用真实数据;绝不为戏剧性外推。 |
| **声化** | 音高 = 数值,节奏 = 时间密度。"听"趋势;让上升的系列成为一条上行、更不协和的旋律。 |

**故事形状(已在 demo 中验证)。**一个点上的冷开场。温柔、稀疏的早期点。平稳的中段。加速:笔记变密,铅笔匆忙。破框,铅笔退缩并翻到红端。狂奔。**一切提前半拍骤停;这是全片唯一的剪辑,切入静默。**然后最后一个数据点,独自一个,随后整个系列一览无余。接着变形为另一种编码,然后更长的记录,然后为下一个值留的空格("下一个夏天?")。片尾卡就住在那个空格里。

适配任何主题:选一个真实数据集和适合它的图表(§1);对系列,60–150 个点合适。给最早画出的标记钉 3 条人的笔记,给最后的钉 2 条记录笔记。在数据中找到那个破框时刻。给最后一个点属于它的静默。

## 3. 视觉语言

- **纸** `#F6F3EC`,固定种子的纤维噪声和隐约的 24 px 点网格(`#E4DDCF`)。两者都在世界空间,镜头移动在它们之上可读。
- **墨** `#2B2723`:轴 1.4–1.6 px,系列线 2.4 px,网格线 `#DDD6C9` 1 px,零线 `#BDB4A5` 1.3 px。刻度数字用 **IBM Plex Mono**(17–20 px,`#6E665C`)。
- **数据点**:r = 6 px,从色带填充,带 1.5 px 墨圈,让接近中心的浅色值在奶油色上仍可见。落位:0.25 s 弹出(×1.55)和一圈细涟漪。间隔小于 0.1 s 的点抑制涟漪。
- **分歧色带**(变暖条纹语法,ColorBrewer RdBu 族),u = (v − 中心) / 半幅:`#2166AC` → `#4393C3` → `#92C5DE` → `#D1E5F0` → `#F2EEE8`(中心)→ `#FDDBC7` → `#F4A582` → `#D6604D` → `#B2182B` → `#7A0F1E`(超过 +1)。中心 = 参考期均值,跨度对称(demo:1971–2000 均值 0.22 °C,半幅 0.85 °C)。**诚实胜过戏剧性**:如果早期值算出来浅,就让它浅。
- **手写体**:**Caveat** 30 px 世界尺寸,蓝铅笔 `#2F5D8A` / 红铅笔 `#A8283A`。逐字符抖动(±1.7° 旋转,±2.5 % 基线)和石墨颗粒(16 % 像素敲除)。写上是左到右揭示,同时笔尖在 x 字高上跳舞。引线是抖动的二次曲线,终点是绕点一圈**未闭合**的环。小涂鸦(三卷浪、心)用同一种笔触。
- **标题与图注字体**:**Newsreader**。标题(66 px)是图表自己的大标题,设在世界空间绘图区左上方,全景时一直留在那里。
- **红蓝铅笔**(原创设计):六棱笔身,蓝半 / 红半,削尖的木锥 `#E3C79C`,着色笔芯。只表现笔尖端。从右下以 35–58° 进入(密集段落更陡,以绝不盖住新点)。抬笔时影子更远更柔。景深:尖端清晰,笔身方向渐虚;作为前景物时完全虚焦。
- **版式规则**:绘图框固定在世界空间(demo 为 1500 × 520)。把数值底线放得足够低,为早期笔记在曲线下方留出**"记忆区"**。后期笔记在其点的左上方。注释钉在**数据空间**(数值偏移加像素偏移),重标定后版式完好。底部 150 px 属于图注。
- **单色例外**:每个绘制调用接受一个绕过色带的 `accent` 颜色(demo 的引擎展示画了一颗 `#D97757` 火花)。

## 4. 动效语言

- **数据的节奏就是影片的节奏。**把系列映射到音乐网格,用细分而非速度加速。demo 在 90 BPM:四分音符上 7 个点 → 八分 24 个 → 十六分 40 个 → 三十二分 27 个(每 2 帧一个点)。90 BPM 下每个 1/32 音恰好落在整帧 24 fps 上,画面/声音零漂移。
- **铅笔表演**(预期 / 动作 / 跟随):每次轻点前抬起,落下时影子与尖端相会,然后一个微小的回弹。后来它变匆忙。狂奔中它像地震仪针一样颤抖。**退缩**:数据破框时它从数字上弹开,冻结半拍,*然后*抬起并端对端翻转到红芯(0.5 s)。**犹豫**:最后一个点前它悬停、失焦、微微抬起,再落下。**退场**:最后一个问题之后它离开画面,铅笔交到观众手中。
- **重标定**做成棘轮咔哒:四步落在 1/32 音上,每步在 0.09 拍内缓动。第二次重标定,在清明阶段,是平滑的。
- **变形**:扫掠从左到右错开,历时 0.85 拍。每个标记先落到条带中心(前 45 %),再拉伸成完整条纹(缓出),生长中失去圆圈。当左端点开始变形时,线段随之淡出。注释在扫掠经过时淡出,然后以铅笔小记号回到条带上方。
- **不淡入空白,不用泛用叠化。**转场是图表操作:轴生长、拉远、重标定、变形,以及空格拉宽变成片尾卡。

## 5. 镜头语言

一张纸上方的 2D 相机 `{x, y, zoom, roll}`。**全片是一个长镜加一次硬切**,而那次剪辑*就是*静默。

| 节拍 | 镜头 |
|---|---|
| 冷开场 | 第一个点的极特写(约 4×)。笔记书写时向上摇跟随引线。 |
| 标题 | 拉回到 1.55×。垂线变成 x 轴;标题排在上方。 |
| 早年 | 推回近,然后跟拍铅笔,最新点保持在画面宽约 62 % 处(过去在后,未来在前)。时间加速时缓慢拉远(2.3 → 1.7×)。 |
| 攀升 | 随上升曲线升降台上摇,荷兰角悄悄渗入(0 → −1.5°)。 |
| 破框 | 2 帧内砸近(1.22 → 1.42×)加衰减抖动。重标定时一次小震。 |
| 狂奔 | 快速拉远到 1.0×,横滚到 −3°,持续 2 px 颤动。 |
| **那一切** | 硬切到空槽特写:虚线列、`2026` 标签、水平地平线。焦点从虚焦的前景铅笔移到落下的笔尖。 |
| 揭示 | 停在最后一个点上等它的笔记写完,再拉回全景(1.06×)。坐标轴重标定以容纳一切。 |
| 变形 | 锁定。变换本身就是运动。 |
| 尺度 | 拉远并平移(→ 0.72×)加入更早的记录。 |
| 回声 | 推向空格;它拉宽成片尾卡(框中框)。 |

规则:关键时刻主体至少占画面高度 1/3(第一个点加笔记、世纪图表、条纹带)。冻结窗格 y 标签:真实轴滚出屏幕时,刻度标签钉在左缘的纸条上。

## 6. 声音

- **三层。**环境随故事变化:房间底噪 → 夜晚蟋蟀 → 海("1933" 前 J 切,后 L 切)→ 随热度越来越响越来越密的蝉鸣(攀升前 J 切)→ 静默后的旷野风 → 房间底噪。**拟音**跟随材料——石墨、纸和木铅笔:轻点加纸腔、手写用带通刮擦声、坐标轴用直尺嘶声、破框用纸穿刺加撕裂噼啪、翻转用嗖声和木质咔哒、重标定用木质棘轮齿、变形用移动的纸扫声。**音乐**是声化加模块化铺底。
- **声化**(`music/score.py`):`midi = 62 + (v + 0.4) × 17`。低于中心的值吸附到 D 大调五声(永远协和),中间值到半音,热的值不量化。发声体是**低通门"plonk"**:正弦载波加轻 FM,调制指数随数值上升(木 → 金属),振幅与亮度一同衰减。**密集段落降低每个音的电平并缩短衰减(≤ 间隙的 1.5 倍)**,让它成为一条颤抖的上行线而不是一堆敲击。只给最后约 15 个点失谐(5 → 45 音分)。静默前那个音是最不协和的(最大失谐加小二度影子)。静默后最后一个点是最干净、最高的音。
- **铺底**:失谐锯齿 pad(Dmaj9 → G/D → D–Bm–G–A → Bb/D–Dm → 半音簇)、柔正弦底鼓、滤波噪声沙锤、16 分镲(9.5 kHz 低通)、正弦次贝斯、采样保持哔声、缓慢上升的持续音。静默之后:D 开放五度(无三音,无回应),变形期间 101 个点的滑音重放,尺度镜头上的 Gmaj7#11 over D,以及片尾卡下**第一个点的音再次响起**。
- **静默**:最后一个点前 1.0 秒真数字静默(所有层)。空格前 0.67 秒近静默。每次之后的第一个声音是其段落最重要的:最后的轻点加它的音,然后是空格的第一笔。
- **混音**:旁白压缩,人声下音乐闪避约 −11 dB、蝉鸣 −6 dB。旁白在 300–4000 Hz 频段 SNR 为 8.6–16 dB。拟音"很轻",最后的轻点除外。响度 −14 LUFS,grain 0。
- **人声**:Kokoro `af_alloy`,语速 0.92,平静中性,5 句,绝不出现在狂奔、静默或变形之上。Whisper 把数字写成数字:把 `asr` 设为 "For 50 years…" 和 "…turned 100…"。

## 7. 字幕与标题

- **字幕就是图注。**Newsreader 42 px 墨色,与图表在 x = 180 左对齐,基线 y ≈ 985,最多两行。其上一条 1 px 细线,加一个小的等宽字眉给出至今画出的年份范围(`1926–1958`)。词按其 whisper 时间戳出现(3 帧上浮并淡入)。离开时字幕上翻。可见期间其后升起一条纸色淡出带,图表墨色绝不与之相撞。
- 停留 ≥ max(1.8 s, 语音 + 0.6 s)(在 `tools/subs.py` 中断言)。狂奔、静默或变形期间无字幕。
- 标题是图表的大标题(世界空间)。片尾卡坐在虚线"下一格"里:标题、`DATA STORYTELLING`、条纹微缩图加一个空的虚线格、`Lemo-Opuscar · LemoLab × Claude Opus 5.5`、数据、字体、人声和音乐署名(含 "2026 value preliminary, retrieved 2026-09-26"),以及一句手写的"她的故事是虚构的。每个数字都是真的。"

## 8. 我们踩过的坑

- 选错 CSV 列:GISTEMP 在季节列之前有 J-D 和 D-N。按表头名选(`JJA`),绝不按索引。
- 注释与后面的数据相撞。把它们钉在**数据空间**,在曲线下留记忆区,第一条笔记放在其点*上方*并配长引线。
- 0.17 秒后就被重标定的破框看不见。把刺穿状态至少保持半拍(铅笔的退缩就住在那里)再做棘轮。
- 右对齐的笔记从左到右写,铅笔必须从引线末端跳到第一个字母(文本相位的 16 %,抬起)。否则它会瞬移。
- `pencilStroke`、`dashedCell` 和 `dataDot` 自行设置 `globalAlpha`。乘上传入的 alpha,否则淡出和擦除对它们无效。
- 混响尾和脉冲尾泄漏过硬静默。把切断前后的素材渲染进单独缓冲,停止之后全部归零。
- 跟拍镜头中世界空间标题被画面边缘裁掉。镜头近时淡出它,全景到来时带回。
- 三十二分音符密度下铅笔笔身横在新点上。密集段落加陡角度。
- `ffmpeg -ss … volumedetect` 在静默内报告假峰值。在解码样本上核验静默。
- 婴儿的笑声(来自 TTS 或合成)听起来诡异。用非人声的柔声(demo 用一个八音盒音)。

## 9. 制作配方(本仓库)

```
styles/dataviz/demo/
  data/        GLB.Ts+dSST.csv (as downloaded) + jja.json      tools/extract_data.py  column → json + story facts
  timeline.js  90 BPM grid, year → beat map, every key beat, chart geometry (single source of truth)
  engine.js    the style: paper, camera, pencil strokes, handwriting, dots, stripes, morph, pencil, caption, shapes
  film.js      the story: annotations, camera path, pencil activities, chart layers, end card, events for the mix
  music/score.py   sonification + modular bed (reads events.json)      mix.py   ambience + foley + narration + ducking
  tools/       words.py subs.py cuecheck.py final_asr.py
```
1. 下载数据集并写提取器。打印旁白将声称的每个事实。
2. 任何绘图之前先写 `timeline.js`(网格加年份 → 拍映射)。
3. 构建 `engine.js`,然后 `film.js`,用真实引擎渲染关卡帧(`node core/render/still.mjs … --range`)。
4. `sh demo/build.sh` 约 2 分钟从头重建一切:extract → TTS → whisper → words → events → score → cuecheck(107 个提示点,最大 0.03 ms)→ mix → subtitles → render(1200 帧,2 个 worker 约 30 s)→ mux(−14 LUFS,grain 0)→ styleframe 和 poster。
5. 审查:最终 mp4 的 1 s 联络表两遍(错开 0.25 s),破框、剪辑和变形的 0.1 s 帧条,最终混音上逐句 whisper,以及样本级静默检查。

## 10. 引擎用法

`demo/engine.js`(ES 模块,Canvas 2D,1920×1080;导入 `/core/lib.js`)。世界单位是缩放 1 下的图表像素。任何世界空间绘制前先调用 `applyCam(g, cam)`。

| 函数 | 作用 | 关键参数 |
|---|---|---|
| `drawPaper(g, cam, {dots})` | 奶油色纸、纤维噪声和点网格,固定于世界空间 | `dots` 0–1 网格透明度 |
| `applyCam(g, cam)` / `w2s` / `s2w` / `viewRect` | 2D 相机变换与换算 | `cam = {x, y, zoom, roll, sx, sy}`(sx/sy = 抖动,px) |
| `valueColor(v, {center, half, alpha})` / `rampRGB(u)` | 分歧条纹色带 | 参考均值 `center`,对称 `half` |
| `pencilStroke(g, pts, o)` | **用铅笔画任意折线**:抖动、渐细、石墨颗粒、写上;返回笔尖 | `color, width, progress, seed, wobble, passes, grain` |
| `inkShape(g, path, o)` | **任意闭合形状**作为铅笔注释标记:平涂 + 排线 + 手绘轮廓 | `fill`(accent)或 `value`(色带),`hatch, progress` |
| `plotShape(g, path, o)` | 把任意路径采样成点线数据系列 | `n, r, values, accent, progress` |
| `stripesFill(g, path, values, o)` | 用变暖条纹填充任意闭合形状 | 色带选项、`accent` + `accentIndex` |
| `dotTrail(g, pts, o)` | 渐细点尾(光标尾 / 彗星) | `color, r0, r1` |
| `handText(g, text, x, y, o)` | 带颗粒和左→右揭示的手写体;返回 `{tip, w}` | `size, color, progress, align, zoom` |
| `setType(g, text, x, y, o)` | 印刷字体,逐字排版 | `size, font, weight, progress, rise, track` |
| `dataDot(g, x, y, r, fill, o)` | 带落位弹出和涟漪的数据点 | `fresh`(落地至今秒数)、`ripple, accent, alpha` |
| `inkLine`, `stripe`, `morphMark(g, u, dot, box, fill)` | 系列线、单条条纹、点→条纹变形于 0..1 | |
| `leader`, `ringPath`, `wavePath`, `heartPath`, `bracketPath`, `sparklePath`, `quadPath` | 注释几何 | |
| `dashedCell(g, x0, y0, x1, y1, o)` | 虚线"下一个值"格,逐笔画出 | `progress, color, dash, gap` |
| `drawPencil(g, o)` | 红蓝铅笔(屏幕空间) | `tip [sx,sy], s, lift 0–1.2, flip 0–1(蓝→红), blur, focus, ang` |
| `caption(g, words, t, o)` | 带定时词的图注式字幕 | `t0, t1, kicker, x, y, size` |
