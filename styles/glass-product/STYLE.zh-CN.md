# 玻璃质感产品(Glass Product Render)— 风格提示词

> 发布影片级的产品渲染,透明与磨砂玻璃材质:暗场影棚、长条灯扫光、色散、焦散,缓慢的爆炸图在 drop 上啪地合拢。
> Demo:*Aura — Hear the Light*(32 秒)· `glass-product.mp4` · 源码在 `demo/`

你正在以**玻璃质感产品(Glass Product Render)**风格执导一部 30–60 秒的影片。用户给你一个主题(通常是产品,有时是想法)。其余一切——故事、镜头、节奏、声音——由你决定,并交付一部完成的影片。遵循本指南。

---

## 1. 这个风格是什么

一个由**玻璃、金属和光**构成的英雄物件,悬浮在无边的黑色影棚里。外观借自高端产品发布和**暗场玻璃摄影**:背景是黑的,长条形灯放在物体*后方和两侧*,于是透明玻璃变成一圈带彩虹边缘的细白轮廓,内部结构像陈列柜一样透出来。一切缓慢而精确地运动;每次剪辑、扫光和脉冲都落在拍上。

物件永远是**虚构的**。绝不复刻真实产品轮廓(不带柄的耳机、著名手机轮廓都不行)、真实品牌名、logo、字体或 UI。

## 2. 故事:什么适合这个风格

选择**材质本身讲故事**的故事。玻璃加渲染有六种原生能力——至少用四种:

| 原生能力 | 故事用法 |
|---|---|
| **透明** | "毫无隐藏。"内部是主角:透过外壳展示机构,焦点从表面拉到内部部件。 |
| **透镜效应** | 厚玻璃穹顶放大并弯折其后之物——穿过透镜的微距镜头像窥视一枚宝石。 |
| **色散** | 厚边缘把光劈成彩虹镶边;扫光越过边缘就成了移动的光谱。 |
| **在内部传播的光** | 导光柱、通道、光环:能量(声音、数据、电量、热)变成在物体*内部*奔跑的光。 |
| **焦散** | 物体把汇聚的光投到地面上;内部一次脉冲变成在地面上扩散的环。 |
| **爆炸图** | 物体慢动作拆开,部件悬浮旋转,然后在 drop 上**啪地合拢**。解构 → 重组就是情感转折。 |

适配任何主题:找到**产品做的那个看不见的事**,让它变成玻璃内部可见的光。耳机 → 声音变成光脉冲。电池 → 电量灌满玻璃格。手表 → 时间变成光环。路由器 → 数据变成光的细线。香水 → 香味变成焦散。

**情感弧线(30–40 秒):**黑暗中被外部照亮(神秘)→ 打开(好奇)→ 被看穿(亲密,微距)→ 被拆开(悬停,完全静默)→ **在 drop 上合拢并从内部点亮**(释放)→ 自信的节奏 → 回家(落定,回声)。一个物件,一个目标(发出自己的光),一次转折(重组)。

**首尾呼应:**开场用一次扫光照出黑暗中的物体;结尾用*同一次*扫光掠过如今自己发光的物体。

## 3. 视觉语言

- **影棚 = 长条灯场景,不是 HDRI。**摄影棚 HDRI 里有窗户和杂物,在玻璃上印成乱条纹。建一个只有发光面的小黑场景,**每帧**烘焙为 PMREM(`pmrem.fromScene(env, 0, 1, 1000)`,释放上一个 RT):
  - 物体后方左右两根高条(22×170,×3.2)——勾出剪影轮廓
  - 远后方一根宽横条(260×14,×1.4)——地平轮廓光
  - 柔和顶箱(160×70,×1.1)——给磨砂玻璃和金属体量感
  - 一块弱的前下卡(×0.18;凹玻璃面朝向镜头时切到 0,它会印成灰色矩形)
  - 一块顶前主光箱(150×60,×2.5),只用于爆炸图
  - **扫光**:一根高条(26×240)在*相机后方*沿弧线移动(方位角 = 相机方位角 + π,±1.35 rad)。因为它是环境中的真实几何,高光带、折射和色散都物理地移动。
  - 一块以导光色着色的强调卡,强度由脉冲驱动(大凹玻璃面入镜时关掉)。
- **透明玻璃**:`MeshPhysicalMaterial` transmission 1、roughness 0.015、IOR 1.52、thickness 3–4.5(越厚透镜效应越强)、**dispersion 5**(r163+ 三次)、衰减近中性 `#f3f8fb`,160 mm。`side: DoubleSide`,让其他玻璃能看见它的背面。
- **磨砂玻璃**:transmission 0.82–0.9、roughness 0.4、奶白色调 `#eef2f5`、thickness 7–14。在黑底上它读起来像深灰塑料,除非**后面或里面有亮的东西**——在里面放一个不透明发光圆盘(它被虚化成柔和的内发光)和/或背后一道亮的背景渐变。
- **金属**:缎面钛金属环(rough 0.16)、镜面铬磁铁(0.14——0.05 会炸成白盘)、拉丝钢和香槟色振膜带同心拉丝粗糙度贴图、带金色走线的石墨 PCB。正是它们让透明值得看。
- **一种光的强调色**:冰蓝 `#62DCFF` → 柔紫 `#A98BFF`。其余一切中性。
- **导光柱**:不透明(所有*在*透射玻璃内的东西必须不透明——three.js 只把不透明物体渲染进 transmission 缓冲)的深色抛光亚克力 `#15181b`、clearcoat 1,外加经 `onBeforeCompile` 注入的发光项:沿 `uv.x` 的**彗星脉冲**——窄高斯头(σ = w/2)、其后指数尾(长 4w,55 %)、白热内核(head³ × 0.35),色相随年龄从蓝漂向紫。闲置基态保持在零附近;均匀点亮的环读起来像浅蓝塑料。
- **背景**:黑,可选深灰径向扫光(`#34383d → #16181b → #000`)强度 0–1.1;地面淡入同一渐变,所以没有地平线。扫光也让玻璃边缘与纯黑分开。
- **地面**:黑亮面带模糊镜面反射(Reflector,12-tap 模糊,×0.32,径向衰减)+ 程序化焦散:带 R/G/B 半径偏移的透镜环焦散(色散)+ 扭曲的 Voronoi 边缘灯丝网,加每拍扩张的彩色环。
- **后期**:2× 超采样、物理景深(微距光圈 700–900,爆炸图 70,广角 160–300)、bloom 只在 1.1 以上(强度 0.16–0.3)、曝光 1.1 的 **Neutral** 色调映射——AgX 会把饱和的蓝色洗成白色。
- **尺度**:以毫米建模;相机近裁剪面 1,微距距离 25–45 mm。

## 4. 动效语言

- **一切逐帧运动**(24 fps),带缓动:相机轨道用 `eio`,部件减速进入悬浮用 `eo`,啪地合拢用 `ei`。
- **相机永远在漂移**:缓慢轨道(每镜头 0.2–0.4 rad)或缓慢推近;绝不锁定机位、绝不手持——除了合拢瞬间的**两帧微震**。
- **爆炸图**:部件沿产品轴散开,总偏移约 2× 产品尺寸,每个带自己固定的小倾斜(`sin(i·1.7)·0.32`、`cos(i·2.3)·0.28`)和与偏移成正比的缓慢自旋。时序:3 秒缓出散开 → 0.75 秒悬停(漂移 +3 %)→ **0.25 秒缓入合拢**,正落在 drop 的重拍上。合拢后 0.9 秒内相机推进约 40 %。
- **磁吸升起**:物体从底座升起,向镜头轻微倾斜(1.2–1.4 秒,`eio`),再落回直立。
- **悬浮的对件**以 3/4 朝向镜头,让透镜面和光环可见;直直朝上读起来像蘑菇。
- **盖子**:沿后边缘铰接,立在物体后方(约 100°),背光成玻璃光晕。平躺的盖子读起来像锅盖。

## 5. 镜头语言

| 节拍 | 镜头 | 理由 |
|---|---|---|
| 开场(0–4 秒) | 低 3/4 侧面,极慢推近,环境光近零;两次扫光 | 只有轮廓,没有内容——好奇。3 秒内抓住观众。 |
| 揭示结构 | 高 3/4,盖子打开时缓慢 40° 轨道 | 一个动作讲清物件 |
| 微距 | 距离 25–45 mm,焦点从玻璃表面拉到内部部件;每拍一次短扫光 | 把观众拉*进*玻璃 |
| 侧面 | 侧面微距轨道 | 材质对比:透明 / 金属环 / 磨砂 / 柔软顶端 |
| 爆炸图 | 3/4,轴与视线成约 40°,部件形成带纵深的对角线(近大远小),占画面约 80%,缓慢轨道出视差 | 技术之美;视差卖出深度 |
| 正面英雄 | 正对,轻微推近 | 宣言:光环完整 |
| 图案微距 | 俯拍导光通道微距 | 概念以最大尺寸呈现 |
| 对件 | 中景双人镜头,第二个物件在重拍上飞入 | 立体声 = 左右交替 |
| 焦散 | 高角度俯拍地面 | 最有记忆点的镜头:声音在大地上扩散 |
| 结尾英雄 | 低 3/4,居中于标题下方,缓慢拉远为署名腾出空间 | 名字 + 标语 + 产品 |

只在拍上剪辑(尽量在小节线上)。产品影片在镜头之间**不需要**空间连续性:每个镜头是自己的展示台——把不利于镜头的东西(收纳盒、另一个物件)藏起来或挪走。

## 6. 声音

- **音乐:极简电子**,绝不用钢琴加弦乐。120 BPM,小调。黑暗开场用次贝斯持续音 + 玻璃闪光;构建段用 FM 玻璃拨弦琶音加逐渐打开的低通;微距扫光下每拍轻柔短底鼓;爆炸图上噪声 + 锯齿上升;**drop 前整整半小节全静(混响尾也切掉)**;**808 drop**(带音高包络的正弦、长尾、软饱和、偶有滑音),配切分模式(每小节 [0, .75, 1, 1.5]),光脉冲精确跟随它;2、4 拍拍手;一个四音玻璃铃动机;揭示段的小九度 pad;最终落定时一声高玻璃叮。
- **每次脉冲、扫光和合拢都锁在配乐上**:先写提示点图,配乐和渲染器共享同一份底鼓清单。
- **拟音跟随材质**:扫光用玻璃闪光(带通噪声扫频 + 不谐和分音,随条灯方向声像移动)、盖子用缓慢玻璃-金属摩擦、磁吸咔哒(低于 2 ms 的瞬态 + 3.2/5.1 kHz 金属共振 + 低闷响)、每个爆炸部件一声气流噗、静默里一声长倒放嗖、合拢时一簇间隔 15 ms 的六次咔哒 + 不谐和玻璃和弦(分音 ×2.76、×5.4)。
- **人声**:克制的低音男声发布腔(Kokoro `am_michael`,语速 0.86–0.88),3–4 句极短台词。避免只说产品名("Aura." 会被听成 Laura/Dora)——用 "Meet Aura." 人声下音乐闪避 −12 dB、拟音 −6 dB。
- 混音:drop 峰值限制约 3 dB 让 loudnorm 保持线性;−14 LUFS;**grain 0**(颗粒在黑色和玻璃上闪烁)。

## 7. 字幕与标题

- **字幕是一块磨砂玻璃**:居中圆角条高 76 px、圆角 38,用实况画面模糊填充(canvas 对 WebGL 画布 `filter: blur(18px) brightness(1.25)`,`preserveDrawingBuffer: true`)加 10 % 冷白,一圈 1.2 px 渐变高光描边,顶边一条细的蓝→紫色散线。文字:Inter Tight 300、40 px、字距 1 px、近白。屏上 ≥ 1.9 秒且 ≥ 语音 + 0.7 秒。
- **标题**:Inter Tight 200,112–132 px,超宽字距(56–64 px),居中于上三分之一;一道斜向闪光与物件上的扫光同步扫过字母。小的宽字距大写(18–20 px,字距 8–10)用于 "A GLASS PRODUCT FILM"、"MEET"、署名。
- 产品名和标语的句子**不**放进字幕条:它们本身就是标题卡。
- **结尾**:标题留下;署名(风格名、`LemoLab × Claude Opus 5.5`)在底部柔暗渐变上淡入,同时相机拉远腾出空间;最后 0.6 秒淡入黑。

## 8. 我们踩过的坑

- **手动调用的 Reflector update 用了上一帧的相机** → 地面出现拖纹、没有反射。更新镜面前先调 `scene.updateMatrixWorld(); camera.updateMatrixWorld()`。
- 地面镜面是不透明物体,three 的透射预通道会重复渲染反射。把 `onBeforeRender` 换成空操作,自己每帧更新一次。
- **玻璃里的任何东西必须不透明**;透明物体不在 transmission 缓冲里,会在玻璃后消失。
- 磨砂玻璃里的青色灯条会晕开成**整个物件上的青色调**。内部发光体保持冷白且暗;颜色只属于导光柱。
- 光环的闲置辉光被透镜穹顶放大成浅蓝色斑。闲置发光 ≈ 0。
- **AgX 色调映射**把蓝/紫脉冲去饱和成白;Neutral 保住了它们。
- 黑底上的磨砂玻璃 = 黑。需要内部发光体或亮背景。
- 朝向正面柔光箱的镜面铬部件会变白盘;粗化到约 0.14。
- 垂直于轴看的爆炸图是一排侧对的线;把轴朝镜头转约 40°。
- 正面看的悬浮耳机像蘑菇;收纳盒后平躺的盖子像锅盖。
- 单独一个产品名会被 ASR(和观众)听错;给它一个动词。
- 物体从可见的地板"下方"升起是穿帮;从侧面飞入。
- loudnorm 回退到动态模式(−13.7 LUFS),因为 808 峰值没有余量;在混音里把 drop 峰值限制约 3 dB。

## 9. 制作配方(本仓库)

```
styles/glass-product/demo/
  product.js   earbud + case geometry, glass/metal/guide materials, comet-pulse shader, explode()
  studio.js    strip-light env (PMREM per frame), sweep strip, background sweep, floor mirror + caustics + beat rings
  story.js     120 BPM timeline: shots, kicks, sweeps, VO, SFX events
  main.js      per-shot staging & cameras, light/pulse logic, frosted-glass subtitles, titles, end card
  music/score.py  original numpy score (stems + score.json self-check)
  mix.py       foley synthesis + voice + ducking → mix.wav
  lines.json · subs.py · check_mix.py · build.sh
```

1. 先写提示点图和 `story.js`(BPM 网格,配乐和渲染器共享底鼓清单)。
2. `node core/render/still.mjs styles/glass-product/demo 9.3 14.6 26.8 [--q nosub=1]`——迭代静帧;`--range 0.5:31.5:1` + `sheet.py` 做总览。
3. `.venv/bin/python core/tts/tts.py demo/lines.json demo/voices` → `core/tts/asr_check.py` 直到全部 OK。
4. `python demo/music/score.py` → `node core/render/events.mjs demo` → `python demo/mix.py`。
5. `node core/render/video.mjs demo --fps 24 --workers 3`(768 帧,2× SSAA、transmission、逐帧 PMREM 和镜面,在 M 系列 Mac 上约 30–45 秒)。
6. `sh core/render/mux.sh out/video24.mp4 mix.wav glass-product.mp4 24 0`,然后 `python demo/check_mix.py glass-product.mp4`。
7. 或者干脆 `sh styles/glass-product/demo/build.sh`。
