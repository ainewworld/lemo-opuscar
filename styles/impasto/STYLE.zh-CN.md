# 油画厚涂 · 刮刀(Impasto · Palette Knife)— 风格提示词

> 用调色刀(palette knife)厚涂的油画:大片、平整、边缘锐利的色面,被光斜掠而过,让每一条颜料棱脊都显露出来。清晰第一:明度结构先于纹理,焦点处是硬边,其余处处是平静色面。
> 演示片:*The Colour of Rain*(39.7 s)· `impasto.mp4` · 源码在 `demo/`
> 参考(仅借鉴语法):*The Umbrellas of Cherbourg*(1964)片头 —— 随音乐编排的俯视雨伞;调色刀雨街绘画(Leonid Afremov 及其周边流派)—— 刀法马赛克、垂直湿漉反射、暖色灯火对冷色黄昏;Sorolla / Sargent —— 寥寥几笔果断的笔触和强烈的光;Edgar Wright 的音乐锁定剪辑 —— 一个动作、一个声音、一次剪切。绝不复制它们的画面、构图、旋律或角色。

## 1. 这个风格是什么
一部由刀痕构成的会动的油画。每一笔都是一个真实物体:一块带棱脊(刀刃压下处)的斜面颜料、一个翘边(刀刃提离处)、断续的条痕(颜料耗尽处)、两种互相拖入的颜色。世界**每帧都从笔触重新绘制**,但静止的颜料从不动 —— 只有故事中会动的东西才动。光斜掠过一个高度场,于是颜料有了体积感。

观感清晰而图形化(缩略图尺寸下如儿童绘本般可读),但在 100 % 裁切下又具有 impasto 厚涂的触感表面。

## 2. 故事:什么适合这个风格
- 关于**色彩、光与天气**的故事:灰 → 彩,夜 → 晨,雨 → 晴。这种媒介可以用新颜色"重铺"任何一笔,于是颜色变化本身成为事件(一把刀把新颜料扫过旧颜料)。
- 音乐故事:声音化作可见的颜料缎带;从高处俯瞰的编舞是留下彩色轨迹的移动色盘。
- 小型角色阵容、可读的剪影(一位乐手、一个孩子、一群雨伞)。面孔简单:眼/眉/嘴是独立的过程化笔触,因此能表演。
- 只有这种媒介最擅长的原生手法:
  1. **刀重铺颜色** —— 每一笔同时保留灰色版和彩色版;一道揭示波逐笔重画(`reveal`、`revC`)。
  2. **编舞画出画面** —— 移动的物体把自身颜色滴落为刀点;俯视时,舞蹈在地面留下一幅曼陀罗。
  3. **掠射光** —— 在情绪峰值处,把光压到掠射角,让每条颜料棱脊接住光,然后再让它落定。
  4. **覆盖式转场** —— 下一镜头的笔触成排扫过上一镜头(`appear`),配以调色刀刮擦的音效。

## 3. 视觉语言
- **明度第一。** 把每套布景设计成一幅平整的、按明度规划的插画(至少 3 档明度),再转成笔触。如果参考图在 480 px 宽就看不清,任何笔法都救不了。
- **笔触大小按重要性与深度。** 粗到细分层:天空/墙面 40–60 px 色面,3–6 px 只出现在边缘和面孔。每个形状:`maxR`(最大笔触)、`detail`(越高 = 小笔触越少)、`dir`(角度、`'edge'`、辐射场或函数)。
- **笔触绝不跨越形状组** → 剪影保持锐利。若要"消失的边缘"需显式选择(把两个形状放进同一 `group`)。
- **薄底稿**(参考图本身,模糊 1.5 px)垫在笔触之下,画布不会以轮廓线的形式露出。
- 刀痕:长度 1.7–3.1 × 半径,宽度 0.95–1.45 × 半径,斜切两端(skew ±0.55),角度抖动 ±13°,明度抖动 ±6 %。人物和雨伞用 `run: 0–0.25`(无毛边流挂)以保持结实。
- 光:`light [-.55,-.6,.7]`、`norm 3.2`、`amb .8`、`dif .28`、`spec .16–.3`、`ao 1.2`。灰色世界 spec 略高(湿)。
- 演示片调色板:雨后黄昏 —— 钴蓝 `#34507e` → 蜜桃 `#d99a78` → 金色 `#f7dca0` 天空;赭石 `#dca064` 与玫瑰 `#c98d7e` 门面,百叶窗绿 `#3f7a6c`,雨棚红 `#b8342a`;雨伞全饱和(镉红 `#dc2f28`、黄 `#f4bc2a`、钴蓝 `#2f62c0`、翠绿 `#23906c`、品红 `#cc3a82`、橙 `#ee7a2a`、青绿 `#26aab4`、紫 `#6e4cc0`)。灰色世界 = 同样笔触的亮度版,略偏冷,残留 5 % 颜色。
- 湿反射是**每个光源下方一叠明确、断裂、渐隐的短横刀点** —— 不是一块涂出来的矩形。
- 不要胶片颗粒:颗粒 + 压缩会吃掉刀痕边缘。

## 4. 运动语言
- 静止的颜料保持静止。只有雨、人物、琴弓、雨伞、缎带和光在动。平滑 24 fps(无步进)—— 清晰是本次的命题。
- 人物是由固定种子逐帧重建的过程化笔触(行走循环、IK 持弓臂、雨伞的开/合/垂持)。
- 每个动作都落在音乐网格上:琴弓换向在每个音符上;雨伞随节拍弹出并带缩放回弹和一阵颜料点;人群的圆环在每个强拍上涌起。
- 预备 → 动作 → 跟随:强拍前琴弓抬起,女孩在雨伞弹开前先向下压伞,雨伞合拢后向下摆入垂持位。

## 5. 镜头语言
- 开头(灰)、中段(彩色的雨伞)、结尾(全彩)用同一个大机位:变化本身就是故事。
- 用过的运镜:缓慢横移 + 推进(全景)、穿过一段寂静的推入(中景)、从水洼向上摇(女孩)、从面部特写拉出(反应)、从头顶旋出升高(舞蹈)、朝拱门推进(终章)。
- 让相机留在画幅之内(`half = W/2/zoom`),否则画布会露出来。

## 6. 声音
- 三层:雨底(嘶声 + 雨滴 + 檐槽细流;在拱门下时低通)、材质拟音(湿卵石脚步、尼龙窸窣、雨伞"fwump"、雨滴落在漆面木头上、弓擦松香、每次重铺颜料时的调色刀刮擦)、音乐。
- 两处真实的静默:大提琴手放弃之后(雨声近无、一滴水、一个孩子脚步的 J-cut、然后一大声溅水),以及最后一个和弦之前数字零的大停顿(雨在半空中冻结)。
- 配乐:D 小调独奏大提琴在一个未解决的 E 音上中断;D 大调街头缪塞特圆舞曲(手风琴 vamp、拨弦低音、小提琴拨弦、沙锤、竖琴琶音、钟琴按上升琶音音高弹出);尾声把 E → D 解决。

## 7. 字幕与片名
- 无旁白:这是一部音乐影片。片名用刀铺入(灰色天空上的 `appear` 扫入,1.1 s),再被雨冲刷而下(下滑并淡出)。
- 片尾卡:深群青上的刀绘片名 + 清晰的 DOM 文本署名(小字必须保持可读)。

## 8. 我们踩过的坑
- `half` 是 GLSL ES 3.00 的保留字。
- 在 stroke VAO 仍绑定时绑定合成四边形,会静默改接 attribute 0 → 下一帧报 "vertex buffer not big enough"。先解绑 VAO。
- 先画建筑再画地面,盖住了建筑的脚 —— 参考图中的绘制顺序很重要。
- 受限笔触在边缘处收缩,留下画布色的轮廓 → 加上底稿纹理。
- 每镜头循环里的全局索引把缎带控制点甩出屏幕外(天上划出一道痕迹)。用局部索引。
- 伞半径 0.46 × 身高看起来像遮阳桌;0.34 才像伞。
- 大衣画成普通矩形像系船柱:A 字收身 + 受光边 + 肩部一点 + 头发一点。

## 9. 制作配方(本仓库)
1. `timeline.js`:BPM 网格、剪切时刻、旋律(`MEL_A`、`MEL_B`)、pop 点。画面和配乐都读它(`tools/dump_timeline.mjs` → `out/timeline.json`)。
2. 布景在 `scenes/*.js` 中作为参考插画(`Ref.fill/line/text/tint`)→ `paintRef()`。
3. `film.js`:镜头、相机、转场(`EDIT` 表)、后期观感。
4. `music/score.py`(采样器)、`mix.py`(拟音 + 环境 + 闪避 + 真静默)。
5. `demo/build.sh` 渲染全部(952 帧约 30 s GPU 渲染)。

## 10. 引擎用法
文件:`demo/engine/impasto.js`(渲染器)、`demo/engine/plate.js`(参考图 → 笔触)。

| API | 作用 |
|---|---|
| `new Impasto(canvas, {W, H, ss})` | WebGL2 渲染器,`ss`× 超采样的颜色 + 高度缓冲 |
| `E.begin()` / `E.finish(post)` | 开始一帧 / 光照 + 调色到屏幕(`light, norm, amb, dif, spec, shin, ao, expo, sat, contrast, vig, lightCol`) |
| `E.batch(Float32Array)` → `E.draw(batch, o)` | 静态笔触集。`o = {M, cam:{x,y,zoom,rot}, t, grey, reveal, revDur, appear, appDur, alpha, run, hgt}` |
| `E.drawNow(Float32Array, o)` | 瞬时笔触(人物、雨、缎带) |
| `E.texture(canvas)` + `E.under(tex, w, h, o)` | 薄底稿(支持 `revC:[x,y,speed]` 揭示波) |
| `new Strokes().push({x,y,ang,len,wid,c,c2,type,taper,bend,skew,alpha,hgt,rev,app,seed})` | 构建笔触;`type`:`KNIFE`、`BRUSH`、`DAB`、`LINE` |
| `new Ref(w, h, scale)` + `.fill(path, fill, props)` / `.line` / `.text` / `.tint` | 参考插画;props `{dir, maxR, detail, group, type, hgt, jit, len, wid, aj, fallback}` |
| `paintRef(ref, {R:[radii], T, rev(x,y), app(x,y,level)})` | 粗→细、限制在形状组内的刀痕 |
| `strokePath(out, pts, {wid, c, type, step})` | 沿折线的笔触 |

最小示例 —— 用刀绘出一个暖橙色四芒星,带一条短光标尾:
```js
import { Impasto, Strokes, KNIFE, DAB, hex } from './engine/impasto.js';
const E = new Impasto(canvas), s = new Strokes(), c = hex('#D97757');
for (let k = 0; k < 4; k++) {                                   // 四个渐细的刀尖
  const a = k * Math.PI / 2;
  s.push({ x: 960 + Math.cos(a) * 60, y: 540 + Math.sin(a) * 60, ang: a, len: 120, wid: 46, c, c2: hex('#f0a07a'), type: KNIFE, taper: .95, seed: k });
}
s.push({ x: 960, y: 540, len: 40, wid: 40, c: hex('#f6c0a0'), type: DAB, seed: 9 });   // 亮核
s.push({ x: 1060, y: 610, ang: .6, len: 90, wid: 16, c, type: KNIFE, alpha: .8, seed: 10 });   // 光标尾
E.begin(); E.drawNow(s.data(), { grey: 0, run: 0 }); E.finish();
```
"只有一种颜色"(单色 + 唯一例外):用 `grey: 1, reveal: 1e6` 画世界,用 `grey: 0` 画那个例外 —— 演示片前半段红伞是唯一颜色,正是这样做的。
