# 中国水墨(Chinese Ink Wash)— 风格提示词

> 宣纸上的写意水墨画,动起来了:留白即空间,一笔便是一座山、一浪,或一剑。
> 演示片:*The Swordsman and the River*(48 s)· `ink-wash.mp4` · 源码在 `demo/`

你要以**中国水墨(Chinese Ink Wash)**风格执导一部 30–60 秒的影片。用户给你一个主题。其余一切 —— 故事、镜头、节奏、声音 —— 由你决定,并交付一部完成的影片。遵循本指南。

---

## 1. 这个风格是什么

一部看上去如同一幅正在你面前被绘出、被展开的中国水墨画(水墨,*shuimo*)的影片。一切是暖色宣纸上的黑色墨,分五色,外加**唯一**的一点红:朱砂印。没有西式意义上的轮廓线:形体由**饱墨笔触**构成 —— 其浓边*即是*轮廓(没骨画法);由渗入纸中的**湿渲染**构成;也由**干笔快皴**构成 —— 纸从笔毫痕迹间露出(飞白)。

画面大部分是**空纸**(留白)。空不是背景 —— 它是水、是天、是雾、是静。一幅好的水墨画面有 60–80 % 是未触之纸。

向上美影厂的《山水情》(1988)学习语法 —— 留白空间、墨晕、古琴主导的节奏、寥寥数笔的人物;动作部分向《卧虎藏龙》的竹林段落学习(失重的"轻功"腾跃、动前的静)。不要复制它们的角色、构图或音乐。

## 2. 故事:什么适合这个风格

选**笔本身即是事件**的故事。墨有六种天生之力 —— 至少用三种,并把最强的一种放在情绪峰值:

| 天生优势 | 故事用法 |
|---|---|
| **一笔即一切** | 一滴墨落在白纸上,晕开成群山。万物是*被画入存在*的,而非被剪辑出来的。 |
| **空即是物** | 江、天、小径都是白纸。切开一物露出*纸白* —— 最强的"特效"是移除墨。 |
| **笔势 = 动作** | 一道剑轨迹写出一个书法字;一段舞是一条线;一拳是一笔干皴。笔顺即编舞。 |
| **飞白** | 高潮是横贯整个画面的一笔快速干皴 —— 墨随动作的速度耗尽。它之前要全场寂静。 |
| **墨晕转场** | 不用硬切或叠化:一滴墨在湿纸上晕开,下一景在它内部生长,前缘有一道深色水痕线。 |
| **手卷** | 整个故事活在一幅长卷上。自右向左平移如展开卷轴;结尾拉回展示全卷并钤印。 |

改编任何主题:找到其核心的**那一个手势**,把它变成一笔。产品发布 → 产品被一笔写出。爱情故事 → 终于相遇的两笔。一段历史 → 随时代展开、末端钤印的长卷。

**45–60 s 的情绪弧线:** 空 → 一滴墨(创生)→ 大空间中的小小人影 → 轻盈/喜悦 → 压倒性的阻碍(以体量画出:一大片湿墨泼)→ 寂静 → 决定性的一笔 → 释放 → 尺度揭示(人影只是整幅画中一个微小的墨点)→ 印。一个人物、一个目标、一次转折。一句哲思式的收尾比凯旋式的更落得住("抽刀断水水更流")。

## 3. 视觉语言

**纸**(程序化,在合成器中生成,不是纹理文件):底色 `#F2ECDE`–`#F3EBDD`(暖宣纸,rgb .95/.925/.87),大块云状斑驳 ±7 %,三个方向的长细纤维(+1.8 % 亮),隐约的纸浆深色小点,相机拉远时淡出的细颗粒(否则会闪烁)。轻暗角(~.22),轻微暖调。纸纹理锚定在世界中,随相机平移。

**墨** —— 五色(墨分五色),作为笔触在纸上的透明度使用(multiply,非 overlay):

| 墨色 | 数值 | 用途 |
|---|---|---|
| 焦 jiao(焦墨) | .96 | 书法、剑、帽檐线、苔点 |
| 浓 nong(浓墨) | .82 | 轮廓、帽、饱墨笔触的深边 |
| 重 zhong(重墨) | .60 | 次要线条、衣褶、剑鞘 |
| 淡 dan(淡墨) | .34 | 山体、衣袍渲染 |
| 清 qing(清墨) | .16 | 远山、面部、雾 |

墨色从低浓度的冷灰 `rgb(.52,.55,.58)` 到全浓度的暖黑 `rgb(.075,.068,.062)`。朱砂 `#B02E22` 只用于印章和主角身上一处极小的点缀(剑穗)—— 它让我们在全景镜头里找到他,并与结尾的印呼应。

**笔触模型**(`demo/ink.js`):中心线(Catmull-Rom,按弧长重采样)× 压力曲线 × 宽度噪声,外加 4–60 根**笔毫**。每根笔毫带一份沿笔画递减的墨量;一个大尺度噪声决定它何处断开。`dry` 0 = 饱满湿笔,.3 = 有肌理,.6+ = 飞白。笔画体的填充随干度 `(1-dry)^1.6` 淡出,因此干笔只由笔毫痕迹构成。
- 压力曲线:`brush`(入笔压、出笔收)、`tip`(两端尖)、`nail`(重头)、`lens`、`fan`(窄 → 宽)、`rise`、`robe`、`even` + 逐点压力。
- **饱墨笔触**(`darkDir`、`side`、`brWet`):笔毫一侧更深 → 笔画自带轮廓。仅此一招,就让衣袍、岩石和波浪读作水墨而非矢量形状。其笔毫进入*湿*层以便融合。
- **湿层与干层**:两块画布。合成器对湿层做渗化(1:1 下约 5 px 的 12 采样含噪 Poisson 模糊、羽化位移),叠加**边缘积墨**(小模糊 − 大模糊)与纸颗粒;干层只加纤维抖动和纸齿断开。
- 体块(斗笠锥、山体)是边缘抖动、细分并带渐变的柔边多边形 —— 绝不是直边平涂。

**山**(`demo/land.js`):逐像素生成一次并缓存 —— 山脊(尖峰指数轮廓、浑圆顶部、3 倍频粗糙度)带脊下渐隐的深色镶边,消散为水平雾带;随后沿坡面下披麻皴纹理笔触、山脊上成簇的苔点。远山:墨色 .12–.16,无纹理。近山:.4–.5 带纹理。山列端部用水平 alpha 遮罩淡出,绝不用倾斜山脊的方式(它会穿过江面)。

**岩石/崖壁**:轮廓(断续、粗细变化的焦墨段)→ 纹理(沿棱线的短斧劈皴)→ 渲染(阴影侧的饱墨竖笔,向下没入雾中)→ 点。**松**:一段虬曲的饱墨主干、几笔尖枝、扇形针簇。**芦苇**:长尖笔 + 凸透镜形叶;仅限前景,在画面底部。

**水**:白纸。动感由几道浅淡干痕、每次落脚处的椭圆**墨圈**(一笔,1.86π,留开口,按 r ∝ age^0.6 扩展并在 ~2.4 s 内淡出)表现;当水变为实体(一堵墙、一浪)时,用宋代风格的**平行水纹线** —— 近边缘密而深、远离处疏而淡 —— 加几处小卷。绝不用均匀线条给笔画体排线(会变成铁丝网)。

**波浪**:浅淡湿墨体 + 沿浪面扫上并在浪头卷过的 4–5 条巨大饱墨笔触(笔触方向*即是*水的运动)+ 几条细水纹 + 不规则墨点作飞沫。

**书法**:用 OFL 毛笔字体(楷书用 Ma Shan Zheng)作**骨架参考**:按笔顺在字形上描出每笔的中心线,由字形粗细设定压力,为藏锋入笔加一个 45° 引入点,撇/钩出笔收细到 .12–.18。以 `solid: true`(笔画体进干层 + 湿晕)和低干度(.17)绘制。不要用字形轮廓裁剪笔画 —— 交叉处会产生缺口。

**人物 —— 写意人物**(`demo/hero.js`):100 单位高的骨架(关节字典:髋、胸、头、臂、腿、下摆点、张口、鞘、飘带),每次绘制重画为笔触。寥寥数笔:斗笠 = 一块湿墨体 + 两条干脊线 + 一笔焦墨檐线;衣袍 = 一块淡墨底体 + 两笔饱墨(前后各一道深边);腿/剑 = 焦墨线;一条飘带随风。面部几乎总藏在斗笠下;仅展示一次(特写或终场鞠躬)用 3–5 笔:剑眉、凤眼眼睑、一笔鼻线、下垂的髭须。

**片名与印**:片名为竖排(英文字形旋转 90°,Cormorant SC 600,宽字距),置于画中空白处,配一枚代码绘制的朱砂白文印(略不规则的红方块中阴刻篆书式线条,带印泥斑点)。

## 4. 运动语言

- **角色以 12 fps 步进**(一拍二);他们的*位置*、相机、墨晕、涟漪、泼溅和波浪以 24 fps 一拍一动。姿态是关键帧关节字典,用 smoothstep 混合。
- **一拍二上的稳定笔画**:每笔以其索引为种子,并沿*归一化*弧长 × 固定参考长度(`gapLen`)计算笔毫断开与宽度噪声,而非实际长度 —— 否则飞白的缺口每次绘制都在爬动,人物闪烁成一团模糊。宽度噪声只允许每个绘制周期一个小的"沸腾"相位(5 绘制周期循环)。
- **轻功腾跃**:身体前倾 ~30°,一膝收起,另一腿后摆,衣袍向后拉成一大块带深色后边的淡墨体,衣袖飘带。步周期:触地(14 %)→ 上升 → 滑翔(45 %)→ 下降;高度 `sin(π·phase)`。每次触地一圈墨环。
- **被画入存在**:笔画按绘制顺序出现(`p` 进度),每一笔落在一个拨弦音上。
- **出手前的静**:画面定格(只有 5 % 的缓慢推入)贯穿全然寂静,随后决定性的一笔约 4 帧横贯画面。后果(浪的裂开)推迟到该笔完成之后。
- **裂开体块**:渲染到临时层,沿切口线两侧用裁剪路径画出两半;上半升起/旋转并淡出,下半塌落压扁;沿两道撕裂边缘加卷曲浪头和淡墨色块;泼溅沿剑向带重力飞出并留在纸上。
- **墨晕**(揭示/转场):对增长的半径使用含噪放射遮罩 `d·(0.62 + 0.8·fbm)`,前缘带深色水痕带。对单个世界元素用世界锚定噪声中逐帧计算的低分辨率(1/4)遮罩和 `destination-in`;场景转场在合成器中于两组图层之间进行。

## 5. 镜头语言

| 节拍 | 相机 |
|---|---|
| 开场 | 固定机位的白纸;墨滴落入其中。先给"无",再给"有"。 |
| 定场 | 缓慢的右至左平移(展卷),落在一幅**高远全景**上:人影 150–180 px 高,江面是一大片空白。 |
| 旅途 | 横向跟移,人影占画面约 60 %,前方留出引导空间;远山视差极慢;偶有深色芦苇从最底部掠过。 |
| 威胁 | **低角度**,地平线压低,体块高耸,人影缩在角落;缓推并加剧抖动。 |
| 寂静 | 硬切到极特写(帽檐,无眼);然后一个把人影、写就的字与威胁压在同一轴上的**过肩**画面。 |
| 释放 | 回到与定场相同的高远尺度 —— 押韵显出何者已变。 |
| 结尾 | 从人影连续拉回到装裱在绫绢上的整幅手卷;钤印;卷下方的片尾卡。 |

## 6. 声音

- **音乐 —— 古琴主导,不是钢琴+弦乐**:古琴(`core/audio/pluck.py` `guqin`:散音、带滑音 `bend` 的按音、吟猱 `vib`、泛音 `harmonic=True`、以 `P.strum` 扫弦),箫的替代(采样长笛,低八度、低通、气声跟随包络),大鼓(`gran_cassa`)+ `timpani`,脚步用 `frame_drum`,钤印用一面小锣。F 宫五声(F G A C D)。按提示而非循环组织:散板开头、风景 60 BPM、旅途 90 BPM(脚步踩拍)、威胁用鼓滚、**数字静默**、三个泛音玻璃质感的音对应三笔写就的笔画、再静默,然后裁切处鼓 + 七弦扫弦;释放段主题回归;最后一个音 = 钤印。
- **静默是字面意义的**:在静默窗口内把整条总线(音乐、环境、混响尾音)以 20 ms 淡变归零;切入静默处环境声硬切。静默中仅允许的声音:一声水滴、剑鸣。
- **拟音跟随材质**:墨滴(短促下落"叮" + 轻湿闷响)、笔/剑破空(带笔毫颗粒的带通噪声,不是金属呼啸)、水上落脚(小溅 + 咚 + 水珠)、抽剑(鞘擦 + 细长金属鸣,在第二段静默前切断)、那一裁(撕裂空气 + 江吼 + 低沉轰鸣)、墨溅(几十个细小的湿点声)、钤印(木闷响 + 纸脆声)。
- **配音**:沉静的英国口音旁白(Kokoro `bm_george`,lang `en-gb`,speed .82–.86),4–6 句,如题跋式铭文 —— 不解释画面。配音下方音乐压 ~8 dB;环境同样压低(一句台词下面轰鸣的江声让 whisper 把 "Halfway" 听成 "This way")。每句用 whisper 验证并在最终混音中复查。

## 7. 字幕与片名

- 字幕即**题跋**:Cormorant Garamond italic 500,46 px,墨色,1 px 字距,至多两行,无底框 —— 放在每个镜头的空白纸处(每个镜头定义自己的字幕位置)。每行起始处一枚小小的朱砂方点。它们以"湿"态出现(部分处于渗化层中),约 0.35 s 内变干。停留 ≥ 配音 + 0.6 s 且 ≥ 1.8 s。
- 片名:两列竖排,直接写在卷上(随平移移动)+ 印;以湿 → 干的方式淡入,平移开始时蒸发消散。
- 片尾卡:整幅手卷置于带绫边和卷轴的深色案上;"CHINESE INK WASH"(Cormorant SC 600,44 px,14 px 字距)与署名行(斜体 30 px)以淡纸色置于下方。

## 8. 我们踩过的坑

- 干笔画出来像虚线 → 笔毫断开必须用大尺度噪声和沿笔画递减的墨量。
- 平行的半透明笔画让衣袍像管风琴管 → 一块底体 + 两笔饱墨。
- 大尺度侧锋大笔触像发刷(每根毫都可见)→ 用带渐变的体块加更少、更低干度的笔画;笔毫笔画留给较小的宽度。
- 山体渐变以竖直条带绘制留下接缝和硬底 → 逐像素山体层,缓存。
- 笔画体分进湿干两层降低了密度(并集 < alpha)→ `solid` 模式把完整笔画体画进干层加湿晕。
- 用字形轮廓裁剪书法造成缺口 → 字体只作骨架。
- 角色笔画在一拍二上重绘产生闪烁 → 固定 `gapLen` 的归一化弧长噪声。
- 平移镜头中字幕继承了世界相机变换滑出屏幕 → 绘制屏幕空间叠加层(字幕、海报上的印)时永远先重置变换。
- 用 `flip=-1` 画的悬崖让人影悬空;悬崖多边形的背面露出一道竖直硬边;岩石底部被图层画布底边裁掉 → 翻转后重新计算屏幕范围、背面画成斜边、用 `destination-in` 渐变淡出图层底部。
- 笔触还在横贯画面时裁切就已开始劈浪 → 笔画结束后再开始后果。
- 少见且每像素开销很重的场景可能超过 Playwright 默认截图超时;重试静帧渲染即可(帧本身是确定性的)。

## 9. 制作配方(本仓库)

```
styles/ink-wash/demo/
  ink.js     笔刷引擎(笔画、笔毫、体块、墨点)      comp.js    WebGL 宣纸合成器(渗化、边缘、纸、墨晕)
  hero.js    写意人物骨架 + 姿态                    face.js    特写面孔(一次性使用)
  land.js    山、皴、崖、松、芦苇、涟漪             wave.js    写意波浪
  glyph.js   从 Ma Shan Zheng 描出的 "水" + 裁切笔  seal.js    朱砂印
  world.js   手卷世界、揭示、镜头 1–2               cross.js   渡江与升起(镜头 3–4)
  climax.js  寂静、书写、裁(5–6)                  passage.js 分水、鞠躬、卷、片尾卡(7–8)
  story.js   时间线(唯一事实来源)                  shots.js   分发器、转场、字幕点位、声音事件
  subs.js    题跋字幕   music/score.py  原创古琴配乐   mix.py  拟音 + 配音 + 音乐   build.sh
```

1. 先写 `story.js` 的时间(配音时长来自 `core/tts/tts.py`),再用同一组数字给配乐下简报(作曲可并行)。
2. `node core/render/still.mjs styles/ink-wash/demo --range a:b:1` + `core/render/sheet.py` 做总览图;设计用 `?test=sheet|pose|shui|frame` 页面;`?nosub=1`、`?poster=1`。
3. `node core/render/events.mjs` → `mix.py` → `video.mjs --fps 24 --workers 3`(1152 帧 ≈ 60–130 s)→ `mux.sh … 24 0`(颗粒 0:纸在 shader 里)。
4. 或者直接 `sh styles/ink-wash/demo/build.sh`。
