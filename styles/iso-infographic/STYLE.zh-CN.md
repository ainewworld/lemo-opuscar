# 等距信息图(Isometric Infographic)— 风格提示词

> 一个系统的流程图活了过来:一座等距立体微缩模型,平面三色块、细墨线标签和 Isotype 数字。相机一个长镜头走遍整个系统,把事物剖开来展示内部,最后一路拉远,直到影片本身变成一张可印刷的信息图。
> 演示片:*From Bean to Cup*(58.8 s)· `iso-infographic.mp4` · 源码在 `demo/`
> **参考(仅借鉴语法):***Monument Valley*(2014):真正的等距建筑、平涂色块、每个面固定三个色调、只会平移缩放而绝不打破投影的相机。*SimCity 2000* 式剖视模型:一块悬浮的、带土壤分层和海洋剖面的板子,整个系统一览无余。Kurzgesagt:一个提问、稳定的向前推进、每步一个清晰的视觉隐喻,数字大到无法感受时就切换尺度。Isotype(Otto Neurath / Gerd Arntz):重复的相同图标代表数量。*Powers of Ten*(Eames,1977):穿越嵌套尺度的连续下潜。不使用它们的任何角色、建筑、图标、配色或音乐。

你要以**等距信息图(Isometric Infographic)**风格执导一部 45–60 秒的影片。用户给你一个主题,通常是一个流程、一条供应链、一个生命周期或"X 如何到达 Y"。其余一切(故事、地图、站点、数字、相机、声音)由你决定,并交付一部完成的影片。遵循本指南。

---

## 1. 这个风格是什么

整部影片是**一张等距地图**:一块方形模型板,投影后恰好是一个接近 16:9 的菱形。流程的每一步是板上的一座**站点**。一条虚线**路线**连接各站。相机从不硬切。它沿路线推进、拉远、平移、跟随,每个站点以同一方式讲述:**一个动作、一个标签、一个由图标构成的数字。**

它成立的关键:
- **平面的真等距。** 无透视、无描边。形体只靠每个面的三个色调区分。
- **信息图家具是画面的一部分。** 引出线、标签大头针、剖切线、剖面线阴影面、跟踪圆环和图例都活在地图上。
- **单一被跟踪主体。** 一个物体(一颗豆、一个包裹、一滴水)带着"你在这里"的圆环穿过整个系统。这把一张示意图变成了一个故事。

## 2. 故事:什么适合这个风格

| 天生优势 | 故事用法 |
|---|---|
| **一镜到底模型** | 任何流程都变成一块板上的路线。把路线铺成**横跨方形板的 Z 形**(远角 → 右 → 中部横穿 → 近角)。直条会浪费结尾的拉远,而方形板恰好填满 16:9。 |
| **剖视** | 一个统一手势:虚线**剖切线**画出,近侧外壳**沿法线滑出并淡去**,留下**带剖面线的切口边缘**。用于水果、船体、集装箱、麻袋、建筑或机器。 |
| **Isotype 数字** | 每个站配一个由相同图标构成的数字,每次排列都不同:3×7 的太阳日历、14 个集装箱图标(1 = 1,000)、一行昼/夜、一支上升的温度计、70 颗豆**排成一只杯子的剪影**、一根 11 格的距离条。 |
| **焦点 + 语境** | 在情绪峰值处,**把主体之外的一切去饱和**(引擎的单色钩子)。这是信息图自己表达"就是这一个"的方式。 |
| **画中画** | 细节标注:一条引出线从地图上长出,末端是一个展示特写的圆形插图。系统与个体同屏。 |
| **尺度揭示** | 结尾拉远到整块板。路线逐站点亮,所有标签同时出现在屏幕上,最后一帧就是一张完成的信息图。 |

**故事形状(在演示片中验证过):**
1. 开场是主体抵达一只手掌的超特写,带标签:**0 km**。
2. 拉回到第一个站点和片名。
3. 数字逐站增长(2 粒种子 → 每麻袋 400,000 颗豆 → 14,000 个集装箱)。主体迷失其中。
4. 在最繁忙处,穿过嵌套剖视下潜并找到它:寂静,和仅剩的唯一颜色。
5. 影片中最响的声音打破寂静,相机猛地拉出。时间跳跃藏在那次下潜里。
6. 转化站点,第二段寂静,然后是轻柔的回报。
7. **呼应:** 相同的特写构图、不同的手和不同的物体,标签此时读出总量。拉回到完整地图。

**数字必须对得上。** 这个风格靠可信度活着:400 + 10,500 + 100 = 11,000 km,Isotype 条按同样比例着色。把流程的真实顺序放在屏幕上(演示片中咖啡豆以生豆运输、在目的国烘焙),如果你改动了 brief 中的顺序,在剧本大纲(treatment)里说明原因。

## 3. 视觉语言

- **投影:** 真等距,轴间 30°。`sx = (x − y)·cos30°·k`,`sy = ((x + y)·½ − z)·k`。世界 x 朝右下,y 朝左下,z 向上。画家算法深度 = x + y + z。绝不旋转或倾斜视图。
- **每面三色**(顶亮 / 左 = +y 面中等 / 右 = +x 面深),按法线逐面选取:
  - 咖啡红 `#CF5140 / #B3352B / #8C2620`
  - 叶绿 `#7BA75F / #5E8C4A / #476F37`
  - 海蓝 `#5A9BCB / #3C7FB1 / #2D6390`
  - 奶油 `#FBF4E6 / #F2E6D0 / #D9C8A9`
  - 土壤 `#A77850 / #8A5B3A / #6A432A`
  - 芥末黄(起重机、道路)`#E9BE5C / #D9A53A / #B0832A`
  - 墨 `#2E2522`
  - 其他颜色由 `tri(c)` 生成:顶面朝暖白混 20 %,暗面朝 `#231A2C` 混 22 %,让阴影略偏冷。
- **实体无描边。** 墨线(2 px)留给信息图元素:引出线、大头针、剖切线、圆环、路线和标签。
- **底板:** 悬浮在奶油色 `#F2E6D0` 背景上,带浅淡的等距点阵和柔和模糊投影。它的两个正面展示三层土壤加卵石,以及海与板缘相接处的一根三蓝水柱。海岸坡只画朝向观众的一侧。
- **需要在全景中可辨识的站点**得到**带虚线墨描边的浅奶油底板**和一处强调色(砖红色烘焙厂、红奶油条纹雨棚咖啡馆)。周围的建筑保持低矮。
- **人物:** Monument Valley 式极简立牌,圆头、双色收身躯体、一条粗臂笔画、以帽子或发型辨识。无面孔。12 fps 步进。
- **主体特写(手):** 三种肤色的平面多面形状(掌心向上亮色、两侧中等、底下深色)、角色色的袖子、手指为朝观众卷曲的两段圆胶囊。开场和结尾的手共用**同一姿态、相机、变焦和标签位置。** 只变肤色、袖子和物体。
- **标签(大头针):** 一个点(墨圈、奶油填充)→ 一段竖直引线 → 一条水平短线 → 文字。标题为 Jost 600 全大写、字距 0.12 em。数字为 Jost 400 44 px,单位 Jost 500 半号。文字带 7 px 奶油晕圈,在任何颜色上都可读。大头针可指上或下、左或右;逐站选择,让标签永不遮住主体。
- **片名:** Jost 700 的词以等距色块的形式挤出来,放在平躺于地平面的奶油底板上(奶油面、咖啡红侧面),每词一个八分音符。
- **云:** 带假视差的平面等距云(1.25× 地面运动)。在 k ≈ 40 以上淡出。

## 4. 运动语言

- **没有线条引路,任何东西都不动。** 路线略先于故事画出,插图打开前引线先长出,外壳滑开前剖切线先画好。
- **剖视节奏:** 剖切线 0.3 s → 外壳滑出 0.35 s(ease-out,alpha 在 10 % 到 75 % 之间 1 → 0)→ 带剖面线的边缘在最后 40 % 内淡入。
- **Isotype 填充:** 图标带回弹缓动(过冲 2.2)逐个弹出,每十六分音符一个。计数数字(km、°C)在同样时值内走完。
- **累积 = 加速。** 演示片中集装箱先落在四分音符上(由起重机),再八分,再四波各约 44 箱的十六分音符(下落 7 单位带小弹跳)。眼睛感到系统正在接管。
- **主体的表演:** 落地压扁(18 %)加两次小弹跳;寂静中随船身摇摆(±0.09 rad);烘焙机中的颜色变化(绿 `#A9B27C` → 黄 `#D9C27A` → 肉桂 `#B07A45` → 棕 `#6A3B22`);一爆为放射状墨色弹点。
- **车辆**沿折线路径 ease-in-out 行进并朝向切线方向。船转弯前先移出码头;否则船尾会扫过起重机。

## 5. 镜头语言

相机 = 一个世界中心 + **对数插值的变焦** k(每单位像素数)。演示片从 k = 3.75(整块板)跑到 8,000(一颗豆)。

| 节拍 | 相机 |
|---|---|
| 开场 | 手的超特写(k ≈ 600),轻微漂移。相机位于掌面上方 0.17 单位,让分枝能装在上方。 |
| 片名 | 拉远 ×35 到第一个站点(位置 eio,变焦对数线性),片名底板同时升起。 |
| 站点 | 保持全景,为细节打开一个圆形插图。 |
| 转移 | 下降(吊臂)或跟随一辆车;下一站的声音先到。 |
| 繁忙站点 | 先锁定,随系统填满而拉出。 |
| 呼吸 | 在空旷水面上长距离横向跟随。 |
| 快进 | 带尾迹和昼/夜图标行的跟随。 |
| **下潜** | 穿过嵌套剖视的三次推进,**慢 → 更快 → 最快**(0.9 s、0.6 s、0.6 s),读作一次坠落。每下一层有一种乐器退出,低通收得更紧。 |
| 寂静 | 缓慢推进(k 3,200 → 8,000),颜色从主体之外的一切中流失。 |
| 猛拉出 | 1.2 s 内拉远 ×470,变焦对数上 ease-out。凡会在拉远中扫过画面的高物都淡入。 |
| 呼应 | 以完全相同的构图推进到第二只手。 |
| 结尾 | 拉回到整块板;片尾卡放在空出的奶油角落。 |

在关键时刻(两只手、滚筒、带圆环的豆)让主体至少占画面高度 1/3,并保持底部 170 px 留给字幕。

## 6. 声音

- **音乐优先。** `demo/timeline.js` 是时刻的唯一事实来源。配乐、拟音事件和检查都读它(`tools/cuecheck.py`:68 个提示点,0 ms 偏移)。
- **配乐:** 原创的**原声世界律动**,约 100 BPM。尼龙吉他指弹(D–A–Bm–G)与卡林巴,随后沙锤、邦戈、cajon 反拍和康加鼓,港口和海上加原声贝斯(`jazz_bass`)。快进段转 B 小调色彩。无钢琴、无弦乐铺底。三音**咖啡豆动机**用卡林巴(A4–F#4–D4)在第一次落地、终场标签和结尾站点琶音中出现。咖啡馆段从 100 慢到约 70 BPM 并停住;寂静之后一把吉他以 80 BPM 重启。
- **两处真实静默:** 下潜(30.0–33.6 s;只剩线路声和 −66 dB 的船体吱呀)和第一滴咖啡之前(45.3–45.9 s;数字零)。每处之后的第一声都是全片最重要的声音之一:**汽笛**(约高于一切 10 dB;D2 锯齿波叠置带失谐和 2.8 s 尾音)和**一滴落入空杯**。
- **三层:**
  - **环境底**,每站一条并交叉渐变:山丘风、树叶和鸟;港口、海鸥与起重机蜂鸣;海涌;城市嗡鸣;咖啡馆人语;清晨麻雀(与山丘同一种鸟合成器,音调升高)。
  - **按材质拟音:** 折断茎秆的纤维脆响、樱桃落掌的肉感闷响、樱桃落网筛的颗粒咔啦、豆粒倒入黄麻袋、集装箱门与落地的非谐钢分音、黄麻撕裂、滚筒随旋转的隆隆、干燥爆裂声、磨豆机啸叫加碾磨、压粉的"嗒"、陶瓷轻响和音高上行的倾注。
  - **音乐**,在配音下压约 8 dB。旁白说话时环境压 7 dB、鸟静音:词尾一声鸟啾让 whisper 把 "travel" 听成 "travels"。
- **声音转场:** 港口出现前 0.6 s 的港口噪声 J-cut、烘焙机炉壁打开前 0.6 s 的滚筒声、汽笛尾音进入城市的 L-cut。终场拉远中,每个站点奏一个卡林巴音。
- **配音:** Kokoro `bf_alice`,0.88–1.0,六句短句,每句在干声和最终混音中都经 whisper 验证。

## 7. 字幕与片名

- **字幕就是地图标签。** 奶油色 `#FBF4E6` 卡片,10 px 圆角、2 px 墨边,一枚咖啡红等距小方块作图例芯片,Jost 500 42 px 墨色文字。位于底部居中、距底边 64 px。边框先画入(0.2 s),文字从左到右擦入;退出时下滑 8 px 并淡出。
- 每行保持 ≥ max(1.8 s, 语音 + 0.6 s)。各行互不重叠,也不与片名或片尾卡重叠。
- **片尾卡 = 地图的图例**,放在空出的奶油角落:片名、风格名、带 Isotype 条的总量、"Lemo-Opuscar · LemoLab × Claude Opus 5.5"、署名。"NOT TO SCALE" 既诚实又是个小玩笑。

## 8. 我们踩过的坑

- **Newell 法线与顶点顺序:** 盒子的 +y 面被当作背面剔除。给每个面一个向外的提示(`out`),剔除前把法线翻到与之一致。
- **复合体的画家排序:** 梯田山丘上的灌木出现在下一层梯田前面。把山画成一项:先每层梯田、后其后排灌木,所有梯田画完再自上而下画前排。起重机的吊臂需要大的深度偏置才能压在船上方。
- **半透明的下落集装箱像幽灵。** 只用运动,不用 alpha。
- **船头压在沙滩上**即便几何上在水里也读作"搁浅"。每条船体周围留出可见的水。离港时先平移出码头再转向。
- **下潜中的时间跳跃:** 画面只剩豆子时,船从中洋瞬移到目的码头。把豆子场**画在屏幕空间、锚定在被跟踪的豆上**并按 k 缩放;它的布局便不依赖船头朝向,跳跃不可见。
- **主体特写身后的巨型世界几何:** k = 600 时一丛灌木是一枚画面大小的绿色圆盘。k > 120 时跳过灌木,在主体层后画一块平面背景幕,随它一起淡出。
- **拉远穿过起重机**给出一帧巨大的吊臂。按变焦淡入高物(`alpha = clamp((80 − k)/40)`)。
- **whisper 与环境嘶声:** 词后连续的叶沙声(2.5–7 kHz)把 "travel" 变成 "travels"。对白下方把高频底噪压得很低。
- **红顶白盒的机器读作房子。** 用钢灰色、深色前面板、顶上的杯子和一个出粉手柄。
- zsh 中 glob 失败会中止 `&&` 链,所以 shell 循环要用 `bash -c` 跑。

## 9. 制作配方(本仓库)

```
styles/iso-infographic/demo/
  timeline.js   节拍网格、提示时刻、字幕、km 数字(唯一事实来源)
  engine.js     风格本体:投影、相机、三色实体、标签、插图、剖视、Isotype、人物、任意形状挤出
  world.js      底板:海岸、梯田山丘、苗床、道路、港口、船、起重机、城市、剖视建筑、货舱/集装箱/麻袋
  hero.js       特写:手掌、采摘手指、分枝、樱桃、杯子、km 标签
  film.js       相机路径、故事状态、站点、叠加层、字幕、片名/片尾卡、声音事件
  music/score.py   原创配乐(采样器)      mix.py   环境 + 拟音 + 配音 + 闪避
  tools/        cuecheck.py subs.py final_asr.py review.sh      tests.js   主体与任意形状测试场景
```
1. 先写 `timeline.js` 和提示图。底板在世界单位中画成正方形(S = 240)。先铺 Z 形路线,再排站点。
2. 搭建站点场景,用 `?k=…&cx=…&cy=…` 静帧按各自变焦逐一检查。单独渲染两个手的特写(`?test=hero`、`?test=hero&end=1`)直到吻合。
3. `sh demo/build.sh` 约 2 分钟重建全部:TTS → whisper → 配乐 → 事件 → 提示检查 → 混音 → srt → 渲染(1,411 帧,2 worker 约 35 s)→ 封装(−14 LUFS,颗粒 0)→ 最终 whisper → 静帧。
4. 至少两次用 `bash demo/tools/review.sh out/revN 6 $(seq 0.3 1 58.3)` 复查,外加从封装后的 mp4 取出的下潜、猛拉出、落地和倾注的帧条。

## 10. 引擎用法

`demo/engine.js` 是无依赖的 Canvas 2D ES 模块代码。一切排队并按深度排序,直到 `flush()`。

| API | 作用 |
|---|---|
| `new Iso(ctx, W=1920, H=1080)` | 引擎实例。`iso.cam = {x, y, z, k}` 设定位于屏幕中心的世界点和变焦(每单位像素)。 |
| `iso.P(x,y,z)` / `iso.unP(sx,sy,z)` | 投影与反投影。 |
| `iso.push(ox,oy,oz,rot,s)` / `iso.pop()` | 局部坐标系(平移、绕 z 旋转、缩放),用于车辆和船。法线一起旋转,任何航向下着色都正确。 |
| `iso.box(x,y,z,w,d,h,tri,{decal,bias,layer})` | 轴对齐盒体,三色。`decal(I)` 在其面上绘制(窗、肋)。 |
| `iso.prism(pts2d,z,h,tri)` | 挤出任意底面多边形。朝向自动,各侧面按法线着色。 |
| `iso.cyl(x,y,z,r,h,tri,{axis:'z'|'x'|'y', n, spin, stripe})` · `iso.cone(...)` · `iso.roof(...)` · `iso.sphere(...)` | 圆柱(立或卧、旋转条纹)、圆锥、坡屋顶、带受光顶盖和暗月牙的平盘球。 |
| `iso.flat(pts,z,color)` · `iso.line3(pts,color,px,{dash})` · `iso.bill(x,y,z,fn)` | 地面贴花、3D 折线、公告板(按变焦缩放的 2D 绘制:人物、手)。 |
| `iso.text3(str,x,y,z,{plane:'xy'|'xz'|'yz', size, extrude, tri})` | 世界平面上的等距文字,可选挤出。 |
| `iso.desat = 0..1`,`iso.keep = true` | **单色钩子:** 除以 `keep = true` 绘制的项之外,一切朝暖灰去饱和。 |
| `iso.sub(fn)` | 排序子队列,用于画在前后墙之间的内部。 |
| `tri(hex)` · `PAL` | 三色生成器与调色板。 |
| `pin(iso,x,y,z,{title,num,unit,dir,up,len,a,icons})` | 标签大头针,带揭示参数 `a`。`icons(g,x,y,dir)` 在其下画一行 Isotype。 |
| `inset(iso,ax,ay,cx,cy,r,a,drawIn)` | 带引出线的圆形细节插图。 |
| `cutLine(g,pts,a)` · `hatch(g,pts)` · `ring(g,x,y,r,a,t,tag)` | 剖切线、剖面线阴影面、带标签的旋转虚线跟踪环。 |
| `ICON.sun/moon/box/sack/bean/cherry(g,x,y,size,lit)` · `iconGrid(g,x,y,n,lit,cols,gap,draw)` | 同一三色语言的 Isotype 图标;点亮数 m 可为小数(渐入)。 |
| `person(g,{body,hat,hair,skin,arm,face,h,basket,apron,tool})` | 供 `iso.bill` 用的极简人物。 |
| `shape(iso, pts2d, [x,y,z], {color, depth, plane, scale})` | **用本风格画任何形状:** 一条 2D 轮廓变成按三色规则着色的等距实体。`sparkPath(n,r,inner)` 和 `cursorPath(h,w,x,y)` 是现成轮廓。 |

最小示例:底座上一个暖橙色 `#D97757` 带光标尾的四芒星,加标签(`?test=spark`,输出在 `demo/stills/engine_shape.jpg`):

```js
import { Iso, PAL, shape, sparkPath, cursorPath, pin } from './engine.js';
const iso = new Iso(ctx); iso.cam = { x: 0, y: 0, z: 2.5, k: 70 };
iso.box(-6, -6, -1, 12, 12, 1, PAL.cream);                                          // 底座
for (let i = 0; i < 5; i++) iso.box(-5 + i * 2.2, 3.2, 0, 1.6, 1.6, .6 + i * .5, PAL.blue);
iso.keep = true;                                                                    // 唯一保留颜色的元素
shape(iso, sparkPath(4, 2.2, .22), [-1, -1, 5], { color: '#D97757', depth: .9, plane: 'xz' });
shape(iso, cursorPath(2.4, .45, 2.7, 0), [-1, -1, 5], { color: '#D97757', depth: .9, plane: 'xz' });
iso.keep = false;
iso.desat = 0;          // 设 1 让火花之外的一切变灰(焦点 + 语境)
iso.flush();
pin(iso, 0, -1, 7.6, { title: 'ANY SHAPE', num: '#D97757', dir: 1, up: 90, a: 1 });
```
