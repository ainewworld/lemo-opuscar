# 低多边形等距岛屿(Low-poly Isometric Island)— 风格提示词

> 透过一个正交等距镜头看到的微小棱面世界:一切是几何块,一切出现的东西都伴着一次弹跳和一个音符到来。
> 演示片:*The Island That Grew*(53 s)· `lowpoly-island.mp4` · 源码在 `demo/`

你要以**低多边形等距岛屿(Low-poly Isometric Island)**风格执导一部 30–60 秒的影片。用户给你一个主题。其余一切 —— 故事、镜头、节奏、音乐、声音 —— 由你决定,并交付一部完成的影片。遵循本指南。

---

## 1. 这个风格是什么

一个由**平面着色的低多边形几何**搭建的微缩世界(六边形柱状地块、带山墙屋顶的盒子房子、圆锥松树、二十面体树),漂浮在一片棱面之海中,由一架**正交相机**以等距角度注视。没有透视、没有地平线:远处的水消融进**屏幕空间的天空渐变**,于是世界像悬在颜色里的模型。是光而非纹理在讲述时间 —— 太阳移动时每个棱面变色,夜里仅剩的颜色是温暖的窗户和一道灯塔光束。

学习自:*Townscaper*(建造即表演;每个部件带弹性弹跳和声音落地;房子自动长出可爱细节)和 *Monument Valley*(等距几何、柔和粉彩调色板、渐变天空、平静节奏、大量留白)。**不要**复制它们的网格、建筑、角色、UI 或字体。绝不在画面上提到它们的名字。

## 2. 故事:什么适合这个风格

选**媒介本身完成叙事**的故事。这个风格有五种天生之力 —— 至少用三种:

| 天生优势 | 故事用法 |
|---|---|
| **程序化生长** —— 地块从海中升起,楼层以弹性着陆堆叠,树木弹出 | 情节是某物在生长。每次生长事件 = 一个声音 = 一个音符。 |
| **正交凝视** —— 无消失点,世界读作桌游模型 | 纯变焦做尺度揭示:开头一个物体占满画面,结尾整个世界是一粒微尘。 |
| **转台旋转** | 一个连续旋转的镜头从每个侧面展示被建造之物。 |
| **平面着色 × 光照方向** | 无需任何纹理工作量的昼夜循环与延时:阴影扫过,棱面重新着色。 |
| **黑暗中的自发光块** | 灯一盏盏亮起;一道光束像钟针或八音盒的梳齿一样扫过世界。 |

**招牌手法(来自演示片):"建造即作曲。"** 每次生长事件从页面导出一个 MIDI 音符;配乐的旋律声部直接从这些事件合成,于是画面真的写下了曲调。给它回报:演示片中灯塔光束每 12 拍转一圈,每拍经过一个环上的格子;站在这些格子上的八座房子在它经过时点亮并鸣响,于是按乱序建起来的音符按**空间顺序**作为完整主题被重放。任何主题都能用:一座楼层即音符的城市天际线、一座花朵即和弦的花园、一件逐部件装配的产品。

改编任何主题:把它变成**一个生长、度过一天、并遇到一个由最后一块解决的小问题的小世界**。保持一个主体(一座岛、一个镇、一座花园),一个目标(变完整 / 变成家),一次转折(夜幕降临,缺了什么 / 有人迷路)。

**45–55 s 的情绪弧线:** 空 → 第一个音符 → 加速的建造之乐 → 安居的一天 → 黄昏暖意 → 缺了一样的静夜 → 最后一块点燃(高潮)→ 拉远见尺度,呼应开场。

## 3. 视觉语言

- **相机**:`THREE.OrthographicCamera`,方位角默认 45°,仰角**30°**(建造)、**33–35°**(白日细节)、**20–25°**(夜 —— 更低的角度拉宽天空带好露出星星)、**50°**(某物扫过世界时的近顶视)。视锥体高度即"变焦":特写 5–7 单位,整岛 12–16,终场尺度揭示最多 420。相机放得足够远(距离 ≥ 3 × 视锥高),否则画面底部看着在海面以下。
- **几何**(世界单位 = 一个六边形地块的外接圆半径):尖顶六边形柱(`CylinderGeometry(r, r, h, 6)`),轴向坐标 → 世界 `x = √3(q + r/2)`、`z = 1.5 r`。中心格周围的第二环恰好 12 格、以精确 30° 分布,适合旋转/节拍同步的创意。高度:沙 0.36–0.42,草 0.74–0.9,丘陵 1.1–1.4,岩石峰 1.95。一块独立的 0.16 厚顶盖(草/沙)盖在更深色的侧面颜色上;**把侧柱顶端沉到顶盖以下 0.1**,否则 z-fighting。地块间留 1.5 % 缝隙,让 AO 画出接缝。
- **道具**:盒子房子宽 0.92、每层 0.62,山墙屋顶棱柱(出檐 0.08)山墙面同墙色;窗是每栋房子各自自发光材质的小四边形;圆锥松(6 面)、二十面体(detail 0)阔叶树、3 面锥棕榈叶;风车(6 面收分塔、4 叶);桩上的码头木板;小船 = 一节捏扁的盒体船身 + 三角帆;灯塔 = 4 节白红相间的 8 面收分环 + 深色廊台 + 自发光玻璃 + 红锥顶。
- **材质**:`MeshStandardMaterial({ flatShading: true, roughness: .88 })`,完全不用纹理。每个地块亮度抖动 ±4 %,免得地面像电子表格。
- **调色板(sRGB)**:沙顶 `#f3dfab` / 侧 `#e2c68e`;草 `#93c96c`、`#7fbd62`;土侧 `#c99c6e`;岩石 `#b4b8bd` / `#8f949c`;墙 `#fbf3e6 #f5c2b0 #b5dccb #a9cbe8 #f7df8f #e9c9e6`;屋顶 `#d9644a #4f7fb8 #e0874f #6a5a8e #3f8f86`;松 `#3f8a5a #4f9c63`;叶 `#7fc36a #9ad06f`;暖窗 `#ffc676`;灯塔 `#f6f2ea` / `#d9544a`。
- **海**:一块 220×220、200×200 段的平面,非索引,在 `onBeforeCompile` 中被四条正弦之和顶点位移(振幅 ≈ 0.2),`flatShading` 让每个三角独立闪烁(roughness 0.55 —— 更低棱面会闪白)。一块 0.55 之下的 5000 单位粗平面覆盖拉远。**浅潟湖**:一块每帧重绘的 512² 画布,在地块升起处画柔和色团,由水 shader 采样以混合深 → 浅颜色和一圈微弱泡沫边 —— 潟湖随岛一同生长。每个地块水线处一道窄白六边环(0.99–1.12 r,不透明度 ≈ 0.32)= 浪花。
- **没有地平线的天空**:后期中把正交深度线性化,把远处像素混合进一条竖直的屏幕渐变(地平线色 → 天顶色)。雾起止设为视锥高度 × cot(仰角)的比例,于是"地平线带"在任何变焦下都保持在画面上三分之一。星星(哈希网格、闪烁)只出现在雾浓处。
- **昼夜关键帧**(天顶 / 地平线 / 深海 / 浅海 / 太阳颜色与强度 / 太阳仰角与方位角):黎明 `#9fb6cf / #f3d2c4 / #4f8ea3 / #8fc9c4`;白天 `#88c8e8 / #eaf5f2 / #38a5bc / #86e2d4` 太阳 2.7;黄昏 `#6f6fa8 / #ffa888 / #5a6a9e / #b08aa6` 太阳 `#ff9a68` 仰角 8°;夜 `#12163a / #4a4478 / #23264a / #363a66`,月亮 `#a9b0e8` 0.9。夜晚的海是去饱和的蓝紫,近相机处更深、朝天光带渐亮,于是暖窗和光束是仅有的亮物。
- **后期**(`demo/post.js`):场景 MSAA + 深度 → GTAO(radius 0.7,scale 1.5;必备,它画出地块间和屋顶下的接缝)→ 天空/雾合成 → 极轻移轴(画面边缘最大半径 3 px,微缩感)→ bloom(threshold 0.95,strength 白天 0.22 / 夜 0.5)→ 粉彩调色(sat 1.04–1.1,柔和对比,夜里小幅蓝色提升)→ NeutralToneMapping。2× 超采样(渲染 3840×2160)。
- **灯塔光束**:一条面向相机的缎带(其平面包含光束轴并每帧转向相机),宽度方向高斯分布,根部亮、随距离衰减,外加一条 2.4× 宽、0.32 强度的光晕副本制造体积感;向下倾 7° 使它在远处与海相接。它下方的水在海 shader 中被照亮:光束方向周围的角度带加逐棱面的闪光。

## 4. 运动语言

- 一切以一拍一动(24 fps)平滑移动。魅力在**到达曲线**,不在步进。
- **从海中升起**(地块):0.5 s 三次缓动从水下升起,随后 `sin(13 s)·e^(−7 s)·0.18` 过冲;破水瞬间(稳定前 0.12 s)爆出一圈六边形水环和 14 颗飞沫。事件时刻是它稳定之时。
- **落下与堆叠**(楼层、屋顶、灯塔环):0.22 s 内下落 2.4 单位(ease-in),落地,弹跳 `|sin(15 s)|·e^(−9 s)·0.22`,Y 方向挤压拉伸 `1 − 0.16·e^(−12 s)·cos(26 s)` 并保持体积。
- **弹出**(树、灯、烟囱、花):缩放 `1 − e^(−9 s)·cos(17 s)` —— 约 25 % 过冲。
- **生活**:风车在"小岛完工"和弦上起转;烟囱冒烟圈;三只海鸥盘旋;小船以与海相同的波函数起伏侧倾(CPU 上求值)。
- **把生长排进音乐网格**:每个十六分音符槽至多一件,让每个事件有自己的音符;地块落在二分 → 四分 → 八分(以密度而非速度渐快)。

## 5. 镜头语言

| 节拍 | 相机 | 为什么 |
|---|---|---|
| 开场 | 孤单一物的正交特写(视锥 7.5),空荡的棱面之海,顶部一条天空带 | 不给观众可看的东西;于是第一块地块成为事件 |
| 生长 | 转台(约 5 s 内方位角 +45°)加缓慢拉远,在节拍上**插入**特写:带水花升起的峰(仰角 23°,视锥 5.2)、堆叠的楼层(26°,6)、码头木板与小船落下(27°,6.6)| 全景展示形状生长;特写卖出弹跳与水花 |
| 白日 | 村庄中景,太阳 2.5 s 内扫过 100°(延时阴影)| 光是时间机器 |
| 离别 | 由码头方向计算的侧机位,相机追随小船 | 船必须横穿画面,而非朝镜头来 |
| 黄昏 | 固定 3/4 全景,缓推,窗逐个八分音符点亮 | 让灯成为唯一的运动 |
| 夜 | 超广,仰角 21°,岛在左下,一点微光远在黑暗中 | 负空间 = 危险 |
| 高潮 | 高角度(50°)以光束速度 0.22× 旋转,随后缓降至 25°,让星空"升起" | 必须看见光束扫过每座房子;然后天空展开 |
| 结尾 | 纯正交变焦 ×25;右下远处一件呼应物 | 尺度揭示与呼应 |

## 6. 声音

- **音乐是事件驱动的**:页面 `EV` 条目带 `note`;配乐脚本在每个确切时刻合成每一个(升起 → 马林巴,弹出 → 卡林巴,楼层 → 木鱼,屋顶 → 卡林巴+马林巴 = 旋律,窗 → 柔卡林巴,环 → 上升马林巴,光束命中 → 卡林巴主奏 + 马林巴八度 + 铃光)。其下:氛围 pad、轻柔马林巴固定音型,沙锤/软底鼓只在白日与高潮段。96 BPM,D 大调五声感。**无钢琴、无弦乐。**
- **一个音符作动机**:D5 的浮标铃开场("大海唯一认识的音符"),结尾一口远钟奏同一个音。
- **静默**:夜段落至低 pad 持续音、海浪与蟋蟀;高潮强拍前最后半拍音乐总线是数字零。
- **拟音跟随材质**(全部在 `demo/mix.py` 合成):升起地块的水下气泡扫 + 带水珠滴答的溅落(越大越低);楼层的木敲 + 0.21 s 后更轻的第二敲(弹跳);屋顶的瓷拍;码头的空板敲;灯塔环的重石闷响;灯室的玻璃叮;点燃时的低"whump"+ 微弱电流嗡。底:低通棕噪声海浪带缓慢涌起和随机拍岸、白日海鸥(下滑 FM 啭鸣)、风车吱呀、黄昏起的蟋蟀。
- **配音**:Kokoro `af_sky`(清亮温柔的女声),语速 0.86–0.92,4–6 句短句。避开 whisper(和听众)混淆的同音词 —— 在一部关于音符的影片里 "sea" 被听成 "C",所以我们改说 "ocean"。
- 混音:配音压缩并高出音乐约 10 dB;配音下音乐压 −8 dB;响度 −14 LUFS;**颗粒 0**(平涂色遇颗粒会闪)。

## 7. 字幕与片名

- **字幕**:无底框 —— Quicksand 600,44 px,暖白 `#fffdf8` 带柔和藏青投影(blur 14),居中于底部上方 118 px;左侧一枚小小的平面着色六边形地块图标(顶 + 两侧面),顶色随时段变化(黎明粉、白日草、黄昏橙、夜窗黄)。从台词前 0.05 s 显示,至少 1.8 s 且绝不短于台词 + 0.6 s,绝不与下一行或片名重叠。
- **片名**:Josefin Sans 600,全大写,78 px,16 px 字距;字母从一条细"水线"下一个接一个升起(间隔 55 ms),像地块一样过冲后落定;下方一行 300 字重的小写副题("a low-poly island film")。
- **片尾卡**:夜间的尺度揭示帧,压暗;同一标题块(静态)、六边形图标、`LOW-POLY ISLAND · LEMO-OPUSCAR`、`LemoLab × Claude Opus 5.5`、署名。排版时让那一点亮着的微小岛屿留在文字块之间的空隙里可见。

## 8. 我们踩过的坑

- `core/three/post.js` 用的是 `perspectiveDepthToViewZ` —— 对正交相机是错的。改用 `orthographicDepthToViewZ`。
- **GTAO 把 sprite 画成实心四边形**(它以 override 材质渲染场景):一个不可见的光晕 sprite 变成海面上一块黑色平行四边形。AO pass 中隐藏所有 sprite/透明物体,并给零不透明度的 sprite 设 `visible = false`。
- 地块侧柱与顶盖共面 → 像素化的 z-fighting 斑块。把柱沉下去。
- 光束用双面加法圆锥读作两条平行白线。改用带高斯轮廓、面向相机的缎带加宽光晕。
- 正交相机放得太近:大幅拉远时画面底部光线起点在海面之下,露出天空。保持相机距离 ≥ 3 × 视锥高。
- 低角度太阳下海面的阴影拉出一道长黑渍;海不接收阴影。
- 相机目标正后方的低角度太阳把棱面之海变成一片浅沙色眩光;关键镜头中让太阳位于相机侧方。
- 小船在 21 单位外 —— 光束找到它时它已出画。由光束角速度反推船的位置,让光束在选定的节拍上找到它(我们用了旋律中的一个休止,让船的应答铃填上空隙)。
- `half` 是 GLSL 保留字。
- 所有生长调度都做在十六分网格上、每槽一件;两件落进同一槽会让旋律浑浊。

## 9. 制作配方(本仓库)

```
styles/lowpoly-island/demo/
  story.js   时间线(96 BPM 网格)、旁白、和弦、昼夜关键帧、镜头
  world.js   六边形布局、全部道具、生长调度 → EV(带音符)、逐帧动画
  sea.js     棱面波浪 shader、浅潟湖贴图、光束照水
  post.js    正交后期:GTAO → 天空/雾 + 星星 → 移轴 → bloom → 调色
  main.js    渲染器、灯光、各镜头相机、HUD(片名、字幕、片尾卡)、EV 导出
  music/score.py   事件驱动配乐(+ check.py:用 librosa 对照事件检查起音/音高)
  mix.py     拟音 + 环境 + 配音 + 闪避     subs.py  字幕提示
  build.sh   一条命令重建
```

1. `node core/render/still.mjs styles/lowpoly-island/demo --range 0.5:52.5:1` + `core/render/sheet.py` —— 总览图,反复迭代。
2. `core/tts/tts.py lines.json voices` → `core/tts/asr_check.py` 直到全部 OK。
3. `node core/render/events.mjs styles/lowpoly-island/demo` → `music/score.py` → `music/check.py` → `mix.py`。
4. `node core/render/video.mjs styles/lowpoly-island/demo --fps 24 --workers 3`(1272 帧,2× SSAA + GTAO)。
5. `sh core/render/mux.sh out/video24.mp4 mix.wav lowpoly-island.mp4 24 0`。或者直接 `sh demo/build.sh`。
