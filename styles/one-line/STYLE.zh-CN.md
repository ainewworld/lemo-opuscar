# 一笔画（One-line Drawing）— 风格提示词

> 一根永不离纸的墨线。它画出整个故事，而当镜头拉远时，它画过的一切原来是一幅画。
> 演示片：*The Line That Never Lifted*（从未提起的线，47.5 s）· `one-line.mp4` · 源码在 `demo/`

你正在以**一笔画（One-line Drawing）**风格导演一部 30–60 秒的影片。用户给你一个主题。其余一切——故事、镜头、节奏、声音——由你决定，并交付一部完成的影片。遵循本指南。

---

## 1. 这个风格是什么

一部由暖白色纸上的**一根连续的线**构成的影片。笔从不上提：在代码里，整部影片字面上就是一个点数组，从笔尖第一次触纸到最后一帧。没有剪辑。镜头像跟拍一样跟随笔尖，带一点滞后和一点预备，所以观众始终看着线*被画出来*。

一切皆线：人物、地点、物件，甚至时间。没有填充、没有阴影、没有第二种线宽、没有背景美术。屏幕上除墨以外只有纸本身和一道柔和的**笔影**（纸面之上的真实世界）。至多一种强调色，只用一次。

从 Osvaldo Cavandoli 的 *La Linea*（1971）学习语法——一根线既是世界又是角色，线的变换就是笑点和转场；从 Gjon Mili 1949 年拍摄的毕加索光绘画照片学习——单一手势的自信与速度；从 Norman McLaren 的 *Begone Dull Care* 和 *Boogie-Doodle* 学习——画*给*音乐听的线。不要照抄 La Linea 的角色、它的咿呀配音，或任何具体的连续线插图。

## 2. 故事：什么适合这个风格

挑选**线的连续性本身就是意义**的故事。一笔画有五个天生优势——至少用三个，并把最强的一个放在情感峰值上：

| 天生优势 | 故事用法 |
|---|---|
| **笔从不上提** | 一段人生、一次旅程、一个过程、一部历史：任何*连续一体*的东西。绝不剪辑；镜头跟随笔尖。 |
| **线即时间** | 笔画的性格随年龄或心境变化：年少时轻快，成年时饱满沉稳，年老时颤抖带飞白断口。某一段可以变色（爱情、危险）再变回来。 |
| **变换** | 风筝线变成自行车架，一个微笑变成一条路。场景不剪辑而是*变形*：上一幅画的最后一笔是下一幅的第一笔。 |
| **停笔即事件** | 笔尖停下时，墨会汇聚并晕开。一个 1.5–3 s 的停顿配音乐切入静默，是这个媒介里最强的节拍（失去、犹疑、一个决定）。 |
| **逆向设计的尺度揭示** | 每个以特写画出的小段落其实是一幅大画的一部分。结尾镜头拉远，观众看到整个故事*原来*是一张脸（一棵树、一幅地图、一个字）。 |

改编任何主题：找到故事可以收尾的**那一幅画**，以及能各自成为它一部分的 6–8 个时刻。一家公司的历史 → 创始人的第一张桌子、第一个产品、第一间办公室……是 logo 的五官。一座城市 → 它的地标是创始人肖像的线条。一个爱情故事 → 两段分开画的人生汇成一颗心。

**40–50 s 的情感弧线：** 空白纸上的单独一点（前 3 s 内的钩子）→ 轻快的前几章 → 唯一有色的一章 → 一次停顿（静默、墨晕开）→ 线恢复，已然改变 → 镜头拉远时最后几笔放慢 → 整幅画，保持 → 一段把笔交出去的尾声。

## 3. 视觉语言

**逆向设计是核心技术。** 先画最终的那幅画，再把它切成章节，再设计每一章，使它在特写下读作独立场景、*同时*读作最终画面的一个局部。演示中行之有效的规则：
- **最终画面的每个区域只画一次。** 章与章之间的连接线必须落在最终画面的自然线条上：镜圈、法令纹、鱼尾纹、下颌轮廓、一根头发。每条"多余"的连接线在揭示时都会变成一道乱纹、一块垂肉或一圈胡子。
- **像欧拉路径一样规划拓扑。** 闭合的母题如嘴（微笑 + 上唇 + 两个侧脸）是一条回路：你从进入的地方离开。要么让下一章从同一点出发（重描的折痕不可见），要么调整章节顺序。我们把"失去"挪到"孩子"之前纯粹是为了拓扑，然后把它做成了情感点（"然后，线还在继续"）。
- **重描合法且不可见：** 沿既有线返回只会让它略微变粗。演示中笔沿着风筝的尾巴和线原路"收回"到头部。
- **尽早且频繁地测试揭示：** 每次改动后一次性渲染整条路径，用最终尺度（`?all=1&cam=0,-170,1`）。

**演示中的映射**（老人的脸）：左耳 = 他的出生（婴儿的拳头卷成耳朵的 C 形，攥着一根也是他眼镜腿的大人手指）；秃顶 = 风筝线，风筝 = 他仅有的一根头发；眼镜 = 自行车（轮 = 镜片，车座 = 左眉，车把 = 右眉，车架 = 鼻梁两侧）；嘴 = 初恋（两个侧脸鼻尖相对；他们的头顶构成上唇的 M，下面是红色的微笑）；鼻子 = 那栋房子（戒指和一扇圆窗是鼻孔）；右眼 + 泪 = 失去；右耳 = 他自己的孩子（出生的镜像）；下颌轮廓 = 暮年；左眼闭合 = 最后一笔。

**纸**：暖白 `#F4EFE4`；程序化斑驳（1400 单位平铺，soft-light）、长纤维（260 单位平铺，拉远时淡出以免闪烁）、近景缩放下以 screen 叠加的稀疏"纸齿"斑点；0.13 multiply 暗角。所有纹理锚定在纸上并随镜头移动。

**墨**：暖黑 `#1D1A17`，作为围绕路径的填充多边形渲染（不是 `ctx.stroke`），逐点与纸色混合成不透明色调。
- 宽度 = 年龄基础宽度 × 笔压 × 细噪声（±8 %）。压力由速度得出：`0.66 + 0.8·exp(−v/300)`（快 = 细，慢 = 粗）。
- 基础宽度（纸面单位）：孩童 2.4（alpha .82）、少年 2.5、成年 2.9（.96）、老年 2.7（.93）、下一代 2.0（.76）。章节边界处 ±60 单位内混合风格。
- 墨晕：同一多边形略放宽，画到离屏层，模糊（≈0.9 × zoom px）后以 22 % 合成。
- 汇聚：速度 < 45 单位/s 处加圆形墨点。
- 老年：垂直于走向的颤抖（两个噪声八度，振幅最高 ≈1.1 单位），长尺度噪声造成的飞白断口加三根细鬃丝；**最后几笔要重新降低干度**，让收尾的手势清晰。
- 停笔：一滴泪滴状墨渍（尖端在停住的笔尖处，铺开时腹部下垂，边缘一道深色墨线）。
- **保持屏幕空间最小线宽。** 线宽随缩放变化，像微距镜头下真实的线，但拉远过程中把宽度所用的缩放钳制在 ≥ 1.3（揭示时 ≈ 3–4 px）。没有它，最终画面会像铅笔画并失去分量。

**颜色**：至多一种强调色，只用一次，并保留在最终画面中有意义的位置。演示的红 `#B3332B` 恰从嘴角开始，到下一章回到墨色，于是老人唯一的颜色是他的微笑。

**笔**：从不画出。只有一道柔和阴影（从笔尖向右下的模糊楔形，长 ≈ 560 × zoom px，alpha .15）和一个 1–4 px 的接触点。手只在交接时以影子出现（每只手合成单一平坦影子，重叠处不变暗）。

## 4. 动效语言

- **一切逐帧（on ones，24 fps）**。魅力在于绘画这一连续行为本身；抽帧会破坏幻觉。
- **时间 = 章节窗口 + 曲率。** 每章有一个时间窗；窗内每点的时间按 `1 + K·turn` 加权（急弯给更多时间，做平滑使速度不跳变）。用标记钉住音乐重拍：按弧长比例 `f`，或按位置 `at:[x,y]`（"笔第二次经过鼻子时"）。停顿是同一位置的两个标记。
- 拐角（高转角处的局部速度极小值）作为候选音符起音导出到音轨。
- 典型速度：走线 300–700 单位/s，小细节（手指、睫毛）50–150。一生的最后一笔应是全片最慢的一笔。

## 5. 镜头语言

镜头是一次连续运动：构图中心、缩放、几度滚转和跟随权重 `f`（0 = 构图，1 = 锁定笔尖）的关键帧。跟随点是笔尖位置在 −0.55…+0.4 s 上的加权平均，产生滞后和预备。软钳制把笔尖保持在画幅的 72 % × 66 % 以内。

| 节拍 | 镜头 |
|---|---|
| 开场 | 微距（z ≈ 4.3）对准笔将落下的空白纸；第一段小景构图为主，f ≈ 0.1 |
| 走线 | 跟随（f 0.6–0.85），拉远至 ≈ 2.4 |
| 各小段 | 构图（f 0.15–0.35），取景使完成的画居中 |
| 停顿 | 保持，静默中极慢推进（4.6 → 5.4） |
| 镜像章 | 与它呼应的章节同构图，镜像 |
| 揭示 | 最后几笔画着的同时，从 ≈ 3 连续拉远到 1，历时 5 s，然后保持 ≈ 1 s |
| 尾声 | 推进到笔停驻处以交接；新线跑起来时再拉远；片尾卡在空白纸里 |

## 6. 声音

- **音乐：一件独奏乐器、一条不断的旋律线**——绘画的声音等价物。演示用大提琴（低力度 `cellos`，单声道，略偏左，0.14 s 重叠的连奏）、童年用 `cellos_pizz`、下一代开始时一个 `hand_chimes` 音。没有钢琴、没有弦乐铺底。
- 把谱子写给画：关键音落在标记和拐角上（握紧落在主音上、每个风筝拐角是一次拨弦、最高音是两个鼻尖第一次相触、最后一只眼的睫毛是最后三个音）。线快 = 短音；线停 = 一个长音淡入寂静。
- **静默是字面上的**：停顿期间把音乐总线归零，包括混响尾；房间底噪降到 15 %。
- **笔在纸上是最重要的声音**：由笔速轨合成——带通噪声（快时明亮 2.2–7.5 kHz，慢时沉闷 0.7–2.4 kHz）、密度 ∝ 速度的随机纸纤维嗒声、振幅 ∝ (v/520)^0.5、按笔尖屏幕位置声像；老年时被飞白断口打断；孩童时更轻更顿。外加落笔时的木质轻叩、墨渍几乎听不见的湿润鼓涨、交接时一声极轻的摩擦。
- **人声**：温暖、回望式的男声旁白（Kokoro `am_liam`，语速 0.84；85 Hz 高通、7.2 kHz 低通以柔化）。5–6 句短台词，给线留出空间。按 whisper 词时间戳摆位，让关键词落在画面节拍上（握紧落在 "**on**" 上、笔恢复落在 "**goes** on" 上）。人声下音乐压 ≈ 5 dB、笔 ≈ 4 dB。响度 −14 LUFS，**噪点 0**（纸的纹理在渲染里）。

## 7. 字幕与标题

- 字幕：Caveat 500，46 px，墨色 84 %，无底框，居中且基线距底 100 px；字幕从左到右**逐字写出**（0.2 s + 每字符 17 ms），后面衬一层柔和的纸色光晕，使经过的墨线不穿过字母；0.45 s 淡出。保持 ≥ 语音 + 0.6 s 且 ≥ 1.8 s。
- 标题：Sacramento（一款单线连笔手写体——本身就是一幅一笔画）76 px，在远离当前小景的空白纸上 1.6 s 写出，配一行小号 Caveat 副题。保持足够短，在镜头推进到它之前消失。
- 片尾卡：两行 Sacramento 标题、"ONE-LINE DRAWING" 用 Caveat 600 加宽字距，下面是署名行，写在新线还在画时、最终画面旁的空白纸里。

## 8. 我们踩过的坑

- **乱连接线毁掉揭示。** 每个早期版本都有被读成胡子、垂肉、围兜或面具的线。修拓扑（哪章从哪进、从哪出），而不是修画。
- **从头顶直直画上去的风筝变成尖顶洋葱头。** 让线就是那根头发，并原路重描（收回）到头顶，弧顶保持干净的弧。
- **从太阳穴横伸出的手被读成螺栓。** 把婴儿拳头卷成耳朵的竖直 C 形，指尖藏进去，指节是四个短圆凸（长环读作弹簧）。
- **头顶被一道弧封死的两个侧脸读作高脚杯**（Rubin 花瓶）。让他们的头顶变成上唇的 M，并让他们的脖子在一点汇入微笑。
- **靠得太近的侧脸会编在一起**（加上线宽之后）；嘴唇间保持 ≥ 5 单位，只在鼻尖相触。
- **眼睛**：带眼袋的杏仁形被读成露齿的嘴；闭合的眼睑（‿）加三根短睫毛效果最好。
- **圆形墨渍读作痣。** 做成铺开时会下垂的泪滴。
- **揭示时线太细。** 钳制宽度缩放（见 §3）。
- **手影作为独立半透明形状**在手指重叠处双重变暗——每只手合成一层。
- **镜头移动时标题与小景相撞。** 对照其时间窗的每一帧检查标题，而不只是第一帧。
- **Whisper 听错**："Sometimes it stops" 被听成 "But sometimes it stops"、"Your turn." 成 "Your turns"——改写措辞（"Sometimes the line stops."、"Your turn now."）而不是硬扛。
- **zsh**：`=====` 作为 echo 分隔符会被展开；机器高负载让 `still.mjs` 变慢——页面支持 `?cams=` / `?camt=`，在一次浏览器会话里渲染多个视角。

## 9. 制作配方（本仓库）

```
styles/one-line/demo/
  face.js    THE drawing: every chapter as SVG path strings + transforms, and the chapter table (time windows, marks, holds)
  geom.js    samples SVG paths by arc length (browser SVGPathElement), adds tangent-continuous connectors, assigns time (curvature-weighted, marks, holds)
  ink.js     line renderer (pressure, bleed, pooling, tremble, dry brush, red stretch, teardrop blot, min screen width)
  paper.js   procedural paper, fibres, tooth, vignette          cam.js    composition keys + nib follow + soft clamp
  shots.js   camera keyframes                                    hands.js  pen shadow and hand shadows
  story.js   single source of truth for voice/subtitle/title/handoff times
  subs.js    written-on subtitles, title, end card               main.js   render(t), debug modes, events for the mix
  lines.json voice script   music/score.py  solo cello score   mix.py  pen-scratch foley + voice + music   build.sh
```

1. 在 `face.js` 里设计最终画面，用 `node core/render/still.mjs styles/one-line/demo 0 --q 'all=1&nopen=1&nosub=1&cams=0,-170,1.0'` 迭代（可加更多 `;x,y,z` 视角在同一运行中检查各小景）。
2. 人声：`core/tts/tts.py lines.json voices` → `asr_check.py`；读 `voices/words.json` 并把台词摆进 `story.js`。
3. 在 `face.js` 里设章节窗口和标记；`node demo/tools/probe.mjs 0.5` 打印各部分边界和笔尖轨迹，用于写镜头关键帧。
4. `node core/render/events.mjs styles/one-line/demo` → `music/score.py` → `mix.py`。
5. `node core/render/video.mjs styles/one-line/demo --fps 24 --workers 3`（1140 帧 ≈ 30–45 s）→ `sh core/render/mux.sh out/video24.mp4 mix.wav one-line.mp4 24 0`。
6. 或者干脆 `sh styles/one-line/demo/build.sh`。
