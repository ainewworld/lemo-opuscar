# 红色窗花剪纸（Red Paper-cut）— 风格提示词

> 被赋予生命的中国窗花剪纸：宣纸和靛蓝夜色纸上的关节式红色剪纸，剪*就是*绘画，孔洞正是光进来的地方。
> 演示片：*Nian Comes to Town*（年兽进城，49 s）· `papercut-red.mp4` · 源码在 `demo/`

你正在以**红色窗花剪纸（Red Paper-cut）**风格导演一部 30–60 秒的影片。用户给你一个主题（也许还有故事）。其余一切——故事、镜头、节奏、音乐、声音——由你决定，并交付一部完成的影片。遵循本指南。

---

## 1. 这个风格是什么

一切可见之物都是**一张用剪刀剪出来的纸**，平贴在另一张纸上。没有绘画、没有渐变阴影、没有轮廓描边：细节、体积和表情只来自**剪掉了什么**。红纸是主角材质；背景也是纸（白天暖宣纸，夜里深靛蓝纸）。角色是**关节式剪纸**（头、躯干、上下肢以铆钉连接），以硬 12 fps 步进动画，像经典的中国剪纸片。

学习**民间窗花**（陕西/蔚县）的语法：锯齿纹、月牙纹、云纹/旋涡纹、对折对称的团花，以及阴刻（红底上剪出线条）与阳刻（空底上留下红色线条网络）的区别。学习 1958–59 年上海美术电影制片厂剪纸短片的关节人物动画和侧面表演。**不要**照抄任何厂牌角色、任何具名艺人的作品、或任何现成的纹样册——一切纹样由代码生成。

与皮影戏保持区别：屏幕后不打光、没有半透明染色皮革、没有签杆。这里纸是**正面打光且不透明**；背光是留给高潮的特殊事件。

## 2. 故事：什么适合这个风格

挑选**剪纸的手艺本身就是情节**的故事。剪纸有五个天生优势——至少用三个，并让至少一个是结局的*起因*，而非装饰：

| 天生优势 | 故事用法 |
|---|---|
| **对折 – 剪 – 展开** | 把一张纸折 2/4/8 次；一剪变多剪。*扇形里剪出的一只灯笼 = 团花里的八只灯笼 = 八户亮灯的人家。*把展开放在最强的节拍上。 |
| **孔即光** | 一张贴在窗上的剪纸，从背后照亮：纸透出深红，每个孔透出金色，纹样被投到世界上。光有纹样的形状。 |
| **对称会复制** | 镜像纹样可以剥离并增殖：团花 → 窗花 → 烟花（烟花不过是天上展开的小团花）。 |
| **碎纸有未来** | 剪时掉落的碎屑之后会回来（作爆竹、雪、彩屑）。免费的铺垫/回报。 |
| **万物都是一张平纸** | 山和怪兽共用同一种锯齿——一道山脊可以立起来变成一头兽。以**尺度揭示**收尾：整部影片原来是真窗户上的一朵窗花。 |

改编任何主题：找到**被剪的那一样东西**，让它*展开后*的形态成为答案。一场产品发布 → 产品的剪影被折进一个扇形，展开成它所有用途的纹样。一个爱情故事 → 两个形象从同一张对折纸上剪出（一对镜像）。一座城市 → 对折纸条上剪出的一栋房子展开成一条街。

**情感弧线（40–55 s）：** 剪刀冷开场（0–3 s）→ 标题 → 宁静的世界 → 威胁（世界变暗/失声）→ 一个安静的决定 → 重拍上的**对折–剪–展开** → 纹样化为光并修复世界 → 黎明 → 尺度揭示。

## 3. 视觉语言

### 纸
- **中国红** `#d2201f` 用于主角和窗花（宽容范围 `#c8102e`–`#d7261e`）。怪兽/反派深一档：`#b00f26`。近侧肢体亮一档（`#c4162c`），远侧肢体深一档（`#8a0c20` / 女孩 `#b8191b`）——是分层纸，不是上阴影。
- **宣纸** `#f2e8d0`（长纤维 + 云雾状密度）、**夜纸**靛蓝 `#1c2446`、**墨色天空** `#0f142a`、**金箔** `#d9a93f` 只在结尾（太阳、标题碎金）。
- **夜规则（重要）：** 所有背景层（远山 `#1f2a55`、近山 `#29356e`、房屋 `#35457f`、树 `#28346c`、雪 `#7a88ba`）都是*靛蓝纸*。只有窗花、灯笼和主角是红的。如果背景和主角都是红的，剪纸剪影就"跳"不出来了（第 1 道门时我们栽在这上面）。
- **日规则：** 宣纸天空、红色房屋、远山用较浅的红 `#e0877f`、中山 `#cf4f4a`。
- **纸纹：** 一张可平铺的中性灰纹理以 `soft-light` 施加进每片内部（±7% 的染色斑驳 @ ~130 px、纤维、深色斑点），再用 `destination-in` 恢复该片自身的 alpha，孔还是孔。
- **剪口边缘：** 每个剪影被采样为折线并抖动（≈0.35 单位、沿弧低频）——手剪的不规则感。每条边的左上一道 1 px 亮边、右下一道暗边（纸的切面）。建筑用直线段 + 抖动，*不要*平滑（平滑会把房子变成面包）。
- **纸厚：** 每片向下层投一道紧贴的软影（偏移 2.6/3.6 px、模糊 5 px × zoom、`rgba(52,6,10,.38)`）。层叠的折纸露出 2–6 道偏移的深色边。

### 剪刻语法
- 人物：**红色块 + 阴刻线条**。每个人物件都带一道**内缩轮廓**（轮廓内 3.5 单位处一条 1.5 单位宽的缝）——经典双钩，并分离红叠红（手臂压衣襟）。
- 纹样库（全部在 `demo/motifs.js`）：`sawRow`（一排细三角孔 = 毛发、草、瓦、流苏）、`sawEdge`（锯齿剪影边）、`crescent` / `crescentRows`（鳞、绗缝）、`swirl` / `doubleSwirl`（动物关节）、`cloudCut`、`rosette`（腮花）、`plum`、`coin`、渐细缝。
- **没有悬浮孤岛。** 封闭圆环下真纸的中心会掉出去。眼睛是两弯月牙（上下眼睑）留出连接桥，外加一个瞳孔*孔*。
- 脸从不变形：表情是**可换脸件**（笑 ∩、惊、怕、坚毅的杏眼、睡 ∪）。
- **团花**按一个 45° 扇形设计并镜像 8 次（D4）。中环是*阳刻*（剪掉环带、留红线：灯笼、折线上的如意卷、环边锯齿）；内外环是*阴刻*。折缝留下淡淡的折痕线——留着，它忠于手艺。

### 光
- 正面打光场景：纸保持原样。夜景：`frame × lightmap`（环境光 ~`rgb(214,214,236)`——温和，纸本身已深）+ 亮窗周围的暖光池，再叠**自发光**的背光窗（光场 × 纸透射经 `multiply`；孔保持全亮），再两级 bloom（半分辨率模糊 10 px / 40 px，强度 ≈0.55）和可选的窗光放射模糊。
- **背光窗花：** 径向光 `#fff6d6 → #ffc46e → #ec782e`、宣纸纤维以 50% multiply、团花的透光精灵用 `#b51d18`。bloom 保持适度——中心处的纹样必须可读。
- **投影纹样：** 团花的孔洞遮罩压扁到地面（`[1.25,0,-0.9,0.3]`）并以 `lighter` 叠加；落在角色上时**被该角色层的 alpha 遮罩**、叠在一块实心暖光斑之上，于是被照亮的脸比纸亮、被剪出的眼睛/眼泪读作黑洞。

## 4. 动效语言

- **角色以 12 fps 步进**（姿势按 `floor(t·12)/12` 采样）；**镜头、光、雪、火焰和飞起的灯笼以 24 fps 逐帧**运动。
- 骨架：女孩 = 头、上衣、2 ×（上臂、前臂+手）、2 ×（大腿、小腿+鞋）、剪刀（铆钉上的两片刀）。怪兽 = 身体、头（大，×1.32）、铰链上的下颌、鬃毛、尾巴、4 ×（大腿、小腿+爪）。铆点：颈、肩、肘、髋、膝、颌、尾。
- 硬姿势、极小的缓动、1 帧过冲（"pop" = 单步 1.15×）。重量感来自**块头和镜头震动**（怪兽每一步落地震画 ~6 px，0.3 s 内衰减）。
- 侧面视图中抬起的近侧手臂会挡脸——让手保持在脸之前，或用道具（团花）遮住它们。
- **折叠**（关键动作）：折页沿折痕法线切成 16 条；每条按 cosθ 压缩、沿折向放大 `1 + 0.28·height`（假透视）、立起时变暗、超过 90° 后以更浅的背面色 `#de3b30` 显示、带随抬起增大的阴影和其后的折痕线。每次折 ≈0.55 s，落在一记木鱼上。
- **剪**：镜头以约 32% 跟随剪刀尖。剪出的纹样通过沿剪刀路径的一串圆形遮罩（r ≈62 单位）揭示，外侧边缘剪过后整个边角料一并移除；刀片每 0.25 s 开合（每剪一下 = 一个八分音符）；碎屑飘出、落地。
- **展开**：三次展开相隔 0.25 s，每片折页从 s = −1（折拢）以 ease-out 摆到 +1——那声"啪！"——然后重拍上一个尺度凸起和暖闪。

## 5. 镜头语言

| 节拍 | 镜头 |
|---|---|
| 冷开场 | 剪刀咬入红纸的极端特写、跟随刀尖；被剪掉的纸片飞走揭示标题 |
| 标题 | 平面正视图；红色剪字以 12 fps 步进弹入；以**翻页**退出（右半折过去）揭示下一场景 |
| 世界 | 缓慢横摇过三层纸（山/村/雪），收在一次推向主角亮窗的推近 |
| 威胁 | 低机位全景；锯齿山脊立起——怪兽从远山*后面*升起、高耸于村庄之上 |
| 记忆点镜头 | 从暗屋内：一只巨眼滑入窗棂并眨一下 |
| 决定 | 中近景，道具在三个被念出的词上弹出 |
| 原生运镜 | 俯拍桌面；折纸时固定、剪时跟随剪刀、展开时拉出 |
| 回报 | 推向发亮的窗，拉回全村灯笼飞向每家；怪兽目眩的特写 |

## 6. 声音

- **音乐**：明亮喜庆的中国室内乐合奏，*不是*钢琴/弦乐，也*不是*皮影戏的戏曲打击乐：琵琶（物理建模，长音上轮指）、筝（`dan_tranh`：分解和弦、刮奏、轮指）、二胡、笛子当 dizi、木鱼、大小锣、框鼓。D 宫五声、2/4 拍 120 BPM、一段 4 小节原创主题。威胁 = 低框鼓心跳 + 二胡滑音；入窗巨眼和展开前的吸气是**全然静默**；**展开重拍上全奏 + 大锣**；筝的八个上行音 = 八扇窗亮起。
- **拟音跟随材质**：剪刀 = 金属剪切扫频（2.5–9 kHz）+ 3.8 kHz 泛音 + 纸纤维脆响；折 = 纸嗖 + 折痕轻叩；展开 = 清脆的纸"啪"；怪兽脚步 = *纸板*闷响（55 Hz + 低噪声），不是血肉；烛 = 火柴划燃 + 轻柔的 whoomp，熄灭 = 一噗；爆竹 = 20–60 ms 的密集咔嗒、渐密、偶有低闷爆；烟花 = 上升的啸声 + 爆响 + 噼啪；黎明 = 一声悠长的纸揭；两声鸟啭。
- **人声**：温暖的祖母讲述者——Kokoro `af_sarah`，语速 0.9，4–6 句。人声下音乐压 ≈9 dB、拟音 ≈3 dB；拟音冲击避开人声窗口。民俗专名在 `lines.json` 里配 `asr` 别名（"Nian" 被听成 "Nyan"/"Nion"——发音正确，接受即可）。
- 混到 −14 LUFS，**无胶片噪点**（纸纤维就是纹理）。

## 7. 字幕与标题

- **字幕 = 红纸横批：** 一条深红纸带 `#a8111f`（比画面里的红更深，奶油字才立得住）、上下锯齿边、燕尾端、金色碎点、一枚小团花作项目符；Fraunces SemiBold 44 px，奶油 `#fff1d6`；距底 70 px 居中，带纸影。它像贴对联一样分两个 12 fps 步"落"到位。保持 ≥ 语音 + 0.7 s 且 ≥ 1.8 s；绝不重叠。
- **标题**：宣纸上的红色剪纸字（阳刻、字芯是真孔），Fraunces 800，以 12 fps 步进逐字弹入；锯齿边条；一枚红印（"年"字剪成孔）；一行斜体副题。
- **片尾卡**：对联纸条从窗侧滑入，一条奶油剪字的红色横批 "RED PAPER-CUT" 从上落入，下方墨色署名行 "LemoLab × Claude Opus 5.5"。

## 8. 我们踩过的坑

- **红叠红。** 红房子红山配红主角读作一团。夜里把背景做成靛蓝；红叠红处用近/远纸色和内缩轮廓分离。
- **覆写部件的 `h`。** 部件对象用 `x0,y0,w,h` 作绘制框——把墙高存进 `p.h` 把房子拉长了。
- **平滑建筑**把矩形变成面包：建筑用直线段折线。
- **透过光照图把一层调暗**也调暗了盖在它上面的东西（雪下透出鬼腿）。改为给该层本身染色（multiply + 恢复 alpha）。
- **`put()` 用 `setTransform`**，因此忽略外层 `translate`；传绝对矩阵。
- **扁平的 cos 压扁折页读作滑卡**，不是折。切成带假透视的条、立起时变暗、显示背面色。
- **剪刻揭示透过孔看到了未剪的纸垛**：只在"未剪"遮罩内画纸垛厚度，剪开的部分给它自己偏移的拷贝。
- 折纸时剪刀指向后方：刀轴必须是行进方向，铆钉略落后于剪切点。
- 以怪兽眼睛为中心的投影纹样盖住了眼；以口鼻为中心并加一块实心暖光斑，眯眼和眼泪才读得清。
- 镜头之间的空帧：把冷开场飞走的纸页与标题卡交叠。
- 测试模式页面不得抛异常中断模块（渲染装置在任何页面错误时退出）；改为守护 `window.render` 的赋值。

## 9. 制作配方（本仓库）

```
styles/papercut-red/demo/
  paper.js    paper textures, piece builder (fill, cut, inset, edge, grain), shadows, transmission
  motifs.js   folk pattern library          rig.js      2D affine rig helpers
  girl.js     jointed girl + face pieces     nian.js     jointed monster + eye pieces + poses
  tuanhua.js  8-fold rosette (one wedge × D4) village.js  houses, hills, plum tree, snow, lanterns
  light.js    night lightmap, backlit windows, bloom, rays, masked projected light
  world.js    village layout (night/day palettes) + lighting pass
  fold.js     fold – cut – unfold sequence   hud.js      subtitle banner, cut-letter text
  story.js    timeline (single source of truth, 120 BPM)   main.js  shots, cameras, events
  sheet.js / climax.js / test.js   model sheets and gate-1 style frame (?test=sheet_girl | sheet_nian | frame)
  lines.json  voice script   music/score.py  original score   mix.py  foley + voice + music   subs.py  srt
```

1. `node core/render/still.mjs styles/papercut-red/demo <t…> [--q nosub=1]` — 审查静帧；`?test=sheet_girl` 等出模型表。
2. `.venv/bin/python core/tts/tts.py lines.json voices` → `core/tts/asr_check.py`，直到全部 OK。
3. `node core/render/events.mjs` → `music/score.py` → `mix.py` → `subs.py`。
4. `node core/render/video.mjs styles/papercut-red/demo --fps 24 --workers 3`（1176 帧，约 30 s）。
5. `sh core/render/mux.sh out/video24.mp4 mix.wav papercut-red.mp4 24 0`，然后 `check_final.py`（对最终混音逐句 whisper + blackdetect）。
或者干脆 `sh styles/papercut-red/demo/build.sh`。
