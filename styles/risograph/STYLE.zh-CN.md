# Risograph 孔版印刷(Risograph Print)— 风格提示词

> 看起来像在孔版印刷机上一帧一帧印出来的动画:两三种半透明专色油墨叠印在暖色纸张上,半调网点、油墨颗粒,以及永远对不太准的印版。
> 演示:*Sunday Ride*(40 秒)· `risograph.mp4` · 源码在 `demo/`

你正在执导一部 **Risograph Print** 风格的 30–60 秒短片。用户给你一个主题(也许还有故事)。其余一切——故事、镜头、节奏、声音——由你决定,并交付一部完成的影片。遵循本指南。

---

## 1. 这个风格是什么

Risograph 一次只印**一种颜色**。每种颜色是一张单独的蜡纸("印版"),带着自己的半透明大豆油墨滚筒过机。这一个事实产生了整个外观:

- **极小的调色板**:2–3 种专色油墨(此处为 Riso 蓝 `#0078BF`、黄 `#FFE800`、荧光粉 `#FF48B0`),印在暖白色偏纸 `#F6F1E6` 上。
- **叠印混色**:油墨半透明且相乘。蓝 + 黄 = 绿,蓝 + 粉 = 紫/靛,黄 + 粉 = 橙红,三色相加 = 近黑。一种油墨的半调(tint)叠在另一种的实地上能给出最亮的混色(60% 蓝点叠实地粉 = 紫)。
- **套印不准**:每张版都偏移几像素落版。颜色边缘露出纸的细条或彩色光晕。
- **半调网点**表现中间调,每张版有自己的网角(蓝 15°、黄 0°、粉 75°)。
- **不完美的油墨**:实地中的纸张针孔、沿走纸方向的浅划痕、斑驳的密度。
- **平面图形、无轮廓**:形体由色块和剪影定义(Tom Haugomat 是参考),而非线条。

**绝不**在画面中引用 RISO 品牌、标志或机器外观。油墨名称仅用作颜色参考。

## 2. 故事:什么适合这个风格

挑选**印刷过程本身讲述故事**的作品。Risograph 有六种原生能力——至少使用四种:

| 原生能力 | 故事用途 |
|---|---|
| **一次一张版** | **印版即叙事**:世界从一种油墨开始,每个转折点(黎明、到达、坠入爱河)增加一张版。把每个角色和场景设计成单色版本身就*完整*,每张额外的版都增加意义。 |
| **叠印混色** | 由油墨构成的转场:一大块某色形状在画面上长大,把它下方的一切变成混色,然后收缩成下一场景的关键形状(演示中一个粉色圆盘吞没公园,变成河上的太阳)。 |
| **套印不准** | 节奏与情绪:印版在音乐重音上**跳开**;在持续静默中**漂离**,在强拍上**弹回**。紧张、眩晕、记忆和"呼吸"全都是套准的事。 |
| **倒影 = 分离的印版** | 水、玻璃或热浪呈现为每张版以各自相位摆动——涟漪*就是*套印不准。 |
| **半调与颗粒** | 每一帧都是"一张新印张";颗粒可以微微沸腾,像一册印刷品翻页书。 |
| **它是一张纸** | 尺度揭示:拉远显示影片是一张从机器里滑出的印张,落在一叠更早的印张上。 |

改编任何主题:决定**第一张版**是什么("之前"的状态)、每张**新增的版**意味着什么、以及**完全叠印**的时刻是什么。产品发布 → 单色的困境,产品作为新油墨到来。城市历史 → 每个时代一种油墨。爱情故事 → 两个人是两种油墨;他们重叠之处出现第三种颜色。

**35–45 秒的情感弧线:** 安静的单色开场(3 秒内设钩子:展示油墨被铺下)→ 每个地点增加一张版和一件乐器 → 一个小转折 → 完全叠印的高潮配一个持续静默 → 温暖的收束 → 纸张的尺度揭示。

## 3. 视觉语言

**流水线(关键部分):** 把每帧画进**一张 RGB 画布,其中 R = 蓝密度、G = 黄密度、B = 粉密度**(0 = 无墨,1 = 实地)。普通的 `source-over` 绘制自然产生**挖空**(后画的形状盖住全部三张版);用 `globalCompositeOperation = 'lighter'` 绘制只向你设置的通道添加油墨——真正的**叠印**。一个 WebGL2 着色器把那张画布"印"出来:

- 每张版:偏移(px)+ 微小旋转(±0.0005 rad)→ 套印不准;采样该版的密度
- 半调:旋转网格上的余弦点函数,**1080p 下周期 7 px**,±0.07 平滑 step 阈值使网点有抗锯齿;密度 ≥0.9 印实地
- 颗粒:阈值上的逐点噪声(±0.08);实地中噪声 > 0.93 处出现针孔(×0.75)
- 油墨密度 `k = 0.80 + 0.14·streak + 0.08·blot`(streak = 沿走纸方向拉伸 ×10 的噪声)
- 合成:`paper × Π mix(1, ink_i, coverage_i)`;纸张带微弱的纤维噪声(±1.5 %)
- 网点锚定在**纸**(网屏)上,而非物体上:镜头摇移时,图像在固定网屏下滑动,正如逐帧印刷
- 每张版一个**闸门**和一次**滚筒扫过**(一条带略重油墨带的移动 x 边缘),让一张版能在镜头中途"到达"

**构图规则(教训换来的):**
- 每个区域**至多两张版,且至多一张为半调**。三层半调叠在一起会变成棕色烂泥。
- 大平涂形状、大量留白纸和实地油墨;天空渐变(20 / 38 / 62 / 100 % 的阶梯带)、阴影和远景层用半调。
- 角色获得一圈**纸白挖空光环**(4–5 px):把角色画进透明层,用 `filter: brightness(0)`(= 零油墨 = 纸色)沿环形盖章 12 次,再画上去。印版在其周围套不准,所以光环获得像真实"陷印"一样的彩色毛边。
- Haugomat 式构图:一条地平线、一个巨大的太阳、一个小人。把角色的头放在画面中最平的颜色上(太阳圆盘效果极佳)。
- 皮肤:**黄 26 %**(读作奶油色;单色场景中变成纸色)。皮肤上的粉点看起来像麻疹——避免。
- 角色上的每种颜色都应含一些蓝,单色版才是完整剪影:毛衣蓝 40 + 粉 100(浅蓝点 → 浆果紫),长裤蓝 75 + 黄 100(→ 橄榄绿),头发蓝 100 + 粉 22,鞋蓝 100。刻意的例外可以是悬念:围巾只用黄 + 粉,所以在黄版到达之前它是**白纸**,并且是第一个亮起来的东西。

**排版也是印的:** 标题和字幕住在一块版(蓝)上,随它一起套不准、起颗粒。片尾标题在两块版上以 10 px 偏移印两次——经典的 riso 双击。字体:Bricolage Grotesque 800(标题)、Jost 500–700(说明字幕)。在 `READY` 之前预载所有字重(`document.fonts.load`)。

## 4. 运动语言

- **角色按 2 拍表演**(12 fps 姿势步进);**镜头逐帧(ones)摇移**(24 fps)——阶梯式镜头运动看起来像抖动。
- **套准不是每帧抖动。** 每个镜头有一组固定的版偏移(±1–3 px)。印版只在有目的时移动:标题重击、印版到达和大动作时的重音**踢动**(8–14 px,约 0.25 秒内衰减并带一点振铃);音乐间歇期最长 ~25 px 的**漂移**,强拍上弹回。持续抖动读起来像闪烁,还会让码率翻倍。
- 颗粒沸腾很微妙(每次印刷重掷 35 % 的颗粒);纸级的划痕和斑块只在剪辑点变化。
- 蹬车:曲柄角由车轮行程得出(`crank = distance / wheelRadius / 2.2`),腿用双骨 IK 对到踏板,围巾是一条行进正弦波。
- 鸽子:圆胸、小碎步配头部摆动、歪头表示"思考"、**4 帧扇翅循环**(上/半/下/收)按 2 拍;鸽群混合 1.2–2.4× 的尺寸,起飞错开最多 0.35 秒。

## 5. 镜头语言

| 节拍 | 镜头 |
|---|---|
| 开场(0–2 秒) | 第一张版从左→右**滚上**时某物体的极端特写;动作(铃铛一拨)落在第一个节拍上 |
| 困倦的城市 | 宽幅横向跟踪镜头:人物小,天空大而空,留给标题 |
| 第一张版加入 | 切到中景跟踪镜头,新油墨扫过画面;把笑料(Tati 式不减速的递接)安排在骑手伸手高度、在他前方、篮子之上,不被遮挡 |
| 新地点 | 固定大远景:让角色横穿画面(Tati) |
| 大场面 | 贴地低角度,前景对象大(鸽子),然后爆发的鸽群填满天空 |
| 反应 | 角色与搭档的中近景,两拍对视 |
| 高潮 | 叠印转场 → Haugomat 构图,机位锁死;全片角色唯一停下的时刻 |
| 收束 | 中景侧拍,太阳在他身后,分享 |
| 结尾 | 正俯拍配长影 → 拉远露出纸从机器里出来,落在一叠更早的印张上 |

## 6. 声音

- **音乐**:轻快**波萨诺瓦**,120 BPM(1 小节 = 2 秒,剪辑点落在偶数秒)。**音乐像印版一样分层**:一种油墨 = 独奏尼龙吉他;+ 黄 = 沙锤、击边梆木、软刷(自行车铃作打击乐);+ 粉 = 倍低音提琴和口哨旋律;完全叠印 = + 颤音琴。最终拉远期间把乐器一件件抽走。高潮的漂移下面一整小节完全静默(混响尾切掉),弹回时全乐队回来。
- **拟音跟随材质**:riso 机器是标志声音(每次印版到达时走纸 "shhk" + 滚筒 "ka-chunk";结尾处马达与纸的摩擦;一次轻软的纸落)。金属:自行车铃(两个非谐分音 ~2.1/3.4 kHz,每响 5 次快速敲击)、刹车啸叫。面包皮脆响(密集的微小带通咔哒)。鸽翅(短促带通噪声脉冲)、咕咕声(300–400 Hz 滑音)。水声拍岸,静默小节中的远处教堂钟(今天是星期天)。
- **人声**:松弛的男声旁白(Kokoro `am_adam`,语速 0.95),5 句短台词,每句用 whisper 核验。人声下压音乐 −8 dB。
- 混音响度 −14 LUFS;`mux.sh` 中不加胶片颗粒(颗粒在印刷里)。

## 7. 字幕与标题

- 字幕:一条**纸白挖空带**(所有版零油墨,6 px 圆角)居中于下方 1000 px 处,文字**只用蓝色**,Jost 500 42 px,字距 0.5 px。因为这条带由"其他版的缺席"定义,它的边缘会带上彩色套印不准的毛边。
- 标题卡:"SUNDAY RIDE" Bricolage 800 190 px 印在天空的蓝版上,由第一个和弦上的左→右擦除揭示,在节拍上移除(印刷品不淡出——它们被切走)。
- 片尾卡:空白纸张,粉 + 蓝双击的标题、"RISOGRAPH PRINT"、致谢、角落的套准十字线,以及铃响时一个微小的骑手骑过基线。

## 8. 我们踩过的坑

- 一个区域三张半调版 = 烂泥。遵守两版/一半调规则。
- 哈希噪声 `fract(p*vec2(233.34,851.73))` 在 1080p 下于实地上产生**竖条纹**。用充分混合的哈希(`fract(vec3(p.xyx)*.1031)` 一族)。
- 每帧套准抖动 + 每帧纸张划痕让画面闪烁,并把 x264 逼到 900 MB。修复:每镜头固定偏移、只在重拍上踢动、纸级噪声只在剪辑点变化、颗粒沸腾 35 %。
- JPEG 截图(4:2:0)把粉/蓝点抹糊。渲染 **PNG 帧**到无损中间片(qp 0、yuv444),再编码一次(crf 16 `-tune grain`)。即便如此 40 秒半调影片约 280 MB;不带 `-tune grain` 的 crf 20 约 120 MB,在 1080p 和 50 % 下依然干净。
- 纸光环层必须复制当前画布变换,否则变焦镜头会以错误比例画角色。
- 透明层里的 `over()`(加法)失去意义;叠印要在版画布上做。
- 在 2D 里安排递接:给予者的手臂在背景层,会消失在骑手身后——把交接放在骑手前方和上方。
- 桥拱用 `evenodd` 填成了实心;改用 `arc(..., true)` 描下缘。
- 条纹衫 + 圆眼镜 + 瘜三条读起来像一个著名绘本角色。用纯色针织衫和别的标志物(一条厚围巾)。
- 毛衣/长裤颜色必须含蓝,否则单色开场显示一颗悬浮的头。

## 9. 制作配方(本仓库)

```
styles/risograph/demo/
  riso.js     WebGL2 print shader (plates, halftone, grain, registration, sweeps, water reflection)
  draw.js     plate-canvas helpers: ink(b,y,p), over() overprint, layer() paper-halo, IK, limbs
  rider.js    rider, bike, pigeon, baguette (all colours as plate densities)
  scenes.js   river, street + bakery      scenes2.js  park, top-down quay, printer, bell ECU
  film.js     timeline (120 BPM), shots, registration kicks/drift, plate gates, subtitles, sound events
  sheet.js    model sheet (?sheet=1)      lines.json  narration
  music/score.py  original bossa nova (numpy)   music/bell.py  bicycle bell
  mix.py      foley + ambience + ducked voice + score → mix.wav
  tools/      video_png.mjs (PNG frames, lossless intermediate), mux.sh (crf16 -tune grain), subs.py
```

1. 先设计印版:单色帧长什么样,每张版增加什么?渲染模型表(`?sheet=1`),带一行 "plates = story"(同一角色分别以 1、2、3 张版,通过 `S.mask`)。
2. `sh styles/risograph/demo/build.sh` 重建一切:TTS → whisper → 乐谱 → 事件 → 混音 → SRT → 渲染(960 帧,3 个 worker 约 2–4 分钟)→ mux。
3. 审查:`node core/render/still.mjs styles/risograph/demo --range 0:40:1.5` + `core/render/sheet.py`;以 0.2 秒步进检查关键动作;以 100 % 和 50 % 检查成片有没有摩尔纹。
