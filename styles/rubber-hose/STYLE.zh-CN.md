# 1930s 橡皮管卡通(1930s Rubber Hose Cartoon)— 风格提示词

> 黑白手绘墨线卡通,每件物品都活着,并随一支热辣爵士乐队摇摆。
> 演示:*Coffee Cup Chase*(50 秒)· `rubber-hose.mp4` · 源码在 `demo/`

你正在执导一部 **1930s Rubber Hose** 风格的 30–60 秒短片。用户给你一个主题。其余一切——故事、镜头、节奏、音乐、声音——由你决定,并交付一部完成的影片。遵循本指南。

参考谱系(学语法,绝不复制角色、设计、旋律或标志):早期 Fleischer Studios 短片(约 1930–33)的"整个世界都在跳舞";*Cuphead* 展示现代团队如何完成这个外观并用大乐队配乐。绝不使用现有卡通角色、名称或剪影。**避免"人身上顶个杯子、插根吸管"式设计**——如果你的主角是一件物品,*整件物品就是身体*。

---

## 1. 这个风格是什么

早期有声时代的手绘黑白动画:角色长着**橡皮管四肢**(等宽圆管,无肘无膝)、**白色四指手套**、**派眼(pie eyes,黑色椭圆瞳孔带一个楔形缺口)**、巨大的圆鞋,以及像气球一样压扁拉伸的身体。背景是柔和的灰色水彩;角色是平涂的白、灰和墨。一切——家具、锅、时钟、窗帘、墙壁——都**随音乐呼吸**。影片看起来像一份磨损的 35 mm 拷贝在 4:3 片窗中放映:闪烁、划痕、灰尘、片门晃动、暗角。

## 2. 故事:什么适合这个风格

挑选**音乐与运动即故事**的作品。橡皮管卡通有四种原生能力——至少用三种,并把最强的放在情感高潮:

| 原生能力 | 故事用途 |
|---|---|
| **一切随节拍呼吸** | 场景本身是角色。高潮处*整个世界*同步起舞——每件道具,连墙壁在内。这是回报镜头。 |
| **米老鼠式配乐(Mickey-mousing)** | 每一步都是一个音符。把道具变成乐器(演示中:一阶盘子是木琴——小角色踩着上行木琴八分音爬上去,大角色踩大号四分音)。 |
| **橡皮管拉伸** | 四肢能伸到任意长度。用在转折点(演示中的手臂绕着漩涡一路伸进下水道,一镜到底)。 |
| **影片是实体物件** | 标题卡像窗帘一样卷起;光圈(iiris)可以被角色抓住拉拢;字幕卡可以被撞到。非常适合开场与结尾。 |

改编任何主题:把题目变成**一个热闹场景内的追逐或表演**(厨房、办公室、玩具店、工厂)。给场景配 5–8 件活物当配角。

**情感弧线(40–55 秒):** 第 1 帧设钩子(弹跳的标题字母、乐队重击)→ 一个小愿望 → 3 段逐级升级的追逐大场面,各一个视觉笑料 → 危险 → 拉伸 → 死寂 → 一个安静善良的转折 → 释放:整个世界起舞 → 带笑料的光圈收场。保持一个主角、一个目标、一次转折。

## 3. 视觉语言

- **画幅**:1920×1080 输出配 **4:3 片窗**(1440×1080 居中,黑边),片窗圆角 r≈28 px,片窗边缘一圈柔内阴影。
- **调色板**——严格灰阶,6 级 + 角色白:
  纸 `#F1EEE6` · 浅 `#C8C5BC` · 中 `#9A978F` · 深中 `#6B6963` · 深 `#3B3A37` · 墨 `#0E0D0C` · 角色白 `#FCFBF7`。
- **对比规则**(重要——我们的第一张风格帧太平了):角色拥有两个极端。角色的白与墨必须比背景中任何东西更亮/更暗。墙壁处于**中灰**(`#8C8981`),瓷砖 `#A29F97`,橱柜 `#66635D`–`#7C7972`。最终合成中加 `contrast(1.14)`。
- **角色**:平涂填充,背对左上光源一侧有一条硬边形体阴影带(浅灰),墨色轮廓在任意变焦下**屏幕空间恒定 6 px**(先变换点再描线),轻微**线条沸腾**(±1.2 px,3 张画以 12 fps 循环)。
- **解剖套件**:
  - 四肢:恒宽面条管(280 px 角色上 13 px),一个平滑弯折,圆端帽。
  - 手套:掌 + 3 根胖手指 + 拇指,喇叭口袖口带折线,手背 3 条缝线。只描并集的外轮廓(先把所有部件粗描一遍,再全部填充)。
  - 派眼:白色椭圆,大黑瞳(占眼的 64% × 74%)朝右上切一个楔口;眨眼用身体色的眼睑加一条睑线。
  - 嘴:带腮边短线的微笑、露灰舌的咧嘴、"O"、波浪形(害怕)、噘嘴(嫌弃)、吐舌 "bleh"、灿烂笑。
  - 鞋:黑色大椭圆,脚尖一点白色高光。
- **物品角色**:脸长在身体上;一个次要特征承载情绪(演示中马克杯的**蒸汽**:慵懒波浪 / 苦涩锯齿 / 笔直警报 / 蔫垂 / 爱心)。立方体或盒子,投影一个真实 3D 立方体、略俯视(仰角 ≈0.26 rad),用仿射变换把脸贴到正面。
- **背景**:一次性画进缓存画布,1.25–1.5× 分辨率(镜头推近仍锐利):平涂水彩 + 柔糊色斑(±5% 明暗)+ 内侧描深边 + 细深灰轮廓(3 px)+ 纸纹。背景永不沸腾。经典母题:带小菱形条纹墙纸、方砖、镶板橱柜、黑白棋盘地板、吊灯。
- **胶片损伤**(画在合成层,不进场景):片门晃动 ±1.2 px 低频加偶发 3–6 px 跳动;每帧亮度闪烁 ±4%;0–3 条竖划痕在几帧间漂移;每帧 3–8 粒灰尘;偶发一根毛发;强暗角(角落 0 → 62% 黑);每次剪辑 3 px 竖跳;0.55 px 模糊。颗粒放进 ffmpeg(`mux.sh` 颗粒 **3**),不放进页面。

## 4. 运动语言

- **角色按 2 拍**(12 fps);镜头逐帧(ones,24 fps)。阶梯式镜头读起来像抖动。
- **节拍栅格**:选一个节拍为整数帧的 BPM。**144 BPM → 1 拍 = 10 帧**,每个节拍都落在偶数帧上,2 拍动画能精确命中。
- **呼吸**:每个静物按 `cos(2π·beats)` 压扁/拉伸——**每个节拍一个极值**(节拍上拉伸、反拍压扁),按 2 拍采样,幅度 ~5–7%。所有道具同相。高潮处幅度 ×3,并让整幅背景画绕地平线压扁(~2.5%)。
- **走路**:每拍一步,身体起伏 10 px;伤心走 = 更小步(34)、起伏 4、手臂耷拉。**跑**:双腿风车(脚绕圆轨道),前倾 0.24 rad,速度线,蒸汽向后吹。
- **预备–停顿–动作**:每个大动作前,下蹲(压到 0.8)、停顿(让乐队停)、然后爆发。撞击带指数回弹的压扁。
- **定帧即表演**:演示中的犹豫节拍 = 下蹲(停)→ 眼睛看向另一角色的背影(停)→ 眼睛上看目标(停)→ 回看 → 上看 + 咧嘴 → 小跳 → 跃出。每次瞥视落在一个八分音符上,配一声木鱼,镜头缓缓推进。
- **乐队骤停时定格**:音乐为"对视"节拍停下时,一切冻结,连背景呼吸也包括。

## 5. 镜头语言

| 节拍 | 镜头 |
|---|---|
| 开场 | 带旋转日纹的标题卡;字母随节拍成波状跳跃;卡片像窗帘卷起露出场景 |
| 定场 | **舞台般宽广、机位锁死**,平视。场景读起来像镜框式舞台;道具沿柜台排开 |
| 反应笑料 | 硬切到脸部特写(前段唯一的大脸镜头) |
| 追逐 | 与跑者并肩的**移动跟摇**,起停缓入缓出;笑料道具先于包袱入画 |
| 竖向大场面 | 别把整个大场面框在远处——用**中景**跟随每个攀爬者(角色 ≈ 画面高 1/4–1/3),让每个音乐台阶和盘子弹跳可读;在攀爬者间切换;坠落时摇下 |
| 危险 | 略俯视角让危险一眼可读;大拉伸期间**保持一镜到底** |
| 安静转折 | 中景双人镜头,然后主角的**背影**在远处走远、变小,另一角色在前景(前景柜台件上)很大 |
| 高潮 | 从特写拉到**中全景**(不要远大远景——脸必须可读):主角居中,活的道具在身后柜台上,**更近的柜台件上一排更大的舞者**站在前景。按小节分 2–3 步(摇摆 → 踢腿 → 集体蹲跳),最后**所有人在末拍定格成 ta-da 姿势**并保持到光圈 |
| 结尾 | 光圈收到主角们身上;一只角色的手套把它拉拢 |

## 6. 声音

- **音乐**:1930s 热舞乐队 / 拉格泰姆——跨弹钢琴、单簧管、小号(开放 + 柱塞弱音器 "wah-wah")、长号、大号 oom-pah、班卓琴打 2、4 拍,刷帚小鼓带滚奏、木琴、木鱼、滑笛、镲。**不要弦乐铺底,不要现代合成器。** 一条原创 4 小节切分主题:标题用一次、追逐用一次、温柔节拍用慢速单簧管独奏版、高潮用转调全乐队尾奏。
- **米老鼠式配乐**:"对视"节拍、笑料前的悬念、以及拉伸后整整 2 拍硬静默(含混响尾);每个包袱一个 stinger;每次拉伸/滑行/坠落一声滑笛;木琴*就是*盘子。
- **拟音按材质**(全部合成):瓷 = 硬非谐分音(~2.7/4.2/6.3 kHz)+ 微小瞬态;厚马克杯 = 更低更闷的分音;糖 = 高音木鱼 + 稀疏脆响;时钟 = 18 Hz 音锤敲两片铃;烤面包机 = 咔哒、八分音符滴答、铃 + 弹簧 "boing";水 = 滤波噪声 + 上升哔声、下水道吸溜、气泡床;橡胶 = 锯齿波过带通的嘎吱。
- **人声**:老式电台播音员像解说赛马一样解说动作(Kokoro `bm_lewis`,语速 1.0),5–7 句短台词。链路:HP 260 Hz / LP 4.6 kHz、tanh 饱和、短房间混响、压缩。人声下压音乐 ~8 dB。
- **光学声带处理**作用于音乐 + 拟音:带限 110 Hz–6.2 kHz,轻微抖晃(0.6 Hz)和颤动(7 Hz),软饱和;然后铺一层嘶声、爆点声和 24 Hz 放映机片门哒哒声——后者是静默期间的*唯一*声音。
- 响度 −14 LUFS(`core/render/mux.sh` 两遍 loudnorm)。

## 7. 字幕与标题

- **字幕是"播音员的字幕卡"**:一块小黑板(rgba(12,11,10,.92)),白色双细线边框、圆点套圆环角饰和一个小小的 1930s 带式话筒图标;文字用 **IM Fell English SC** 36 px,纸白。画在场景层里,随影片一起晃动和闪烁。无淡入淡出,直接弹入弹出。默认在底部(y≈986),动作低位时移到顶部。一张卡可跨两段语音;每张卡 ≥ 语音 + 0.6 秒。
- **标题**:**Shrikhand** 胖复古手写体,白面、14% 墨轮廓、墨色阴影向右下偏移;每个字母随节拍成行进波跳跃。副行用 **Limelight** 大写。
- **片尾卡**:同一日纹,一块波浪边牌子写 "The End"、风格名、`LemoLab × Claude Opus 5.5`,底部小字致谢。以黑色光圈开场。

## 8. 我们踩过的坑

- **第一张风格帧又平又灰。** 把墙推到中灰,纯白/墨留给角色,加对比滤镜。30 年代的拷贝是浓黑 + 亮白。
- **Kokoro 把 "bitter" 听成 "better"**,出现在省略号之后(`is... bitter!`)。"And boy, is this coffee bitter!" 则通过。每句都用 whisper 检查;也检查最终 mp4(whisper 会写出 "7am"/"they're"——比较前先归一化)。
- 播音员短句 → 字幕太短。把连续台词合并到一张卡。
- **纯正面视角下立方体读成高盒子**——用仰角 ~0.26,表情时略转 3/4。
- "伤心"眉画成"生气":按内端/外端定义眉毛(内端 = 靠近鼻子一侧),而非左右。
- 大远景让角色太小(评审意见):盘子木琴和舞蹈高潮的远镜头毁掉了两个包袱。米老鼠式配乐需要中景;高潮需要挤满舞者的中全景,不是全屋视角。
- 踢出的腿画在马克杯身体后面会被把手挡住——向剪影外侧踢。
- 画出来的角色在某些机位会与背景道具相撞(一个锅从马克杯头上"长"了出来)。检查每个镜头的最终帧。
- 排成一排的烟团读起来像"思考气泡"——散开并让它们长大。
- 跃出弧线太高会出画;让弧线保持在当前变焦的片窗内。
- 不同长度的 `sfx` 式片段 → numpy 广播错误。把片段放进定长缓冲(`mix.py` 的 `seq()`)。
- zsh:`echo =====` 失败(`=word` 展开),macOS 上没有 `timeout`。
- JS:`-x ** 6` 是语法错误;写 `-(x ** 6)`。

## 9. 制作配方(本仓库)

```
styles/rubber-hose/demo/
  toon.js    constant-width ink + line boil + affine stack      film.js   4:3 gate, weave, flicker, scratches, vignette
  chars.js   mug & cube rigs, pie eyes, gloves, shoes, steam     cast.js   living kitchen props (all take a breath phase)
  bg.js      cached watercolor backgrounds (kitchen, cupboard+sink)
  story.js   144 BPM bar grid, VO times, subtitle cards, shots, key moments, music cues  (single source of truth)
  scenes.js  every shot: camera, props, acting            events.js  foley event list → events.json
  ui.js      title lettering, announcer title card        sheet.js   model sheets (?mode=sheet / ?mode=kitchen)
  music/score.py  original big-band score (VSCO 2 CE / VCSL samples via core/audio/sampler.py, banjo via pluck.py)
  mix.py     foley synthesis + radio-voice chain + ducking + optical-track aging
  build.sh   one-command rebuild (≈9 min, mostly TTS/whisper/sample loading; frames render in ~50 s)
```

1. 先写小节栅格(`story.js`),再写提示映射;照它配乐(一个分叉的子代理可以根据 `story.js` + 提示清单并行编写 `music/score.py`)。
2. 模型表:`node demo/tools/still.mjs demo 0 --q 'mode=sheet&w=2880&h=1620' --w 2880 --h 1620`。
3. `core/tts/tts.py lines.json voices` → `core/tts/asr_check.py`。
4. 审查:`core/render/still.mjs demo --range a:b:1` + `core/render/sheet.py`(两轮完整过),并在关键表演节拍上以 1/12 秒做帧条。
5. `node core/render/events.mjs demo` → `python music/score.py` → `python mix.py`。
6. `node core/render/video.mjs demo --fps 24 --workers 3` → `sh core/render/mux.sh out/video24.mp4 mix.wav rubber-hose.mp4 24 3` → `python demo/tools/final_asr.py rubber-hose.mp4`。
