# 科幻情景喜剧卡通(Sci-Fi Sitcom Toon)— 风格提示词

> 成人向科幻情景喜剧动画:粗厚的沸腾轮廓、平涂色、一个倦怠的天才和一个紧张的跟班、一个发着绿光的传送门,以及每个平行宇宙一套配色。
> 演示:*Coffee Run*(57.5 秒)· `scifi-toon.mp4` · 源码在 `demo/`
> 灵感来自 adult-swim 时代的科幻情景喜剧卡通。借鉴*语法*,绝不借鉴角色。

你正在执导一部 **Sci-Fi Sitcom Toon** 风格的 30–60 秒短片。用户给你一个主题(也许还有故事)。其余一切——前提、笑料、角色、镜头、节奏、音乐、声音——由你决定,无需请求批准,交付一部完成的影片。遵循本指南。

---

## 1. 这个风格是什么

面向成人的、看起来手绘的 2D TV 动画:**统一粗黑轮廓且沸腾**、**平涂填充配硬边阴影形(无渐变)**、**带小瞳孔的大白眼**、**弹性嘴巴**、既怪异又可爱的外星人,以及被当破烂家什对待的科幻硬件。喜剧是**对话驱动**的:即兴感的交谈、插话、尴尬停顿、反应镜头、升级,以及最后一秒的反转。

**版权红线(不可协商):**
- 绝不复刻任何现有节目的角色、剪影或配色组合(如白大褂刺猬蓝发老头 + 黄衫小孩)、名称、口头禅、打嗝梗、标志,或任何现有传送枪的外观。
- 自己发明角色、道具和传送装置。绝不在影片或文档中写来源节目名称;一句"灵感来自 adult-swim 时代的科幻情景喜剧卡通"就够了。

## 2. 故事:什么适合这个风格

这个类型的引擎是**一个微小、日常的目标 + 荒诞庞大的科幻手段**。天才什么都能解决,却用它干鸡毛蒜皮的事;跟班付出情感代价。

| 原生能力 | 故事用途 |
|---|---|
| **平行宇宙** | 每次跳跃 = 新配色、新音乐动机、新生物。观众仅凭颜色和声音就读出"我们跳了"。 |
| **恶心又可爱的生物** | 每个世界配一种既恶心*又*可爱的生物。保持非语言(音效),影片始终保持双人戏。 |
| **双人反差** | 面瘫低能天才 vs 慌乱跟班。笑点在于两人反应的*差异*。 |
| **传送门即语法** | 发光的传送门是唯一发光的东西,每次转场都经过它。 |
| **对话喜剧** | 插话、结巴、抢话、面瘫单词回答、沉默。 |

**改编任何主题**——把它变成一件差事:
- 产品发布 → 天才穿越次元寻找一件能用的产品;每个宇宙里都是更糟的版本;带回来的那件有反转。
- 一堂课 / 讲解 → 跟班问一个简单问题;每个宇宙是一个按字面理解的错误答案;最后一个是对的,但有代价。
- 节日 / 活动 → "派对的 X 用完了" → 越来越离谱的 X 的宇宙。

**45–60 秒的节拍表**(已在演示中验证):
1. **冷开场(8–12 秒)**——日常问题,展示而非讲述(空咖啡壶、最后一滴)。跟班过度解释,天才一个词打断。无音乐,无标题。
2. **传送门 + 标题砸入(2–3 秒)**,落在音乐强拍上。
3. **跳跃 1(6–8 秒)**——慢:到达、尝试、插入特写揭示不对劲、**音乐切断**、反应镜头、单词否决。
4. **跳跃 2(6–8 秒)**——更快更糟;跟班崩溃;同一个否决词。
5. **蒙太奇(3 × 1 秒)**——三次法则变成机关枪:每宇宙一秒,每次同一个词,剪辑踩在拍上。
6. **破格(4–5 秒)**——一个*可疑地正常*的宇宙。模式打破;平静本身就是笑点。
7. **回家(12–16 秒)**——放松 → 反转(带回来的东西是错的)→ **2 秒以上死寂** → 天才用一句话暴露他的价值体系 → 收尾梗。
8. **收尾梗(button)**——回调开场台词,让故事成环。
9. **片尾卡(4–5 秒)。**

经验法则:每个荒诞画面之后必须跟一个**反应特写**。笑点长在脸上,不在怪物身上。

## 3. 视觉语言

- **线条**:近黑 `#1b1422`,角色与道具 **7 px**,背景细节 4–6 px,圆角连接。**线宽在屏幕空间恒定**——特写是"以同样粗细重画"的,绝不放大。(实现:先把点变换到屏幕,再用单位变换描线。)
- **线条沸腾**:在屏幕空间以 ~7 px 步长重采样每条轮廓,沿法线用低频噪声位移,幅度 ~1.7 px;**3 张沸腾画以 12 fps 循环**。一切都在沸腾,包括定格姿势和背景——没有一帧是死的。
- **填充**:只用平涂色。阴影是裁剪在填充内的硬边深色形(每个形体一个,在背光侧)。发光是 1–2 圈平整的半透明环,不是渐变。天空是**平涂色带**,不是渐变。
- **脸**:大白眼(3/4 视角下相触或相叠),瞳孔 4–5 px 圆点,面瘫角色有厚重的上眼睑、眼袋、胡茬点。嘴巴参数化(开度、宽度、嘴角卷曲、偏斜),带深色口腔、牙条和舌头。眉毛承载大部分情绪。
- **角色设计**:剪影必须能在黑色下读出。给每个主角一个荒诞的服装点子(演示:天才穿浴袍 + 毛绒拖鞋 + 护目镜;跟班戴骑行头盔 + 巨大的圆眼镜)。避免白大褂 + 刺猬头。
- **调色板——每个宇宙一套**,各 3–5 色,与上一个世界差异最大化:
  - 家中实验室:鼠尾草绿 `#a7c3b1`、橄榄色地板、暖木色、一处橙色点缀。
  - 果冻世界:品红天空条 `#ff4f9a→#ff9bcb`、青柠果冻 `#b8f03c`、青 `#52e0e0`。
  - 马克杯世界:橙色天空 `#ff7a2f→#ffb862`、青绿山丘 `#2b9c98`、奶油色。
  - 牙齿世界:红 `#c3122f`、牙龈粉 `#ff8fa6`、牙白。鸽子世界:板岩蓝 `#5f78a8`、灰系。克隆世界:反转紫 `#3b1f66` + 黄 `#e8d84a`。
  - "正常"世界:刻意乏味的米色 `#f1e3c6` 和棕色。
- **传送门**:竖椭圆(x 缩放 ~0.74),疙疙瘩瘩的黏液边缘 `#3fd93a` 带 7–8 px 轮廓,5 条螺旋臂以 `#b8ff5a`/`#21b33c` 交替、**逐帧(ones)**旋转,苍白的核,环绕的火花,底部滴落,开启时给整个场景盖一层平涂绿。开启带 ~12% 过冲(back-ease 0.32 秒)——更弹的过冲会把演员盖住。
- **屏幕图形**:左上角复古终端风的"宇宙读数"标签(VT323,打字机式打出,按世界着色,1 秒镜头打字更快);标题用带黏液滴落的胖圆展示字体。

## 4. 运动语言

- **角色按 2 拍(12 fps)**:姿势、嘴、眨眼、走路循环和沸腾全部以 12 fps 步进。**镜头运动、传送门漩涡、飞行道具和屏幕擦除逐帧(24 fps)**。
- **表演优先于移动**:大部分喜剧是定格姿势加小变化——眼睛一抽、头不动瞳孔滑动、一次吞咽、汗珠。加闲置生命:呼吸(±1% 纵向压扁)和由语音响度驱动的点头。
- **预备 → 动作**:举起遥控器前先下压;投掷前先把手臂向后拧。
- **落地压扁拉伸**(衰减余弦压扁 ~22%),飞出传送门时拉伸,"被吸入" = 边拉伸边向传送门中心缩放。
- **从音频做口型**:每句台词以 24 Hz 计算 RMS(开度)和谱质心(宽 vs 圆);在 12 fps 绘图时刻采样。尖叫时夸张(嘴放大 1.5–1.9×)。
- **紧张角色抖动**:12 fps 的 3–6 px 随机偏移加颤抖的瞳孔;随恐慌升级幅度。

## 5. 镜头语言

| 节拍 | 镜头 |
|---|---|
| 冷开场 | 问题物体的静止插入特写,缓慢推进 |
| 对话 | 中景双人镜头;**插话时硬切特写** |
| 荒诞揭示 | 插入极端特写,然后切到反应特写 |
| 恐慌 | 紧特写,关键词上一个短促镜头抖动 |
| 跳跃 | "冲入"传送门的急推 → 全屏漩涡擦除 → 下个世界从漩涡中打开 |
| 蒙太奇 | 每个世界取景相同(双人左、生物右),只有世界在变 |
| 冰冷沉默 | 对峙双人镜头,极缓推入,除沸腾外一切不动 |
| 收尾梗 | 大远景,传送门和两个角色都在画内 |

别把脸放进字幕带(底部 170 px)。保持宇宙标签不遮脸。

## 6. 声音

- **配乐**(合成;无需采样):120 BPM,让剪辑咬在半秒拍上。**特雷门琴(theremin)**主奏(正弦 + 少量 2/3 次谐波,连奏滑音 ~70 ms,每个音起后 150 ms 淡入颤音,弹簧混响),叠在模拟贝斯、16 分音符方波琶音和复古鼓机之上。主题用小调(演示:D–A–B♭–A–E–F–E–E♭–D 半音下行)。
- **每个宇宙一个动机**,写成独立提示,其**第一拍即剪辑点**:弹跳大号 + 摇晃主奏 + 滑笛(果冻)、刷帚摇摆爵士配颤音琴(马克杯)、四踩脉冲上的 1 秒 stinger(蒙太奇)、Karplus–Strong 尼龙吉他的电梯波萨("正常"世界)、暖 Rhodes + 特雷门 "aah"(放松)、上行颤音弦(恐慌)。
- **静默即包袱**:在揭示插入镜头和冰冷停顿处硬切音乐(含混响尾)。只留房间底噪:日光灯嗡鸣 + 时钟滴答。
- **拟音**(合成):传送门开启(次重击 + 下扫噪声 + 上升漩涡)、传送门嗡鸣、关闭 "fwump"、每次擦除的漩涡嗖声、吐出和落地时的卡通 pop/boing、黏液生物的湿 glorp/squish/blink、吸管吸吮、咬牙、鸽子咕咕、店铃、水泡声、卡通眨眼 "blip"、遥控器滴答。
- **人声**:双人戏。面瘫天才 = 低而平的声音(Kokoro `am_onyx`,语速 0.82–0.9,轻饱和 + 180 Hz 提升做出沙砾感)。跟班 = 更高更快(Kokoro `am_eric`,语速 1.1–1.15,存在感提升)。生物非语言;一个小生物可以说一两个词(Kokoro `af_sky` 升 7 个半音)。压缩、RMS 匹配、短早期反射让声音落进房间。对白下压音乐 ~−7 dB。母带 −14 LUFS。

## 7. 字幕与标题

- **字幕**:底部居中,**Baloo 2 ExtraBold 50 px,白字 11 px 黑描边**(看起来像卡通自己的字幕),左侧一个角色色小**说话者药丸标**(沸腾轮廓)。超过 ~1300 px 的行折成两行。重叠行堆叠;旧行变暗到 70%。
- **时间**:在屏 `max(audio + 0.35 s, 0.9 s + chars / 17)`;世界切换处裁切,并**在静默节拍之前**裁掉,让静默落在干净画面上。
- **标题**:1950s 原子时代电视标题——奶油色的厚块字母(Bungee)带硬品红偏移阴影和粗墨轮廓,环绕一条倾斜的青色轨道环,一颗咖啡豆绕环飞行,几颗闪烁的四角星;在音乐强拍上按 12 fps 步进弹出。**避免酸性绿、黏液滴落和摇摆泡泡字**——那套组合读起来像某个特定节目的标志。
- **片尾卡**:深紫,一个缓慢变暗的传送门、标题、终端字体的风格名、"LemoLab × Claude Opus 5.5"、致谢;欢迎在传送门里放一个微小的片尾彩蛋。

## 8. 我们踩过的坑

- Kokoro + whisper:低音里的人名 "Pim" 被读成 "Pam"——选能在低音里幸存的名字(Gary 可以)。连字符结巴("b-broken")被读成 "be broken";结巴写成音节("buh, buh-broken"、"Wh, wh, why")。"decaf" 可能出来 "D-cuff";"dee-caf" 可靠。
- Whisper 会听错很短的片段,除非转写前垫 ~0.6 秒静音。
- 要让插话真实,把被打断的台词生成得*比需要的更长*,在另一角色切入处截断音频。
- 弹簧传送门(库 `spring`)过冲到 ~135% 并吞掉演员;用温和的 back-ease。
- 杯子里的棕色团块读起来像土豆。咖啡需要拉花爱心、越过杯沿的滴落和蒸汽。
- 放在柜台后面的角色会消失——检查家具后面的生物是否仍露出脸和上半身。
- 方波合成的镲片在 8–20 kHz 混叠成刺耳嘶声,频谱图上是蜂鸣线;用带通噪声加一点 FM。
- D1(37 Hz)的持续低音在笔记本音箱上只是隆隆声;结束在 D2。
- 音乐提示被切时,混响尾也要切,否则"死寂"不死。
- `ffmpeg fps=1` 的接触印片最多偏移半秒——别误诊镜头边界。

## 9. 制作配方(本仓库)

```
styles/scifi-toon/demo/
  toon.js     vector engine: matrix stack, screen-space boil, constant line width, flat shading
  chars.js    the cast (parametric eyes, mouths, hands, noodle limbs) + props
  worlds.js   one function per universe + creatures + the portal
  story.js    single source of truth: VO start times, shots, wipes, tags, key beats, music cues
  main.js     acting per shot, cameras, wipes, tags, subtitles, title, end card, window.EV
  lines.json  script (tts text, subtitle text, speaker, voice, pitch, cut)
  voice.py    per-character processing + lip-sync envelopes   asr.py   padded whisper check
  music/score.py  synthesized score from the cue list        mix.py   foley + voices + ducking + ambience
  srt.mjs  build.sh  sheet.sh (contact sheets)  strip.sh (consecutive-frame strips)  levels.py (stem meters)
```

1. 写剧本大纲。通过生成测试台词并测量 f0 中位数 / 音高方差来定配音。
2. `core/tts/tts.py lines.json out/raw` → `voice.py` → `asr.py`,直到每句通过。
3. 把语音时刻、镜头和提示放进 `story.js`;在 `main.js` 中排镜头;用 `sheet.sh`(1 帧/秒)和 `strip.sh`(连续帧)审查——至少两轮。
4. `core/render/events.mjs` → `music/score.py` → `mix.py`(检查 `levels.py` 和频谱图)。
5. `sh demo/build.sh` 复现一切:TTS → 人声 → 事件 → 配乐 → 混音 → SRT → 渲染(1380 帧,4 个 worker 约 15 秒)→ 以 −14 LUFS 封装。M 系列 Mac 上完整重建约 1 分钟。
