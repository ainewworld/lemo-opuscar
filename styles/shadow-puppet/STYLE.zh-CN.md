# 皮影戏(Shadow Puppetry)— 风格提示词

> 中国皮影戏:半透明的染色皮革皮偶,雕得像蕾丝,贴在棉布幕上,由身后的油灯照亮。
> 演示:*Hou Yi Shoots the Suns*(后羿射日,54 秒)· `shadow-puppet.mp4` · 源码在 `demo/`

你正在执导一部 **Shadow Puppetry(皮影戏)** 风格的 30–60 秒短片。用户给你一个主题。其余一切(故事、镜头、节奏、声音)由你决定,并交付一部完成的影片。遵循本指南。

---

## 1. 这个风格是什么

一个小舞台,蒙一块白布幕。幕后,一位艺人把用**半透明染色驴皮**刻成的平面皮偶贴在布上,一盏**油灯**从后面照亮它们。观众看到的是*透射光*下的色彩:红、绿、赭像彩色玻璃一样发光,镂空的孔洞最亮,两片重叠处更暗。皮偶用**可见的线铆钉**连接,由**三根细签子**操纵(脖子一根、两手各一根),因为它们略离开幕布,呈现为柔和的灰线。

这是现场戏剧,不是定格动画。幕布**随灯焰闪烁**,皮偶**在手中微微颤抖**,腿和翎毛**绕着铆钉自由摆动**。

参考语法(学习,不复制):Lotte Reiniger 的*《阿赫迈德王子历险记》*(1926)的侧脸表演和蕾丝式景物;陕西/华阴皮影的雕刻、敷彩和锣鼓节奏。绝不复刻某件具体的历史皮偶、旋律或录音。

## 2. 故事:什么适合这个风格

挑选**媒介本身讲故事**的作品。皮影戏有五种原生能力。至少用三种,并把最强的放在情感高潮:

| 原生能力 | 故事用途 |
|---|---|
| **光即世界** | 唯一光源是布后的一盏灯。让灯成为剧情的一部分:灯多 = 更热/更危险(画面过曝、颜色漂白);灯少 = 平静、色彩饱满。演示中,*每个太阳都是一盏灯*,每支箭熄灭一盏,画面随之逐级变暗。 |
| **离开幕布 = 又大又糊** | 皮偶被拉离幕布朝灯靠近时会变大变糊。用于登场(一团巨大的柔光压上幕布然后 snapped 变清晰)、死亡和退场(金乌翻滚着离开幕布,溶进光里)、魔法与梦境。 |
| **走到幕布后** | 终极尺度揭示:切到或移到幕后,展示灯、艺人的手和签子。"天空"原来是一块一米宽的布,"太阳"原来是一盏灯。放在高潮之后当回声。 |
| **雕刻与半透** | 英雄是*镂空脸*(脸是一个孔,只留眉、眼、鼻、嘴几条细皮条),光从他们身上透过。反派是实脸。重叠变暗、孔洞发光、景物如蕾丝。 |
| **手持而非动画** | 运动连续并带活的颤抖。腿像钟摆摆动,翎毛滞后于头,火是一块雕出的火苗件在签子上抖动。 |

改编任何主题:找到你的故事里**灯是什么**(太阳、炉火、一个念头、灯塔),以及**什么会离开幕布**(什么离开、死去,或只存在于想象)。产品发布 → 产品就是那盏最终照亮幕布的灯。一段记忆 → 人影离开布幕,随遗忘而模糊。

**45–60 秒的弧线:** 黑暗中一盏灯亮起 → 布上出现一个世界 → 灾难到来(光变化)→ 英雄登场与亮相定格 → 动作,配打击乐 → 一个静默的抉择 → 世界恢复 → 走到幕布后 → 布上的结尾卡。

## 3. 视觉语言

**渲染模型(风格的核心)。** 逐像素合成:
`image = tonemap( lampLight(x,y) × hideTransmission(x,y) × clothTexture(x,y) )`
- `hideTransmission` 是一张初始为**白色**的 2D 画布;每个皮偶部件以 `globalCompositeOperation = 'multiply'` 画上去。镂空处透明(保持白),重叠自动变暗。
- `lampLight` = 每盏灯有一个宽瓣(σ ≈ 700 px)加一个紧热点(σ ≈ 120 px),各自独立闪烁(≈ ±6% 的 7 Hz 值噪声加一点 23 Hz 正弦)。暖光色 `(1, .77, .46)`。
- `tonemap`:`1 − exp(−hdr)`。曝光为 `1.75 / √(lamps lit)`,十盏灯 ≈ 一盏灯的 3 倍:过曝、灼热、漂白,但仍可读。
- 布:细织纹(以 ~2.6 rad/px 的 sin × sin 加噪声扭曲)、纤维斑点、大块低频密度斑、布与框相接处变暗。
- 后期:3 级模糊金字塔的 bloom(阈值 0.72,暖色调 `(1,.82,.6)`)、**暖色暗角**(向 `(.7,.47,.25)` 变暗,绝不用中性灰,否则过曝帧会发灰)、饱和度 ×1.1、温和 S 曲线。热浪(UV 扭曲向上漂移)只在世界燃烧时出现。ffmpeg 中胶片颗粒 2。

**染料(透射色)。** 朱砂 `#b8211a`、焰 `#d9541c`、赭 `#dc9d1e`、金 `#c98a26`、石绿 `#236e3a`、玉绿 `#2f8a5c`、靛 `#22647e`、生皮 `#e2bd80`、墨 `#1a100a`(轮廓、头发、靴)。每件皮偶乘上一层**皮革纹理**(斑驳半透 + 纤维 + 斑点,可平铺的 512² 噪声),并用 `destination-in` 恢复其 alpha,让孔洞存活。

**雕刻即密度。** 只留细皮条,镂掉大部分面积:
- 盔甲 = 成排的厚月牙孔("亮鱼鳞"),裤 = 菱形格,腰带 = 钱纹孔(圆孔中间留一方块皮),领 = 四瓣云肩带云卷刻纹,袖与身不同色,剪影里手臂才读得出;
- 每个彩色区域加深色雕边(1× 下 1.5–2.4 px);
- 朝靴:高黑靴筒刻云卷、翘头、厚白底整块雕出(凹槽 + 一排椭圆孔)。
- **用不透明填充来镂刻。** 用 `destination-out` 时,填充 alpha 决定镂掉多少;总是先把 `fillStyle` 设成 `'#000'`。

**角色结构(关节皮偶)。** 11 个部件:头 + 盔、胸、裙、两条上臂、两条小臂、两只手、两条腿(+ 箭箙、弓、雉鸡翎)。头约为"自然"的 1.2 倍,盔占整个人物的约四分之一。关节处有圆瓣和可见铆钉(深色环 + 浅色结)。手臂由手部目标经双骨 IK 摆位;弓是程序化绘制(弓臂随开弓弯曲,弦连到扣弦手,**箭尾落在瞄准线上**),握点 = 肩 + u·118,箭尾 = 握点 − u·(40 + 72·pull)。

**景物 = 空幕布上的雕件。** 幕布大部分只是被照亮的布。山每座一件,顺山脊刻宽地层,峰旁刻云孔;树 = 一件树干加一整片布满叶形孔的蕾丝树冠;地面是底部一条窄雕带(回纹带 + 钱纹孔),裂纹刻成渐细的缝,随土地烧穿而变宽变长。水是一条独立的靛色波纹带,可以掀离。**火**是一件 S 形卷曲火舌的雕件(红 → 橙 → 黄色带,尖端螺旋钩)插在签子上,以 12 fps 换件并抖动。不要卡通火焰。

**太阳 / 徽记。** 一件圆形雕件:火舌边缘(卷向交替、舌间滴水孔)、珠环、半透明橙红圆盘,上面叠一个独立的深色剪影(如三足乌),以便它能脱落。

**舞台。** 红黑漆木框、雕花金云卷门楣、立柱,以及布在框内缘的暖色溢光;开场和结尾卡的大全景里,底部有几颗模糊的孩子的头。

**幕后(镜像视角)。** 用镜像相机(`x → −x`)渲染同一张透射画布。幕布周围是深色木作;灯(灯盘 + 电线)挂在幕前,一盏亮(火焰带加法发光),其余刚被掐灭,拖着烟(幕布上深色的烟缕,靠近亮灯处转为暖白)。手和袖子是**带暖色轮廓光的剪影**(遮罩减去向光偏移的遮罩),签子锐利。

## 4. 运动语言

- 皮偶与相机**24 fps 连续**。给每个皮偶加手持颤抖(≈ 3 px / 0.018 rad 低频噪声;艺人"绷着劲"时 ×1.8)。只有火件按 12 fps 步进。
- 身体随主签平滑移动;**腿和翎毛做模拟**(由身体加速度和头部旋转驱动的阻尼摆/弹簧链,120 Hz 预模拟,渲染确定性)。
- 戏曲式顿挫:碎步快跑 → 小跳 → 蹲 → **大锣上亮相定格**(保持 ~1 秒,只有翎毛颤动)→ 抬头。
- 头从不换表情;态度 = 头的角度 + 身体倾斜(向上 = 决意,向下 = 慈悲/悲悯)。
- 登场压上幕布(0.55 秒内缩放 2.6 → 1、模糊 34 → 0)。退场掀离(缩放 ×1.9、模糊 +30 px,约 0.9 秒淡出)。
- 灯:新灯先炸亮(过冲到 1.5×)再稳住。被掐灭的灯在 0.35 秒内随快速闪烁熄灭。

## 5. 镜头语言

| 节拍 | 镜头 |
|---|---|
| 开场 | 观众席视角:带孩子们头的完整舞台框。全黑,直到布后一根火柴炸亮。极缓推入。 |
| 进入故事 | 推过框,直到布幕填满画面。 |
| 灾难 | 横移 1.5× 扫过燃烧的大地(给出灾难区域)。 |
| 英雄登场 | 1.15× 跟随;亮相定格的锣上,一个 5 帧**急推**(打击乐重音变成镜头运动)。 |
| 第一动作 | 特写手/弓/脸,然后沿箭的方向甩摇至目标。 |
| 重复 | **锁定大远景**,让观众看清变化的每一步(此处:九级灯暗)。 |
| 抉择 | 中近景,目标在远端边缘:英雄在左、空荡的天空、最后的太阳在右。音乐停。 |
| 回声 | 拉远再次露出舞台框,**右移,一根模糊的前景立柱擦过画面**,然后从幕后走出。缓推,再快速俯冲进火焰,在结尾卡前闪成暖白。 |

z ≥ 1 时钳制相机,使它永不离开幕布矩形(否则出现黑边)。

## 6. 声音

- **音乐 = 锣鼓经模式,不是泛泛的钢琴 + 弦乐。** 大锣击后音高下坠("哐")、小锣音高上扬("台")、铙钹、硬质高音梆鼓(木鱼)、低音桶鼓。一把明亮鼻音的拉弦(二胡采样,升调、高频架 + 鼻腔共振峰、音高曲线重采样做大滑音和揉弦)有两种模式:灾难用**苦音**(微升 4 度 / 微降 7 度),英勇与疗愈用**欢音**( plain 五声)。唢呐式的尖厉簧片(双簧管 + 1.2–3 kHz 共振峰 + 饱和)只用于高潮。
- 模式映射剧情:开场长锣 → 每盏灯一击、渐加速 → 灾难下的心跳鼓 → 入场前加速的*急急风* → 亮相大锣 → 每击一声锣的快捶 → 静默抉择的**硬停**(≤ 30 ms,含混响尾)→ 决断时一声极轻的小锣 → 温柔的拉弦主题 → 进幕后的锣擦 → 最后一声大锣余韵。
- **拟音跟随材质**:开演与收场的醒木、火柴划燃、灯点燃 "fwoomp"、竹签敲布、皮件掀离时的干皮翻动、皮步声、弓吱呀(随开弓升调)、弦弹响、箭啸、命中皮革拍击、掐灯("pfft" + 嘶声)、拍翅、噼啪、热浪低鸣(静默处硬切)、水声、安静的幕后房间底噪和一次呼吸。
- **人声**:一位说书人(Kokoro `am_michael`,语速 0.86–0.88),5–6 句短台词,压缩,加一点小剧场混响。人声下压音乐 ~12 dB、拟音 ~4 dB;人声保持高于底床 ≥ 12 dB。每句用 whisper 核验,*并且*复查最终混音(单独通过的词在音乐下会糊:"shadow play still" 变成了 "shadow place";改写词句,别硬扛)。

## 7. 字幕与标题

- 字幕是**说书人的牌子**:一块窄黑漆板(深棕渐变,0.93 alpha)、细金内线、左侧一枚朱砂印章,刻"说"字(Ma Shan Zheng),文字用 Cormorant Garamond 600,46 px,奶油色 `#f3e2bf`,居中于底部上方 58 px。0.22 秒内上滑 18 px。每句从起点显示到语音 + 0.8 秒(≥ 1.8 秒),下一句前 0.3 秒切掉。
- 标题与结尾卡**也是皮偶**:深色皮匾,字被镂出(`fillText` 配 `destination-out`,字被灯光照亮),回纹带红边、绿色云卷角花、刻字红印,由两根签子抬上来、掀离幕布退场。

## 8. 我们踩过的坑

- **矢量图太平。** 均匀填充和稀疏雕刻读起来像剪贴画。用皮革纹理、密得多的镂空、更深的染色和每个区域的深色雕边来修。
- **高跷腿 / 鸡蛋躯干 / 手臂陷进躯干。** 放大头、加长裙、放宽裤、加云肩、袖与胸不同色。
- **太阳光芒像锯条或花瓣。** 火舌要有粗底、鼓腹和尖端钩,卷向交替,约 40 px 长 × 0.78 弧间距。
- **过曝帧的灰色角落**来自中性暗角。改用暖色变暗。
- **箭看不见。** 生皮色在亮幕上消失。用深色箭杆(`#4a2612`,3 px)。箭尾必须落在瞄准线上,否则箭指向侧面。
- **镜像会把部件上下翻转**,如果某个辅助函数对两个轴都用 `C[0]` 构建旋转。x 项用 `C[0]`,y 项用 `C[3]`。
- **用 `lighter` 画的烟**在亮布上不可见。正常画深色烟缕,只在灯附近加暖色加法那一笔。
- **以顶边一盏灯为中心推入**会把双手推出画面。向框中心推,只在最后俯冲时把定点移到火焰。
- **热浪/噼啪底床漏进静默。** 在停顿处硬切。
- Headless Chrome 截图在另外 14 个渲染共享 GPU 时偶尔超时。重试即可。

## 9. 制作配方(本仓库)

```
styles/shadow-puppet/demo/
  carve.js     cutting toolkit: piece sprites, cut/cutLine/cutTaper, pattern library, hide texture, rivets
  gl.js        WebGL2 screen compositor (lamp field × transmission × cloth, mirror, bloom, haze, warm fade)
  houyi.js     jointed puppet (11 pieces, IK arms, bow, plumes, rods)    poses.js  key poses
  suns.js      carved suns + crow                     scenery.js  mountains, ground strip, river, tree, hut, fire pieces
  stage.js     lacquer frame, audience, pillar wipe, cut-letter plaques
  backstage.js rim-lit silhouettes (hands, lamps), lamp flame, smoke
  story.js     timeline (single source of truth)      main.js  shots, acting, lamps, events
  hud.js       subtitle placard    test.js  ?test=model | frame | hands | (main) poster
  lines.json   narration   mix.py  foley + voice + music ducking   music/score.py  original gong-and-drum score
  tools/       cues.py (SRT), mux.sh (CRF 22), probe.mjs (render timing)
```

1. `node core/render/still.mjs styles/shadow-puppet/demo 0 --q test=model`:先做模型表(角色风险最先)。然后 `--q test=frame&f=ten|one` 风格帧和 `--q test=hands`。
2. `.venv/bin/python core/tts/tts.py lines.json voices` → `core/tts/asr_check.py`(同音词用 `asr` 字段)。
3. 时间轴写在 `story.js`。用 `still.mjs --range 0.5:54:1.5` + `core/render/sheet.py` 审查(两轮,错开半步),再从 mp4 抽关键动作的帧条。
4. `node core/render/events.mjs` → `music/score.py` → `mix.py`。
5. `node core/render/video.mjs … --fps 24 --workers 3`(1306 帧,M 系列 Mac 3 个 worker 约 80 秒)。
6. `sh demo/tools/mux.sh out/video24.mp4 mix.wav shadow-puppet.mp4 24 2`。或者直接 `sh demo/build.sh`。
