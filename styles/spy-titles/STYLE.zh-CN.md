# 60 年代间谍片头(Spy Title Sequence)— 风格提示词

> 一部剪纸风格的四色墨影片头序列,献给一部从未存在过的间谍电影:剪影在由字幕本身搭建的场景中追逐,每一次铜管重音都是一次剪辑,而片名是最后被拼装完成的东西。
> 演示:*The Velvet Cipher*(44 秒)· `spy-titles.mp4` · 源码在 `demo/`

你正在以**60 年代间谍片头**风格执导一部 30–60 秒的影片。用户给你一个主题。其余一切由你决定——故事、镜头、节拍、声音——并交付一部完成的影片。遵循本指南。

---

## 1. 这是什么风格

1950 年代末 / 1960 年代片头设计的图形语法(Saul Bass 的*《西北偏北》*、*《桃色血案》*、*《迷魂记》*;Kuntzel + Deygas 2002 年为*《猫鼠游戏》*创作的致敬):**纸上平涂的不透明墨色、手剪边缘、抽象到只剩剪影、以及作为画面结构一部分的排印**。片头序列本身就是一个故事:一个目标、一场追逐、几个场景、一次揭示——而揭示的就是片名。

它**不是**枪管开场,不是蹑手蹑脚的卡通黑豹,也不是对任何真实片头标志、字体、角色或镜头的复制。字幕只包含虚构的角色名("A LEMOLAB PICTURE"、"STARRING THE AGENT"、"MUSIC BY THE SAMPLER")——绝不使用真实人名。

## 2. 故事:什么适合这个风格

挑选那些**追逐的东西最终就是影片本身**的故事。这种媒介有五种原生能力——至少使用三种,并把最强的一种放在情感高潮:

| 原生能力 | 故事用法 |
|---|---|
| **文字即场景** | 每个场景恰好是一行字幕,而这行字*就是*建筑:字母作廊柱(主角藏在 **I** 后面),单词作火车车厢(他跳过词与词之间的空隙),名字里的 **O** 作轮盘,破折号作屋檐边缘,一个字母作锁。在某些时刻每行字必须完全可读。 |
| **字幕即节奏** | 字幕落在节拍上。铜管重音 = 硬切。每条字幕停留足够长,以便连同字幕一起读清。 |
| **图形匹配剪辑** | 抽象让形状押韵变得廉价而有力:车轮 → 轮盘 → 瞳孔 → 月亮 → 锁孔。在铜管上剪辑,并随追逐加速让间隔缩短(2 小节 → 1.5 小节 → 2 拍)。 |
| **斜线网格** | 开场沿一条 30° 斜线分裂,繁衍成网格;高潮时所有碎片沿相同斜线飞回拼成片名;片名沿同一条切线合拢。开启的伤口 → 闭合的接缝。 |
| **剪影木偶** | 人物是扁平剪纸,始终侧面,按双帧(twos)动画。所有表演靠轮廓和节拍:奔跑、伏低、回望、定格。 |

改编任何主题:把主题变成**麦高芬(MacGuffin)**,片名是它的目的地。产品发布 → 产品是被盗的物件,其标志是碎片拼装成的结果。一场讲座 → 核心观点被当作字幕的四个"章节"追逐。一个生日 → 追逐以名字拼合告终。

**情感弧线(35–45 秒):**一个形状 + 一行任务简报的冷开场(3 秒内抓住观众)→ 失窃 → 穿越 3–4 个场景的追逐,每个比上一个更短 → 一个笑点(主角半隐;停格定格)→ 形状匹配剪辑的加速蒙太奇 → 剪影在巨大圆形前的捕获 → 世界沿网格碎裂并拼装成片名 → 一个安静的收尾:一拍静默、一声邦戈鼓、一句面无表情的台词。

## 3. 视觉语言

- **四色墨,无渐变**:墨黑 `#1b1714`、纸奶油色 `#efe4c9`、信号红 `#d23a22`、芥末黄 `#e2a52a`。仅允许"更深纸色"变体用于层次/阴影:`#9a2a18`(暗红)、`#b07e1c`、`#3a322b`(远处的城市)。每个场景一个主导底色:黑(冷开场、屋顶)、红(网格、火车、赌场)、奶油(天鹅绒、片名)、芥末(机场)。
- **剪刀切割边缘**:每个多边形每约 9–10 px 重采样一次,沿法线被低频噪声位移(振幅 1.2–2.2 px,大形状更大),外加偶发的 1–2 px 缺口。**在物件局部空间中切割一次边缘并缓存**——移动的剪纸保持同一条边缘,和真实剪纸动画一模一样。(在屏幕空间计算的边缘会在物件移动时"爬行"。)
- **纸张层叠**:分离的部件之间由**底色中 2.4 px 的剪切缝隙**分隔,并投下小小的纸影(偏移 2.5/3.5 px,模糊 5,alpha 约 0.3)。整个人物以缝隙作为轮廓,这样黑色人物在黑色字母前仍然可读。
- **纸张纹理**:一整帧纹理以正片叠底放在最上层(低频斑驳 + 微弱纤维),再以滤色叠上一层稀疏的"墨空洞"斑点(只在深墨上显现),外加微弱的水平刮板条纹。混流时的胶片颗粒约 6。无半调(那属于其他风格)。
- **剪影人物**(见 `demo/stills/modelsheet_v1.jpg`):7 头身的特工,窄檐帽(帽带是一道剪切缝),宽肩夹克,尖头鞋,**一条红领带是他唯一的颜色**(奔跑时向后飘动——运动指示)。反派高 1.2 倍:宽平帽檐,A 字形大衣带红色衬里(只在奔跑时显现),手腕上拴着一把芥末色钥匙,让麦高芬在每一个镜头里都可寻。部件在人物内部**融合为一个轮廓**;只在肩、肘、髋/下摆和膝处留细(1.7 px)缝。手是尖锐的楔形。除特写中的奶油色眼缝外无面部。
- **麦高芬**始终放在黑色衬底上(= 墨色键线),使其在任何底色上可读;它是画面中最亮的东西。
- **字体**:字幕用 League Gothic(OFL),用 opentype.js 提取字形轮廓并逐字母**重新裁切**(边缘噪声、±0.8° 旋转、±1.5 px 基线抖动)。影片片名用自定义几何剪切字形(直线切 + 弧线、粗细不均、活泼的交错基线)——绝不用真实片头的字体。副标题用 League Spartan 600。

## 4. 运动语言

- **双帧木偶**(12 fps):人物、手、字母落位、飞机的姿势*和*位置。**相机、字幕滑动、网格生长按单帧(24 fps)**——步进的相机读起来像抖动。
- 跑步循环:8 张画,每拍一步(132 BPM 下循环 = 2 拍),前倾 0.3 rad,领带以约 65° 飘动。步行:每拍一步,大衣摆动。
- 字幕沿网格线滑入,在节拍上戛然停住(ease-out,0.2 秒),字母带着纸拍击声落位。
- **停格(stop-time)**:铜管重音时整个画面(包括背景滚动)定格 2 拍,音乐完全静默,然后恢复——大乐队手法的视觉化,一个无言的笑点。
- 高潮:上一场景被切成平行于切线的条带,沿对角线交替滑走(N×NW),同时片名字形沿同一对角线飞入,落在连续的十六分音符上。

## 5. 镜头语言

| 节拍 | 相机 |
|---|---|
| 冷开场 | 锁定,黑色上居中的单一形状(锁孔)。它其实是片名 **I** 的极端特写。 |
| 每个字幕场景 | 从**足以读完整行字幕的远景**开始,然后推/移近到动作。 |
| 追逐 | 横向跟移(《猫鼠游戏》语法):屏幕方向始终从左 → 右,被追者在前,追者在后。 |
| 蒙太奇 | 铜管重音上的硬切;圆形跨剪辑保持相同的屏幕位置和大小。 |
| 主角时刻 | 巨大奶油色月亮前的剪影。 |
| 结尾 | 推近片名的锁,直到画面与冷开场完全一致,然后在最后的邦戈鼓上硬切回完整片名。 |

## 6. 声音

- **音乐:1960 年代间谍大乐队**(不是冷峻黑色爵士,不是拉格泰姆),小调,约 132 BPM。原创动机:从五级音开始的半音下行,然后跳到主音(B–A♯–A–G | E),附点节奏。**避免**著名的 E–F–F♯–F 爬行和 Em(maj9)结尾和弦;以 Em6/9 收尾。
- **铜管重音 = 剪辑点**:`trumpet_stac` + `trombone_stac` 八度叠加 + crash,约 0.25 秒,提前 8 ms 放置,让采样峰值对准帧。冲浪吉他低音弦弹响(`electric_guitar`)过自制弹簧混响(色散啁啾回声,约 41 ms 往返,2 秒衰减)。`jazz_bass` 行走贝斯。早期用刷子(柔军鼓 + 蛋沙锤),火车段落用鼓棒(十六分"铁轨"军鼓)。赌场用 `world_perc` 邦戈/沙锤。片名用大和弦,然后一个短促收束,**一拍数字静默**,一声干邦戈。
- **静默是工具**:冷开场只有一声磁带咔哒;停格和最后一拍是真正的零(含混响尾);最后一句台词只在磁带嘶声上播出。
- **拟音跟随材质**:纸(剪切"shh"、滑动、每个字母落位的纸拍、盲翻、碎裂时的撕裂声)、金属(钥匙叮当、链条绷断、钥匙滑入锁、锁的咔哒)、磁带(咔哒、嘶声)。环境只作暗示:喷气机掠过(声像 L→R)、带节拍车轮"哐当"的火车隆隆、渐慢的轮盘球滴答、屋顶风声。
- **人声**:英式任务简报男声(Kokoro `bm_george`,语速 0.9–0.97)过磁带链:带通 220–5200 Hz、软饱和、0.9 Hz 抖晃、人声下方渐起的嘶声。4–6 句极短台词;最后一句呼应第一句("Nobody knows what it opens." → "Now you know what it opens.")。人声下音乐压低约 −7 dB。响度 −14 LUFS。

## 7. 副标题与片名

- **副标题**:左下方 (96, 958) 处一条窄纸带(剪刀切端头,倾斜 −1°),一个小红色锁孔字形作项目符,League Spartan 600 44 px。深色场景用奶油带 + 墨字;奶油场景用墨带 + 奶油字。0.18 秒内从左滑入 60 px。显示 ≥ max(1.8 s, 人声 + 0.6 s)。
- **字幕住在场景里**,从不在副标题带中。每个场景一行。
- **片名**:自定义剪切字形;麦高芬的槽位是一个字母(这里 CIPHER 的 I 是带红锁孔的黑色"锁板";钥匙的轮廓恰好填入)。
- **结尾卡**:小片名、"60s SPY TITLE SEQUENCE"(剪切 League Gothic)、红色 Spartan 的 "LemoLab × Claude Opus 5.5"、轻触帽檐的小特工。

## 8. 我们踩过的坑

- 每个内部部件都带缝隙描边让人物像木偶关节示意图。把每个人物画进一个离屏层让部件融合,只切关节缝(`destination-out`),然后以 8 方向底色轮廓 + 一层阴影合成。
- 重置变换的 `clear()` 会悄悄杀掉相机 → 在背景填充期间保留相机矩阵。
- 主角完全藏在 I 后面读起来像"没有人":偏移他,让帽檐、鼻子、领带结和飘动的领带伸出柱子之外。领带必须挥动(带行波正弦 + 宽度摆动的多段飘带),否则像舌头。
- 只被部分看到的字幕("R R I N")读起来难受:始终以完整行的全景开场。
- 词车厢之间黑色的电线杆读起来像字母 I——把背景道具推入更深的底色变体。
- 芥末底色上的芥末钥匙会消失——给它黑色衬底。
- 直接掉进空格字符的轮盘会盖住相邻字母;把词的两半围绕 2.2 × 半径的空隙排版。
- 用轮盘/瞳孔/月亮匹配近景手臂:跨剪辑保持圆心一致,否则匹配不成立。
- 铜管断奏采样需要约 8 ms 到达峰值——提前放置,让重击落在剪辑点上。
- 尖峰混音(安静刷子上的大重音)在 −1.2 dBTP 上限下停在 −14.4 LUFS;在 loudnorm 前先推约 4 dB 进限制器。

## 9. 制作配方(本仓库)

```
styles/spy-titles/demo/
  paper.js   four inks, scissor edges (cached), cut gaps, paper shadow, texture, silhouette layer + joint slits
  glyph.js   League Gothic → opentype.js outlines → re-cut letters
  chars.js   agent / courier rigs (side, front, back), poses, run/walk cycles, key + keyhole
  title.js   custom title glyphs, lock-plate I, diagonal split
  scenes.js  keyhole, grid, velvet, intro, airport, train, wheel, casino, pupil, rooftop, title background
  film.js    timeline, acting, cameras, subtitles, sound events     story.js  132-BPM grid (single source of truth)
  sheet.js / frames.js   model sheet and gate-1 style frames
  music/score.py   original big-band score (sampler)      mix.py  foley + tape voice + ducking
```

1. `node core/render/still.mjs styles/spy-titles/demo 12 20.8 --q nosub=1` —— 审查静帧(`?sheet=1&v=1`、`?frame=airport|train|title`)。
2. `core/tts/tts.py lines.json voices` → `core/tts/asr_check.py`(6/6)。
3. `python music/score.py` → `node core/render/events.mjs` → `python mix.py`。
4. `node core/render/video.mjs styles/spy-titles/demo --fps 24 --workers 3`(1058 帧 ≈ 17 秒,Canvas2D)。
5. `CRF=24 sh demo/tools/mux.sh out/video24.mp4 mix.wav spy-titles.mp4 24 6`(核心 mux + CRF 旋钮:平涂墨色 + crf19 颗粒 = 270 MB,crf24 = 18.5 MB 且无可见差异)。或者直接 `sh demo/build.sh`。
