# 瑞士动态图形(Swiss Motion Graphics)— 风格提示词

> 动起来的国际主义排版风格:一个模数网格、一款字体、一种信号红,以及像印刷机一样精确的运动。
> 演示:*Five Rules for a Poster*(44 秒)· `swiss-motion.mp4` · 源码在 `demo/`

你正在以**瑞士动态图形**风格执导一部 30–60 秒的影片。用户给你一个主题。其余一切(故事、版式系统、节拍、配乐、声音)由你决定,并交付一部完成的影片。遵循本指南。

---

## 1. 这是什么风格

在网格上动起来的纯 2D 平面设计:平面白纸、黑色字体与色条、极浅的灰,以及**一种**饱和红。这是 1950–70 年代苏黎世音乐会海报的语言(Müller-Brockmann、Hofmann、Gerstner、Crouwel),以现代识别系统的方式动起来(Experimental Jetset、Pentagram):**每个元素吸附到网格,每次移动落在节拍上,没有弹跳**。

魅力在于**严谨加一个例外**。整个画面服从系统,于是那个不服从的元素就成了角色。

绝不复制某张具体历史海报的构图(不要从 Müller-Brockmann 那里搬同心圆或扇形构图)。不要用 Helvetica 或 Akzidenz 字体文件。选一款 OFL 新怪诞体(Archivo、Inter、Schibsted Grotesk、Instrument Sans……)。绝不在海报上点名真实机构。

## 2. 故事:什么适合这个风格

挑选**系统本身讲故事**的主题。瑞士设计有五种原生能力。至少用三种,把最强的一种放在情感高潮:

| 原生能力 | 故事用法 |
|---|---|
| **模数网格** | 网格既是舞台也是规则书。展示它被搭建(线条按节拍画出),在段落间隙短暂展示,并在高潮处**让网格有意义**:演示中,7 列 = A 多利亚式的 7 个音,16 行 = 16 个八分音符,于是海报*就是*乐谱。 |
| **吸附 = 节拍** | 每个元素的到位是一次打击乐:字体咔哒、切刀、鸭嘴笔。画面与音乐共享同一坐标系,而不是事后对同步一遍。 |
| **规则生成设计(programme)** | 情节是一组规则逐一施加到一件作品上。结尾展示同一程序生成许多作品(Gerstner 式揭示)。 |
| **极端尺度对比** | 700 px 数字旁边是 19 px 技术注释。巨大元素是章节卡,微小元素是质感。 |
| **一种信号色** | 只有一样东西是红的,所以红 = 主角。当它破坏规则时,它是屏幕上唯一不精确的东西。 |

**改编任何主题:**把它变成**一个系统加一个例外**。产品发布:产品的规格表在网格上组装,然后一个特性破格而出。公司历史:每个十年是加到一张海报上的一条规则。爱情故事:两个不同网格上的两个红色元素,当其中一个离开自己的网格时影片结束。

**情感弧线(30–60 秒):**秩序被搭建(好奇、干脆)→ 秩序完成(正确而有点无趣,*说出来*)→ 犹豫(红色元素抽动又吸附回去)→ 破格(全片唯一的非吸附、线性移动;鼓退出)→ 其他一切围绕它重新流动,更好(全乐队回归)→ 揭示(网格有意义)→ 尺度揭示(同一系统,多个产出)→ 回到结尾卡上的主角作品。

## 3. 视觉语言

- **画面网格**:1920×1080,12 列,96 px 侧边距,24 px 栏距(122 px 列宽),24 px 基线。把画面当作**一个对页 spread**:左页(1–6 列)= "程序"(数字、规则文字、注释);右页(8–12 列)= 作品(海报 706×1008,比例 0.70 ≈ 瑞士世界格式)。
- **作品网格**:从内容推导(Gerstner)。演示中海报是 7 列 × 91 px、16 行 × 40 px,文字区有 26 px 基线网格。我先试了 12 个半音列:色条只有 43 px 宽,海报看起来像数据图表。**选让色条有分量的模数尺寸。**
- **色板**:页面 `#EAE9E5`、纸 `#FFFFFF`、墨 `#111111`、信号红 `#E30613`、网格线页面上 `#CFCEC9` / 搭建时 `#C9C8C2` / 纸上 `#E2E1DC`、次级条 `#CFCEC9`。无渐变、无阴影、无粒子、无颗粒(mux 颗粒 0)。
- **字体**:全片一款字族(演示:**Archivo** 可变体,字重 400–800)。≥ 90 px 时字距 −2.2%。小写标题(`neue musik`)。规则数字约 980 px(字形高 700 px),与海报底边对齐,**光学上**齐左(减去字形左侧空隙)。注释 19 px Medium。绘制前始终 `document.fonts.load` 每个字重。
- **构图**:齐左,右侧不齐。一切在网格线上。大块留白是版式的一部分。最终构图必须比"正确"的**明显更大胆**:
  - 一条主对角线带强弱交替的长短节奏;
  - 红色元素约 2× 尺度;
  - 元素**出血**冲出纸缘;
  - 字压印红色圆上(黑压红)。
  仅仅把正确构图倾斜是不够的。
- **色条即音符**:条宽 = 列宽减 8 px;一个音符的连续格合并为一条(接缝处多画 1 px,否则抗锯齿出细缝,旋转时尤甚)。
- **次级声部**(贝斯)是黑色条下方的浅灰条。它们读起来像阴影对角线,不用第二颜色就给出深度。

## 4. 运动语言

- **只用两条曲线。**吸附用精确 ease `cubic-bezier(.7,0,.2,1)`,画线、播放头和破格者用线性。无过冲、无弹簧、无弹跳。
- **时长就是音符时值**,按影片 BPM(120:1/8 = 0.25 秒,1/16 = 0.125 秒)。吸附提前一个音符时值开始并**落在节拍上**。
- **入场是擦除或裁剪揭示,绝不是淡入。**单词从基线下方的裁剪矩形升起(1/16 音符),向上离开(1/8 音符)。线条沿自身长度生长。纸以竖直擦除出现。大数字以**4 段缓步**爬入("一次一格")。
- **删除是切刀。**一条 2 px 线在 1/16 内穿过元素,然后元素在 1/8 内垂直塌缩到中线。
- **涟漪按距离排序**,从成因处向外。红圆落定后,单元每两个一组按十六分音符重排,最近的先动。
- **例外移动方式不同。**它是线性的、不吸附,中途停一拍八分音符(一次回望)。它边走边长大。旁边的坐标读数从 `col 5.00 row 0.00 · on grid` 变成红色的 `off grid`,值为非整数(甚至负数)。
- 一切以流畅 24 fps 渲染。没有步进:这个风格是数字精度,不是手工感。

## 5. 镜头语言

"相机"是一个 2D 矩阵(中心、缩放、旋转)。它只用精确 ease 移动,且只在节拍上。

| 节拍 | 相机 |
|---|---|
| 开场 | 锁定全画面。一个手势:一条红线划过,网格列从它上面按十六分音符长出 |
| 搭建(规则) | 锁定对页,让观众读到因果(规则,左)→ 结果(作品,右) |
| 破格 | 左页滑出,作品移到中左,网格线延伸到整个画面(网格比页面大) |
| 揭示 | **把作品在 1.5 拍内旋转 90° 后停住。**然后标签(音名、小节号)才擦入,播放头扫过两小节。每个音条在其起音的精确帧变红:把起音放在整数帧上(24 fps 下 0.25 秒的倍数) |
| 尺度揭示 | 边旋转回正边拉出,露出同一系统的一墙作品 |
| 结尾 | 红线再次划过,切走其他作品。推回开场对页,结尾卡在左页,主角作品在右 |

## 6. 声音

- **音乐**:Motorik / 克劳特摇滚,120 BPM,A 多利亚式(不是通用钢琴弦乐铺底)。每条规则叠加一件乐器:
  1. 只有踩镲;
  2. + 完整 motorik 鼓组(`drum_kit`:底鼓 1、3、3&;军鼓 2、4;闭镲八分);
  3. + `electric_bass` 八分音符根音脉冲;
  4. + numpy 锯齿琶音十六分音符,滤波器渐开;
  5. + `glockenspiel`,叠一支柔和的 numpy 方波主旋律。

  **破格的那一小节去掉鼓**,落定时回归。揭示前加一小节近静默(贝斯踏板 + 四分音符滴答)。揭示期间只保留底鼓 + 贝斯 + 旋律,让每个音符可闻。
- **旋律来自与画面相同的 JSON**(`score.json`:列 → 音高,行 → 起音,长度 → 时值)。"海报即乐谱"在代码里是真的,不是装的。
- **拟音跟随材质**,干而近,无混响:
  - 铅版咔哒(金属瞬态 + 3.3 / 5.1 kHz 共振 + 木托盘);
  - 鸭嘴笔 "tss";
  - 切纸刀(带通扫频 + 金属咔嚓);
  - 纸拍击 / 滑动;
  - 数字每步的 "thunk";
  - 色块吸附;
  - 圆落定(58 Hz 毛毡闷响)。

  破格者是唯一*唱歌*的元素:跟随其位置的正弦滑音。
- **人声**:冷静、干脆的女叙述者,Kokoro `af_sarah`,语速 1.0。它的 3–8 kHz 辅音能量约为 `af_kore` 的 7 倍。台词保持规则式:"Rule one. Build a grid." 每句用 whisper 校验(数字写成 `"asr": "Rule 1, …"`)。
- **混音**:人声压缩,人声下音乐压约 −10 dB(人声高于音乐 ≥ 6 dB),−14 LUFS。

## 7. 副标题与片名

- **副标题是版式的一部分**,不是底部一条杠。每行位于对页左页第 1 列:第一句作 30 px Medium 灰色引子,其余作 76 px Bold 陈述。每个单词按 whisper 时间戳裁剪揭示。非规则行用 Regular 字重("Perfect. And a little dull.")。其他镜头中该行位于那个镜头的第 1 列,在作品标题基线上,或像美术馆标签放在墙下方。
- **标题卡**:`Five Rules / for a Poster`,120 px Bold,两行齐左,坐在开场红线上。上方一行 19 px 说明加 1 px 细线(`A programme in five steps · 1961 · ♩ = 120`)。
- **说明行 + 注释**:左页顶部(标题 / `Rule 0n / 05` / 关键词);第 5 列底部:每条规则 2–3 条技术注释(`Columns 7 · Rows 16 · Module 91 × 40`)。第 7 列底部:小节计数器 `bar 04.3`。
- **结尾卡**:再次呈现开场对页。`Swiss Motion / Graphics` 120 px,下方红线,`LemoLab × Claude Opus 5.5` 36 px,底部注释,右侧主角海报。

## 8. 我们踩过的坑

- **12 列像图表。**网格模数必须给图形元素分量。我们给作品用更少更宽的列,画面保留标准 12 列。
- **"更好"的构图没有明显更好。**四个小阶梯 → 一个散点布局没有说服力。修复:一条长短节奏的主对角线、2× 红色元素、出血、字压红。
- **旋转揭示需要停顿。**边转边标读起来像噪声。排序:旋转(1.5 拍)→ 停住 → 网格线 → 标签 → 播放头 → 扫描。
- **合并色条在旋转缩放后显出接缝**(相邻矩形的抗锯齿)。格相接处多画 1 px。
- **标签与页眉重叠**:旋转镜头前隐藏说明行。
- **单词时间**:whisper 会拆分或合并单词("type face"),`asr_check` 报告第一个词在 −0.6 秒(填充)。按字母对齐并钳到 0(`tools/words.py`)。
- **副标题规则**(≥ 语音 + 0.6 秒且 ≥ 1.8 秒):两行差了 2 毫秒。`tools/subs.py` 会断言,微调开始时间修复。
- **切墙必须沿着线**:在屏幕空间从红线进入的那一侧收缩墙板。
- 墙上其他海报共享相机矩阵,所以只在墙镜头中绘制。否则以 ±786 px 泄入其他镜头。
- Canvas `letterSpacing` 也影响 `measureText`,所以设完字体再算宽度。

## 9. 制作配方(本仓库)

```
styles/swiss-motion/demo/
  score.json  grid = score: stiff / final melody, bass, circle, bleeds, timeline
  ease.js     cubic-bezier(.7,0,.2,1), snap(t, t_arrive, dur), steps(), track()
  film.js     layout system, rules, poster, circle, reveal, wall, end card, foley events
  main.js     loads fonts, score, lines, whisper word times; ?nosub=1, ?poster=1
  lines.json  voice script (af_sarah)          tools/words.py  word timings → subtitle reveal
  music/score.py  motorik score from score.json   mix.py  foley + ducked voice + music
  tools/subs.py   subtitle intervals (asserted) → srt     build.sh  one-shot rebuild
```

1. 先设计版式系统:画面网格、作品网格、列和行*意味着什么*。写 `score.json`。
2. `node core/render/still.mjs styles/swiss-motion/demo --range 0.5:43.5:1 --out …` 然后 `sheet.py`。审查 1 秒概览加破格和每个转场前后密集的 0.25 秒条带。
3. `tts.py` → `asr_check.py`(0 处不匹配)→ `tools/words.py`。
4. `music/score.py`(起音来自 `score.json`;检查扫描起音 ≤ 5 ms)→ `events.mjs` → `mix.py`(逐行打印人声/音乐/拟音 dB)。
5. `video.mjs --workers 3`(1056 帧约 12 秒)→ `mux.sh … 24 0`。或者直接 `sh styles/swiss-motion/demo/build.sh`(从零约 55 秒)。
