# 移轴微缩(Tilt-Shift Miniature)— 风格提示词

> 一座看起来真实的小镇,从高处用移轴镜头和延时相机拍摄,于是整个世界读起来像一个桌面上模型。
> 演示:*Toy Town Rush Hour*(38 秒)· `tilt-shift.mp4` · 源码在 `demo/`

你正在以**移轴微缩**风格执导一部 30–60 秒的影片。用户给你一个主题。其余一切——故事、镜头、节拍、声音——由你决定,并交付一部完成的影片。遵循本指南。

---

## 1. 这是什么风格

一座从高屋顶透过**移轴镜头**看到的小镇:画面只有一条薄薄的水平窄带清晰,上下一切融为虚化。你的眼睛把这读作微小物体的微距镜头,于是小镇变成了模型。还有两样东西让戏法成立:**饱和、阳光感的色彩**(模型铁路漆)和**延时**(汽车和人以发条玩具般快速、抽动的步伐移动)。

参考是 Sam O'Hare 的*The Sandpit*(2010)。学它的语法:高视点、虚化带、延时节奏、扫过街道的云影。不要复制它的城市或音乐。在你的影片里,小镇、车辆和行人全部原创且程序化。不出现真实地标、品牌或标志。

## 2. 故事:什么适合这个风格

这种媒介有四种原生能力。至少用三种:

| 原生能力 | 故事用法 |
|---|---|
| **延时速度** | 时间本身是角色。快进展示系统(交通、人流、日出)。**突然降到真实速度(×40 → ×1)**是你最强的招:它说"看这一个小东西"。放在情感高潮。 |
| **虚化带** | 清晰带是你的指针。移动它(变焦跟焦)跟随主体,在最亲密的时刻把它收窄成一条细缝。 |
| **上帝视角的尺度** | 一切从上方看,像桌游或机器。系统类故事最合适:一座城市作为音序器、一个蚁群、一座工厂、一场正在搭建的节日。结尾上升直到小镇变成图案。 |
| **长曝光光轨** | 黎明或黄昏,车灯留下像笔一样在小镇上作画的光轨。一条光轨就可以是整个开场。 |

**改编任何主题:**把主题变成*一个有许多小角色的系统*,再找系统绕着弯的那个*唯一小角色*。产品发布 → 城市车流涌向一家店铺。爱情故事 → 两个通勤者每天早晨在同一条斑马线上交错。历史课 → 一条街延时穿越一个世纪。

**情感弧线(30–45 秒):**安静(一个角色)→ 系统醒来(角色倍增,节奏累积)→ 最大密度 → **硬降到单一细节的真实时间**(反转、笑点、核心)→ 释放回快进 → 上升到尺度揭示。一个主体、一个目标、一次反转。

## 3. 视觉语言

- **相机高度与角度**:始终高。45–55° 俯角的斜视图,距主体 110–200 米,镜头垂直 FOV 27–30°。"桌游"时刻用正俯视(90°)。真实移轴永远从高处拍,绝不在街道高度。唯一的例外是情感高潮。那时,降到真正的**角色高度的中近景**:相机约 1.7 米高、6–8 米远、俯角约 12°、FOV 17°。一个虚化的前景物(主角车带车灯的引擎盖边缘)框住清晰的角色,他们占画面高约 1/4–1/3。从高处用长焦让角色成了小点,毁掉了那个时刻(评审意见)。
- **虚化带**(`demo/post.js`):物理景深混合屏幕空间条带。以像素计的弥散圆 = `mix(aper·(1/focus − 1/z), sign(dy)·amp·(max(0,|dy|−w)/0.5)^1.2, mix)`,钳制在 30 px。
  - 典型值:条带半宽 `w` 0.055(最亲密镜头 0.035)、`amp` 30、`mix` 0.55–0.7。物理光圈 `aper` 5000–9000(世界单位为米)。
  - 把带放在主体上。主体移动时,每帧投影到屏幕并把带滑过去(`band.follow`)。
  - 在输出分辨率收集(2× 超采样渲染之后):128 个螺旋采样、逐像素随机旋转,远处样本不得渗到近处清晰样本上。
- **调色**:NeutralToneMapping。饱和度 ×1.55,柔对比 +0.42,高光略暖,暗角 0.3。夜间降低饱和。
- **光照**:一个带锐利阴影的硬太阳(4096 阴影贴图逐镜头适配),半球环境光保持低(~0.6,暖色地面反弹)让阴影保持蓝色但不浑浊,加天空渐变环境贴图用于玻璃和车漆。
  - **逐镜头作弊太阳方位角**:每个延时片段是独立镜头,把太阳对到相机后侧或旁侧,给看到的立面顺光。固定太阳让半部影片逆光发灰。
  - 黎明:太阳在地平线下约 3.5°,东方一个粉橙低位补光(`#ffb48c`),只有约 9% 窗户亮着,钠灯街灯光池。应读作清晨 6 点,不是半夜。
- **模型般的细节**(区分"实拍微缩"与"游戏 CG"的地方):
  - 立面着色器带冲孔 / 带形 / 幕墙 / 砖砌窗型,1.6–3 米开间,亮窗框,更暗的窗洞,世界空间污垢噪声。窗户有反射天空的玻璃色调(粗糙度 0.08–0.22,金属度 0.35),墙体向地面变暗(伪造接触 AO)。
  - 遮阳篷、店招、空调外机、阳台、水箱、天线、太阳能板、女儿墙。
  - 磨损的道路标线、井盖、沥青补丁和油渍。
  - 汽车:圆润车身、深色玻璃舱、车轮,每辆车下一个柔和接触阴影斑,停下时红色刹车灯亮。
  - 在这一切之上再加 GTAO。
- **色板**:立面是暖白、奶油、陶土、砖红、浅黄、薄荷、天蓝。汽车是白、银、黑、红、蓝和黄色出租车。公园绿饱和 `#6fa24a`。路面沥青深 `#4b4e53`,让白标线和车跳出来。行人是 0.5 米彩色胶囊,像模型铁路小人。
- **近景角色**:有机车削身体,带光泽"绒毛"材质(`MeshPhysicalMaterial`,sheen 1,sheenRoughness 0.55)。比真实尺寸大 20–30%,以便屏幕上可读。

## 4. 运动语言

- **延时顿挫是这个风格的灵魂。**快进时,整座城市(车、人、灯、太阳)以 **8 Hz** 更新,24 fps 下每个位置保持 3 帧。120 BPM 下恰好是一个十六分音符,所以每次跳动都落在音乐网格上。**相机每帧保持流畅。**当速率降到 ×2 以下,顿挫消失,运动变得丝滑,这让实时降落重击得多。速率在 ×2 到 ×6 之间时步进到 12 Hz。
- 交通是逐片段预计算的 **IDM 跟车仿真**:96 秒周期灯、"不堵路口"逻辑、一条停下所有车道的斑马线。大流入加堵路口给出诚实的死锁。逐片段选周期偏移,让灯变化落在小节线上。
- 人群是闭式解:红灯时聚在街角,绿灯时涌过,×24 下读起来非常美。
- 主角角色需要艺术指导的节拍。写脚本(黎明车路径、按节拍时间拟合的火车运动学、鸭子跳),别指望仿真恰好踩拍。
- 近景表演:预备压缩(0.28 秒)→ 拉伸跳起 → 落地压缩→ 回稳。把喜剧节拍做成成功前的第二次失败尝试。

## 5. 镜头语言

| 节拍 | 相机 |
|---|---|
| 开场 | 高斜角远景,极慢滑动;虚化带跟随单一主体(一条光轨) |
| 片名 | 越过屋顶的斜角推向**世界内的招牌**(霓虹字母每八分音符亮一个) |
| 系统醒来 | 交叉口或车站上的中高斜角,缓推;带停在停车线 / 站台边缘 |
| 密度顶峰 | **正俯视,缓慢旋转**——最"玩具"的角度 |
| 实时细节 | 从俯视**一头俯冲**进主角车引擎盖后的低中近景,车头和车灯作虚化前景。视线先于机身落到角色上(注视目标比位置更快 ease-out)。俯冲中速度从 ×40 变到 ×1;落在最窄的带上。旋转俯视使其结尾朝向近景方向,否则俯冲会拧。 |
| 结尾 | **垂直上升**,对数高度(40 米 → 820 米),穿过薄云层,直到小镇变成电路板图案 |

## 6. 声音

- **音乐**:极简马林巴合奏(Steve Reich 语法:脉冲、相位、声部逐一加入、脉冲和弦)。不要通用钢琴弦乐。**固定乐句骨架;城市事件只决定哪些音符发声。**车过停车线门控马林巴 A,绿灯奏木鱼重音,人群触发钟琴,火车车厢奏贝斯。每段有基础填充率,让乐句保持可闻。
  - 密度顶峰时骨架填满,加相位马林巴 B 和调谐车笛和弦(采样铜管断奏脉冲八分)。
  - 实时降落是**磁带停止**:音乐变速 1 → 0.22,声部逐一退出,然后真正静默。间歇期每个故事事件只奏一个柔和音符,每跳升音阶一级。
  - 影片第一个音是最终和弦的最高音。
- **声音设计跟随速度**:延时时以音乐为先,带微弱的颗粒"加速城市"嘶声、轨道哐当和继电器咔哒。真实速度时世界突然变真实:怠速引擎、远处城市、麻雀、小鸭嘎嘎和啾啾、蹼掌拍打沥青。释放时引擎轰鸣,上升期间风声向上扫。
- **人声**:松弛的美式男声(Kokoro `am_adam`,语速 0.9–0.95),5–6 句短台词。人声下音乐压约 8 dB。每句用 whisper 校验;正文把数字写成词,`asr` 字段里放数字。

## 7. 副标题与片名

- 副标题是**道路交通标志**:绿 `#0f5e3c` 圆角面板带内嵌白色键线,Overpass 600 44 px 白字(Overpass 是开源 Highway-Gothic 复刻,OFL),左侧一个亮绿灯的微型红绿灯图标。放底部上方 118 px,在下虚化带内。
- 左上角保持一个**延时时钟**(Overpass Mono):`07:12` 带小号秒数和速度读数(琥珀色 `×24 TIME-LAPSE`,绿色 `×1 REAL TIME`)。它是观众对这招原生戏法的速度计。
- 片名:世界内屋顶霓虹招牌,装在面向宽大道的建筑上,没有东西挡它。下方加一个小路牌标签:"A TILT-SHIFT MINIATURE"。
- 结尾卡:俯视小镇上同样的路牌语言。展示片名、风格名和 `LemoLab × Claude Opus 5.5`。

## 8. 我们踩过的坑

- **高楼 + 浅俯角 = 没有街道**:第一版是摩天楼森林。保持 2–10 层、俯角 45°+。
- **黎明主体藏进街道峡谷**:把主角路线放在最靠近相机一侧的车道上,让带跟随它。
- **霓虹招牌被遮挡**:让它面向宽大道。
- **实例上限悄悄丢掉主角车**(上限 1,400 对 2,800 辆存活)。按到相机距离剔除(半径 = 4× 相机高度)并提高上限。
- **车在停车线前 2 米就停**,因为 IDM 的拥堵车距同样适用于它们。对故事关键的路口,把停车线移近并减去拥堵车距。
- **死锁让故事车道空了**:堵路口饿死了路口前路段。主干道豁免堵路口,让队伍排在主角身后。
- **对焦滞后一帧**:先算角色再算相机,让 `band.follow` 用上本帧位置。
- **俯视 → 斜角俯冲拧了 180°**:旋转俯视,让屏幕向上已经对齐近景。
- **近景太远**:高峰时刻最初用了高处长焦视角,鸭子只占画面 1/15。放低放近。前景引擎盖用小近裁面(0.08 米)。大灯放在车头上边缘,从上方才可读;让主角车等上升的相机先抬离它。
- **云冲淡了结尾**:用无光照白色、低不透明度、相机以下几乎不放。
- **街灯光池像气泡**:更密、更大、更淡,让它们融成暖色街道线。近景区移除街具。
- **整个场景逆光发灰**:逐镜头作弊太阳方位角。
- **黎明像半夜**:加粉色的东方补光,亮窗减少约 3 倍。

## 9. 制作配方(本仓库)

```
styles/tilt-shift/demo/
  post.js    tilt-shift DOF (band + physical), grade      city.js   procedural town, facade shader, sign
  geo.js     merged-geometry builder                      sky.js    clock → sun/sky/fog/env, dawn glow
  traffic.js lanes, lights, IDM sim, fleet, trails, walkers   train.js commuter train
  ducks.js   lathe ducks + hop choreography               story.js  120 BPM timeline, time windows, rate curves
  main.js    cameras, stepping, crowds, HUD, events       mix.py    ambience + foley + VO + score
  music/score.py  sampled marimba score (skeleton + event gating)   subs.mjs  subtitle export
```

1. `sh styles/tilt-shift/demo/build.sh` 从零重建一切:TTS → whisper → 事件 → 副标题 → 配乐 → 混音 → 912 帧渲染(M 系 GPU 上 3 worker 约 60–80 秒)→ mux(−14 LUFS,颗粒 1)→ 风格帧和海报。
2. 用 `node core/render/still.mjs styles/tilt-shift/demo <t…> --q noev` 迭代(`noev` 跳过事件扫描)。调试标志:`nohud`、`nodof`、`nostep`、`az=<deg>`、`cam=x,y,z,lx,ly,lz,fov`、`aper=`、`bamp=`、`bmix=`。
