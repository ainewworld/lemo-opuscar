# 浮世绘(Ukiyo-e)— 风格提示词

> 江户时代的木刻版画活了过来:平涂色块、刻出的墨线、普鲁士蓝、晕染(bokashi)天空、摸得到的纸——还有一台像展开手卷一样在版画上移动的相机。
> 演示:*Toward the Mountain · 山へ五景*(44 秒)· `ukiyoe.mp4` · 源码在 `demo/`

你正在以**浮世绘**风格执导一部 30–60 秒的影片。用户给你一个主题。故事、镜头、节拍、音乐和声音由你决定,并交付一部完成的影片。遵循本指南。

---

## 1. 这是什么风格

每个镜头都是**一幅完整的木刻版画**:一张和纸、细双墨边框、由分版印出的平涂色域、最上层的黑色主版线、竖排题签和一枚红印章。世界刻意保持平面。深度来自水平层叠、雾带和大胆裁切——绝不来自透视渲染、光照或明暗。

让它读作*印刷品*而非*矢量图*的关键:
- **纸始终可见**:温暖的和纸、长纤维、边缘微旧。
- **每种颜色是独立的版**,与主版线**套印错位**(1.5–2.5 px)。
- 大色域显示**木纹**和**马连磨压**(baren rubbing,不均匀墨色、圆弧擦痕)以及细密的**胡麻刷**(goma-zuri)斑点。
- **晕染(bokashi)**——手工擦拭的渐变——在天空和水中。

绝不复刻具体的名画(不复制*《神奈川冲浪里》*、*《凯风快晴》*、*《大桥骤雨》*)。学语法,画你自己的构图。

## 2. 故事:什么适合这个风格

这种媒介有五种原生能力。影片至少建立在其中三种上,把最强的一种放在情感高潮。

| 原生能力 | 故事用法 |
|---|---|
| **一系列景**(北斋的富岳三十六景、广重的东海道五十三次) | 同一个恒定主体出现在不同构图中——故事靠它*每次在画面中的位置*来讲(地平线上的一个小点 → 被窗框住 → 被巨浪压小 → 填满整张纸)。 |
| **手卷** | 场景不切;相机沿一条长卷**从右向左**滑动(真实的阅读方向),下一幅版画从右边到来。加快滑动以加速叙事。 |
| **逐版印刷** | 一个场景可以像制作版画那样*出现*:先主版线,然后每个色版落位(先略微错位,再吸附套准)带马连压出的不均匀墨。用它开场,也用它重生。 |
| **纸就是白** | 泡沫、雪、雾和空白天空都是未印刷的纸。浪的泡沫可以填满画面,真的把版画洗回一张白纸。 |
| **画框是实物** | 边框线、题签和印章是物理存在。足够大的东西(浪、龙、山)可以**破出边框**进入装裱纸——这种媒介自己的"第四面墙"。 |

改编任何主题:把它变成**一个旅程或一个系列**,带一个恒定主体。产品发布 → 五个地点的五幅产品图。一座城市 → 五幅版画中的一天。一段人生 → 五个年纪,每幅版画里同一棵树。

**情感弧线(40 秒):**序破急(jo-ha-kyū)——缓慢、开阔、静止(序)→ 脉搏渐聚(破)→ 冲向顶峰的急速(急)→ 硬切到静默(间,ma)→ 安静的收束与尺度揭示。一个角色、一个目标、一次转折。

## 3. 视觉语言

**画布与纸。**1920×1080 的纸 = 缩放 1 时的屏幕。墨框在 `x 44–1876, y 38–1042`(3.4 px),外推 9 px 一条细外线;再外是纸边。纸落在一条长装裱卷(`#c9b690`,间隔 260 px)上,左端一根木轴。

**色板**(用这些,不是泛泛的"日式"色):

| 名称 | 十六进制 | 用途 |
|---|---|---|
| 纸 | `#eee2c6` | 和纸底(带 ±3% 斑驳,纤维 `#fbf6e9` / `#c7b893`) |
| 普鲁士蓝 | `#1d3a66` · 深 `#13284a` · 浅 `#4d6f98` | 天空、水、山、浪 |
| 深渊 | `#0f2344` | 浪的内部 |
| 淡蓝 | `#8db0c6` · `#bcd0d6` | 水面反光、低空 |
| 墨(主版) | `#231f1c` | 所有主版线 |
| 红(Beni) | `#b8412f` · 淡 `#e3a08a` · 桃 `#efc4a8` | 太阳、毡凳、印章、黎明晕染、题签舌 |
| 赭 / 秸秆 | `#cf9f4a` · `#c9a45c` | 斗笠、道路、腰带 |
| 绿 | `#8aa152` · 深 `#50703c` · 松 `#3e5a3a` | 田野、树木 |
| 靛蓝布 | `#2c4a70` · 腿套 `#1d2c44` | 衣物 |

**分版。**把每个颜色组画进各自的离屏画布("版"),缓存一次:
`g0` 主版线 · `g1` 蓝 · `g2` 绿 / 次级 · `g3` 红 / 人物。以固定的套准偏移合成 `g1 (2.2,−1.3)`、`g2 (−1.8,1.9)`、`g3 (1.5,2.2)`。每个色版上依次施加:木纹 `source-atop` α≈0.1–0.17(天空/水最强),马连擦痕 `destination-out` α≈0.38(深木色上 0.2),胡麻刷斑点 `destination-out` α≈0.3。主版:只加斑点(α 0.12)。完成的纸上画上浅色纤维(α≈0.09),让纸从墨下透出。

**木纹** = 扭曲噪声场的等值线(`u = y·0.035 + fbm·9 + 结节`),`|frac(u)−0.5|>0.4` 处的细暗线加宽色调带。**马连** = 约 260 条模糊圆弧 + 之字擦痕。动态大填充(浪)在其裁剪内得到同样纹理(木纹 + 纸色马连叠层)。

**晕染(bokashi)**逐像素生成(一条顶缘按列被低频噪声游走 ±20–30 px 的渐变)——绝不用 `fillRect` 条带,那会留竖缝。

**线。**主版线 2.4–3 px;大轮廓(山、浪、树干)是可变宽度的填充笔画,两端渐细,带 ±20–35% 低频宽度抖动。远处的东西(雨中的山)用灰色主版线或不用线。

**母题(怎么画):**
- *山*:不对称凹坡(`y = s^1.55` 左,`s^1.8` 右),锯齿峰顶,雪帽是**沿沟谷滴下**——12 根随机深浅的雪指(有的很长),窄而尖,由轻波的雪线相连;右侧阴影带;黎明时雪上的淡红光。
- *雾(suyari-gasumi)*:长圆带,平涂色,两端渐隐、向下柔和消散。
- *松*:弯干带鳞皮,枝条末端是平顶**针叶垫**(扇贝形顶缘带针笔扇,平底线)。
- *田野*:高、平、平行层叠——水平田埂间距渐增、带轻波;横埂**平行且倾斜**,不向灭点会聚;埂线宽度变化。
- *雨*:两组角度略异的细直线覆盖一切;天空顶部浓墨晕染。
- *浪*:归一化轮廓(背坡 → 浪峰 → 前唇 → 卷曲 → 空心正面)。身体是**三条蓝带加带间晕染**(峰旁浅蓝 → 普鲁士 → 深渊),由背坡曲线内偏移的粗笔画构成;**成组的白色流线**(每组 3 条,断成长弧)。沿浪峰的泡沫缘;**分形爪**:每个大爪裂成 3 指,每指再裂,所有尖端向内钩;白前层后方偏移一层淡蓝背层;喷沫成**簇**(一个大点、几个中点、许多小点)。
- *爪根*必须**长出**泡沫:把根收细到约 40% 宽,再埋进不规则的白泡沫团(先描所有团,再全部填充 → 一个并集轮廓)。直插在浪峰上的爪读起来像木板。
- *题签*:竖排,奶油 `#f3e7c6`,粗 + 细墨框,顶部淡红舌带系列题,下方毛笔字写景名;旁边或下方一枚红印(红底挖白字,边缘剥落)。
- *人物*在风景中很小(80–130 px),平面,大斗笠、清晰剪影。侧面旅人:低圆锥斗笠遮住上半张脸,掖起的和服后摆折进腰带,深色腿套,草鞋,杖,胸前系着的行囊。近景:剃过的头顶(浅蓝灰),折起的发髻,一笔画的眼。

## 4. 运动语言

- 版画是静止的。**画面大部分不动**;每景有一两个小动作(风中帽带、成行摇动的秧苗、雨、一叶船、蒸汽、灯笼、一片落叶)。
- **人物与自然以 8 fps 步进**;雨和浪爪 **12 fps**;**相机按单帧(24 fps)移动**。步进的相机像抖动。
- **印刷揭示**:每版在约 0.34 秒内出现,带一次斜向马连扫压,其边缘斑驳(噪声),落定时滑 5–6 px 套准。
- **转场是卷轴滑动**(缓动),越来越快:1.0 秒 → 0.9 秒 → 0.6 秒。题签落入(淡入 + 14 px),印章*盖下*(缩放 1.35→1 用时 0.2 秒)。
- 高潮得到全片**唯一的大相机移动**,而且它需要时间——分四拍演奏(共约 4.5 秒):
  1. **起**(约 1.9 秒):海隆起成墙;相机上摇越过顶边框并略微变宽,人物缩小。
  2. **悬 / 亮相**(约 1.2 秒):浪峰立在装裱纸的边框之外,爪张开且近乎冻结(抖动 ×0.25)——整幅版画作为一个物件完整可见。鼓滚到达顶点,然后 80 毫秒静默的吸气。
  3. **落**(约 1.2 秒):浪唇伸长并向镜头方向旋转下压,爪长 ×2.5,相机带小侧滚推到 3×。
  4. **沫**(约 0.7 秒):分形爪从浪唇迸发填满画面,淡出成裸纸 → 硬切到静默(间)。

## 5. 镜头语言

| 节拍 | 相机 |
|---|---|
| 开场 | 锁定在白纸上;第一幅版画在我们面前逐版印出 |
| 早期各景 | 锁定画面,像在墙上读一幅版画。主体很小 |
| 中景 | 极缓推近(1.00 → 1.065)朝向一个取景物(圆窗) |
| 转场 | 手卷从右 → 左滑过装裱间隔 |
| 高潮 | 第一次大移动:上摇越过顶边框进入装裱区,推近;然后急冲变焦进泡沫 |
| 高潮后 | 硬切到白纸 —— 停住(間)—— 然后重印 |
| 结尾 | 从最后一幅拉回,揭示整条卷轴:所有景并排(尺度揭示);结尾卡在卷轴上 |

让副标题避开人物(底部条带距边缘约 80 px;必要时把人物上移)。

## 6. 声音

- **音乐:序破急**,用日本乐器——**三味线**(`pluck.py shamisen` 带 sawari 嗡鸣)、**尺八**、**太鼓**、**拍板**(木拍板)。不要钢琴、不要弦乐垫。
  - 拍板在开场印刷期间加速(每版一击)——歌舞伎的幕启。
  - 尺八自由节奏,*都节音阶*(miyako-bushi,D E♭ G A B♭),长音带气息,每个音上滑进入,乐句尾 *meri* 下沉。
  - 三味线:慢脉冲(72 BPM),然后带小紧鼓的固定音型(96 BPM);最快的卷轴滑动上奏快速上行跑句。
  - 太鼓心跳从 0.9 秒间隔加速到高潮的滚奏;撞击处一记全击;然后**绝对静默**(混响尾也切掉)。四大鼓击重印最后一景。开场尺八动机回归并解决;结尾卡下,带 sawari 的长三味线音鸣响。
  - 尺八来自采样:`flute`/`recorder`,压平振幅与音高颤音(除以 60 ms 包络;f0 跟踪并反扭),加与包络锁定的 1–4 kHz 气声,起音处 *muraiki* 送气爆发。
  - 太鼓来自采样:`gran_cassa` + `toms:low_mallet` + `frame_drum:large` + 合成鼓皮(音高下落 ~120→58 Hz)和鼓槌闷击。
- **拟音跟随材质**:纸(马连摩擦 = 带约 9 Hz 圆形调制的带通噪声;卷轴滑动;题签滑入;印章 = 低闷响 + 黏揭),木(版放下、空木桥步、木上杯),玻璃(风铃分音 2.36 / 5.15 / 7.98 kHz),水(田野细流、带雨滴的雨垫、约每 4 秒的海涌),鸟(云雀啾、雁、最后一景鸢的 *pii-hyoro*)。
- **人声**:平静的男讲述者,第一人称,5 句短台词(Kokoro `am_adam`,语速 0.84–0.88)。人声下音乐压约 −8 dB(最后一句 −10 dB),氛围约 −4 dB。响度 −14 LUFS,`mux.sh` 颗粒 **0**(纸就是颗粒)。

## 7. 副标题与片名

- **副标题 = 横向题签**:奶油 `rgba(243,231,198,.96)` 纸条,2.6 px + 1 px 墨框,左侧小红印"旅",Shippori Mincho 500 42 px 墨字,底部上方 72 px 居中。0.22 秒随揭示遮罩"印入",0.25 秒淡出。每行停留 ≥ max(1.8 秒, 人声 + 0.75 秒)。
- **景题签**(竖排,Yuji Syuku):淡红舌上是系列题,下方是景号 + 景名(一 田毎の朝 · 二 雨の橋 · 三 茶屋の窓 · 四 海立つ · 五 山),其下/旁钤印——每景的"句号"。
- **片名**:竖排题签 山へ五景 + 横排英文纸条 *Toward the Mountain* 放在第一幅版画上,盖一枚印,第一句台词前移走。
- **结尾卡**:深靛蓝 `#161a22` 上整条卷轴横贯中部;上方标题,下方 `UKIYO-E · a Lemo-Opuscar demo · LemoLab × Claude Opus 5.5`,一枚印(深色背景上用 `source-over` 画,不用 multiply)。

## 8. 我们踩过的坑

- 6 px `fillRect` 条带的晕染留可见竖缝 → 逐像素生成。
- 太多斑点 / 纤维叠层让暗部像砂纸或划伤胶片 → 斑点 α≈0.3,纤维 α≈0.09。
- 没有木纹 + 马连的平涂读起来像矢量图。把纹理放到每个色版上,以及大动态填充的裁剪内。
- 规则透视网格的稻田显得数字。用平行、倾斜、平面的层叠。
- 之字形雪线像皇冠;平滑波浪像糖霜。用随机长度的窄尖雪滴,并强制控制点 x 单调(否则出现微型自相交环)。
- 半圆盘画的松丛像遮阳伞 → 带针扇的平顶垫。
- 第一版高潮只有 0.7 秒,读起来像"闪过一些泡沫";这个原生移动需要约 1 秒的悬停拍才能被读懂。
- 第一版浪像水帘(流线从底部呈扇形)。流线必须沿背坡轮廓;身体要有分带蓝;爪必须分叉且内钩——一条卷曲的条带读起来像丝带。
- 偏移曲线在紧卷的浪唇处自相交 → 内流线只用背坡。
- 画到版画外(浪破边框)必须同时逃出纸裁剪和画框裁剪;把浪两侧裁到画框,只有顶部破出。
- `mountain()` 只在传入平涂色时才填充,渐变身体是透明的——小心选项标志。
- 用 `multiply` 画的印在深色结尾卡或浪上消失 → 那里用 `source-over`。
- 前景树上的人物读起来像在树"前面";让低枝避开步道。
- 纯噪声的墨揭示像霉斑扩散 → 把方向性(斜向)扫掠与边缘噪声结合。
- 副标题条带盖住底部 150 px 内的一切 —— 抬高地平线 / 人物。

## 9. 制作配方(本仓库)

```
styles/ukiyoe/demo/
  print.js     paper, woodgrain, baren, specks, blocks, bokashi, carved lines, reveal masks, cartouche, seals
  nature.js    mountain + snow drips, pines, rocks, rain, geese, simple claws
  traveler.js  the traveler (walk / stand / hold hat / straw cape / sit & drink / back view / hat off)
  views.js     the five prints: cached blocks (g0–g3) + per-frame paint()
  wave.js      sea rows, wave geometry, banded body, fractal claws, spray clusters
  story.js     the timeline (single source of truth)     main.js  camera, scroll, sheets, reveal, titles, subtitles, events
  lines.json   voice   music/score.py  original score   mix.py  foley + voice + ducking + the silent ma   subs.py  cues → srt
  build.sh     one-command rebuild
```

1. `node core/render/still.mjs styles/ukiyoe/demo <t…>`(`--q nosub=1`,角色表用 `--q test=trav`,`--q poster=1`)。
2. `core/tts/tts.py lines.json voices` → `core/tts/asr_check.py`。
3. `node core/render/events.mjs styles/ukiyoe/demo` → `music/score.py` → `mix.py`。
4. `node core/render/video.mjs styles/ukiyoe/demo --fps 24 --workers 3`(1056 帧 ≈ 45 秒,Canvas2D)。
5. `core/render/mux.sh out/video24.mp4 mix.wav ukiyoe.mp4 24 0` → `check_asr.py ukiyoe.mp4`。
