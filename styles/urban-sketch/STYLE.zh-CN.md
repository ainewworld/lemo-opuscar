# 城市速写 · 钢笔淡彩(Urban Sketch · Pen & Wash)

> **一句话:**公园长椅上的一页速写簿:精细的深褐针管笔线条微微抖动、越过转角、永远不完全闭合,上面滴落松散的透明水彩。颜色略微偏离线条,溢过线,在页缘溶进奶油色冷压纸。
>
> **演示:** *Where the Wind Went*,32.4 秒,1920×1080,24 fps,无旁白。一座公园只以墨线速写存在,页面上唯一的颜色是一顶草帽。一阵风偷走帽子,而**风吹到哪里,页面就画到哪里**。
>
> **参考(只学语法):**
> - 城市速写速写簿内页:先线后彩;颜色错位;角落手写的日期和地点;页缘碎裂成点触。
> - *《纸人》*(Paperman,2012):单色世界中的一件彩色物;风当媒人。
> - *《红气球》*(The Red Balloon,1956):一件物品作主角,相机跟着它穿过城市。
> - 爵士圆舞曲(Vince Guaraldi 一派):3/4 摇摆,三拍行走的贝斯、刷子、单簧管主旋律。
>
> 不从这些里复制任何东西:没有角色、旋律、版式或字体。

---

## 1. 这是什么风格
现场报道式绘画,几分钟内在原地完成。两层始终明显分离:
1. **墨线。**一条细而近乎恒定的线(0.3–0.5 mm 针管笔),深褐 `#2b2520`。它轻微抖动、越出转角几个像素、中途断笔,暗示多于描绘:几个窗的记号代替整面网格,扇贝形碎片代替整棵树的轮廓。
2. **水彩。**在上面罩染的透明水彩。它与线条**错位**1–3 px,有时溢过线,为高光和人物留出纸白(留白/reserve)。干边缘更深(颜料在边缘积聚),颜料颗粒化渗入纸齿。

页面本身是图像的一部分。暖奶油 `#f5eede` 冷压纸有大尺度斑驳和细密纸齿。没有东西从边画到边:画溶成叶子大小的点触和白洞,留出空白边距供手写。

## 2. 适合的故事,与原生招法
适合:旅行日记、城市肖像、一地的一天、"我注意到那一刻……"、生活切片、小人物的轻喜剧,任何受益于"被观察、手工制作"感的东西。

**原生招法(只有这种媒介做得到):**
- **先线后色。**展示笔按笔画出一个主体(按真实笔顺),然后滴入水彩。作画过程就是奇观。
- **颜色即到达。**每个像素有一个*颜色到达时间*。水彩从源头以毛糙湿润锋面和深色潮线向外扩散,于是你可以用一个事件(风、跑者、音乐、日出)来作画。人物保持冻结的线稿,直到颜色触及他们才开始移动。
- **唯一着色之物。**以无色速写加一件着色物开场;它成为主角。
- **页面即画框。**拉远直到整页可见,边缘溶解,边距中有手写标题和注释。一举兼作结尾卡和尺度揭示。

## 3. 视觉语言(带数字)
| 元素 | 数值 |
|---|---|
| 纸 | `#f5eede`;斑驳 fbm 在 0.0011 和 0.0062 cycles/px,±4.5 %;纸齿瓦片叠在最上面的一切之上,包括人物 |
| 墨 | `#2b2520`,覆盖率 96 %;世界线宽 1.3–3.4 px(远细近粗);抖动 0.9–1.3 px;越界 3–8 px;30–60 % 的长笔画有一个 3–9 px 断口 |
| 水彩 | 2–3 层毛边(边缘噪声 4–12 px),multiply 混合;alpha 0.4–0.65;偏离线条 0.7–1× 线宽;干边缘笔画 30–40 % |
| 颗粒化 | 颜料 × (0.82 + 0.36 · fbm(p · 0.21)) |
| 湿锋 | 到达时间上 0.16 秒的 smoothstep 揭示;锋面带加深 +70 %(高斯于 +0.07 s,σ 0.08 s);边缘噪声 ±240 px 粗 + ±40 px 细 |
| 树叶 | 浅底洗(阳光 `#d6d56f`),然后明暗色团,然后按光照方向着色的 5–20 px 叶点:`#d6d56f` → `#aabf57` → `#7fa04a` → `#56793c` → `#3f5d36`;边缘留洞;扇贝形墨碎片只出现在轮廓上 |
| 天空 | 几个大而柔的 `#9fbcd6` / `#86a6c8` 椭圆,10–20 % alpha,向上渐隐;云是带 `#b7b3c9` 腹部的留白 |
| 建筑 | 石灰岩 `#d8c6a0`、赭 `#cfaa72`、玻璃 `#98b1c8`、砖 `#c49a7a`;阴影面 = 颜色与 `#5a5f82` 混 45 %;远处块体与雾 `#b9c0cc` 混 50 % |
| 草坪与小径 | `#c3c96f` / `#dcd98b` 亮带,`#7f9c52` 阴影点;小径 `#d8ccb1`;草 = 每丛 2–4 笔墨挑,近相机更密 |
| 人物 | 3D 骨架,正交投影;躯干剪影来自截面;四肢为有机锥管;头发与头为一个整块;脸留白(侧面一笔鼻);阴影面 = 颜色与紫 `#464873` 混 40 % |
| 页缘 | 噪声边界(fbm 0.004,±80 px);内侧 70 px 宽白色点触带,外侧 70 px 宽彩色点触喷 |

## 4. 运动
- 人物以 12 fps **沸腾(boil)**:线抖和水彩种子每 1/12 秒变化。静止页面不沸腾(它是真实的一页);相机每帧移动,流畅。
- 人物保持预备、动作和跟随:站起前下蹲、扑空时的冲刺踉跄、俯冲后的匍匐滑行。脚步落在节拍上(跑循环 = 2 拍)。
- 风是画出来的:每拍在帽子后方生成墨的 "~@" 卷线,0.4 秒画入,再从尾部擦除;叶点跟随帽子拖尾。
- 颜色从不吸附。它从一点带噪声圆形裁剪(人物)或通过到达场(世界)绽放。

## 5. 相机
5120×2880 页面上的 2D 相机(最终拉远以 0.375× 1:1 展示它)。
- 设计好的移动用三次缓动。跟拍用作用于前视目标的临界阻尼弹簧,相机像手持跟拍一样滞后(刚度 28,坠落段 70)。
- 演示用了推近、拉远、横移跟拍、升摇、带微侧滚的甩摇、撞击时带 0.35 秒抖动的急推、一次长拉远,以及下摇进入边距。
- 故事节拍上保持主体至少三分之一画面高;帽子得到一圈淡纸晕(留白),在繁密枝叶上仍然可读。

## 6. 声音
三层;无旁白。
- **氛围**:纸张房间底噪 → 公园鸟鸣(颜色到来后) → 天际线前一拍进入的低城市嗡鸣(J-cut)。静默那一小节一切退出。
- **拟音**:冷压纸上的笔(带通噪声,1.6–7.5 kHz,带纤维振幅纹理和颗粒咔哒,每真实一笔一次爆发;速写铺开期间数千次重叠成嘶声;天际线笔画更亮,读起来像踩镲);每次大绽放的湿刷 "shhh";右声道的风 J-cut;草帽作纸拍打,频率和电平跟随其速度,声像跟随其屏幕 x;节拍上的脚步;车铃;俯冲、滑行、接住的拍击和水扑通。
- **音乐**:150 BPM F 大调爵士圆舞曲:Sneakybass 三拍行走、合成刷子加踩镲踏板、2–3 拍上的立式钢琴、单簧管主旋律、城市段的弱音小号、拨弦固定音型、树迸发处的颤音琴和马林巴重击、顶点处悬浮的 D♭maj7♯11,随后**一小节真正的静默**。之后第一个声音是带定音鼓的半音单簧管下滑;接住落在全奏的下拍上。
- 混音:音乐在接住段下沉;拟音 90 Hz 高通;−14 LUFS,LRA 7。

## 7. 标题与文字
不需要副标题。所有文字是**页面上的手写**,以从左到右的揭示和笔声写上:
- 角落注释用 Reenie Beanie(`Sun. 3:40 pm — windy`);
- 标题和版权页用 Caveat(500–600 字重),在空白页边距中左对齐。

文字留在世界里,随相机移动,绝不作为覆盖层。

## 8. 我们踩过的坑
- **颜色场里的直边。**源头包围盒忽略了其竖直拉伸(`sy`),到达半径之外缓慢"爬行"的部分被方形盒子切断。按实际(带噪声的)距离裁剪,不要按 bbox。
- **后退塔楼周围的矩形遮罩**在天空中留下白缺口。用真实阶梯剪影(收分、尖顶、金字塔、水箱)遮罩。
- **角色跑进未画区域时丢色。**在角色起点采样一次到达(或绑定到给他们上色的事件),绝不在当前位置采样。
- **静态墨线不能被后来的水彩遮挡。**远景人群因此用"胡萝卜人"(一个洗色团、两条腿线、一个头点)代替完整骨架;建筑墨线在绘制前先被更近的建筑和树冠内部擦除。
- **混合坐 → 站时 IK 双脚钉死**导致腿外撇。把脚目标向髋下位置混合。
- **正面朝向的头变秃。**始终先画头发块,再从其下部挖出脸。
- Headless Chrome 和大画布:5120² 的墨、时间、颜色和页面画布没问题,但要自己把墨和时间打包进 RGBA 字节纹理(`getImageData`),到达场上传为 `R16F`(可滤波)。

## 9. 本演示如何构建(本仓库)
```
styles/urban-sketch/demo/
  engine.js   pen, wash, foliage, arrival field, GL compositor, figure rig, hat, bike, handwriting, sketchShape
  world.js    the static page: sky, skyline (ink in stroke order), trees, lawn, path, lamp, pond, bridge, crowd, edge dissolve
  poses.js    character looks + pose library (sit, run, walk, cycle, dive, prone, wave)
  film.js     timeline: hat path, camera, performances, colour sources, sound cues
  audio/      score.py (music) · foley.py (all procedural sound) · mix.py
  build.sh    one command, from nothing to urban-sketch.mp4
```

渲染:`node core/render/video.mjs styles/urban-sketch/demo --fps 24 --workers 4` 在 M 系列 Mac 上约 40 秒渲染 778 帧;世界构建每 worker 约 4 秒。

## 10. 引擎用法
所有函数在 `demo/engine.js` 中,且是确定性的(同种子,同笔痕)。

| 函数 | 作用 |
|---|---|
| `penStroke(pts, {w, wob, over, gap, seed, smooth})` | 沿任意折线准备一条针管笔笔画(抖动、越界、渐细、断口) |
| `drawPen(ctx, stroke, p=1, col=INK, alpha=1, from=0)` | 画到比例 `p`(画入);`from` 从尾部擦除 |
| `rasterPen(inkCtx, timeCtx, stroke, t0, dur, win)` | 把笔画烘焙进静态墨层 **外加**逐像素到达时间(着色器中的笔顺回放) |
| `wash(ctx, poly, [r,g,b], {a, j, layers, edge, dx, dy, seed})` | 任意多边形上的水彩洗(毛边、罩染、深色潮线、偏移) |
| `reserve(ctx, poly, a)` | 把颜色提回纸白(留白、前景遮挡) |
| `dab(ctx, x, y, r, angle, col, a, seed)` / `foliage(ctx, crown[], opts)` | 叶点 / 整个树冠 |
| `arrivalField(W, H, gw, gh, sources, {amp, creep})` | 每格的颜色到达时间;`sources = [{x, y, t, v, R, sy, mask, hard}]` |
| `compositor(canvas, layers)` → `draw(cam, t)` | WebGL 页面:纸 × 洗(由到达揭示、湿锋)× 墨(由笔画时间揭示) |
| `figure(look, pose, place, {seed, boil})` → prims | 一个速写人(挖脸 / 洗色 / 墨线基元);`prims.head`、`prims.hand` 供附着 |
| `hat(c, r, [rx, ry, rz])`, `bike(place, phase, col)` | 带真实 3D 朝向的道具 |
| `drawPrims(ctx, prims, {color, ink, clip})` | 绘制基元;`color` 0..1 = 水彩到达多远;`ink` = 画入进度(数字或逐基元函数) |
| `sketchShape(ctx, poly, col, {ink, wash, offset, color, p})` | 一次调用画出这个风格的**任意形状** |
| `handwrite(ctx, text, x, y, size, p, {font})` | 从左到右写上的手写 |

**"唯一颜色"钩子。**让一切保持 `color: 0`(纯墨),只给保留颜色的那个元素传 `color: 1`,像草帽那样。或者给那个元素一个 t = 0 的到达源,其他一切更晚。

最小示例:一个暖橙 `#D97757` 四角闪亮,带一条短光标尾迹。
```js
import { sketchShape, sparkle, penStroke, drawPen, hex } from './engine.js';
const star = sparkle(960, 540, 120, .24);                       // 4-point star polygon
sketchShape(ctx, star, hex('#D97757'), { ink: 3, wash: .7, offset: 3, seed: 7 });
drawPen(ctx, penStroke([[1040, 610], [1180, 640], [1300, 646]], { w: 3, wob: 1.2, over: 6, seed: 8 }), 1);   // the tail
```
