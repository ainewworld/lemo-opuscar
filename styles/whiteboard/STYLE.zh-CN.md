# 白板讲解(Whiteboard Explainer)— 风格提示词(v2,无手版)

> 一堂在一整块光亮白板上现场画出的科普讲解:真正按笔画逐笔*书写*出来的单线手写字、没有手的悬浮马克笔、一块可以移动的磁贴、一块能让时间倒流的板擦 —— 以及一台直到最后拉出全景、整堂课挂上墙才离开白板的镜头。
> 演示片:*Einstein in Your Pocket*(111 s)· `whiteboard.mp4` · 源码在 `demo/`
> 参考(仅借鉴语法):RSA Animate / Cognitive Media(一块连续的白板,镜头行进而非剪辑,最后整板揭示);minutephysics(一句话 = 一幅画,能承载物理的最简几何);Steve Reich 的 *Piano Phase*(同一图形以两种节速并行作为结构)。绝不复制他们的画、角色、手或音乐。

你正在以**白板讲解(Whiteboard Explainer)**风格执导一部 60–120 秒的讲解片。用户提供主题(通常是科学或"X 是怎么工作的")。你来决定脚本、白板布局、镜头路线、声音与配乐,并交付一部完成的影片。

---

## 1. 这是什么风格

**一块实体白板**上的一堂课。观众学到的一切都以白板笔当着他们的面、按真实的书写顺序画出。白板是一张*地图*:每个想法住在自己的区域里,镜头在区域之间行进,通常**由笔引领**(笔画出一条线,镜头沿线而行)。结尾镜头拉出,观众发现整段讲解其实是一幅画。

让它显得真实而非"动画文字"的细节:墨水在笔尖落点处洇开、干涩的断续与斑点、越过交点并不完全闭合的笔画、从未被完全擦净的旧课残影、漂移得比白板慢的光泽反光,以及**每一笔都有**声音。

**本版本没有手。** 马克笔悬浮(带真实的投影阴影,抬起时阴影变大),在句子间隙停在画面外,再飞回来。实物道具(磁贴、板擦)自行移动。不要画手、手臂或光标。

## 2. 故事:什么适合这个风格

| 天然优势 | 故事用法 |
|---|---|
| **按笔画顺序书写** | 揭示本身就是讲解:一个方程在旁白念到每一项时,恰好逐项出现。 |
| **一块板,一台镜头** | 白板上的距离 = 论证中的距离。回到先前的图是一次免费的呼应(demo 回到第一个方程来计算 38 μs × c ≈ 11 km)。 |
| **笔引领镜头** | 转场是画出来的:一条轨道、一条信号线、一段轨迹。镜头沿这条线前往下一个想法。 |
| **磁贴** | 白板上唯一被允许*移动*的物体。把主角("你在这里"的图钉)交给磁贴;它可以被拿起、放下、滑动、沉入。 |
| **板擦倒流** | 反向擦除一条轨迹读起来像撤销时间。用一次,就在笑点之后。 |
| **双笔并行** | 一段二重奏:两个量实时对比(demo:地面时钟与轨道时钟以两种节速各自滴答)。 |
| **整板揭示** | 结尾:越过边框拉回到墙面和笔槽。之前每一幕同时重现。 |

**故事形状(demo 中已验证):** 以一个极小的物体(图钉)开场抓人 → 尺度揭示 → 第一个重拍上的标题 → 三步讲机制 → **静默 + "但是,有个问题。"** → 用视觉二重奏解释转折 → 一个展示后果的笑点(图钉每个节拍漂移一天、漂进大海)→ 板擦倒流 → 同步给出修正 → 拉回整块白板 → 在标题下方写出结尾卡。

改编任何主题:找到**一样观众拥有的东西**(手机、一条面包、一只灯泡)、一个令人惊讶的数字、一个可以在板上*走*出来的后果。把惊讶放在中段、一次静默之后。

## 3. 视觉语言

- **白板**:暖白 `#fbfbf9 → #eeede9` 渐变,一层隐约的擦痕/微划痕平铺,约 46 条**残影笔迹**(旧词、圆圈、箭头),以 5–10 % 的灰色 `#9aa0a8` / 淡蓝 `#8aa0c8` 呈现。一道柔和的对角**窗户反光**(白色,10–16 %)以 0.35× 于镜头的速度移动 —— 这一个细节就卖出了"光面"。
- **墨色**:黑 `#23262c`、蓝 `#2a5cb3`、橙 `#d97757`,透明度 0.94,以 **multiply** 合成,使交叠像真实马克笔一样变深。绘图线宽 6–11 px,书写线宽为大写高度的 13 %。
  - 颜色语义:**黑** = 事物与结构,**蓝** = 信号、光、测量,**橙** = 你 / 时间 / 那件要紧的东西(每幕只用一种强调色)。单色变体:只保留一个橙色元素("唯一的颜色")。
- **笔触特征**:约每 0.6 × 宽度重采样一次;沿法线的低频手抖(±2.6 px,波长约 220 px)加一层更细的颤动;按方向变化的平头笔宽调制(0.8–1.0);起笔压力爬坡(0.72 → 1)与收笔 12 % 渐细;圆从某个角度起笔并**越过闭合点**;矩形为 4 笔、角部略有过冲;每条长笔起笔内侧一个更深的洇墨点。
- **干性马克笔纹理**:一张 512 px 的斑点与短划痕贴图从墨水层减去(destination-out),锁定于白板空间,镜头拉远时淡出。
- **字体**:单线字体 **EMS Tech**(OFL,Architects Daughter 的单笔画版),每个字形带 ±2° 旋转、±3.5 % 基线与缩放抖动。缺失字形(μ ≈ → × − ✓ ² ↓ ° ± .)在引擎中手工定义。标题大写高度 200 / 120 px,标签 30–70 px。
- **道具**:白板马克笔(白色笔杆、墨色色环与笔帽、毡制笔尖),一块带小橙色标签的炭色毡制板擦,一枚光亮的橙色**地图钉磁贴**(径向渐变、白点、镜面高光、柔和投影)。铝框与笔槽只在最后的全景镜头中出现,挂在暖灰墙面 `#d8d3ca` 上。

## 4. 运动语言

- **手速**:每一笔遵循 `u − sin(2πu)/2π × 0.8` —— 落笔慢、中段快、提笔慢。笔画被调度进一个**时间窗**(引擎解出速度),因此书写总是在词语上收尾。
- 笔画之间的**跳笔**:抬起高度与距离成正比(阴影滑开并变糊),为窗口最大值的 35 %。间隔 > 0.75 s:笔飞出到画面外的停泊点,并在下一笔前 0.42 s 返回。
- **磁贴**:放下 = 0.3 s,抬起 → 0、大阴影收缩;滑动 = 每步 smoothstep、带一点抬起;沉入 = 倾斜 0.5 rad 并下落 40 px。
- **板擦**:沿路径匀速移动,以 90 % 强度擦除一条 90–230 px 的带(总会留下 10 % 残影)。
- **速度**:标题 3 s,标签 0.3–0.8 s,一整颗卫星约 1 s。比真实的手快 —— 这是一堂加速的课 —— 但不能快到丢失笔画顺序。

## 5. 镜头语言

- 一台 8000 × 4500 白板上的 2D 镜头:位置、变焦(按 1/z 插值,使推近有移动车的质感)、少量旋转。
- **语法**:(1) 拉远揭示尺度;(2) 沿正在绘制的线骑行;(3) 观众必须阅读时静止;(4) 一次静默之后猛切进新想法;(5) 最后一次越过边框的拉出。
- 真实 180° **运动模糊**:镜头每帧移动超过 14 px 时,最多渲染 12 个子帧并平均。
- 每个镜头都要为底部 12 % 的字幕留空。

## 6. 声音

- **每一笔都有声音**:带通毡毛划过光面的噪声(2.2–7.5 kHz 嘶声 + 0.5–1.5 kHz 笔身),以笔画自身的速度曲线作包络,起笔处 4 ms 笔尖嗒声,随机的粘滑颗粒,约 28 % 的长笔上出现**白板吱声**(1.5–2.6 kHz 正弦,带 7–13 Hz 颤音)。蓝笔略低沉,橙笔略明亮。声像 = 笔画的屏幕 x;镜头越近越响。
- **道具**:磁贴落在钢板上 = 咔嗒 + 金属模态(830/1370/2210/3120 Hz)+ 140 Hz 板体闷响;板擦 = 250–2600 Hz 毡毛摩擦,由其之字形轨迹调制;笔槽 = 塑料弹跳 + 铝制余音;笔帽开合。
- **房间**:低低的房间底噪,以及一座**按地面时钟秒数滴答的挂钟** —— 静默段里唯一的声音。
- **配乐**:120 BPM 的发条极简主义,D 大调 / B 小调:马林巴八分音符琶音、大提琴 + 低音拨奏、每拍一下的木鱼滴答、钢片琴主题、响亮段落才有的沙锤/拍手。信号配钢片琴 ping,下落的信号配一段竖琴滑奏,漂移的物体配断奏进行曲(大号 + 大管,半音下行)。任何"两个量渐行渐远"的时刻,让**同一图形以两种节速**并行(phasing),然后在修正时让它们 snaps 齐一。倒流 = 前一段提示的倒放与压缩。
- **混音**:VO 在最上层(压缩、轻房间感),配乐低于 VO RMS 6.5 dB 并在说话时再 duck 9 dB,拟音低于 VO 约 11 dB;−14 LUFS。

## 7. 字幕与标题

- 标题与结尾卡**直接写在板上**,用同一种单线手写体;结尾卡写在标题下方,让影片结束在它开始的地方。
- 内嵌字幕:米白色圆角标签(90 %),Architects Daughter 44 px,深色墨字,左下角一道短的橙色马克笔划。按分句断行,每行 ≤ 44 字符,短分句合并,1250 px 以上分两行。

## 8. 我们踩过的坑

- **一支笔、太多任务**:单支笔被连续调度会越拖越晚(卫星迟到了 12 s)。给每幅画一个窗口(`by:`),让重叠任务交给另一支笔。
- **最小笔画时长 × 虚线**:一条 60 段的虚线,若每段下限 0.09 s,要花 6 s。虚线需要自己更小的下限。
- **洇墨点比笔画起点还大** → 每个字母上出现灰晕。让点留在笔画之内。
- **标点消失**:字体里的句号是 1 px 的笔画。把小于线宽的笔画渲染成点。
- **被推近切掉一半的标签**很难看:一个标签在它出现的每个镜头里必须要么完全在内、要么完全在外。
- **子帧太少的运动模糊**会让文字频闪。子帧之间步长 ≤ 4 px。
- **英式配音 + 美式音素**:Kokoro `bm_george` 配 `lang: en-us` 把 "clocks" 读成 "Clarks"。英式音色用 `en-gb`;用 `medium.en` 校验。
- 让板擦路径避开你想保留的标签(有一次它擦掉了半个 "orbit")。

## 9. 制作配方(本仓库)

1. 把脚本写成短行(`demo/lines.json`),用 `core/tts/tts.py` 合成(音色 `bm_george`,`lang: en-gb`),用 `demo/tools/asr_check.py` 校验(`WM=medium.en`)→ `voices/words.json` 词级时间。
2. 布置白板(每个想法的区域),然后写 `demo/film.js`:VO 起始时间、用 `at(id, word)` 把图画挂在口语词上、笔、镜头关键帧。
3. `node core/render/events.mjs demo` → `events.json`(每一笔、每一次擦除、磁贴、提示锚点)。
4. `music.py`(读同一份 events)→ `mix.py`(由 events 生成的拟音 + VO + duck 的配乐)。
5. `node core/render/video.mjs demo --fps 24` → `core/render/mux.sh … 24 2`。整部影片约 30 s 渲染完。
6. `demo/build.sh` 执行第 3–5 步外加字幕、海报与剧照;`--vo` 会连第 1 步一起重做。

## 10. 引擎用法(`demo/engine/wb.js`)

| 函数 | 作用 |
|---|---|
| `loadFont(name, url)` | 加载由 `demo/tools/svgfont2json.py` 转换的单线字体(`'tech'` = EMS Tech) |
| `line / curve / poly / arc / circle / rect / roundRect / arrow / dashed / hatch` | 手绘形状 → `Stroke` / `Stroke[]`。选项:`w`、`color`、`jitter`、`over`(过冲)、`bow`、`lap`(圆的交叠)、`clip`(圆角矩形)、`alpha` |
| `text(str, x, y, {h, align, w, color, font})` | 按书写顺序以笔画生成手写文本(`h` = 大写高度) |
| `new Stroke(points, opts)` | 任意路径(扁平 `[x,y,…]`)以马克笔风格生成 |
| `new Pen(id, color, {park})` | 一支悬浮马克笔;`park` = 其画面外停泊点(屏幕像素) |
| `Timeline.draw(pen, shapes, t, {by, speed, minGap, maxGap})` | 调度笔画;带 `by` 时会解出手速以按时收笔 |
| `Timeline.erase(path, t, dur, {width, strength})` | 沿路径的毡制板擦(留下残影) |
| `Timeline.cue(t, type, extra)` | 导出到 `events.json` 的额外声音/音乐锚点 |
| `new Camera([[t, x, y, zoom, roll, ease], …])` | 关键帧 2D 镜头;缓动 `io` `i` `o` `l` `s` |
| `new Board(tl, {ghosts})` · `board.render(ctx, t, cam)` | 白板、墨水(multiply + 干性纹理 + 板擦)、反光、`objs`(世界道具)与 `overlays`(屏幕层) |
| `penPose / drawMarker / drawEraser / drawPinMagnet` | 实体道具 |

最小调用 —— 用马克笔画一颗暖橙色四角星花,带一条短光标尾迹:

```js
import * as W from './engine/wb.js';
await W.loadFont('tech', 'fonts/EMSTech.json');
const tl = new W.Timeline(), O = new W.Pen('orange', '#D97757');
const star = [], cx = 960, cy = 540, R = 120, r = 26;
for (let i = 0; i <= 8; i++) { const a = i * Math.PI / 4 - Math.PI / 2, q = i % 2 ? r : R; star.push([cx + Math.cos(a) * q, cy + Math.sin(a) * q]); }
tl.draw(O, [W.poly(star, { w: 10 }), W.line(cx + 150, cy + 60, cx + 150, cy + 150, { w: 10 })], 0.5, { by: 1.6 });
tl.draw(O, W.text('ready', cx + 190, cy + 150, { h: 60 }), 1.7, { by: 2.4 });
tl.end();
const board = new W.Board(tl), cam = new W.Camera([[0, 960, 540, 1]]);
board.objs.push({ draw: (ctx, t, c) => W.drawMarker(ctx, O, W.penPose(O, t, cam), c, t) });
window.render = t => board.render(ctx, t, cam);           // ctx = your 1920×1080 canvas 2D context
```
单色变体:全部用黑笔画,只给那个要紧的元素 `{ color: '#D97757' }`。
