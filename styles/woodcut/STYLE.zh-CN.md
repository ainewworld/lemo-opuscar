# 木刻版画(Woodcut Print)— 风格提示词

> 一幅会自我雕刻的凸版画:每一帧都是一块黑色木板,光只存在于刻刀刻去的地方。最多一种颜色,只留给那件燃烧的东西。
> 演示片:*The Bell Founder*(58.5 s)· `woodcut.mp4` · 源码在 `demo/`
> 参考(仅借鉴语法):Frans Masereel《Passionate Journey》(1919)与 Lynd Ward《Gods' Man》(1929),以一幅幅自成起讫的版画讲述的无字木刻小说;Käthe Kollwitz 的木刻,情感藏在凿刀的走向里;Gustave Doré 的版画,以线条的间距与方向构筑光影和体积。绝不复制他们的版面、人物、边框或标题。

你正在以**木刻版画(Woodcut Print)**风格执导一部 40–60 秒的影片。用户提供主题,其余一切(故事、镜头、节奏、声音)由你决定,并交付一部完成的影片。遵循本指南。

---

## 1. 这是什么风格

每个镜头都是**一幅印制版画**:直纹纸上的黑色油墨,四周留出纸边。它遵循真实凸版印刷的三条法则:

1. **黑是木板表面,白是刻刀刻去的地方。** 光不是画上去的,是*刻*出来的。亮部是许多宽刀痕;暗部是未动的木头。
2. **画面以被雕刻的方式出现。** 没有淡入。刀痕沿形体一次一刀地生长,先粗凿后细线,正是刻工的工序。
3. **木板是镜像。** 板上的字母是反的。只有揭开纸的那一刻它才读正,而这个翻转正是本风格自有的转场。

唯一的颜色(demo 中是第二块版、"铜色" `#C8502A`)只印在白色已被刻去的地方,因此它从刀痕中发出光来,从不落在黑色上。

## 2. 故事:什么适合这个风格

| 天然优势 | 故事用法 |
|---|---|
| **光是刻出来的** | 关于火、黎明、发现、一盏灯被点亮的故事:光的瞬间可以字面上*就是*一次放射状刀痕的爆发。 |
| **雕刻 = 时间** | 画面一刀一刀地生长,是银幕上可见的耐心劳作。适合手艺、劳作、坚持与初次尝试。 |
| **镜像的木板 → 真正的印张** | 一次揭示或回心转意:观众读到一个反写的词,纸被揭开,它读正了。 |
| **雪 = 点刻** | 白点是木头上的伤口。它们可以冻结在半空,或被"重新上墨填回",直到天空干净。这带来别的媒介没有的结尾。 |
| **一块色版** | 留给唯一要紧的东西(熔化的金属、一颗心、一簇火焰)。让它在高潮时铺满画面,之后收缩为一个高光点。 |
| **无字小说的节奏** | 口白至多四五句。版画承载故事;一次失败之后的空白可以完全无声。 |

**故事形状(demo 中已验证):** 黑暗中第一刀(地平线)→ 世界被刻出 → 第一张印张揭开(镜像 → 读正)→ 一个双手的长特写 → 一组小祭品的快速蒙太奇 → 第一次尝试在**特写中失败** → 一张无声的版画 → 一次个人的牺牲 → 第二次尝试中色版漫过画面 → 最长的静默 → 酬赏之声 → 颜色退到一个高光点 → 白痕被重新上墨填回 → 最后一刀又落回地平线。

改编任何主题:找到那件应当*发光*的东西(那是你的色版)、那件*由手做成*的东西(那是你的长特写)、以及结尾时应当*消失*的那件东西(那是你的点刻纹理)。

## 3. 视觉语言

**色板**:墨 `#111111` · 纸 `#EFE8D8` · 木板本身 `#D8C29C`(只在出现木板的镜头里)· 一块色版 `#C8502A`。色版叠在墨上几乎不可见,因此要把它规划在刻出的白色上。

**版框**:1920×1080,印制图像区 `36, 36, 1848×912`。底部纸边(132 px)放字幕。图像边缘就是木板边缘:毛糙的墨痕,绝不是干净的矩形。

**刻刀类别**(宽度为 1080p 下 1× 镜头的像素):
| 工具 | 宽度 | 用途 |
|---|---|---|
| 刻刀 `k` | 1.2–2 | 轮廓,把黑色形体从黑色背景中分出的白色描边 |
| V 形凿 `v` | 2–8 | 排线、头发、胡须、细腻的光 |
| U 形凿 `u` | 10–22 | 光芒、天空长扫、最初的粗坯 |
| 点刻 `stab` | 半径 3–8 | 雪、火星、土屑、木屑 |

**排线(木头里的 Doré 语法)**:线条**方向随形**(钟被水平弧线包裹,坡面沿跌落线,火与光放射,布随褶皱)。**宽度随调子**:亮 = 几乎并成一片白的宽刀痕,中间调 = 细刀痕,暗 = 不刻。远 = 密而细,近 = 疏而粗。每条线都是独立的一刀,长 30–160 px,起刀钝、收刀渐细,边缘带小木屑。绝没有连续的机器线。

**人物**:黑色剪影 + 背景上的一圈白色刀痕光环 + 只在受光边缘的掠光排线(光向量 z ≈ 0.2,因此平面区域保持黑)。**皮肤刻成白色,五官留黑**(无字小说的法则)。小尺寸时,带白刀痕的黑脸无法辨认。

**特写(手、器物)**:不要手绘。雕一个小的高度场(胶囊体、团块、板条、褶皱),打光,把灰度图送进 `woodcutFilter`(§10)。刀痕于是沿等值线走,就像雕版师顺着面颊走刀。demo 的双手、圆规和滤镜剧照就是这样做的。

**印刷**:遮罩(白 = 刻去)经过一个 WebGL2 合成器:位移并噪声阈值的边缘(刀口毛刺)、±6 % 的墨色不匀、木纹条痕、未着墨的斑点、色版带自己的斑驳和固定的 3 px 套印偏移。Block 模式显示上墨的木板:带木纹光泽的亮黑,凹槽里露出浅色木头。

## 4. 运动语言

- **角色按每两帧一步(12 fps)行走**;镜头、雪、火与光以 24 fps 运行。排线在每个身体部位的局部空间生成,因此刀痕随肢体移动而不沸腾。只有火与熔化的金属每 2 帧重刻一次,那是刻意的沸腾。
- **每个关键动作都有预备 / 动作 / 跟随**:锤子后仰 4 帧 → 击打 2 帧 → 定格 + 3 帧镜头抖动;风箱用整个身体推;投掷是握紧 → 释放 → 手停在空中。
- **雕刻揭示**:每刀有自己的起始时间与速度(0.08–0.35 s)。揭示键:`light`(亮部先、由粗到细)、`radial`(从一点:光芒、浇注)、`down`,或任意函数。
- **硬切 = 一次新的压印**:两帧套印偏移(`jolt`:[5,−3] 然后 [−2,1] px)。
- **纸张转场**(唯一的转场语法):墨辊滚过墨(一道湿亮扫过)→ 纸铺下 → 马连盘旋压磨、图像从背面浸透 → 纸张沿一个滚筒朝镜头剥开,起初沉重、末尾迅速,背面显出镜像的透印。

## 5. 镜头语言

镜头在纸面上移动;纸边保持固定。"刻刀就是镜头":刀尖,或稍后最亮的那道刀痕,永远是焦点。

| 节拍 | 镜头 |
|---|---|
| 钩子(0–3 s) | 黑色木板的极特写;跟随刻刀刻出一条白线(地平线)。 |
| 世界 | 随群山、屋顶与空塔被刻出,从 3.5× 拉回 → 1×:一条线变成一个世界。 |
| 第一印 | 锁定拍上墨 / 铺纸 / 马连 / 剥离;随后俯摇推近到空的钟室。 |
| 呼吸 | 铸钟师双手上的 4 s 近乎静止微距(缓推 1.0 → 1.13)。 |
| 蒙太奇 | 每拍硬切,不断加速(1 / 1 / 1 / .5 / .5 / .25 / .25 s),每次落点带一下 jolt。 |
| 第一色 | 推近坩埚,铜转橙,让第一种颜色落在特写里。 |
| 失败 | 急推变焦(0.2 s)到钟壁,定格 1.3 s,裂缝爬升。 |
| 静默 | 画中画:工坊门、门外的村民、铸钟师的背影、缓缓放下的锤。除了雪,什么也不动。 |
| 高潮 | 只从金属流开始(z 2.4),放射状刀痕从铸模爆发,随后升起摇出,两面被照亮。 |
| 签名 | 钟声响起时从钟壁到整个山谷 8× → 1× 的连续拉出:声音传多远,镜头就走多远。 |

## 6. 声音

- **网格优先**:60 BPM,通过一次 3:2 节拍转换(60 的三连八分 = 90 的八分)为锻炉段切到 90 BPM。`timeline.json` 是唯一事实来源。`tools/cuecheck.py` 把配乐提示对到画面事件与两处静默(demo:25 个提示,最大偏移 0 ms)。
- **配乐**:只用低音弦乐(低音提琴、大提琴、spiccato、pizz;中提琴只在钟响之后)+ 木与皮(木鼓、木鱼、框鼓)+ 大鼓 / 定音鼓 + 一面大锣 + 一件**合成的铁砧**(模态 numpy:3–5 个非谐分音 + 锤击瞬态)。**钟响之前任何地方都没有钟的音色**:村子"没有声音",因此第一声钟就是高潮。D 小调,在钟的余响中转入 D 大调。
- **拟音跟随材质**,全部合成:刀入木(短瞬态 + 由刀速调制的带通纤维撕裂声)、木屑、墨辊粘滞、纸张空气声、马连锉磨、湿剥离;铜器按尺寸(锅 = 低沉宽厚;钥匙与环 = 高而纯净);陶土刮擦与碎裂;风箱皮革 + 气;熔融气泡、浇注轰鸣、入模嘶声;钟为模态模型(hum 0.5、prime 1、tierce 1.2、quint 1.5、nominal 2、2.5、3、4,各有自己的衰减与拍频)+ 两次山谷回声。
- **两次真正的静默**:29.7–32.3 s(只有 −40 dB 的远处风声;其后第一个声音是圆规盖的*咔嗒*)与 44.3–47.3 s(**数字静默**,实测 −91 dB;其后第一个声音是钟,全片最响的一刻)。
- **J/L 剪**:火的噼啪在双手镜头之前进入;室外风声闷着延续进工坊;风把剥离声引上钟室;钟的尾音垫在结尾卡之下。
- **混音**:音乐在语音下 duck 约 8 dB(钟后 6 dB),在关键拟音下 4 dB。**拟音也 duck**(−5 dB;在与金属击打共享节拍的句子下 −9 dB)。旁白:Kokoro `am_onyx` 语速 0.88,共 4 句。

## 7. 字幕与标题

- **字幕是纸边里的活版印刷**,位于版画之下,像木刻小说里的版画题注。绝不覆盖图像。IM Fell English 42 px,墨 `#111`,经过同一套印刷着色器。墨迹 0.1 s 浮起、无滑动,0.15 s 淡出。停留 ≥ max(1.8 s, 语音 + 0.6 s)。
- **标题**:以*镜像*刻入木板(IM Fell English SC),只有第一张印张揭开时才读得正。
- **结尾卡**:一张崭新的印张:标题从黑色版面上刻出,一只小钟保留影片最后一点铜色高光,随后是 *A Woodcut Print*、Lemo-Opuscar、LemoLab × Claude Opus 5.5 与活版致谢。标题之下最后的一刀呼应影片的第一个声音。

## 8. 我们踩过的坑

- **白雪上的白雪看不见。** 白痕只在黑底上可读。加上黑色雪堆与风刻的地面;雪花在天空与深色块上可读。
- **给每个表面都排线看起来像皮毛或雨。** 用掠光让平面保持黑,只在受光边缘留 3–6 刀。
- **带白刀痕的黑脸小了读不出。** 把皮肤刻白、五官留黑,并给白色部分描一圈黑色保留线。
- **手绘的多边形手和道具像连指手套和团块。** 雕一个高度场,任何近看的东西都用 `woodcutFilter`。
- **带调性正弦摆动的短排线段会变成锯齿形人字纹**(第一口钟)。用长刀痕(14–50 × 间距)、一条平滑调子配单一的宽高光带和一条细轮廓光,以及更强的光环,让暗面仍有边缘。
- **画在主体之上的蒸汽像火焰。** 把它画在主体*背后*,只有几缕从剪影边逸出。
- **由半透明圆盘叠出来的马连透印**会留下灰环。从一层淡淡的整体浸透开始,沿向内螺旋加柔和的径向渐变点。
- **镜头间懒式共享的缓存笔触**(`X.coatFolds || []`)会让帧依赖哪个渲染 worker 先画哪个镜头。每个缓存必须在首次使用时自行构建。
- **金属礼物的击打盖住了旁白**(耳语把 "it had" 听成 "is had")。拟音也必须在语音下 duck。把闯祸的击打声像挪离中央。
- **文件体积**:细排线 + 每次压印的墨噪 + grain 6 让一部 58 s 影片在 CRF 19 下达 326 MB。以 CRF 28 和 `-tune grain` 重编码:93 MB,1:1 裁切下无可辨差异。
- `woodcutFilter` 里的结构张量在平坦区域会产生 NaN(box blur 留下微小的负和)。`sqrt` 之前先 clamp。
- `still.mjs` 在多个渲染并发时可能失败。最多重试 3 次。

```

                 print.js (WebGL2 print/block compositor), filter.js (image → woodcut)
  stage.js       print frame, camera, caption          world.js   the valley (mountains, village, tower, snow)
  chars.js rig.js views.js   founder & apprentice (parts rig, poses, expressions)   hands.js   height-field sculpts → filter
  interior.js fx.js          workshop, crucible, pour, sparks, mould; bell, bellows, gifts, villagers, sound rings
  trans.js       paper curl / peel        shots.js shots2.js   the 17 shots        film.js main.js   assembly, captions, events
  timeline.json  tempo grid + every cue   music/score.py   original score   mix.py   foley + ambience + voice + ducking + bell
  tools/         cuecheck.py subs.py final_asr.py mux.sh      test.js   ?test=char|hands|pour|village|sheetA|sheetB|filter|spark
```
1. 先写 `timeline.json`(网格 + 提示键)和提示表;交给一个音乐子代理;并行画图。
2. 在任何故事之前先建引擎和一帧风格帧。在静帧上把雕刻 + 印刷的质感调对。
3. `sh demo/build.sh` 重建一切:TTS → whisper → 配乐 → events → 提示校验 → 混音 → srt → 渲染(1404 帧 4 workers 约 45 s)→ mux(−14 LUFS、grain 6、CRF 28)→ 对影片跑 whisper → 风格帧 / 海报 / 引擎示例。
4. 用影片本身出的 1–2 fps 联络表复审两次,外加每个关键动作(剥离、砸碎、裂缝、光芒、钟的拉出、结尾卡)的原尺寸帧。

## 10. 引擎用法

`demo/engine/index.js` 是自包含的(只导入 `/core/lib.js`)。它把**任何路径或形状**画成雕出的浮雕并印制出来。你始终在两块画布上工作:一块**遮罩**(填黑 = 未刻的板;画白 = 刻去)和一块可选的**色版**(alpha = 版的浓度),然后调用打印机。

| 函数 | 作用 | 关键选项 |
|---|---|---|
| `canvas(w=1920, h=1080)` | → `[canvas, ctx]` | |
| `shape(polys, o)` | 一个雕出的实体:黑色剪影 + 白色光环 + 由 `light` 照亮的随形排线。返回 `{ draw(g, t), strokes, halo, reg, tone }`。 | `light`(`light(x,y,z)`)、`sp` 间距、`wmax`、`lo/hi` 调子范围、`dir`(`'contour'` / 角度 / `dirRing(cx,cy,sy)` / `dirRadial(cx,cy)` / 函数)、`halo` px、`white`(带黑刀痕的白色部件)、`tone(reg)→(x,y)=>0..1` 覆盖、`seg`、`gap`、`reveal:{t0,t1,key,speed}` |
| `cutAlong(path, o)` | 把路径断成手刻的刀痕(轮廓、规则线、绳索、裂缝)。 | `w`(数值或 `(u,pt)=>w`)、`kind` `'k'|'v'|'u'`、`closed`、`seg:[a,b]`、`gap:[a,b]`、`reveal:{t0,t1,speed}` |
| `hatch(region, o)` | 对任意 `Region` 的流线排线(等距、方向场与宽度场)。 | `dir(x,y)`、`tone(x,y)`、`sp`、`wmax`、`seg`、`gap`、`kind`、`reveal` |

| `rays(cx, cy, o)` | 一次雕刻之光的爆发。 | `n`、`r0`、`r1:[a,b]`、`w`、`jit`、`bend`、`a0/a1`、`reveal:{t0,t1,jit}` |
| `drawStrokes(g, strokes, {t, color})` | 在时刻 `t` 把刀痕画到遮罩上(带揭示计时的刀痕被逐刀刻出,连刀尖也是)。`color:'#000'` 重新上墨。 | |

demo 级、可复用:`demo/trans.js` 的 `curl(g, front, back, xf, r)` + `peelState(u)`(纸张剥离);`demo/hands.js` 的 `Sculpt`(胶囊 / 团块 / 板条 / 褶皱 → `shade(light)`)用于特写。

**最小示例**:一颗暖橙 `#D97757` 的四角火花,带一条光标尾迹,被刻入并保留自己的颜色。它正是 `demo/test.js` 里的 `?test=spark`;结果是 `demo/stills/engine_example.jpg`。

```js
import * as WC from './engine/index.js';
const [mask, m] = WC.canvas(), [plate, c] = WC.canvas(), P = WC.makePrinter();
const star = []; for (let i = 0; i < 8; i++) { const a = i / 8 * Math.PI * 2 - Math.PI / 2, r = i % 2 ? 70 : 260; star.push([960 + Math.cos(a) * r, 500 + Math.sin(a) * r]); }
const spark = WC.shape([star], { light: WC.light(.5, -.6, .6), sp: 9, halo: 8,
  reveal: { t0: 0, t1: .8, key: (x, y) => Math.hypot(x - 960, y - 500) / 300 } });        // carved from the centre out
const tail = WC.cutAlong([[1030, 590], [1090, 680], [1110, 770]], { w: 24, kind: 'u', seg: [300, 400], reveal: { t0: .8, t1: 1.1, speed: 900 } });

function frame(g, t) {
  m.fillStyle = '#000'; m.fillRect(0, 0, 1920, 1080);                                       // the uncut block
  c.clearRect(0, 0, 1920, 1080);
  WC.drawStrokes(m, WC.rays(960, 500, { n: 36, r0: 300, r1: [420, 640], w: 10, seed: 2, reveal: { t0: .5, t1: 1.0 } }), { t });
  spark.draw(m, t);
  WC.drawStrokes(m, tail, { t });
  WC.plate(c, [star], t > .8 ? 1 : 0);                                                      // the one colour
  g.drawImage(P.render(mask, plate, { seed: 4, plate: '#D97757' }), 0, 0);
}
```

**对照片或影片帧用滤镜**(用于重绘实拍素材):`const F = WC.woodcutFilter(video, { rect: [36, 36, 1848, 912], sp: 5, reveal: { t0, t1, mode: 'light' } }); m.fillStyle = '#000'; m.fillRect(…); WC.drawStrokes(m, F.strokes, { t });` 然后印刷。一帧 1080p 约 1,900 刀、140 ms。见 `demo/stills/filter_v1.jpg` 与 `?test=filter&img=…`。运动镜头则按每两帧(12 fps)重跑一次并使用相同 `seed`,让刀痕在图像未动的地方保持稳定。
